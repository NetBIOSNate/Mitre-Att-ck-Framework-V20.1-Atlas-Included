# AML.E0021 - lkmanka58

[MITRE ATLAS](../README.md) / [Entities](README.md)

[lkmanka58](AML.E0021%20-%20lkmanka58.md) is a GitHub handle associated with malicious modifications to the Amazon Q Developer VS Code extension in July 2025. Repository activity linked to the handle included inserting instructions intended to make the AI agent delete filesystem and cloud resources, and modifying a packaging script to incorporate the payload into production builds.[[timeline-analysis]] The unauthorized changes reached a public release, although reporting did not establish successful destructive execution. [group-profile](https://www.404media.co/hacker-plants-computer-wiping-commands-in-amazons-ai-coding-agent/) The cited reporting does not establish the operator's real-world identity or broader organizational affiliation.
