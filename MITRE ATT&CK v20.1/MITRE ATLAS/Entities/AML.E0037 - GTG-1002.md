# AML.E0037 - GTG-1002

[MITRE ATLAS](../README.md) / [Entities](README.md)

[GTG-1002](AML.E0037%20-%20GTG-1002.md) is a cyberespionage activity cluster assessed with high confidence to be Chinese state-sponsored. They have targeted organizations in the technology, finance, chemical manufacturing, and government sectors. [anthropic-report](https://www-cdn.anthropic.com/d7dd50dd1185f59be051b307150d877f2b82bd2c.pdf)

Their operations integrate [Claude Code](../Software/Tools/AML.S0022%20-%20Claude%20Code.md) into an intrusion framework that delegates tasks to AI agents while retaining human control over target selection and critical decisions. The framework was used for reconnaissance, exploitation, and intelligence collection(/studies/AML.CS0069). [anthropic-report](https://www-cdn.anthropic.com/d7dd50dd1185f59be051b307150d877f2b82bd2c.pdf)

**Entity type**  Activity Cluster

## Uses

- [AML.S0022 - Claude Code](../Software/Tools/AML.S0022%20-%20Claude%20Code.md) — [GTG-1002](AML.E0037%20-%20GTG-1002.md) integrated [Claude Code](../Software/Tools/AML.S0022%20-%20Claude%20Code.md) into an intrusion framework connected to reconnaissance, remote command execution, browser automation, code analysis, and vulnerability testing tools through MCP servers. They used it to inspect target infrastructure, develop and validate exploits, harvest and test credentials, move laterally, create persistent access, and exfiltrate data. [anthropic-report](https://www-cdn.anthropic.com/d7dd50dd1185f59be051b307150d877f2b82bd2c.pdf)
