# AML.E0003 - spiderSilk

[MITRE ATLAS](../README.md) / [Entities](README.md)

[spiderSilk](AML.E0003%20-%20spiderSilk.md) is a cybersecurity company focused on AI-assisted exposure management. They help organizations discover publicly exposed assets, identify security weaknesses, and monitor source code and credential leaks. [group-profile](https://spidersilk.com/) Their researchers have identified exposed infrastructure and sensitive data, including a misconfigured Clearview AI repository containing source code and credentials.[[clearview-research]]
