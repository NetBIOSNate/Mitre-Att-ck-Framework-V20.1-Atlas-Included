# AML.E0023 - Snyk

[MITRE ATLAS](../README.md) / [Entities](README.md)

[Snyk](AML.E0023%20-%20Snyk.md) develops security technology that helps organizations identify and fix security issues across code, dependencies, containers, and cloud infrastructure. [group-profile](https://snyk.io/about/) Their research organization, Snyk Labs, investigates security risks in AI-native applications and develops protections for AI agents.

**Entity type**  Organization
