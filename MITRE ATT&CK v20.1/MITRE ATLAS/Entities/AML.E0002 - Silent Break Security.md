# AML.E0002 - Silent Break Security

[MITRE ATLAS](../README.md) / [Entities](README.md)

[Silent Break Security](AML.E0002%20-%20Silent%20Break%20Security.md) was a Utah-based security testing firm specializing in network and application testing, red teaming, and adversary simulation. They developed offensive-security tooling and provided training in malware development, adversary simulation, and offensive machine learning. NetSPI acquired the company to expand its security-testing software and services. [group-profile](https://www.netspi.com/newsroom/press-release/netspi-acquires-silent-break-security/)

**Entity type**  Organization
