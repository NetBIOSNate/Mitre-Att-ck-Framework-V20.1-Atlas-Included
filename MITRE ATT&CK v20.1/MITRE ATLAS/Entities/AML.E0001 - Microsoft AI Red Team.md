# AML.E0001 - Microsoft AI Red Team

[MITRE ATLAS](../README.md) / [Entities](README.md)

[Microsoft AI Red Team](AML.E0001%20-%20Microsoft%20AI%20Red%20Team.md) is an interdisciplinary team established in 2018 to identify security vulnerabilities and responsible AI failures in AI systems, including harmful model behavior. They evaluate AI through adversarial testing and use their findings to inform mitigations. [group-profile](https://www.microsoft.com/en-us/security/blog/2023/08/07/microsoft-ai-red-team-building-future-of-safer-ai/) The team developed Counterfit, an open source automation tool for security testing machine learning models, [counterfit](https://www.microsoft.com/en-us/security/blog/2021/05/03/ai-security-risk-assessment-using-counterfit/) and PyRIT, an open source framework for identifying risks in generative AI systems through automated adversarial prompting, multi-turn attacks, and response scoring. [pyrit](https://www.microsoft.com/en-us/security/blog/2024/02/22/announcing-microsofts-open-automation-framework-to-red-team-generative-ai-systems/) They also publish assessment frameworks, practical guidance, training, and lessons learned to help organizations establish and improve their own AI red teaming practices. [team-homepage](https://learn.microsoft.com/en-us/security/ai-red-team/)
