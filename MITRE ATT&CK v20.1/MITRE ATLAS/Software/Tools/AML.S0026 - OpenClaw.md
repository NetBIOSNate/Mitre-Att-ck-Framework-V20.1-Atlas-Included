# AML.S0026 - OpenClaw

[MITRE ATLAS](../../README.md) / [Software](../README.md)

[OpenClaw](AML.S0026%20-%20OpenClaw.md) is an open source AI assistant that runs on user-controlled infrastructure. Its gateway connects configurable language models to messaging channels, external tools, skills, and persistent workspace context. It supports tasks such as web browsing, file operations, and command execution through conversational interfaces. [canonical-source](https://github.com/openclaw/openclaw)

**Software type**  Tool

**Software categories**  ai-agent, ai-agent-framework
