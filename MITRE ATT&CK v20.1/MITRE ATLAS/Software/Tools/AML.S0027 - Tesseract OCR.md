# AML.S0027 - Tesseract OCR

[MITRE ATLAS](../../README.md) / [Software](../README.md)

[Tesseract OCR](AML.S0027%20-%20Tesseract%20OCR.md) is an open source optical character recognition engine provided as a command line program and reusable library. It recognizes text in images across more than 100 languages and produces outputs including plain text, searchable PDF, and structured formats containing text and layout information. It supports neural-network-based recognition and a legacy character pattern recognition engine. [canonical-source](https://github.com/tesseract-ocr/tesseract)
