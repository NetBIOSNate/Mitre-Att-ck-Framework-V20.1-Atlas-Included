# AML.S0033 - L1B3RT4S

[MITRE ATLAS](../../README.md) / [Software](../README.md)

[L1B3RT4S](AML.S0033%20-%20L1B3RT4S.md) is a publicly available collection of jailbreak prompts. It organizes reusable templates by model and provider, including prompts that impersonate system instructions, introduce unrestricted personas, constrain response formats, and obscure instructions through text transformations. [canonical-source](https://github.com/elder-plinius/L1B3RT4S)

**Software type**  Tool

**Software categories**  prompt-package

## Techniques implemented

- [AML.T0054 - LLM Jailbreak](../../Tactics/08%20AML.TA0012%20-%20Privilege%20Escalation/AML.T0054%20-%20LLM%20Jailbreak/README.md) — [L1B3RT4S](AML.S0033%20-%20L1B3RT4S.md) supplies prompt templates that combine user requests with unrestricted persona roleplay, purported system instruction updates, and instructions to suppress refusals. Some templates transform instructions using stylized Unicode, character substitutions, or encoding to obscure their content while directing the model to produce otherwise restricted responses. [canonical-source](https://github.com/elder-plinius/L1B3RT4S)
