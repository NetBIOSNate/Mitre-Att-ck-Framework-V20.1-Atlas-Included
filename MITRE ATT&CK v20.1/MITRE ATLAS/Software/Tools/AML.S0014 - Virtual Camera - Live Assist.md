# AML.S0014 - Virtual Camera: Live Assist

[MITRE ATLAS](../../README.md) / [Software](../README.md)

[Virtual Camera: Live Assist](AML.S0014%20-%20Virtual%20Camera%20-%20Live%20Assist.md) is an Android application that substitutes still images, local video files, or network streams for the device's camera feed. It provides real-time controls for resizing, rotating, positioning, zooming, and flipping the replacement feed for use in other applications.
