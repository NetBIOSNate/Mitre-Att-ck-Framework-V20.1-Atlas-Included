# AML.S0024 - G0DM0D3

[MITRE ATLAS](../../README.md) / [Software](../README.md)

[G0DM0D3](AML.S0024%20-%20G0DM0D3.md) is an open source, browser-based interface for querying multiple language models and testing their safeguards. It combines model specific jailbreak prompt templates, parallel model queries, response scoring, and an input transformation engine called Parseltongue. It supports hosted model providers and local OpenAI-compatible model servers. [canonical-source](https://github.com/elder-plinius/G0DM0D3)

**Software type**  Tool

**Software categories**  program, prompt-package

## Techniques implemented

- [AML.T0054 - LLM Jailbreak](../../Tactics/08%20AML.TA0012%20-%20Privilege%20Escalation/AML.T0054%20-%20LLM%20Jailbreak/README.md) — [G0DM0D3](AML.S0024%20-%20G0DM0D3.md) combines model-specific jailbreak prompts with input transformations intended to circumvent language-model safeguards. It can submit queries to multiple models in parallel and score their responses to select a preferred result. [canonical-source](https://github.com/elder-plinius/G0DM0D3)
