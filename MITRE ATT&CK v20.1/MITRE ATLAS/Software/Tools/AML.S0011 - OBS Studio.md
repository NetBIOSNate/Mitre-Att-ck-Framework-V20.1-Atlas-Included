# AML.S0011 - OBS Studio

[MITRE ATLAS](../../README.md) / [Software](../README.md)

[OBS Studio](AML.S0011%20-%20OBS%20Studio.md) is free, open-source software for video recording and live streaming on Windows, macOS, and Linux. It captures and mixes audio and video from sources including webcams, application windows, images, and capture cards. It supports configurable scenes, transitions, audio filters, and extensions through plugins and scripts. [source-1](https://obsproject.com/)
