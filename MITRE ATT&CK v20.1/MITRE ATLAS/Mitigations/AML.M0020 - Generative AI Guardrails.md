# AML.M0020 - Generative AI Guardrails

[MITRE ATLAS](../README.md) / [Mitigations](README.md)

Guardrails are safety controls placed between users, tools, and generative AI models to evaluate prompts, retrieved context, model outputs, and agent actions before they are accepted, executed, or shown to a user. They can help block, modify, or route unwanted content such as malicious code, malicious instructions, sensitive data, unsupported claims, policy-violating responses, or unsafe tool requests.

Guardrails can be implemented using rule-based controls such as filters, allowlists, blocklists, regular expressions, schema validation, policy rules, and permission checks, or using AI-based techniques such as classifiers, LLM reviewers/judges, named entity recognition, groundedness checks, and task-adherence checks. They may be applied at multiple stages of a generative AI workflow, including input handling, prompt construction, retrieval, tool execution, model output review, and post-deployment monitoring.

Examples of specific guardrail implementations include: [owasp-llm-top10](https://owasp.org/www-project-top-10-for-large-language-model-applications)   [datadog-llm-guardrails](https://www.datadoghq.com/blog/llm-guardrails-best-practices)  [azure-ai-content-safety](https://learn.microsoft.com/en-us/azure/ai-services/content-safety/overview)  [nvidia-nemo-guardrails](https://docs.nvidia.com/nemo/guardrails/about-nemo-guardrails-library/rail-types)
- Input moderation: Screen user prompts for harmful content, prompt injection attempts, jailbreak attempts, sensitive data, off-topic requests, or inputs that exceed expected length or format.
- Output moderation: Scan model responses before sending them to users for harmful content, PII, secrets, policy violations, unsupported claims, or unsafe code using classical scanners, classifiers, or a dedicated reviewer model .
- System prompt and policy enforcement: Enforce system instructions, user roles, domain boundaries, response formats, and refusal policies before the model responds (See [Generative AI Guidelines](AML.M0021%20-%20Generative%20AI%20Guidelines.md)).
- Tool and action guardrails: Validate tool calls, tool arguments, permissions, and tool outputs before execution or before results are returned to the model. Require human approval for high-impact, irreversible, privileged, or externally visible actions (See [Human In-the-Loop for AI Agent Actions](AML.M0029%20-%20Human%20In-the-Loop%20for%20AI%20Agent%20Actions.md), [Input and Output Validation for AI Agent Components](AML.M0033%20-%20Input%20and%20Output%20Validation%20for%20AI%20Agent%20Components.md)).
- Retrieval guardrails: Filter and validate retrieved documents before they are added to model context, including checks for untrusted sources, malicious instructions, irrelevant context, or sensitive data.
- Groundedness and factuality checks: Compare model responses against trusted source material or approved knowledge bases to detect unsupported or hallucinated claims.
- Sensitive data and secret protection: Detect, redact, or block personal information, credentials, tokens, proprietary data, system prompts, and other confidential information in prompts, retrieved context, tool outputs, and model responses.
- Structured output validation: Enforce schemas, type checks, allowed values, and safe formats before model outputs are consumed by downstream systems

Guardrails should be continuously evaluated, red-teamed, and updated as adversarial techniques evolve. Guardrail decisions should be logged (See [AI Telemetry Logging and Monitoring](AML.M0024%20-%20AI%20Telemetry%20Logging%20and%20Monitoring.md)) and observed failures should be systematically incorporated into updated policies, evaluation datasets, detection logic, prompts, and [Generative AI Model Alignment](AML.M0022%20-%20Generative%20AI%20Model%20Alignment.md).

**Mitigation categories**  Technical - AI

**Lifecycle phases**  AI Model Engineering, AI Model Evaluation, Deployment, Monitoring and Maintenance

## Techniques mitigated

- [AML.T0051 - LLM Prompt Injection](../Tactics/06%20AML.TA0005%20-%20Execution/AML.T0051%20-%20LLM%20Prompt%20Injection/README.md) — Screen user inputs, retrieved content, and tool responses for instructions that attempt to override authorized behavior. Apply independent checks to resulting outputs and proposed actions, blocking or routing suspicious activity for review before it reaches users or downstream systems.
- [AML.T0053 - AI Agent Tool Invocation](../Tactics/06%20AML.TA0005%20-%20Execution/AML.T0053%20-%20AI%20Agent%20Tool%20Invocation/README.md) — Validate proposed tool selections, arguments, targets, and destinations against the authorized task and applicable policies before execution. Block disallowed operations and inspect returned content before adding it to model context.
- [AML.T0054 - LLM Jailbreak](../Tactics/08%20AML.TA0012%20-%20Privilege%20Escalation/AML.T0054%20-%20LLM%20Jailbreak/README.md) — Evaluate prompts and conversation history for attempts to circumvent behavioral restrictions, and independently check generated outputs and proposed actions against policy. Block prohibited results even when the model follows a jailbreak prompt.
- [AML.T0061 - LLM Prompt Self-Replication](../Tactics/07%20AML.TA0006%20-%20Persistence/AML.T0061%20-%20LLM%20Prompt%20Self-Replication/README.md) — Inspect generated responses for reproduction of malicious instructions from input content. Block or quarantine instruction-bearing output when it reproduces an attack payload rather than fulfilling the authorized task.
- [AML.T0062 - Discover LLM Hallucinations](../Tactics/11%20AML.TA0008%20-%20Discovery/AML.T0062%20-%20Discover%20LLM%20Hallucinations/README.md) — Check generated package names, commands, URLs, and other externally verifiable entities against authoritative sources before presenting them as valid. Suppress or flag unsupported entities to reduce opportunities for adversaries to identify exploitable hallucinations through the protected service.
- [AML.T0067 - LLM Trusted Output Components Manipulation](../Tactics/09%20AML.TA0007%20-%20Defense%20Evasion/AML.T0067%20-%20LLM%20Trusted%20Output%20Components%20Manipulation/README.md) — Validate generated citations, links, source metadata, and recommended actions against trusted source records and the authorized task before presenting responses to users. Detect and block fabricated attribution, misleading references, or instructions that use apparent authority to induce unauthorized actions.
- [AML.T0067.000 - Citations](../Tactics/09%20AML.TA0007%20-%20Defense%20Evasion/AML.T0067%20-%20LLM%20Trusted%20Output%20Components%20Manipulation/AML.T0067.000%20-%20Citations/README.md) — Verify that generated citations resolve to the referenced sources and support the associated claims. Preserve source provenance and reject fabricated, mismatched, or misleading citations.
- [AML.T0068 - LLM Prompt Obfuscation](../Tactics/09%20AML.TA0007%20-%20Defense%20Evasion/AML.T0068%20-%20LLM%20Prompt%20Obfuscation/README.md) — Inspect model-visible content for concealed instructions, including encoded text, hidden formatting, and Unicode manipulation. Normalize or decode supported representations in an isolated inspection process and evaluate both original and transformed content before processing.
- [AML.T0069 - Discover LLM System Information](../Tactics/11%20AML.TA0008%20-%20Discovery/AML.T0069%20-%20Discover%20LLM%20System%20Information/README.md) — Inspect responses for disclosure of nonpublic system instructions, internal configuration, and implementation details. Block or redact information that the requesting user is not authorized to receive.
- [AML.T0069.000 - Special Character Sets](../Tactics/11%20AML.TA0008%20-%20Discovery/AML.T0069%20-%20Discover%20LLM%20System%20Information/AML.T0069.000%20-%20Special%20Character%20Sets/README.md) — Detect and restrict responses that expose nonpublic prompt delimiters or internal formatting conventions designated as sensitive.
- [AML.T0069.001 - System Instruction Keywords](../Tactics/11%20AML.TA0008%20-%20Discovery/AML.T0069%20-%20Discover%20LLM%20System%20Information/AML.T0069.001%20-%20System%20Instruction%20Keywords/README.md) — Restrict disclosure of internal function names, routing keywords, and tool identifiers that the requesting user is not authorized to receive.
- [AML.T0069.002 - System Prompt](../Tactics/11%20AML.TA0008%20-%20Discovery/AML.T0069%20-%20Discover%20LLM%20System%20Information/AML.T0069.002%20-%20System%20Prompt/README.md) — Detect and block unauthorized disclosure of system instructions in model responses, including partial or transformed disclosures where detectable.
- [AML.T0070 - RAG Poisoning](../Tactics/07%20AML.TA0006%20-%20Persistence/AML.T0070%20-%20RAG%20Poisoning/README.md) — Screen content at ingestion and retrieval for malicious instructions, deceptive claims, and violations of source policies. Quarantine suspicious entries before indexing or exclude them from model context when retrieved.
- [AML.T0071 - False RAG Entry Injection](../Tactics/09%20AML.TA0007%20-%20Defense%20Evasion/AML.T0071%20-%20False%20RAG%20Entry%20Injection/README.md) — Check retrieved document bodies for embedded content that impersonates separate retrieval results, documents, or metadata. Preserve document structure and source metadata supplied by the retrieval system rather than accepting replacements asserted within document text.
- [AML.T0077 - LLM Response Rendering](../Tactics/15%20AML.TA0010%20-%20Exfiltration/AML.T0077%20-%20LLM%20Response%20Rendering/README.md) — Validate generated HTML, Markdown, links, and embedded resources before rendering or fetching external content. Block unauthorized destinations and references that encode sensitive information in URL paths or query parameters, including requests triggered automatically by previews. Consider blocking the URLs from responses entirely.
- [AML.T0078 - Drive-by Compromise](../Tactics/04%20AML.TA0004%20-%20Initial%20Access/AML.T0078%20-%20Drive-by%20Compromise/README.md) — Inspect web content before incorporating it into model context and validate actions induced by that content before execution. Block embedded instructions that redirect the agent into unauthorized activity. This addresses prompt-based compromise rather than exploitation of browser software vulnerabilities.
- [AML.T0080 - AI Agent Context Poisoning](../Tactics/07%20AML.TA0006%20-%20Persistence/AML.T0080%20-%20AI%20Agent%20Context%20Poisoning/README.md) — Inspect content entering or reentering an agent's context, including conversation history, summaries, and retrieved memories, for malicious instructions or unauthorized behavioral changes. Block or quarantine suspicious content before incorporation, and independently validate resulting outputs and actions across subsequent interactions.
- [AML.T0080.000 - Memory](../Tactics/07%20AML.TA0006%20-%20Persistence/AML.T0080%20-%20AI%20Agent%20Context%20Poisoning/AML.T0080.000%20-%20Memory/README.md) — Inspect proposed memory writes and retrieved memories for malicious instructions, unauthorized preferences, or changes inconsistent with the user's task. Block or quarantine suspicious content before storage or reuse. Pair content checks with [Memory Hardening](AML.M0031%20-%20Memory%20Hardening.md).
- [AML.T0080.001 - Thread](../Tactics/07%20AML.TA0006%20-%20Persistence/AML.T0080%20-%20AI%20Agent%20Context%20Poisoning/AML.T0080.001%20-%20Thread/README.md) — Evaluate retained conversation content and summaries for malicious instructions that could influence later turns. Recheck proposed actions against authorized objectives throughout the thread rather than treating previously accepted content as trusted.
- [AML.T0082 - RAG Credential Harvesting](../Tactics/10%20AML.TA0013%20-%20Credential%20Access/AML.T0082%20-%20RAG%20Credential%20Harvesting/README.md) — Detect credentials and secrets in retrieved documents before they enter model context or are returned to a user. Redact or block prohibited disclosures and inspect resulting outputs and tool arguments for credential leakage.
- [AML.T0085.002 - Conversation Context and Memory](../Tactics/13%20AML.TA0009%20-%20Collection/AML.T0085%20-%20Data%20from%20AI%20Services/AML.T0085.002%20-%20Conversation%20Context%20and%20Memory/README.md) — Inspect proposed disclosures of conversation history, summaries, and memory content against the requesting user's authorization and the current task. Block or redact sensitive information before it is returned or transferred to another component.
- [AML.T0085.003 - System Instructions](../Tactics/13%20AML.TA0009%20-%20Collection/AML.T0085%20-%20Data%20from%20AI%20Services/AML.T0085.003%20-%20System%20Instructions/README.md) — Inspect model responses for unauthorized reproduction or disclosure of protected system instructions. Block or redact matching content before response.
- [AML.T0086 - Exfiltration via AI Agent Tool Invocation](../Tactics/15%20AML.TA0010%20-%20Exfiltration/AML.T0086%20-%20Exfiltration%20via%20AI%20Agent%20Tool%20Invocation/README.md) — Inspect tool arguments, message bodies, uploaded content, and destinations before write operations or external requests. Block unauthorized transfers of sensitive information, including content embedded in URLs or other tool parameters.
- [AML.T0094 - Delay Execution of LLM Instructions](../Tactics/09%20AML.TA0007%20-%20Defense%20Evasion/AML.T0094%20-%20Delay%20Execution%20of%20LLM%20Instructions/README.md) — Preserve relevant risk context across conversation turns and revalidate actions when deferred instructions become active. Do not reset restrictions solely because a new user message or event occurs after untrusted content was introduced.
- [AML.T0099 - AI Agent Tool Data Poisoning](../Tactics/07%20AML.TA0006%20-%20Persistence/AML.T0099%20-%20AI%20Agent%20Tool%20Data%20Poisoning/README.md) — Inspect content returned from connected data sources for malicious instructions and deceptive information before adding it to model context. Apply source, relevance, and task-consistency checks, and block resulting actions that violate policy.
- [AML.T0100 - AI Agent Clickbait](../Tactics/06%20AML.TA0005%20-%20Execution/AML.T0100%20-%20AI%20Agent%20Clickbait/README.md) — Evaluate model-visible interface content and proposed computer-use actions against the authorized task. Block deceptive instructions that induce unrelated navigation, command execution, credential entry, or data transfer, and validate destinations before acting.
- [AML.T0102 - Generate Malicious Commands](../Tactics/03%20AML.TA0001%20-%20AI%20Attack%20Adaptation/AML.T0102%20-%20Generate%20Malicious%20Commands/README.md) — Inspect requests and generated commands for prohibited behavior using the task context and service policy. Block malicious command generation or release through the protected service, and independently validate commands before execution when an execution interface is present.
- [AML.T0108 - AI Agent](../Tactics/14%20AML.TA0014%20-%20Command%20and%20Control/AML.T0108%20-%20AI%20Agent/README.md) — Inspect agent inputs and proposed actions for attempts to establish unauthorized command retrieval, execution, or result transmission. Block tool operations and communications inconsistent with the agent's authorized task before execution.
- [AML.T0110.000 - Definition and Instructions](../Tactics/07%20AML.TA0006%20-%20Persistence/AML.T0110%20-%20AI%20Agent%20Tool%20Poisoning/AML.T0110.000%20-%20Definition%20and%20Instructions/README.md) — Inspect tool descriptions, schemas, examples, and operational instructions before exposing them to the model. Reject content that directs unrelated data collection, concealed actions, or manipulation of other tools, and independently validate resulting tool requests.
- [AML.T0110.002 - Runtime Response](../Tactics/07%20AML.TA0006%20-%20Persistence/AML.T0110%20-%20AI%20Agent%20Tool%20Poisoning/AML.T0110.002%20-%20Runtime%20Response/README.md) — Validate tool responses before incorporating them into model context. Detect malicious instructions, fabricated errors, embedded resources, or other content that instructs the agent, and check subsequent actions.
- [AML.T0112.000 - Local AI Agent](../Tactics/16%20AML.TA0011%20-%20Impact/AML.T0112%20-%20Machine%20Compromise/AML.T0112.000%20-%20Local%20AI%20Agent/README.md) — Mediate local agent actions involving command execution, file access, credentials, and system configuration. Validate requested operations against authorized scope and block prohibited actions before they reach the operating system or connected applications.
- [AML.T0129 - Triggers in Multimodal Inputs](../Tactics/09%20AML.TA0007%20-%20Defense%20Evasion/AML.T0129%20-%20Triggers%20in%20Multimodal%20Inputs/README.md) — Inspect supported image, audio, video, text, and metadata inputs for concealed instructions or triggers before model ingestion.
- [AML.T0130 - AI Agent Response Biasing](../Tactics/16%20AML.TA0011%20-%20Impact/AML.T0130%20-%20AI%20Agent%20Response%20Biasing/README.md) — Check retrieved instructions and generated recommendations for unauthorized preferences, source promotion, or departures from the user's criteria. Compare recommendations against approved selection criteria and supporting evidence before presenting them.
- [AML.T0137.003 - Extract Memorized Data](../Tactics/13%20AML.TA0009%20-%20Collection/AML.T0137%20-%20Training%20Data%20Information%20from%20AI%20Models/AML.T0137.003%20-%20Extract%20Memorized%20Data/README.md) — Inspect generated outputs for sensitive training content or recognizable portions of protected records before release. Use sensitive-data detection and protected reference matching where available. Block or redact detected disclosures.
- [AML.T0145 - Poison AI Agent Learning Environment](../Tactics/07%20AML.TA0006%20-%20Persistence/AML.T0145%20-%20Poison%20AI%20Agent%20Learning%20Environment/README.md) — Independently check generated outputs and proposed actions against applicable policies at runtime. Block prohibited outputs and actions to limit the impact of learning from a poisoned environment.
