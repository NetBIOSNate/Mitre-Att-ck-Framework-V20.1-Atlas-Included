# AML.T0112 - Machine Compromise

[MITRE ATLAS](../../../README.md) / [AML.TA0011 - Impact](../README.md)

Adversaries may compromise a machine by exploiting or manipulating AI-enabled components on the system. Compromising a victim system allows the adversary to execute arbitrary code, steal credentials, exfiltrate data, and continue to persist on the system.

Adversaries may target a [Local AI Agent](AML.T0112.000%20-%20Local%20AI%20Agent/README.md) which if compromised grants them the capabilities and permissions of the agent, or [AI Artifacts](AML.T0112.001%20-%20AI%20Artifacts/README.md) which can contain embedded malware.
