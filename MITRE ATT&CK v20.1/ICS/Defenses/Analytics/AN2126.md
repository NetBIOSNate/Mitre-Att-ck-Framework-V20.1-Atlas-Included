# AN2126 - Analytic 2126

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies a firmware update utility on an Industrial Control System (ICS) Linux engineering host initiating a connection to a device Internet Protocol (IP) address on its firmware update port, by a User Identifier (UID) not in the approved firmware manager UIDs, outside a scheduled maintenance window. OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0731#AN2126)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — Linux Audit SYSCALL/EXECVE/SOCKADDR records (configured audit rule): firmware updater connecting to device on firmware port, by User Identifier (UID) not in authorized firmware manager UIDs, outside maintenance window schedule · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **AuthorizedFirmwareInventory** — Cryptographic hash inventory of authorized firmware versions per device model.
- **AuthorizedFirmwareManagers** — Accounts authorized to perform firmware update operations.
- **ChangeControlWindow** — Scheduled maintenance periods during which firmware updates are authorized.
- **EngineeringWorkstationList** — IP allowlist of workstations authorized to perform firmware updates.
- **FirmwareSessionSizeThreshold** — Minimum byte count for a session to be considered a firmware transfer rather than routine configuration traffic, derived from known firmware image sizes.
- **FirmwareUpdateWindow** — Time window within which a device reboot following a large session is considered part of the same firmware update event.
- **MaintenanceWindowSchedule** — Recurring scheduled periods when firmware updates are expected to occur.
