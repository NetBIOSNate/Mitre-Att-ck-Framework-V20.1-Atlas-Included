# AN2123 - Analytic 2123

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies a process whose executable name matches a known Industrial Control System (ICS) service daemon but whose execution path falls outside the documented vendor installation directories, or whose binary hash does not match the package manager's recorded checksum for that package. OT operational-fidelity gate: Alert only when execution violates an approved signer/hash/path/parent/process or tool allowlist, or originates from an unauthorized user/tool, and is tied to an OT asset or follow-on OT-relevant action. Suppress vendor-signed software, approved engineering utilities, diagnostics, patching, backup, and documented maintenance.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0725#AN2123)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — Linux Audit SYSCALL/EXECVE/SOCKADDR records (configured audit rule): execve where exe basename matches Industrial Control Systems (ICS) daemon names but path outside vendor install paths · [DC0034 - Process Metadata](../Data%20Components/DC0034%20-%20Process%20Metadata.md)
- **linux:pkgintegrity** — rpm -V/dpkg --verify checksum mismatch for installed Industrial Control Systems (ICS) package binary · [DC0059 - File Metadata](../Data%20Components/DC0059%20-%20File%20Metadata.md)

## Mutable elements

- **AssetInventoryDeviceTypes** — Maintained inventory of expected vendor/product identity strings per enrolled device IP.
- **ICSDaemonNames** — List of expected Linux ICS service daemon process names.
- **ICSVendorProcessNames** — List of known ICS vendor executable names used as the masquerade-target watchlist.
- **VendorHashBaseline** — Cryptographic hash inventory for all legitimate versions of vendor ICS binaries, updated on every patch cycle.
- **VendorInstallPaths** — Authorized installation directories for each ICS vendor application.
