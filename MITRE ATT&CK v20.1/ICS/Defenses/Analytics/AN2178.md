# AN2178 - Analytic 2178

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies a new device appearing on the Industrial Control System (ICS) network with network behavior consistent with an ICS master station, with a Media Access Control (MAC) address not in the approved device inventory. OT operational-fidelity gate: Alert only when the master/station identity or source is not authorized for the target device and command function, or when a normally authorized master violates its configured role/sequence and produces a corroborating device/process-state change. Suppress legitimate redundancy/failover, hot-standby promotion, commissioning, and approved engineering master activity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0792#AN2178)

## Mutable elements

- **ApprovedSCADAServers** — IP/identity allowlist of legitimate master/control server systems.
- **RegisteredMasterAddresses** — Inventory of authorized station/master addresses for protocols using logical addressing distinct from IP.
- **RogueMasterTimeWindow** — Time window within which command traffic to multiple devices from a single unrecognized source is considered a coordinated rogue master event.
