# AN1863 - Analytic 1863

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies a vendor-distributed software update package that, upon execution, exhibits behavior inconsistent with the vendor's documented installation profile: spawning unexpected child processes, writing files outside the vendor's standard manifest, or loading unsigned Dynamic Link Libraries (DLLs). OT operational-fidelity gate: Alert only when execution violates an approved signer/hash/path/parent/process or tool allowlist, or originates from an unauthorized user/tool, and is tied to an OT asset or follow-on OT-relevant action. Suppress vendor-signed software, approved engineering utilities, diagnostics, patching, backup, and documented maintenance.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0730#AN1863)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **fim:hashcompare** — installed binary hash does not match vendor-published checksum for claimed version · [DC0059 - File Metadata](../Data%20Components/DC0059%20-%20File%20Metadata.md)
- **WinEventLog:Sysmon** — Microsoft-Windows-Sysmon/Operational Event ID 11 FileCreate/overwrite or Event ID 2 FileCreateTime, as applicable: Process creation and file creation correlation: vendor installer creates files outside vendor install manifest or spawns undocumented child process · [DC0059 - File Metadata](../Data%20Components/DC0059%20-%20File%20Metadata.md)

## Mutable elements

- **VendorInstallManifest** — Documented list of files/registry keys a legitimate vendor installer is expected to create.
- **VendorInstallProfile** — Documented expected process behavior for a legitimate vendor installer, established through lab testing.
