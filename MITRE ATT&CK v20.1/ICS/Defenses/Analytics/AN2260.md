# AN2260 - Analytic 2260

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies Industrial Control System (ICS) vendor engineering software initiating a device restart command from a Windows host outside a scheduled maintenance window. OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0801#AN2260)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **engineeringworkstation:ApplicationLog** — device restart command initiated outside change control window by account not in approved engineer list · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **BulkRestartTimeWindow** — Time window within which multiple device restarts are considered a coordinated event.
- **ChangeControlWindow** — Scheduled maintenance periods during which restarts are authorized.
- **EngineeringWorkstationList** — IP allowlist of workstations authorized to issue device restart commands.
