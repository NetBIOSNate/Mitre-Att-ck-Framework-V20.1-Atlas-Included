# AN1855 - Analytic 1855

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies an unsigned or unexpected process calling Windows hooking Application Programming Interfaces (APIs) (SetWindowsHookEx, SetWinEventHook) targeting an Industrial Control System (ICS) engineering or Human-Machine Interface (HMI) process, immediately followed by that target process loading a Dynamic Link Library (DLL) not present in the vendor's signed module baseline. Confirmed in the wild: Stuxnet replaced Siemens' s7otbxdx.dll on engineering workstations to intercept and falsify Programmable Logic Controller (PLC) read/write calls between WinCC/STEP7 and the controller. OT operational-fidelity gate: Alert only when execution violates an approved signer/hash/path/parent/process or tool allowlist, or originates from an unauthorized user/tool, and is tied to an OT asset or follow-on OT-relevant action. Suppress vendor-signed software, approved engineering utilities, diagnostics, patching, backup, and documented maintenance.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0722#AN1855)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **edr:ProcessIntegrity** — Process integrity/hash mismatch detected on Industrial Control Systems (ICS) communication process post-hook-install event · [DC0034 - Process Metadata](../Data%20Components/DC0034%20-%20Process%20Metadata.md)
- **WinEventLog:Sysmon** — EventCode=7 of Industrial Control Systems (ICS) vendor communication Dynamic Link Library (DLL) with hash not in signed baseline · [DC0016 - Module Load](../Data%20Components/DC0016%20-%20Module%20Load.md)
- **WinEventLog:Sysmon** — EventCode=10 where SourceImage outside the approved ICS vendor/process baseline accesses TargetImage associated with an ICS application or service · [DC0035 - Process Access](../Data%20Components/DC0035%20-%20Process%20Access.md)

## Mutable elements

- **ApprovedICSVendorProcessList** — Allowlist of processes permitted to install window/event hooks on ICS engineering and HMI hosts.
- **ICSServiceBinaryList** — List of binary paths for ICS gateway, OPC, and historian services on Linux assets that should never be launched with LD_PRELOAD set.
- **VendorPackageManifest** — Package manager manifest cross-reference confirming a shared library belongs to an installed, signed package.
- **VendorSignedDLLHashBaseline** — Cryptographic hash inventory of all vendor-signed ICS communication DLLs, refreshed on every legitimate vendor patch cycle.
