# AN2110 - Analytic 2110

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies a process setting LD_PRELOAD before launching an Industrial Control System (ICS) service binary, or writing to /etc/ld.so.preload, where the injected library path is not part of the vendor's package manifest. OT operational-fidelity gate: Alert only when execution violates an approved signer/hash/path/parent/process or tool allowlist, or originates from an unauthorized user/tool, and is tied to an OT asset or follow-on OT-relevant action. Suppress vendor-signed software, approved engineering utilities, diagnostics, patching, backup, and documented maintenance.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0722#AN2110)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL+PATH** — Linux Audit SYSCALL+PATH records: write to /etc/ld.so.preload by User Identifier (UID) outside authorized admin list · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)
- **auditd:SYSCALL** — Linux Audit SYSCALL/EXECVE/SOCKADDR records (configured audit rule): execve with env containing LD_PRELOAD where exe matches Industrial Control Systems (ICS) service binary list and preload library not in vendor package manifest · [DC0034 - Process Metadata](../Data%20Components/DC0034%20-%20Process%20Metadata.md)

## Mutable elements

- **ApprovedICSVendorProcessList** — Allowlist of processes permitted to install window/event hooks on ICS engineering and HMI hosts.
- **ICSServiceBinaryList** — List of binary paths for ICS gateway, OPC, and historian services on Linux assets that should never be launched with LD_PRELOAD set.
- **VendorPackageManifest** — Package manager manifest cross-reference confirming a shared library belongs to an installed, signed package.
- **VendorSignedDLLHashBaseline** — Cryptographic hash inventory of all vendor-signed ICS communication DLLs, refreshed on every legitimate vendor patch cycle.
