# AN2128 - Analytic 2128

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies a scripting interpreter process iterating through Industrial Control System (ICS) data sources and writing output to a local file or piping to a network socket, by a User Identifier (UID) not associated with documented automation scripts. OT operational-fidelity gate: Do not alert on novelty, scan/read volume, or enumeration alone. Alert when the source role is not authorized for discovery/polling and the target scope, address/tag range, protocol, or rate deviates from the established operational baseline. Suppress normal SCADA/HMI/historian polling, commissioning, asset inventory, backup, diagnostics, and approved engineering activity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0734#AN2128)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — Linux Audit SYSCALL/EXECVE/SOCKADDR records (configured audit rule): execve of scripting interpreter making sequential Industrial Control Systems (ICS) protocol reads with output to file, by User Identifier (UID) not in authorized scripting UIDs · [DC0029 - Script Execution](../Data%20Components/DC0029%20-%20Script%20Execution.md)

## Mutable elements

- **ApprovedHistorianClients** — Allowlist of applications/accounts authorized to perform bulk historian queries.
- **ApprovedSCADAServers** — IP allowlist of legitimate SCADA/historian servers.
- **AutoCollectionTimeWindow** — Time window within which sequential reads across multiple devices are considered part of a single automated collection event.
- **BulkQueryThreshold** — Record count threshold above which a historian query is considered a bulk export rather than a routine query.
