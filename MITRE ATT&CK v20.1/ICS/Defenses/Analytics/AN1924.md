# AN1924 - Analytic 1924

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies Industrial Control System (ICS) master-role command traffic originating from a source not in the approved control server inventory, directed at multiple field devices in a pattern consistent with control-server behavior. Documented in Maroochy Water Services (falsified PDS/station addresses to impersonate the master) and the 2017 Dallas Siren incident (rogue radio transmitter to 156 sirens). OT operational-fidelity gate: Alert only when the master/station identity or source is not authorized for the target device and command function, or when a normally authorized master violates its configured role/sequence and produces a corroborating device/process-state change. Suppress legitimate redundancy/failover, hot-standby promotion, commissioning, and approved engineering master activity.

## Log sources and channels

- **assetinventory:MasterAddress** — command traffic uses master/station address not in registered master addresses · [DC0110 - Asset Inventory](../Data%20Components/DC0110%20-%20Asset%20Inventory.md)
- **operationaldb:AlarmEvent** — device receives commands from two distinct master identities within a short window · [DC0108 - Device Alarm](../Data%20Components/DC0108%20-%20Device%20Alarm.md)
- **NSM:Content** — write/control command traffic from source not in approved Supervisory Control and Data Acquisition (SCADA) servers directed at multiple distinct device IPs within rogue master time window · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **ApprovedSCADAServers** — IP/identity allowlist of legitimate master/control server systems.
- **RegisteredMasterAddresses** — Inventory of authorized station/master addresses for protocols using logical addressing distinct from IP.
- **RogueMasterTimeWindow** — Time window within which command traffic to multiple devices from a single unrecognized source is considered a coordinated rogue master event.
