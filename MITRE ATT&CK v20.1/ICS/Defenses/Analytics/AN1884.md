# AN1884 - Analytic 1884

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies an Industrial Control System (ICS) protocol session consistent with a program download to a field device from a source not in the approved engineering workstation list, correlated with a device mode-change alarm transitioning to PROGRAM/STOP immediately preceding the transfer. Documented in Stuxnet (code/data block download to alter programmable logic controller behavior) and Triton (TriStation protocol program download to the Triconex Safety Instrumented System). OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

## Log sources and channels

- **assetinventory:ProgramHash** — post-transfer program hash does not match last authorized program baseline · [DC0110 - Asset Inventory](../Data%20Components/DC0110%20-%20Asset%20Inventory.md)
- **operationaldb:AlarmEvent** — device_ip transitions to PROGRAM/STOP mode without operator_ack and without corresponding open change ticket reference · [DC0108 - Device Alarm](../Data%20Components/DC0108%20-%20Device%20Alarm.md)
- **NSM:Content** — S7comm Download Block / Common Industrial Protocol (CIP) Download Program / Distributed Network Protocol (DNP3) program file transfer to device_ip from source not in engineering workstation list within mode change to download window of mode-change event · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **engineeringworkstation:ApplicationLog** — program download session logged without corresponding change ticket reference · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **ChangeControlWindow** — Scheduled maintenance periods during which program downloads are authorized.
- **EngineeringWorkstationList** — IP allowlist of workstations authorized to perform program downloads.
- **ModeChangeToDownloadWindow** — Time window within which a mode-change event and subsequent download session are considered the same engineering action.
- **ProgramDownloadSizeThreshold** — Minimum byte count distinguishing a full program download from routine traffic.
