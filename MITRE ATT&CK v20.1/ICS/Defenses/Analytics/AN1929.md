# AN1929 - Analytic 1929

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies a loss of communication with serially-connected field devices correlated with a configuration change event on the serial-to-Ethernet gateway. Documented in the 2015 Ukraine attack, where Sandworm used malicious firmware to render serial-to-Ethernet converters inoperable. OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0797#AN1929)
