# AN2268 - Analytic 2268

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies an Industrial Control System (ICS) Windows service (Open Platform Communications (OPC) server, historian, Supervisory Control and Data Acquisition (SCADA) polling service) consuming abnormal Central Processing Unit (CPU)/memory resources and becoming unresponsive following receipt of a high volume of connections to its application port, correlated with watchdog timeout or service crash events. OT operational-fidelity gate: Alert only when a device-specific traffic/resource threshold is exceeded and the same window shows service degradation, failed polling, device alarm/restart, resource exhaustion, or malformed/out-of-spec protocol behavior. Suppress planned load tests, maintenance, network convergence/failover, and known equipment faults after operator confirmation.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0723#AN2268)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — Microsoft-Windows-Sysmon/Operational Event ID 3 NetworkConnect: inbound connection rate to Industrial Control Systems (ICS) application port exceeds threshold per minute from unexpected sources · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **WinEventLog:System** — EventCode=7034, 7036 for Industrial Control Systems (ICS) service within detection window of connection flood · [DC0041 - Service Metadata](../Data%20Components/DC0041%20-%20Service%20Metadata.md)

## Mutable elements

- **CPUUtilizationThreshold** — Network device CPU utilization percentage above which sustained load suggests packet-processing strain from flood traffic.
- **DoSConnectionThreshold** — Connections-per-minute threshold exceeding normal SCADA polling cadence, derived from the device's actual configured scan rate.
- **DoSDetectionWindow** — Time window over which flood rate and subsequent device silence are correlated, typically 1-5 minutes.
- **ExpectedPollInterval** — Device-specific supervisory poll interval used to determine what counts as a process historian gap.
- **InterfaceErrorThreshold** — Deviation from baseline interface error/discard rate, tuned against historical interface health data.
- **MalformedPacketThreshold** — Number of malformed/out-of-spec PDUs within the detection window constituting a flood, set above the device's documented error-tolerance baseline.
