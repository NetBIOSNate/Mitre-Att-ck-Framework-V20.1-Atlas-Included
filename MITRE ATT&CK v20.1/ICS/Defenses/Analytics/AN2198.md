# AN2198 - Analytic 2198

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies ACL modifications on Industrial Control System (ICS) network devices specifically blocking ICS reporting message ports while allowing command ports to remain open. OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.
