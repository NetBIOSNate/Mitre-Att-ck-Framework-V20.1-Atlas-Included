# AN2235 - Analytic 2235

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies Hypertext Transfer Protocol (HTTP) requests to an embedded device's management web interface containing exploit-pattern content (oversized parameters, directory traversal sequences) from a source not in the approved engineering workstation list. OT operational-fidelity gate: Alert only when execution violates an approved signer/hash/path/parent/process or tool allowlist, or originates from an unauthorized user/tool, and is tied to an OT asset or follow-on OT-relevant action. Suppress vendor-signed software, approved engineering utilities, diagnostics, patching, backup, and documented maintenance.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0740#AN2235)

**Platforms**  [Embedded](../../Platforms/Embedded.md)

## Log sources and channels

- **NSM:Content** — Hypertext Transfer Protocol (HTTP) request to device management web interface with exploit-pattern payload from source not in engineering workstation list · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **ApprovedClientCIDR** — IP ranges from which legitimate access to the ICS web interface is expected.
- **ExploitPatternSignatures** — Regex/signature set for known exploit payload patterns and published CVE-specific payload signatures for in-use ICS web products.
- **ExploitToShellWindow** — Time window within which a child shell process spawned from the web server is considered connected to a preceding exploit-pattern request.
