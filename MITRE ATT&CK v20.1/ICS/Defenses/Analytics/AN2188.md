# AN2188 - Analytic 2188

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies a network-device ACL, filter, or rate-limit policy change that suppresses or blocks ICS alarm-notification traffic outside the approved network-change baseline. OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0728#AN2188)

**Platforms**  [Network Devices](../../Platforms/Network%20Devices.md)

## Log sources and channels

- **networkdevice:syslog** — Access Control List (ACL)/policy change affecting alarm notification traffic ports without corresponding change ticket · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **AlarmConfigAddressRange** — Protocol register/address ranges corresponding to alarm threshold and configuration values per device type.
- **AlarmConfigPaths** — File system paths for alarm configuration files/databases on Windows alarm servers.
- **ApprovedWriteSources** — IP allowlist of sources authorized to write to ICS devices, including alarm configuration.
- **HMIAlarmParentAllowlist** — Allowlist of recognized HMI/alarm management application processes authorized to modify alarm configuration.
- **SuppressGracePeriod** — Time window within which a legitimate operator acknowledgment is expected following an alarm status change, typically 10-30 seconds.
