# AN1890 - Analytic 1890

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies a process performing rapid, bulk deletion or overwrite of files across multiple Industrial Control System (ICS)-relevant directories within a short time window, by a process not associated with documented data retention management, correlated with a system crash shortly after. Documented in CaddyWiper, deployed via GPO alongside Industroyer2. OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0758#AN1890)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **gpo:deployment** — destructive payload deployed via Group Policy Object (GPO) to multiple hosts simultaneously · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **WinEventLog:Sysmon** — EventCode=23 across multiple Industrial Control Systems (ICS) data directories exceeding bulk deletion threshold within data destruction time window, by process not in authorized data management tools · [DC0040 - File Deletion](../Data%20Components/DC0040%20-%20File%20Deletion.md)
- **WinEventLog:System** — System crash or unexpected halt occurring within wiper crash window of the bulk deletion event · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **AuthorizedDataManagementTools** — Allowlist of backup/archival/retention management tools authorized to perform bulk file operations.
- **BulkDeletionThreshold** — File count threshold across monitored directories that distinguishes bulk destruction from routine cleanup.
- **DataDestructionTimeWindow** — Time window over which bulk deletion activity is measured.
- **EngineeringWorkstationList** — IP allowlist of workstations authorized to issue memory erase commands.
- **WiperCrashWindow** — Time window after bulk deletion within which a system crash is considered part of the same destructive event.
