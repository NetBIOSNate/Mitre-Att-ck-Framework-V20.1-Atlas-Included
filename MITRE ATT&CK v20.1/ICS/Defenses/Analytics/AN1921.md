# AN1921 - Analytic 1921

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies iptables/nftables rules on Industrial Control System (ICS) Linux gateways that selectively drop ICS reporting message traffic based on content while allowing command traffic to pass. OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0789#AN1921)
