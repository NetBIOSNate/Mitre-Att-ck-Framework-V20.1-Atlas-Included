# AN2170 - Analytic 2170

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies vendor-specific firmware-update protocol traffic to ICS device IP addresses from a source not in the approved engineering-workstation or firmware-management baseline. OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0731#AN2170)

**Platforms**  [Network Devices](../../Platforms/Network%20Devices.md)

## Log sources and channels

- **netflow:ipfix** — IPFIX/NetFlow flow record (src/dst IP, src/dst port, protocol, packets/bytes/time): Trivial File Transfer Protocol (TFTP) session to device Internet Protocol (IP) address from source not in engineering workstation list followed by device reboot syslog within firmware transfer window · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **AuthorizedFirmwareInventory** — Cryptographic hash inventory of authorized firmware versions per device model.
- **AuthorizedFirmwareManagers** — Accounts authorized to perform firmware update operations.
- **ChangeControlWindow** — Scheduled maintenance periods during which firmware updates are authorized.
- **EngineeringWorkstationList** — IP allowlist of workstations authorized to perform firmware updates.
- **FirmwareSessionSizeThreshold** — Minimum byte count for a session to be considered a firmware transfer rather than routine configuration traffic, derived from known firmware image sizes.
- **FirmwareUpdateWindow** — Time window within which a device reboot following a large session is considered part of the same firmware update event.
- **MaintenanceWindowSchedule** — Recurring scheduled periods when firmware updates are expected to occur.
