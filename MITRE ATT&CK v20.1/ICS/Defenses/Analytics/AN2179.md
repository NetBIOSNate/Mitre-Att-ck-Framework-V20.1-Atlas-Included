# AN2179 - Analytic 2179

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies transfer protocol traffic such as the Trivial File Transfer Protocol (TFTP) or vendor-specific protocol traffic initiating firmware-update mode on Industrial Control System (ICS) device Internet Protocol (IP) addresses from sources not in the approved engineering workstation list. OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

## Log sources and channels

## Mutable elements

- **AlarmSilenceGracePeriod** — Time window within which alarm telemetry going silent following a mode-change message is considered directly connected.
- **AuthorizedFirmwareManagers** — Accounts authorized to perform firmware update mode activation.
- **ChangeControlWindow** — Scheduled maintenance periods during which firmware update mode activation is authorized.
- **EngineeringWorkstationList** — IP allowlist of workstations authorized to activate firmware update mode.
- **MaintenanceWindowSchedule** — Recurring scheduled periods when firmware update activities are expected.
