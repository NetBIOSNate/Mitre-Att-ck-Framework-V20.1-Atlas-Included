# AN2270 - Analytic 2270

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies a host process making sequential Industrial Control System (ICS) protocol reads with output piped to a local staging file, from a process not associated with a recognized Human-Machine Interface (HMI) or historian tool. OT operational-fidelity gate: Do not alert on novelty, scan/read volume, or enumeration alone. Alert when the source role is not authorized for discovery/polling and the target scope, address/tag range, protocol, or rate deviates from the established operational baseline. Suppress normal SCADA/HMI/historian polling, commissioning, asset inventory, backup, diagnostics, and approved engineering activity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0734#AN2270)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=11 where an unrecognized process creates a staging/output file after bulk ICS data access activity · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)

## Mutable elements

- **ApprovedHistorianClients** — Allowlist of applications/accounts authorized to perform bulk historian queries.
- **ApprovedSCADAServers** — IP allowlist of legitimate SCADA/historian servers.
- **AutoCollectionTimeWindow** — Time window within which sequential reads across multiple devices are considered part of a single automated collection event.
- **BulkQueryThreshold** — Record count threshold above which a historian query is considered a bulk export rather than a routine query.
