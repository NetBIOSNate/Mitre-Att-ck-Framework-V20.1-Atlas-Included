# AN2183 - Analytic 2183

[ICS](../../README.md) / [Analytics](README.md)

Use an OT-capable protocol decoder to monitor SNMP requests/responses and identify access to vendor-internal or undocumented OIDs from sources outside the approved NMS inventory, especially SET operations or unusual walks against control-network infrastructure. This is network-protocol observation, not OS API execution; require decoded SNMP transaction content or equivalent packet inspection.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0753#AN2183)
