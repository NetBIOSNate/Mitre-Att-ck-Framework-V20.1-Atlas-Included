# AN2145 - Analytic 2145

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies a Linux process invoking Industrial Control System (ICS) vendor write Application Programming Interfaces (APIs) or Open Platform Communications (OPC) Unified Architecture (UA) write calls to setpoint tags on field devices, from a User Identifier (UID) not associated with the authorized control application, with values exceeding the safe operating range. OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0776#AN2145)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **NSM:Content** — decoded ICS protocol write/setpoint operation to a control/output address from a client identity or source not in the approved control-application baseline · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **ApprovedWriteSources** — IP allowlist of sources authorized to write to parameter/setpoint registers.
- **BaselineValueRange** — Documented safe operating range for each monitored parameter.
- **ParameterDriftThreshold** — Percentage deviation from rolling baseline considered significant drift.
- **SetpointAddressRange** — Register/address ranges corresponding to parameter and setpoint values for the device type.
- **TimeWindow** — Time window over which post-write drift is measured.
