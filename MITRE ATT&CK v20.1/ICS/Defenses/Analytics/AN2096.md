# AN2096 - Analytic 2096

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies an embedded OT/IoT device sending DNS to a resolver not defined for its role, tunneling-like native DNS, or direct HTTPS/TLS to an unapproved DoH endpoint. Because many embedded devices have fixed communications, require deviation from the device-specific resolver/destination profile and corroborating query or destination evidence.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0934#AN2096)

**Platforms**  [Embedded](../../Platforms/Embedded.md)

## Log sources and channels

- **NSM:TLS/HTTP** — SNI/HTTP host or resolver endpoint identification when observable · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **NSM:DNS** — Device DNS query/response content · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **NSM:Flow** — Device-to-resolver/DoH destination flow · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **DeviceResolverProfile** — Expected DNS resolver(s) per device/model/site
- **ApprovedVendorDomains** — Vendor/cloud domains required for operation
- **ApprovedDoHProviders** — Permitted encrypted DNS, normally empty for fixed-function devices
- **NoExternalConnectivityRoleList** — Devices that should not resolve externally
- **QueryPattern** — Tunneling characteristics used as corroboration, not sole trigger
