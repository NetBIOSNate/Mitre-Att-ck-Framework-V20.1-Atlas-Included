# AN2129 - Analytic 2129

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies an Industrial Control System (ICS) Linux service process initiating an outbound connection on a commonly-used port to a destination not in the approved vendor domain list. OT operational-fidelity gate: Alert only when the asset's documented role does not permit the connection and the destination/proxy/service is outside the approved communications profile, with process/service identity used as corroboration where available. Suppress approved vendor support, update repositories, remote operations, failover paths, and documented temporary connectivity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0736#AN2129)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — Linux Audit SYSCALL/EXECVE/SOCKADDR records (configured audit rule): connect() syscall on port (e.g., 80, 443, 8080, etc.) to destination not in approved vendor domains, from Industrial Control Systems (ICS) service process · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **ApprovedVendorDomains** — Allowlist of legitimate vendor domains for software updates, licensing, or remote support.
- **NoExternalConnectivityRoleList** — Inventory of ICS hosts whose documented function never requires outbound internet connectivity.
