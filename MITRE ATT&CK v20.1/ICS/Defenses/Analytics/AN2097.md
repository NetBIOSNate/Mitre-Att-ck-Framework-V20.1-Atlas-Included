# AN2097 - Analytic 2097

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies ICS clients sending DNS directly to unauthorized resolvers, native DNS with tunneling characteristics, or HTTPS/TLS connections to known/identified DoH infrastructure that bypass the site resolver/proxy architecture. Alert on policy violation plus content/flow corroboration; do not alert solely on high DNS volume.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0934#AN2097)

**Platforms**  [Network Devices](../../Platforms/Network%20Devices.md)

## Log sources and channels

- **NetworkDevice:IDS** — DoH/DoT identification, SNI/HTTP host when observable, DNS tunneling signatures · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **NSM:DNS** — DNS query/response metadata and content · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **NSM:Flow** — Client-to-resolver or client-to-DoH endpoint flow · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **ApprovedResolvers** — Authorized recursive resolvers/forwarders
- **ApprovedDoHProviders** — Permitted encrypted DNS services
- **ApprovedCommunicationMatrix** — Which ICS zones/assets may resolve externally
- **QueryPattern** — Encoded/long labels, unusual types, entropy and periodicity as corroboration
- **KnownDoHEndpoints** — Resolver/API destinations used to identify bypass
