# AN2257 - Analytic 2257

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies an SSH authentication/session to an ICS Linux asset from a VPN-assigned or remote-access source outside the approved remote-administration baseline. OT operational-fidelity gate: Alert only when the account/device/session violates the approved identity + source host/jump path/zone policy and is corroborated by access to a protected OT asset, execution, configuration change, or another security-relevant follow-on event. Suppress approved shift activity, vendor support, break-glass use, commissioning, and documented remote-access windows.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0803#AN2257)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **syslog:auth** — Secure Shell (SSH) session from Virtual Private Network (VPN)-assigned Internet Protocol (IP) address correlated with remote access authentication anomaly · [DC0088 - Logon Session Metadata](../Data%20Components/DC0088%20-%20Logon%20Session%20Metadata.md)

## Mutable elements

- **ApprovedRemoteAccessOrigins** — Documented geographic regions/ASNs from which legitimate ICS-role remote access is expected.
- **ExpectedSessionPattern** — Baseline of normal session timing/duration for each ICS-role account's remote access usage.
- **RemoteAccessToICSWindow** — Time window correlating VPN authentication with subsequent ICS-zone network access.
