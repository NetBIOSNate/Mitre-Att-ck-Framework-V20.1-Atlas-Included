# AN2231 - Analytic 2231

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies an ICS device presenting protocol identity attributes (for example vendor, product, model, or capability identifiers) that conflict with the identity and capabilities recorded for that network address/device in the authorized asset inventory. OT operational-fidelity gate: Alert only when execution violates an approved signer/hash/path/parent/process or tool allowlist, or originates from an unauthorized user/tool, and is tied to an OT asset or follow-on OT-relevant action. Suppress vendor-signed software, approved engineering utilities, diagnostics, patching, backup, and documented maintenance.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0725#AN2231)

**Platforms**  [Embedded](../../Platforms/Embedded.md)

## Log sources and channels

- **NSM:Content** — GetIdentity/Identity Object response vendor/product string does not match enrolled asset inventory for device_ip · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **AssetInventoryDeviceTypes** — Maintained inventory of expected vendor/product identity strings per enrolled device IP.
- **ICSDaemonNames** — List of expected Linux ICS service daemon process names.
- **ICSVendorProcessNames** — List of known ICS vendor executable names used as the masquerade-target watchlist.
- **VendorHashBaseline** — Cryptographic hash inventory for all legitimate versions of vendor ICS binaries, updated on every patch cycle.
- **VendorInstallPaths** — Authorized installation directories for each ICS vendor application.
