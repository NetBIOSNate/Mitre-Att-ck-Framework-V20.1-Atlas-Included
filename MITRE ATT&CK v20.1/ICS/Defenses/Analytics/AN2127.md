# AN2127 - Analytic 2127

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies a mount event for removable storage media on an Industrial Control System (ICS) Linux asset, followed by execution of a binary from the mounted path within a short window. OT operational-fidelity gate: Alert only when the account/device/session violates the approved identity + source host/jump path/zone policy and is corroborated by access to a protected OT asset, execution, configuration change, or another security-relevant follow-on event. Suppress approved shift activity, vendor support, break-glass use, commissioning, and documented remote-access windows.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0733#AN2127)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — Linux Audit SYSCALL/EXECVE/SOCKADDR records (configured audit rule): syscall=execve; mount/udisksctl invoked to mount a removable block device on an ICS asset outside the approved removable-media workflow · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **auditd:SYSCALL** — Linux Audit SYSCALL/EXECVE/SOCKADDR records (configured audit rule): execve with path under /media/ or /mnt/ removable mount point within Universial Serial Bus (USB) execution window of mount event · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **AuthorizedUSBAllowlist** — Hardware ID inventory of USB storage devices authorized for use on ICS engineering and HMI workstations.
- **EngineeringWorkstationList** — IP allowlist of workstations authorized to perform file transfers to field devices.
- **USBExecutionWindow** — Time window after device insertion/mount within which process execution is considered directly connected to the insertion event.
