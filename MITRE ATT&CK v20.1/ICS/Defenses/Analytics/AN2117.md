# AN2117 - Analytic 2117

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies a write to alarm threshold configuration files on a Linux-based alarm server by a User Identifier (UID) that is not the alarm management service. OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0777#AN2117)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Mutable elements

- **AlarmThresholdAddressRange** — Register addresses specifically corresponding to alarm threshold/deadband configuration.
- **ApprovedWriteSources** — IP allowlist of sources authorized to modify alarm configuration.
- **SafeAlarmThresholdRange** — Documented safe range for alarm thresholds per parameter.
