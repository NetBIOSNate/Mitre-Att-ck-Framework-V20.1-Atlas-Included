# AN2122 - Analytic 2122

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies Secure Shell (SSH) or local authentication by an Industrial Control System (ICS) service or operator account from a source Internet Protocol (IP) address outside the approved administrative Classless Inter-Domain Routing (CIDR) subnet, or a sudo/su escalation event by an ICS service account that does not normally require interactive privilege escalation, correlated with subsequent execution of ICS engineering tools. OT operational-fidelity gate: Alert only when the account/device/session violates the approved identity + source host/jump path/zone policy and is corroborated by access to a protected OT asset, execution, configuration change, or another security-relevant follow-on event. Suppress approved shift activity, vendor support, break-glass use, commissioning, and documented remote-access windows.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0724#AN2122)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — Linux Audit SYSCALL/EXECVE/SOCKADDR records (configured audit rule): sudo/su success for Industrial Control Systems (ICS) service account UID without the expected automated invocation pattern · [DC0067 - Logon Session Creation](../Data%20Components/DC0067%20-%20Logon%20Session%20Creation.md)
- **syslog:auth** — sshd Accepted publickey/password for Industrial Control Systems (ICS)-role account from source not in approved admin CIDR · [DC0002 - User Account Authentication](../Data%20Components/DC0002%20-%20User%20Account%20Authentication.md)

## Mutable elements

- **ApprovedAdminCIDR** — IP ranges from which SSH administrative access to ICS Linux assets is authorized.
- **ApprovedHostList** — Inventory of workstations/jump hosts from which ICS-role accounts are authorized to authenticate.
- **ApprovedNMSCIDR** — IP ranges from which network device administrative access is authorized.
- **AuthToDeviceWindow** — Time window after anomalous logon within which device-subnet connection is considered correlated, typically 5-15 minutes.
- **ICSRoleAccountPatterns** — Naming convention or group-membership pattern identifying accounts with engineering, operator, or ICS service roles.
- **OfficeHoursWindow** — Defined normal working hours for interactive ICS engineering activity, widened for 24/7 shift-based operations.
