# AN2107 - Analytic 2107

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies a write to alarm configuration files on a Linux-based Supervisory Control and Data Acquisition (SCADA)/alarm server by a User Identifier (UID) that is not the alarm management service, or the alarm management service process receiving Application Programming Interface (API) calls that suppress alarm classes without a corresponding operator session. OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0728#AN2107)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **alarmserver:ApplicationLog** — alarm suppression Application Programming Interface (API) call logged without operator session identifier (ID) · [DC0108 - Device Alarm](../Data%20Components/DC0108%20-%20Device%20Alarm.md)
- **auditd:SYSCALL+PATH** — Linux Audit SYSCALL+PATH records: write to Industrial Control Systems (ICS) alarm configuration file by User Identifier (UID) not in authorized alarm admin UIDs · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)

## Mutable elements

- **AlarmConfigAddressRange** — Protocol register/address ranges corresponding to alarm threshold and configuration values per device type.
- **AlarmConfigPaths** — File system paths for alarm configuration files/databases on Windows alarm servers.
- **ApprovedWriteSources** — IP allowlist of sources authorized to write to ICS devices, including alarm configuration.
- **HMIAlarmParentAllowlist** — Allowlist of recognized HMI/alarm management application processes authorized to modify alarm configuration.
- **SuppressGracePeriod** — Time window within which a legitimate operator acknowledgment is expected following an alarm status change, typically 10-30 seconds.
