# AN2121 - Analytic 2121

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies an Industrial Control System (ICS) Linux service process (historian daemon, Open Platform Communications (OPC) gateway) being killed or crashing following a sustained high-rate inbound connection pattern recorded by network monitoring, correlated with daemon log entries indicating connection limit exhaustion or out-of-memory conditions. OT operational-fidelity gate: Alert only when a device-specific traffic/resource threshold is exceeded and the same window shows service degradation, failed polling, device alarm/restart, resource exhaustion, or malformed/out-of-spec protocol behavior. Suppress planned load tests, maintenance, network convergence/failover, and known equipment faults after operator confirmation.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0723#AN2121)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — Linux Audit SYSCALL/EXECVE/SOCKADDR records (configured audit rule): Industrial Control Systems (ICS) service process terminated (SIGKILL/SIGSEGV) following high-rate inbound connections recorded in netflow within the same window · [DC0033 - Process Termination](../Data%20Components/DC0033%20-%20Process%20Termination.md)
- **syslog:daemon** — Industrial Control Systems (ICS) daemon log entry indicating connection limit exceeded, out of memory, or watchdog timeout · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **CPUUtilizationThreshold** — Network device CPU utilization percentage above which sustained load suggests packet-processing strain from flood traffic.
- **DoSConnectionThreshold** — Connections-per-minute threshold exceeding normal SCADA polling cadence, derived from the device's actual configured scan rate.
- **DoSDetectionWindow** — Time window over which flood rate and subsequent device silence are correlated, typically 1-5 minutes.
- **ExpectedPollInterval** — Device-specific supervisory poll interval used to determine what counts as a process historian gap.
- **InterfaceErrorThreshold** — Deviation from baseline interface error/discard rate, tuned against historical interface health data.
- **MalformedPacketThreshold** — Number of malformed/out-of-spec PDUs within the detection window constituting a flood, set above the device's documented error-tolerance baseline.
