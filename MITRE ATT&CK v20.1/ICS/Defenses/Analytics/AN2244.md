# AN2244 - Analytic 2244

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies Industrial Control System (ICS) protocol sessions that bulk-read configuration data, program blocks, or data record objects from field devices -- function code sequences retrieving entire data dictionaries rather than operational process values -- from a source with no prior history of configuration-read sessions. OT operational-fidelity gate: Do not alert on novelty, scan/read volume, or enumeration alone. Alert when the source role is not authorized for discovery/polling and the target scope, address/tag range, protocol, or rate deviates from the established operational baseline. Suppress normal SCADA/HMI/historian polling, commissioning, asset inventory, backup, diagnostics, and approved engineering activity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0749#AN2244)

## Mutable elements

- **AuthorizedICSApplications** — Allowlist of processes expected to perform legitimate bulk reads of ICS data.
- **BulkAccessThreshold** — Number of distinct files read within the detection window that constitutes bulk collection.
- **ICSDataPaths** — File system paths containing ICS configuration, project, and sensitive operational data.
