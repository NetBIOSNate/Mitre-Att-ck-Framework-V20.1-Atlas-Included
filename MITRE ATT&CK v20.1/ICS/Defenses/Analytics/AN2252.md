# AN2252 - Analytic 2252

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies deauthentication frames targeting enrolled Industrial Control System (ICS) wireless device Media Access Control (MAC) address from a source not in the approved wireless infrastructure. OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

## Mutable elements

- **ApprovedWirelessAdminList** — Accounts/sources authorized to modify wireless infrastructure configuration.
- **DeauthTimeWindow** — Time window within which multiple deauthentication events are considered a coordinated mass event.
- **MassDeauthThreshold** — Number of simultaneously deauthenticated enrolled devices that constitutes a mass event.
