# AN2239 - Analytic 2239

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies Open Platform Communications (OPC) Unified Architecture (UA) method invocations or International Electrotechnical Commission (IEC) 61850 Abstract Common Services Interface (ACSI) service requests arriving at a field device from a client identity not in the approved application allowlist, where the invoked method is a write or control operation rather than read/subscribe. OT operational-fidelity gate: Alert only when execution violates an approved signer/hash/path/parent/process or tool allowlist, or originates from an unauthorized user/tool, and is tied to an OT asset or follow-on OT-relevant action. Suppress vendor-signed software, approved engineering utilities, diagnostics, patching, backup, and documented maintenance.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0742#AN2239)

## Log sources and channels

- **NSM:Content** — write/control method invocation from client identity not in approved application list · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **ApprovedApplicationList** — Allowlist of application identities authorized to issue OPC UA or IEC 61850 write/control service requests.
- **ApprovedOPCClients** — Allowlist of OPC client application identities authorized to invoke write/control methods.
- **AuthorizedICSApplications** — Allowlist of process executables permitted to load ICS vendor automation API libraries.
