# AN2278 - Analytic 2278

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies Industrial Control System (ICS) protocol master-role traffic originating from a Windows host that is not the authorized Supervisory Control and Data Acquisition (SCADA) or Distributed Control System (DCS) server. OT operational-fidelity gate: Alert only when the master/station identity or source is not authorized for the target device and command function, or when a normally authorized master violates its configured role/sequence and produces a corroborating device/process-state change. Suppress legitimate redundancy/failover, hot-standby promotion, commissioning, and approved engineering master activity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0792#AN2278)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=3 unexpected Windows host opening Industrial Control Systems (ICS) protocol connections to multiple field device Internet Protocol (IP) addresses in polling pattern characteristic of master station · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **ApprovedSCADAServers** — IP/identity allowlist of legitimate master/control server systems.
- **RegisteredMasterAddresses** — Inventory of authorized station/master addresses for protocols using logical addressing distinct from IP.
- **RogueMasterTimeWindow** — Time window within which command traffic to multiple devices from a single unrecognized source is considered a coordinated rogue master event.
