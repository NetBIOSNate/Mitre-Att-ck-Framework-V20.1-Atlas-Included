# AN1922 - Analytic 1922

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies a firmware write command targeting a specific Input/Output (I/O) module slot address within a controller chassis from a source not in the approved engineering workstation list, distinguishing module-level firmware modification from main-processor firmware updates by its slot-addressed targeting. OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0790#AN1922)

**Platforms**  [Embedded](../../Platforms/Embedded.md)

## Log sources and channels

- **assetinventory:FirmwareHash** — module-specific firmware hash post-write does not match authorized module firmware inventory · [DC0004 - Firmware Modification](../Data%20Components/DC0004%20-%20Firmware%20Modification.md)
- **NSM:Content** — firmware write service targeting specific slot/rack address from source not in engineering workstation list outside change control window · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **AuthorizedModuleFirmwareInventory** — Hash inventory of authorized firmware versions per I/O module type and slot position.
- **ChangeControlWindow** — Scheduled maintenance periods during which module firmware updates are authorized.
- **EngineeringWorkstationList** — IP allowlist of workstations authorized to perform module-level firmware updates.
