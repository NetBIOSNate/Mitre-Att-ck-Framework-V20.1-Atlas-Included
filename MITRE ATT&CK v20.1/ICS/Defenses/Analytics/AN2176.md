# AN2176 - Analytic 2176

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies network device configuration changes (network address translation rules, static routes, access control list modifications) combined with NetFlow path deviations for Industrial Control System (ICS) device traffic and Transport Layer Security (TLS) certificate issuer anomalies in Operational Technology (OT) management traffic. OT operational-fidelity gate: Alert only when the asset's documented role does not permit the connection and the destination/proxy/service is outside the approved communications profile, with process/service identity used as corroboration where available. Suppress approved vendor support, update repositories, remote operations, failover paths, and documented temporary connectivity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0764#AN2176)

**Platforms**  [Network Devices](../../Platforms/Network%20Devices.md)

## Log sources and channels

- **netflow:ipfix** — IPFIX/NetFlow flow record (src/dst IP, src/dst port, protocol, packets/bytes/time): next-hop change for device subnet traffic or unexpected path through new gateway not in expected next-hop baseline · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **networkdevice:syslog** — Network Address Translation (NAT)/route/Access Control List (ACL) configuration change from source not in approved net admins outside config change window · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **AiTMCorrelationWindow** — Time window within which a MAC binding change and protocol baseline deviation are considered correlated.
- **ExpectedNextHopBaseline** — Documented expected network path for device subnet traffic.
- **TopologyChangeTicket** — Change-management reference confirming an authorized hardware replacement or topology modification.
