# AN2066 - Analytic 2066

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies a field device loading a modified autorun image (boot read-only memory, bootloader firmware) detected by a discrepancy between the device's declared firmware hash and the authorized firmware inventory hash, with post-reboot device behavior diverging from expected (unexpected protocols active, unanticipated network connections). OT operational-fidelity gate: Alert only when execution violates an approved signer/hash/path/parent/process or tool allowlist, or originates from an unauthorized user/tool, and is tied to an OT asset or follow-on OT-relevant action. Suppress vendor-signed software, approved engineering utilities, diagnostics, patching, backup, and documented maintenance.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0748#AN2066)

**Platforms**  [Embedded](../../Platforms/Embedded.md)

## Log sources and channels

- **assetinventory:FirmwareHash** — device firmware hash does not match authorized firmware inventory following a reboot event · [DC0004 - Firmware Modification](../Data%20Components/DC0004%20-%20Firmware%20Modification.md)
- **NSM:Connections** — device establishes new network connections or activates protocols not seen in pre-reboot baseline · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **AuthorizedICSSoftwareInventory** — Inventory of binaries legitimately authorized to be referenced by autorun/startup mechanisms on ICS hosts.
- **AutorunModificationWindow** — Time window correlating removable media insertion with a subsequent autorun configuration change.
