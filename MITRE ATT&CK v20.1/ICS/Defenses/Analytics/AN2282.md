# AN2282 - Analytic 2282

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies a vendor firmware update tool activating firmware-update mode on a field device from a Windows host, outside a scheduled maintenance window or by an account not in the approved firmware management role. OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=1 firmware update tool process activating firmware mode, by account not in authorized firmware managers, outside maintenance window schedule · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **AlarmSilenceGracePeriod** — Time window within which alarm telemetry going silent following a mode-change message is considered directly connected.
- **AuthorizedFirmwareManagers** — Accounts authorized to perform firmware update mode activation.
- **ChangeControlWindow** — Scheduled maintenance periods during which firmware update mode activation is authorized.
- **EngineeringWorkstationList** — IP allowlist of workstations authorized to activate firmware update mode.
- **MaintenanceWindowSchedule** — Recurring scheduled periods when firmware update activities are expected.
