# AN1861 - Analytic 1861

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring of the alarm and process historian layer identifies an alarm status transitioning to suppressed, shelved, disabled, or acknowledged without a corresponding operator action recorded within a grace period, correlated with Industrial Control System (ICS) protocol write traffic to alarm configuration or threshold registers arriving in the same window from a source not in the approved engineering list. OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

## Log sources and channels

- **operationaldb:AlarmEvent** — alarm status transitions to suppressed/shelved/disabled/acknowledged without matching operator_id entry within suppress grace period · [DC0109 - Process/Event Alarm](../Data%20Components/DC0109%20-%20Process%20-%20Event%20Alarm.md)
- **operationaldb:ProcessHistory** — process value crosses known alarm threshold but no corresponding alarm event recorded within expected latency window · [DC0107 - Process History/Live Data](../Data%20Components/DC0107%20-%20Process%20History%20-%20Live%20Data.md)
- **NSM:Content** — Generic Object Oriented Substation Event (GOOSE) dataset stNum value decreases (replay indicator) or test-mode bit asserted on protection relay without scheduled maintenance · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **NSM:Content** — write function code targeting alarm config address range from source not in approved write sources within suppress grace period of the alarm status change · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **AlarmConfigAddressRange** — Protocol register/address ranges corresponding to alarm threshold and configuration values per device type.
- **AlarmConfigPaths** — File system paths for alarm configuration files/databases on Windows alarm servers.
- **ApprovedWriteSources** — IP allowlist of sources authorized to write to ICS devices, including alarm configuration.
- **HMIAlarmParentAllowlist** — Allowlist of recognized HMI/alarm management application processes authorized to modify alarm configuration.
- **SuppressGracePeriod** — Time window within which a legitimate operator acknowledgment is expected following an alarm status change, typically 10-30 seconds.
