# AN2206 - Analytic 2206

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies a process on an Industrial Control System (ICS) Windows host querying device operating state or process values via vendor Application Programming Interfaces (APIs) at a frequency or scope exceeding documented Human-Machine Interface (HMI) refresh behavior, from a process not in the recognized HMI/Supervisory Control and Data Acquisition (SCADA) application list. OT operational-fidelity gate: Do not alert on novelty, scan/read volume, or enumeration alone. Alert when the source role is not authorized for discovery/polling and the target scope, address/tag range, protocol, or rate deviates from the established operational baseline. Suppress normal SCADA/HMI/historian polling, commissioning, asset inventory, backup, diagnostics, and approved engineering activity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0727#AN2206)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **opc:applog** — Open Platform Communications (OPC) client polling frequency for tag set exceeds documented Human-Machine Interface (HMI) refresh baseline from client not in approved application list · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **ApprovedOPCClients** — Allowlist of OPC client application identities authorized to connect.
- **ApprovedSCADAServers** — IP allowlist of legitimate SCADA/HMI/historian servers authorized to poll field devices.
- **BaselinePollRate** — Measured normal polling frequency per device, derived from actual baseline traffic capture.
- **KnownTagAddressRanges** — Documented register/tag address ranges that legitimate SCADA polling actually queries.
