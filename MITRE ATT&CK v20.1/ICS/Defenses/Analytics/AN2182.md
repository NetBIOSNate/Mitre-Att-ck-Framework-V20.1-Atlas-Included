# AN2182 - Analytic 2182

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies network device management session authentication such as Secure Shell (SSH), Remote Authentication Dial-In User Service (RADIUS), and Terminal Access Controller Access-Control System Plus (TACACS+) using valid Industrial Control System (ICS) network administrator credentials but originating from source IPs outside the approved Network Management System (NMS) Classless Inter-Domain Routing (CIDR) subnet or at times inconsistent with the account's normal usage pattern, where the session performs configuration changes not reflected in any open change-control ticket. OT operational-fidelity gate: Alert only when the account/device/session violates the approved identity + source host/jump path/zone policy and is corroborated by access to a protected OT asset, execution, configuration change, or another security-relevant follow-on event. Suppress approved shift activity, vendor support, break-glass use, commissioning, and documented remote-access windows.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0724#AN2182)

**Platforms**  [Network Devices](../../Platforms/Network%20Devices.md)

## Log sources and channels

- **networkdevice:aaa** — TACACS+/RADIUS authentication success for Industrial Control Systems (ICS) network admin account from source not in approved Network Management System (NMS) Classless Inter-Domain Routing (CIDR) subnet · [DC0002 - User Account Authentication](../Data%20Components/DC0002%20-%20User%20Account%20Authentication.md)
- **networkdevice:syslog** — configuration change logged without corresponding change ticket reference following anomalous authentication · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **ApprovedAdminCIDR** — IP ranges from which SSH administrative access to ICS Linux assets is authorized.
- **ApprovedHostList** — Inventory of workstations/jump hosts from which ICS-role accounts are authorized to authenticate.
- **ApprovedNMSCIDR** — IP ranges from which network device administrative access is authorized.
- **AuthToDeviceWindow** — Time window after anomalous logon within which device-subnet connection is considered correlated, typically 5-15 minutes.
- **ICSRoleAccountPatterns** — Naming convention or group-membership pattern identifying accounts with engineering, operator, or ICS service roles.
- **OfficeHoursWindow** — Defined normal working hours for interactive ICS engineering activity, widened for 24/7 shift-based operations.
