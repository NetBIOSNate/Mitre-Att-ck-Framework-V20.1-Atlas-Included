# AN2055 - Analytic 2055

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies wireless controller management log entries showing Service Set Identifier (SSID) or Media Access Control (MAC) address filter configuration changes for the Industrial Control System (ICS) wireless network from an account not in the authorized wireless admins. OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0912#AN2055)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Application** — wireless controller management log: SSID or MAC filter config change from account not in authorized wireless admins · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **ApprovedWirelessAdminList** — Accounts/sources authorized to modify wireless infrastructure configuration.
- **DeauthTimeWindow** — Time window within which multiple deauthentication events are considered a coordinated mass event.
- **MassDeauthThreshold** — Number of simultaneously deauthenticated enrolled devices that constitutes a mass event.
