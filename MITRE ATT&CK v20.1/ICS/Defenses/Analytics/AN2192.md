# AN2192 - Analytic 2192

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies Industrial Control System (ICS) network device syslog showing a gap in expected event sequence numbers, or syslog forwarding interruption from a device coinciding with a period of suspicious activity on that device. OT operational-fidelity gate: Alert only when execution violates an approved signer/hash/path/parent/process or tool allowlist, or originates from an unauthorized user/tool, and is tied to an OT asset or follow-on OT-relevant action. Suppress vendor-signed software, approved engineering utilities, diagnostics, patching, backup, and documented maintenance.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0750#AN2192)

**Platforms**  [Network Devices](../../Platforms/Network%20Devices.md)

## Log sources and channels

- **networkdevice:syslog** — syslog sequence number gap or forwarding interruption coinciding with suspicious activity window for the same device · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **AuthorizedLogManagementTools** — Allowlist of processes/accounts authorized to delete or truncate ICS application logs.
- **LogClearLookbackWindow** — Time window prior to a log-clear event within which other suspicious activity is considered correlated.
- **ScheduledLogRotationWindow** — Documented schedule for legitimate, automated log rotation/archival.
