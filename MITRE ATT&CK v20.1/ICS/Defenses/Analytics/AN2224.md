# AN2224 - Analytic 2224

[ICS](../../README.md) / [Analytics](README.md)

Near-real-time connection monitoring identifies connections to Industrial Control System (ICS) field device management ports from Internet Protocol (IP) addresses routed through external remote access infrastructure rather than from within the expected ICS network segments. OT operational-fidelity gate: Alert only when the account/device/session violates the approved identity + source host/jump path/zone policy and is corroborated by access to a protected OT asset, execution, configuration change, or another security-relevant follow-on event. Suppress approved shift activity, vendor support, break-glass use, commissioning, and documented remote-access windows. This analytic is implementable from session/flow metadata (endpoints, ports, protocol/service, timing, bytes); it does not require or claim packet-payload visibility.

## Mutable elements

- **ApprovedRemoteAccessOrigins** — Documented geographic regions/ASNs from which legitimate ICS-role remote access is expected.
- **ExpectedSessionPattern** — Baseline of normal session timing/duration for each ICS-role account's remote access usage.
- **RemoteAccessToICSWindow** — Time window correlating VPN authentication with subsequent ICS-zone network access.
