# AN1878 - Analytic 1878

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies a file written to an Industrial Control System (ICS) host from a remote network share, where the file has an executable or script extension, immediately followed by execution of that file from the same path. Documented in the PIPEDREAM toolkit's modular design, where components transfer files to compromised Programmable Logic Controllers (PLCs) and engineering workstations. OT operational-fidelity gate: Alert only when execution violates an approved signer/hash/path/parent/process or tool allowlist, or originates from an unauthorized user/tool, and is tied to an OT asset or follow-on OT-relevant action. Suppress vendor-signed software, approved engineering utilities, diagnostics, patching, backup, and documented maintenance.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0745#AN1878)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — Windows Security Event ID 5140/5145: EventCode=5145 for file write to Industrial Control Systems (ICS) host, source not in authorized file sources · [DC0102 - Network Share Access](../Data%20Components/DC0102%20-%20Network%20Share%20Access.md)
- **WinEventLog:Sysmon** — EventCode=11 with executable/script extension from remote-sourced write operation · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=1 of the newly-created file within tool transfer window of its creation · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **AuthorizedFileSources** — Allowlist of network shares/hosts authorized to write executable or script files to ICS Windows assets.
- **EngineeringWorkstationList** — IP allowlist of workstations authorized to perform file transfers to field devices.
- **SuspiciousFilePatterns** — Filename/extension patterns inconsistent with the device's normal configuration exchange profile.
- **ToolTransferWindow** — Time window after file creation within which execution is considered directly connected to the transfer event.
