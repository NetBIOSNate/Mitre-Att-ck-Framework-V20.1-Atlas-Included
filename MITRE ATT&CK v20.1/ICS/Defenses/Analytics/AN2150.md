# AN2150 - Analytic 2150

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies a user-facing application on an ICS Linux workstation spawning a child process outside the expected application-child baseline. OT operational-fidelity gate: Alert only when the account/device/session violates the approved identity + source host/jump path/zone policy and is corroborated by access to a protected OT asset, execution, configuration change, or another security-relevant follow-on event. Suppress approved shift activity, vendor support, break-glass use, commissioning, and documented remote-access windows.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0791#AN2150)

**Platforms**  [Linux](../../Platforms/Linux.md)

- **auditd:SYSCALL** — Linux Audit SYSCALL/EXECVE/SOCKADDR records (configured audit rule): syscall=execve; document/viewer process launches a child process outside the expected viewer-child baseline · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
