# AN2271 - Analytic 2271

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies an Industrial Control System (ICS) vendor process making outbound connections on commonly-allowed port (e.g., 80, 443, 8080, etc.) to a destination not in the approved vendor domain list, from a host whose documented role does not require external connectivity. OT operational-fidelity gate: Alert only when the asset's documented role does not permit the connection and the destination/proxy/service is outside the approved communications profile, with process/service identity used as corroboration where available. Suppress approved vendor support, update repositories, remote operations, failover paths, and documented temporary connectivity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0736#AN2271)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=3 on port 80/443/8080 from process not matching Industrial Control Systems (ICS) vendor update process allowlist · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **ApprovedVendorDomains** — Allowlist of legitimate vendor domains for software updates, licensing, or remote support.
- **NoExternalConnectivityRoleList** — Inventory of ICS hosts whose documented function never requires outbound internet connectivity.
