# AN2262 - Analytic 2262

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies a password change event for an Industrial Control System (ICS) service or operator account performed by an account not in the authorized credential administration role, immediately followed by failed authentication attempts from the Industrial Control System (ICS) service itself. OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0771#AN2262)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — Windows Security Event ID 4624/4625: EventCode=4723, 4724 for Industrial Control Systems (ICS) service/operator account by account not in authorized credential admins outside credential rotation schedule · [DC0002 - User Account Authentication](../Data%20Components/DC0002%20-%20User%20Account%20Authentication.md)
- **WinEventLog:System** — Industrial Control Systems (ICS) service failing to start (authentication failure) within credential change impact window of the password change event · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **AuthorizedCredentialAdmins** — Accounts authorized to change credentials for ICS service and operator accounts.
- **CredentialChangeImpactWindow** — Time window after a credential change within which a service authentication failure is considered directly connected.
- **CredentialRotationSchedule** — Documented schedule for routine credential rotation.
