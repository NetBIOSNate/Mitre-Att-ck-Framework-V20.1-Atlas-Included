# AN1867 - Analytic 1867

[ICS](../../README.md) / [Analytics](README.md)

Real-time network monitoring identifies a source issuing systematic, sequential Industrial Control System (ICS) protocol reads sweeping the full register/address range across multiple field devices within a short time window, from a source not in the approved control server list. OT operational-fidelity gate: Do not alert on novelty, scan/read volume, or enumeration alone. Alert when the source role is not authorized for discovery/polling and the target scope, address/tag range, protocol, or rate deviates from the established operational baseline. Suppress normal SCADA/HMI/historian polling, commissioning, asset inventory, backup, diagnostics, and approved engineering activity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0734#AN1867)

**Platforms**  [Embedded](../../Platforms/Embedded.md)

## Log sources and channels

- **historian:applog** — bulk export query returning above bulk query threshold records from account not in approved historian clients · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **NSM:Content** — source not in approved Supervisory Control and Data Acquisition (SCADA) servers issuing reads covering sequential address ranges across multiple device Internet Protocol (IP) addresses within auto collection time window · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **ApprovedHistorianClients** — Allowlist of applications/accounts authorized to perform bulk historian queries.
- **ApprovedSCADAServers** — IP allowlist of legitimate SCADA/historian servers.
- **AutoCollectionTimeWindow** — Time window within which sequential reads across multiple devices are considered part of a single automated collection event.
- **BulkQueryThreshold** — Record count threshold above which a historian query is considered a bulk export rather than a routine query.
