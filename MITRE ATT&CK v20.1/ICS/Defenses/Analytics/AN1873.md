# AN1873 - Analytic 1873

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies an internet-facing Industrial Control System (ICS) application server, web Human-Machine Interface (HMI), historian web interface, vendor remote access portal) process spawning an unexpected child process immediately following an inbound web request containing exploit-pattern content. Documented across multiple incidents involving internet-exposed ICS web interfaces. OT operational-fidelity gate: Alert only when execution violates an approved signer/hash/path/parent/process or tool allowlist, or originates from an unauthorized user/tool, and is tied to an OT asset or follow-on OT-relevant action. Suppress vendor-signed software, approved engineering utilities, diagnostics, patching, backup, and documented maintenance. Analyst implementation must limit predicates to fields actually retained by the web server/WAF (for example URI/path/query/header/status/source); request-body or payload signatures require WAF/DPI or request-body logging and must not be inferred from a basic access log.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0740#AN1873)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **webserver:applog** — Web server/WAF access or request log: exploit-relevant URI/path/query/header/status pattern against ICS web interface from unapproved source; request-body claims require WAF/DPI logging · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **WinEventLog:Sysmon** — EventCode=1 with parent matching web/application server process and image matching shell/script interpreter within exploit-to-shell window of anomalous request · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **ApprovedClientCIDR** — IP ranges from which legitimate access to the ICS web interface is expected.
- **ExploitPatternSignatures** — Regex/signature set for known exploit payload patterns and published CVE-specific payload signatures for in-use ICS web products.
- **ExploitToShellWindow** — Time window within which a child shell process spawned from the web server is considered connected to a preceding exploit-pattern request.
