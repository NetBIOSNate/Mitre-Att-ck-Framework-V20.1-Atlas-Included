# AN2207 - Analytic 2207

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies an Industrial Control System (ICS) Windows application such as a Supervisory Control and Data Acquisition (SCADA) server or Distributed Control System (DCS) interface generating anomalously high-frequency write Application Programming Interface (API) calls to field devices, exceeding the configured scan rate baseline for that point. OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0737#AN2207)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **opc:applog** — Open Platform Communications Data Access (OPC DA) write queue depth or write throughput to a single point exceeds configured baseline by a significant margin · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **BruteForceDetectionWindow** — Time window over which write rate is measured for threshold comparison.
- **MaxNormalStateChangeRate** — Maximum rate at which the physical process value is expected to legitimately change state.
- **MaxWriteQueueDepth** — Maximum legitimate write queue depth for SCADA/DCS write operations to a single point.
- **MaxWriteRatePerPoint** — Maximum legitimate write rate to a single I/O point, derived from the device's configured scan cycle and physical process response time.
