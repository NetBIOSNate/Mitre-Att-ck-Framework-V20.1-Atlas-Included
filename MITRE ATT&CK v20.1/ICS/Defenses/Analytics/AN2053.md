# AN2053 - Analytic 2053

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies a network infrastructure configuration change that results in a communication gap between previously-connected Industrial Control System (ICS) zones, from a source not in the approved network administration list. This technique-level analytic synthesizes Serial COM (T1695.001), Ethernet (T1695.002), and Wi-Fi (T1695.003). OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0910#AN2053)

## Log sources and channels

- **networkdevice:syslog** — Access Control List (ACL)/firewall/routing configuration change from source not in approved Network Management System (NMS) Classless Inter-Domain Routing (CIDR) subnet outside change control window · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **operationaldb:AlarmEvent** — communication-loss alarm for affected devices within comm block correlation window of the flagged configuration change · [DC0109 - Process/Event Alarm](../Data%20Components/DC0109%20-%20Process%20-%20Event%20Alarm.md)

## Mutable elements

- **ApprovedNMSCIDR** — IP ranges authorized for network infrastructure configuration changes.
- **ChangeControlWindow** — Scheduled maintenance periods during which connectivity-affecting changes are authorized.
- **CommBlockCorrelationWindow** — Time window correlating a configuration change with subsequent communication loss.
