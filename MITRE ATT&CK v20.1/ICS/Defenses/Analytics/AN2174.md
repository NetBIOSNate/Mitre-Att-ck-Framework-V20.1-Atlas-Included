# AN2174 - Analytic 2174

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies large outbound data transfers from Industrial Control System (ICS) server Internet Protocol (IP) addresses to destinations outside the approved ICS zone, following a pattern of bulk reads from engineering document stores or historian databases. OT operational-fidelity gate: Do not alert on novelty, scan/read volume, or enumeration alone. Alert when the source role is not authorized for discovery/polling and the target scope, address/tag range, protocol, or rate deviates from the established operational baseline. Suppress normal SCADA/HMI/historian polling, commissioning, asset inventory, backup, diagnostics, and approved engineering activity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0749#AN2174)

## Log sources and channels

- **netflow:ipfix** — IPFIX/NetFlow flow record (src/dst IP, src/dst port, protocol, packets/bytes/time): sustained high-byte-count flow from Industrial Control Systems (ICS) server Internet Protocol (IP) address to destination outside ICS zone following bulk read activity · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **AuthorizedICSApplications** — Allowlist of processes expected to perform legitimate bulk reads of ICS data.
- **BulkAccessThreshold** — Number of distinct files read within the detection window that constitutes bulk collection.
- **ICSDataPaths** — File system paths containing ICS configuration, project, and sensitive operational data.
