# AN2212 - Analytic 2212

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies a control/command message arriving at a field device from a source not in the approved control server list, where the command targets safety-critical output points and does not correspond to any scheduled or operator-acknowledged process action. Documented precedent: Industroyer2 connected directly to specific International Electrotechnical Commission (IEC)-104 RTUs and toggled hardcoded Information Object Addresses (IOAs) to OFF using command type 46, targeting circuit breaker outputs. OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

## Mutable elements

- **ApprovedSCADAServers** — IP allowlist of legitimate control sources.
- **RapidToggleWindow** — Time window within which multiple safety-critical output changes are considered a coordinated event.
- **SafetyCriticalOutputAddresses** — Documented register/IOA addresses corresponding to safety-critical outputs per device.
