# AN1923 - Analytic 1923

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies a user-invoked action on an Industrial Control System (ICS) workstation immediately followed by a process execution chain inconsistent with normal ICS operations -- the user-driven trigger plus the resulting anomalous execution chain together distinguish this from generic malware execution. OT operational-fidelity gate: Alert only when the account/device/session violates the approved identity + source host/jump path/zone policy and is corroborated by access to a protected OT asset, execution, configuration change, or another security-relevant follow-on event. Suppress approved shift activity, vendor support, break-glass use, commissioning, and documented remote-access windows.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0791#AN1923)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=1 chain originating from user-invoked file open or link click action, spawning processes not in expected document viewer children · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=3 from resulting process to destinations not in approved destinations list · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **ApprovedDestinations** — Allowlist of network destinations consistent with legitimate document/link content.
- **ExpectedDocumentViewerChildren** — Documented normal child processes for legitimate document viewers/handlers.
