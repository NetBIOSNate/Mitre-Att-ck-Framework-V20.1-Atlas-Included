# AN2219 - Analytic 2219

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies successful authentication to an Industrial Control System (ICS) device or application using credentials that are either documented vendor defaults (T1694.001) or extracted from configuration files/firmware where stored in cleartext (T1694.002), from a source not in the approved access list. This technique-level analytic unifies both sub-techniques. OT operational-fidelity gate: Alert only when the account/device/session violates the approved identity + source host/jump path/zone policy and is corroborated by access to a protected OT asset, execution, configuration change, or another security-relevant follow-on event. Suppress approved shift activity, vendor support, break-glass use, commissioning, and documented remote-access windows.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0905#AN2219)

## Log sources and channels

- **NSM:Content** — authentication success using credential matching default vendor credential list or known hardcoded credential patterns from source not in engineering workstation list · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **DefaultVendorCredentialList** — Documented default username/password combinations for all device models in the environment.
- **EngineeringWorkstationList** — IP allowlist of legitimate authentication sources.
- **KnownHardcodedCredentialPatterns** — Documented hardcoded credential values for in-use ICS products.
