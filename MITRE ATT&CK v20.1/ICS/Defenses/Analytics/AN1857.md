# AN1857 - Analytic 1857

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies an Industrial Control System (ICS)-role account authenticating via interactive or remote logon from a workstation not in the approved host inventory, or outside the account's established usage pattern, immediately followed within a short window by that session connecting to the field device network or ICS application. OT operational-fidelity gate: Alert only when the account/device/session violates the approved identity + source host/jump path/zone policy and is corroborated by access to a protected OT asset, execution, configuration change, or another security-relevant follow-on event. Suppress approved shift activity, vendor support, break-glass use, commissioning, and documented remote-access windows.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0724#AN1857)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — Windows Security Event ID 4624/4625: EventCode=4624 for Industrial Control Systems (ICS)-role account from workstation not in approved host list or outside office hours window · [DC0067 - Logon Session Creation](../Data%20Components/DC0067%20-%20Logon%20Session%20Creation.md)
- **WinEventLog:Security** — Windows Security Event ID 4624/4625: EventCode=4672 for Industrial Control Systems (ICS)-role account from anomalous session · [DC0088 - Logon Session Metadata](../Data%20Components/DC0088%20-%20Logon%20Session%20Metadata.md)
- **WinEventLog:Security** — Windows Security Event ID 4624/4625: EventCode=4648 for Industrial Control Systems (ICS)-role account from process outside approved ICS vendor process list · [DC0002 - User Account Authentication](../Data%20Components/DC0002%20-%20User%20Account%20Authentication.md)
- **WinEventLog:Sysmon** — EventCode=3 to device subnet within auth-to-device window of the anomalous logon · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **ApprovedAdminCIDR** — IP ranges from which SSH administrative access to ICS Linux assets is authorized.
- **ApprovedHostList** — Inventory of workstations/jump hosts from which ICS-role accounts are authorized to authenticate.
- **ApprovedNMSCIDR** — IP ranges from which network device administrative access is authorized.
- **AuthToDeviceWindow** — Time window after anomalous logon within which device-subnet connection is considered correlated, typically 5-15 minutes.
- **ICSRoleAccountPatterns** — Naming convention or group-membership pattern identifying accounts with engineering, operator, or ICS service roles.
- **OfficeHoursWindow** — Defined normal working hours for interactive ICS engineering activity, widened for 24/7 shift-based operations.
