# AN2124 - Analytic 2124

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies a process executing iwconfig or ip link set <wlan> promisc, or loading mac80211 monitor mode, on an Industrial Control System (ICS) Linux asset outside normal configuration management activity. OT operational-fidelity gate: Alert only when the account/device/session violates the approved identity + source host/jump path/zone policy and is corroborated by access to a protected OT asset, execution, configuration change, or another security-relevant follow-on event. Suppress approved shift activity, vendor support, break-glass use, commissioning, and documented remote-access windows.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0726#AN2124)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — Linux Audit SYSCALL/EXECVE/SOCKADDR records (configured audit rule): execve of wireless configuration utility setting monitor/promiscuous mode outside change management window · [DC0034 - Process Metadata](../Data%20Components/DC0034%20-%20Process%20Metadata.md)

## Mutable elements

- **ApprovedWirelessDeviceInventory** — MAC/certificate inventory of devices authorized to associate with ICS wireless infrastructure.
- **DesignatedWirelessManagementStations** — Hosts authorized to legitimately enable wireless monitor mode for diagnostics.
- **WirelessOnboardWindow** — Time window after wireless association within which ICS-directed traffic is considered part of the same onboarding event.
