# AN2227 - Analytic 2227

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies multiple field devices becoming unreachable simultaneously following a network infrastructure configuration change event. OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0910#AN2227)

## Log sources and channels

## Mutable elements

- **ApprovedNMSCIDR** — IP ranges authorized for network infrastructure configuration changes.
- **ChangeControlWindow** — Scheduled maintenance periods during which connectivity-affecting changes are authorized.
- **CommBlockCorrelationWindow** — Time window correlating a configuration change with subsequent communication loss.
