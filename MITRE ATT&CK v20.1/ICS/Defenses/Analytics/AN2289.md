# AN2289 - Analytic 2289

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies network traffic to Industrial Control System (ICS) Application Programming Interface (API) ports such as 4840 used in the Open Platform Communications (OPC) Unified Architecture (UA) or vendor-specific API ports from source Internet Protocol (IP) addresses not in the approved application client list, where the traffic pattern is consistent with write/control method invocations rather than subscription/read traffic. OT operational-fidelity gate: Alert only when execution violates an approved signer/hash/path/parent/process or tool allowlist, or originates from an unauthorized user/tool, and is tied to an OT asset or follow-on OT-relevant action. Suppress vendor-signed software, approved engineering utilities, diagnostics, patching, backup, and documented maintenance.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0742#AN2289)

## Log sources and channels

- **zeek:ssl** — Zeek ssl.log/TLS metadata: server_name (SNI), certificate chain/issuer/subject where available; compare with approved vendor domains/certificates · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **ApprovedApplicationList** — Allowlist of application identities authorized to issue OPC UA or IEC 61850 write/control service requests.
- **ApprovedOPCClients** — Allowlist of OPC client application identities authorized to invoke write/control methods.
- **AuthorizedICSApplications** — Allowlist of process executables permitted to load ICS vendor automation API libraries.
