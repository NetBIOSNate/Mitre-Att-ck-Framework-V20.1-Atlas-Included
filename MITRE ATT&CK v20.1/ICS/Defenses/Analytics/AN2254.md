# AN2254 - Analytic 2254

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies an Secure Shell (SSH) connection to an Industrial Control System (ICS) Linux asset from a source Internet Protocol (IP) address that appeared on the ICS network within a short window and is not in the approved device inventory. OT operational-fidelity gate: Alert only when the account/device/session violates the approved identity + source host/jump path/zone policy and is corroborated by access to a protected OT asset, execution, configuration change, or another security-relevant follow-on event. Suppress approved shift activity, vendor support, break-glass use, commissioning, and documented remote-access windows.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0744#AN2254)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **syslog:auth** — Secure Shell (SSH) connection from source Internet Protocol (IP) address that appeared on Industrial Control Systems (ICS) network within new device window, not in approved device inventory · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **ApprovedDeviceInventory** — Hardware ID inventory of all devices authorized to connect to the ICS network, ideally enforced via NAC/802.1X.
- **NewDeviceWindow** — Time window after first network appearance within which access to ICS systems is considered part of the same onboarding/intrusion event.
