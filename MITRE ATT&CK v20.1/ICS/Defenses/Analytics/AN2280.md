# AN2280 - Analytic 2280

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies Windows serial port configuration changes on Industrial Control System (ICS) gateway hosts that would disrupt communication with serial field devices. OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0797#AN2280)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=13 to Communication (COM) port configuration key by process not in authorized serial port management tools · [DC0063 - Windows Registry Key Modification](../Data%20Components/DC0063%20-%20Windows%20Registry%20Key%20Modification.md)

## Mutable elements

- **SerialBlockCorrelationWindow** — Time window within which a serial gateway configuration change and subsequent device communication loss are considered causally connected.
