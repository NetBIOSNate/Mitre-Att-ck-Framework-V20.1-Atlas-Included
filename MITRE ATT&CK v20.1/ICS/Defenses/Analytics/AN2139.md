# AN2139 - Analytic 2139

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies rapid, bulk deletion of files across Industrial Control System (ICS) data directories on a Linux asset, by a User Identifier (UID) not associated with documented data retention management, correlated with worm-based propagation indicators consistent with documented Linux wiper malware (Awfulshred, SoloShred). OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0758#AN2139)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL+PATH** — Linux Audit SYSCALL+PATH records: rm/shred/dd operations across multiple Industrial Control Systems (ICS) data directories exceeding bulk deletion threshold, by User Identifier (UID) not in authorized data management UIDs · [DC0040 - File Deletion](../Data%20Components/DC0040%20-%20File%20Deletion.md)
- **auditd:SYSCALL** — Linux Audit SYSCALL/EXECVE/SOCKADDR records (configured audit rule): Secure Shell (SSH)-based propagation pattern (connection to multiple hosts followed by file transfer and execution) within a short window · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **AuthorizedDataManagementTools** — Allowlist of backup/archival/retention management tools authorized to perform bulk file operations.
- **BulkDeletionThreshold** — File count threshold across monitored directories that distinguishes bulk destruction from routine cleanup.
- **DataDestructionTimeWindow** — Time window over which bulk deletion activity is measured.
- **EngineeringWorkstationList** — IP allowlist of workstations authorized to issue memory erase commands.
- **WiperCrashWindow** — Time window after bulk deletion within which a system crash is considered part of the same destructive event.
