# AN2190 - Analytic 2190

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies a new device connecting to an Industrial Control System (ICS) network switch port that was previously unused or previously assigned to a different device Media Access Control (MAC) address immediately following physical access to the environment, with subsequent Industrial Control System (ICS) protocol traffic to field devices. OT operational-fidelity gate: Alert only when the account/device/session violates the approved identity + source host/jump path/zone policy and is corroborated by access to a protected OT asset, execution, configuration change, or another security-relevant follow-on event. Suppress approved shift activity, vendor support, break-glass use, commissioning, and documented remote-access windows.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0733#AN2190)

## Mutable elements

- **AuthorizedUSBAllowlist** — Hardware ID inventory of USB storage devices authorized for use on ICS engineering and HMI workstations.
- **EngineeringWorkstationList** — IP allowlist of workstations authorized to perform file transfers to field devices.
- **USBExecutionWindow** — Time window after device insertion/mount within which process execution is considered directly connected to the insertion event.
