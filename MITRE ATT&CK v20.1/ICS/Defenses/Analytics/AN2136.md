# AN2136 - Analytic 2136

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies a Linux process generating Industrial Control System (ICS) protocol unsolicited responses or publishing Open Platform Communications Unified Architecture (OPC UA) data changes for device addresses it does not own, from a User Identifier (UID) not associated with the authorized data acquisition service. OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0746#AN2136)
