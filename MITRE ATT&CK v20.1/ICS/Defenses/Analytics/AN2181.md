# AN2181 - Analytic 2181

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies a host generating rapid, sequential Transmission Control Protocol (TCP) connection attempts across multiple destination ports on Industrial Control System (ICS) device Internet Protocol (IP) addresses, targeting ICS-specific protocol ports, from a source not in the approved control server inventory. OT operational-fidelity gate: Do not alert on novelty, scan/read volume, or enumeration alone. Alert when the source role is not authorized for discovery/polling and the target scope, address/tag range, protocol, or rate deviates from the established operational baseline. Suppress normal SCADA/HMI/historian polling, commissioning, asset inventory, backup, diagnostics, and approved engineering activity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0907#AN2181)

**Platforms**  [Network Devices](../../Platforms/Network%20Devices.md)

## Log sources and channels

- **netflow:ipfix** — IPFIX/NetFlow flow record (src/dst IP, src/dst port, protocol, packets/bytes/time): source generates short-lived flows to single dst across multiple Industrial Control Systems (ICS) protocol ports (502,102,44818,20000,4840) within port scan time window, source not in approved Supervisory Control and Data Acquisition (SCADA) servers · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **ApprovedSCADAServers** — IP allowlist of legitimate sources.
- **PortScanTimeWindow** — Time window within which connections across multiple ports are considered a single scan event.
