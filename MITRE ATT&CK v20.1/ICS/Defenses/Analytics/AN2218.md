# AN2218 - Analytic 2218

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies successful authentication to a field device using credentials matching documented vendor-default values, from a source not in the approved access list. OT operational-fidelity gate: Alert only when the account/device/session violates the approved identity + source host/jump path/zone policy and is corroborated by access to a protected OT asset, execution, configuration change, or another security-relevant follow-on event. Suppress approved shift activity, vendor support, break-glass use, commissioning, and documented remote-access windows.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0756#AN2218)

**Platforms**  [Embedded](../../Platforms/Embedded.md)

- **EngineeringWorkstationList** — IP allowlist of legitimate authentication sources.
