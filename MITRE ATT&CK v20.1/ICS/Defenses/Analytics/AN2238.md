# AN2238 - Analytic 2238

[ICS](../../README.md) / [Analytics](README.md)

Real-time network monitoring identifies a field device's source Media Access Control (MAC) address changing without a corresponding documented hardware replacement, combined with protocol-level anomalies (transaction identifier reuse, function-code patterns deviating from baseline) for traffic associated with that device Internet Protocol (IP) address. OT operational-fidelity gate: Alert only when the asset's documented role does not permit the connection and the destination/proxy/service is outside the approved communications profile, with process/service identity used as corroboration where available. Suppress approved vendor support, update repositories, remote operations, failover paths, and documented temporary connectivity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0764#AN2238)

## Mutable elements

- **AiTMCorrelationWindow** — Time window within which a MAC binding change and protocol baseline deviation are considered correlated.
- **ExpectedNextHopBaseline** — Documented expected network path for device subnet traffic.
- **TopologyChangeTicket** — Change-management reference confirming an authorized hardware replacement or topology modification.
