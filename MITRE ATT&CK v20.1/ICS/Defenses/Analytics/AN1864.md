# AN1864 - Analytic 1864

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies a field device entering firmware update mode and receiving a large data transfer on its firmware-capable protocol port from a source not in the approved engineering workstation list, followed by a device reboot, with post-reboot firmware hash not matching the authorized inventory. OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0731#AN1864)

## Log sources and channels

- **assetinventory:FirmwareHash** — reported firmware hash post-reboot not in authorized firmware inventory · [DC0004 - Firmware Modification](../Data%20Components/DC0004%20-%20Firmware%20Modification.md)
- **operationaldb:AlarmEvent** — device reboot/restart alarm within firmware update window of the flagged transfer session · [DC0108 - Device Alarm](../Data%20Components/DC0108%20-%20Device%20Alarm.md)
- **NSM:Content** — session on firmware-capable port exceeds session size threshold from source not in engineering workstation list outside change control window · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **engineeringworkstation:ApplicationLog** — firmware write session initiated without corresponding change ticket reference · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **AuthorizedFirmwareInventory** — Cryptographic hash inventory of authorized firmware versions per device model.
- **AuthorizedFirmwareManagers** — Accounts authorized to perform firmware update operations.
- **ChangeControlWindow** — Scheduled maintenance periods during which firmware updates are authorized.
- **EngineeringWorkstationList** — IP allowlist of workstations authorized to perform firmware updates.
- **FirmwareSessionSizeThreshold** — Minimum byte count for a session to be considered a firmware transfer rather than routine configuration traffic, derived from known firmware image sizes.
- **FirmwareUpdateWindow** — Time window within which a device reboot following a large session is considered part of the same firmware update event.
- **MaintenanceWindowSchedule** — Recurring scheduled periods when firmware updates are expected to occur.
