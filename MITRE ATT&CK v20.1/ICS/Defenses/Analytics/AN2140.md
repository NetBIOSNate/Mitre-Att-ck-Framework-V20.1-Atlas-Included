# AN2140 - Analytic 2140

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies systemctl stop or kill commands targeting Industrial Control System (ICS) service processes on Linux assets, from a User Identifier (UID) that is not the ICS service owner or an authorized system administrator. OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0765#AN2140)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — Linux Audit SYSCALL/EXECVE/SOCKADDR records (configured audit rule): syscall=execve; systemctl/kill command targets a critical ICS service from a UID not in the authorized service-administration set · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **AuthorizedServiceAdmins** — Accounts authorized to stop/start critical ICS services.
- **BulkRestartTimeWindow** — Time window within which multiple device restarts are considered a coordinated event.
- **CriticalICSServiceList** — List of Windows services whose stoppage constitutes a high-impact event.
- **EngineeringWorkstationList** — IP allowlist of workstations authorized to issue device restart commands.
