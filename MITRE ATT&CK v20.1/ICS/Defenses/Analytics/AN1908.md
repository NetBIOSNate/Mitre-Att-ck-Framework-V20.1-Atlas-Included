# AN1908 - Analytic 1908

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies an Industrial Control System (ICS) protocol write to a parameter/setpoint register where the written value falls outside the documented safe operating range, or where the write originates from a source not in the approved write-source list, correlated with subsequent historian tag drift. Documented precedent: FrostyGoop directly modified Modbus holding register values on ENCO heating controllers in Lviv, Ukraine, causing a two-day remediation outage. OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

## Log sources and channels

- **operationaldb:ProcessHistory** — tag value deviates from rolling baseline mean by more than parameter drift threshold percent within time window following a flagged write · [DC0107 - Process History/Live Data](../Data%20Components/DC0107%20-%20Process%20History%20-%20Live%20Data.md)
- **NSM:Content** — write function code (FC 6/16) to setpoint address range with value outside baseline value range, or from source not in approved write sources · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **scada:applog** — parameter write logged without corresponding operator_id in the Human-Machine Interface (HMI) audit trail · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **ApprovedWriteSources** — IP allowlist of sources authorized to write to parameter/setpoint registers.
- **BaselineValueRange** — Documented safe operating range for each monitored parameter.
- **ParameterDriftThreshold** — Percentage deviation from rolling baseline considered significant drift.
- **SetpointAddressRange** — Register/address ranges corresponding to parameter and setpoint values for the device type.
- **TimeWindow** — Time window over which post-write drift is measured.
