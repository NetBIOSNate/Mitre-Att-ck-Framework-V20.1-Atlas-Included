# AN2135 - Analytic 2135

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies execution on an ICS Linux asset of an executable or script from a path commonly used for inbound file transfer or staging, by a UID outside the approved deployment/administration baseline. OT operational-fidelity gate: Alert only when execution violates an approved signer/hash/path/parent/process or tool allowlist, or originates from an unauthorized user/tool, and is tied to an OT asset or follow-on OT-relevant action. Suppress vendor-signed software, approved engineering utilities, diagnostics, patching, backup, and documented maintenance.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0745#AN2135)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL+PATH** — Linux Audit SYSCALL+PATH records: file transfer (scp, sftp, rsync, etc.) placing executable on Industrial Control Systems (ICS) Linux asset, followed by execve of the transferred file within tool transfer window · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)

## Mutable elements

- **AuthorizedFileSources** — Allowlist of network shares/hosts authorized to write executable or script files to ICS Windows assets.
- **EngineeringWorkstationList** — IP allowlist of workstations authorized to perform file transfers to field devices.
- **SuspiciousFilePatterns** — Filename/extension patterns inconsistent with the device's normal configuration exchange profile.
- **ToolTransferWindow** — Time window after file creation within which execution is considered directly connected to the transfer event.
