# AN2133 - Analytic 2133

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies web server or Industrial Control System (ICS) application logs showing exploit-pattern requests to Industrial Control System (ICS) vendor web interfaces, followed by the web server daemon User Identifier (UID) spawning unexpected shell processes. OT operational-fidelity gate: Alert only when execution violates an approved signer/hash/path/parent/process or tool allowlist, or originates from an unauthorized user/tool, and is tied to an OT asset or follow-on OT-relevant action. Suppress vendor-signed software, approved engineering utilities, diagnostics, patching, backup, and documented maintenance. Analyst implementation must limit predicates to fields actually retained by the web server/WAF (for example URI/path/query/header/status/source); request-body or payload signatures require WAF/DPI or request-body logging and must not be inferred from a basic access log.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0740#AN2133)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — Linux Audit SYSCALL/EXECVE/SOCKADDR records (configured audit rule): unexpected process creation from web server daemon User Identifier (UID) spawning shell process · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **webserver:applog** — Web server/WAF access or request log: exploit-relevant URI/path/query/header/status pattern against ICS web interface; request-body claims require WAF/DPI logging · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **ApprovedClientCIDR** — IP ranges from which legitimate access to the ICS web interface is expected.
- **ExploitPatternSignatures** — Regex/signature set for known exploit payload patterns and published CVE-specific payload signatures for in-use ICS web products.
- **ExploitToShellWindow** — Time window within which a child shell process spawned from the web server is considered connected to a preceding exploit-pattern request.
