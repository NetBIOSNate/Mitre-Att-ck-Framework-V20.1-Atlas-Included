# AN2243 - Analytic 2243

[ICS](../../README.md) / [Analytics](README.md)

Detect embedded hooking by correlating an independently acquired firmware/module integrity measurement that differs from the approved vendor/baseline image with protocol-response behavior that also departs from the device's known deterministic behavior. A protocol-response anomaly by itself does not prove a hook because firmware versions, device state, communications faults, and vendor-specific behavior can produce response differences. Treat network anomalies as corroboration and require independent integrity evidence or vendor/device attestation before escalating the condition as firmware-level hooking. Monitoring mode: periodic or event-triggered integrity verification plus near-real-time protocol monitoring where a capable OT protocol decoder is deployed.

## Log sources and channels

- **NSM:Content** — deterministic function code response content diverges from the device's established per-function response baseline without a corresponding firmware update event · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **assetinventory:FirmwareHash** — independently acquired firmware/module hash or vendor integrity measurement differs from approved baseline; protocol-response anomalies are corroboration only · [DC0004 - Firmware Modification](../Data%20Components/DC0004%20-%20Firmware%20Modification.md)

## Mutable elements

- **ApprovedICSVendorProcessList** — Allowlist of processes permitted to install window/event hooks on ICS engineering and HMI hosts.
- **ICSServiceBinaryList** — List of binary paths for ICS gateway, OPC, and historian services on Linux assets that should never be launched with LD_PRELOAD set.
- **VendorPackageManifest** — Package manager manifest cross-reference confirming a shared library belongs to an installed, signed package.
- **VendorSignedDLLHashBaseline** — Cryptographic hash inventory of all vendor-signed ICS communication DLLs, refreshed on every legitimate vendor patch cycle.
