# AN2090 - Analytic 2090

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies shell/CLI access to an embedded controller, gateway, HMI appliance, or IoT/OT device from an unauthorized source/account, or command execution that is inconsistent with the device role and approved maintenance workflow. Require a session/command authorization violation or corroborating configuration/firmware/process effect; do not infer maliciousness from deterministic timing alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0931#AN2090)

**Platforms**  [Embedded](../../Platforms/Embedded.md)

## Log sources and channels

- **device:CLI** — Device shell/CLI command audit when available  · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **device:auth** — SSH/Telnet/console or vendor remote-management session  · [DC0067 - Logon Session Creation](../Data%20Components/DC0067%20-%20Logon%20Session%20Creation.md)

## Mutable elements

- **ApprovedManagementSources ** — Engineering workstations/jump hosts permitted to administer the device 
- **AuthorizedAccounts ** — Approved local/vendor accounts 
- **HighRiskCommands ** — Firmware, configuration write/erase, service manipulation, shell escape 
- **DeviceRole ** — Whether interactive shell/CLI is expected on this device class 
- **MaintenanceWindow ** — Approved vendor/engineering activity
