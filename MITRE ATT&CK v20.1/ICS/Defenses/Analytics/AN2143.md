# AN2143 - Analytic 2143

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies passwd/chpasswd modification of Industrial Control System (ICS) service account credentials by a User Identifier (UID) that is not a designated system administrator, outside a formal credential rotation procedure. OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0771#AN2143)

## Mutable elements

- **AuthorizedCredentialAdmins** — Accounts authorized to change credentials for ICS service and operator accounts.
- **CredentialChangeImpactWindow** — Time window after a credential change within which a service authentication failure is considered directly connected.
- **CredentialRotationSchedule** — Documented schedule for routine credential rotation.
