# AN1886 - Analytic 1886

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies access to Industrial Control System (ICS) documentation repositories by an account or session context not associated with documented engineering roles, immediately followed by bulk file access or archive creation. OT operational-fidelity gate: Do not alert on novelty, scan/read volume, or enumeration alone. Alert when the source role is not authorized for discovery/polling and the target scope, address/tag range, protocol, or rate deviates from the established operational baseline. Suppress normal SCADA/HMI/historian polling, commissioning, asset inventory, backup, diagnostics, and approved engineering activity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0754#AN1886)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **fileserver:audit** — sequential access to above bulk document access threshold files within information repository time window from single session · [DC0102 - Network Share Access](../Data%20Components/DC0102%20-%20Network%20Share%20Access.md)
- **historian:applog** — historian Structured Query Language (SQL) query returning above bulk query threshold rows from account not in approved historian clients · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **WinEventLog:Security** — Windows Security Event ID 4624/4625: EventCode=4624 by account not in authorized engineer accounts · [DC0067 - Logon Session Creation](../Data%20Components/DC0067%20-%20Logon%20Session%20Creation.md)

## Mutable elements

- **ApprovedHistorianClients** — Allowlist of applications/accounts authorized to perform bulk historian queries.
- **AuthorizedEngineerAccounts** — Allowlist of accounts with documented engineering roles authorized to access ICS documentation repositories.
- **BulkDocumentAccessThreshold** — File count threshold distinguishing bulk reconnaissance from routine reference lookups.
- **BulkQueryThreshold** — Row count threshold for historian queries considered bulk export.
- **InformationRepositoryTimeWindow** — Time window within which sequential file accesses are considered part of a single bulk collection event.
