# AN2250 - Analytic 2250

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies Hypertext Transfer Protocol (HTTP) requests to an embedded Human-Machine Interface (HMI) panel's built-in web server capturing screen images, or Virtual Network Computing (VNC) connections to embedded HMI panels, from source Internet Protocol (IP) addresses not in the approved operator workstation list. OT operational-fidelity gate: Do not alert on novelty, scan/read volume, or enumeration alone. Alert when the source role is not authorized for discovery/polling and the target scope, address/tag range, protocol, or rate deviates from the established operational baseline. Suppress normal SCADA/HMI/historian polling, commissioning, asset inventory, backup, diagnostics, and approved engineering activity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0751#AN2250)

**Platforms**  [Embedded](../../Platforms/Embedded.md)

## Log sources and channels

- **NSM:Content** — Virtual Network Computing (VNC) connection or screen-capture Hypertext Transfer Protocol (HTTP) request to embedded Human-Machine Interface (HMI) panel from source not in approved operator workstation list · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **AuthorizedScreenCaptureTools** — Allowlist of remote support, training, or documentation tools legitimately authorized to perform screen capture.
- **CaptureToFileWindow** — Time window correlating a screen capture API call with a subsequent image file write.
