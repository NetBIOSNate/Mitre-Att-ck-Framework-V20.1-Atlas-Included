# AN1860 - Analytic 1860

[ICS](../../README.md) / [Analytics](README.md)

Real-time network monitoring identifies a source issuing read-only Industrial Control System (ICS) protocol requests to multiple field devices at a polling rate exceeding the legitimate Supervisory Control and Data Acquisition (SCADA) baseline, from a source not in the approved control server allowlist. Because the action is read-only, source-identity and rate deviation are the only available distinguishing signals. OT operational-fidelity gate: Do not alert on novelty, scan/read volume, or enumeration alone. Alert when the source role is not authorized for discovery/polling and the target scope, address/tag range, protocol, or rate deviates from the established operational baseline. Suppress normal SCADA/HMI/historian polling, commissioning, asset inventory, backup, diagnostics, and approved engineering activity.

## Log sources and channels

- **opc:applog** — client_id not in approved Open Platform Communications (OPC) clients issuing high-volume read requests · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **NSM:Content** — read-only function codes from source not in approved Supervisory Control and Data Acquisition (SCADA) servers at rate exceeding baseline poll rate or covering address ranges outside known tag ranges · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **ApprovedOPCClients** — Allowlist of OPC client application identities authorized to connect.
- **ApprovedSCADAServers** — IP allowlist of legitimate SCADA/HMI/historian servers authorized to poll field devices.
- **BaselinePollRate** — Measured normal polling frequency per device, derived from actual baseline traffic capture.
- **KnownTagAddressRanges** — Documented register/tag address ranges that legitimate SCADA polling actually queries.
