# AN2205 - Analytic 2205

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies a mass deauthentication event targeting multiple enrolled Industrial Control System (ICS) wireless devices simultaneously, or a wireless access point configuration change excluding enrolled device Media Access Control (MAC) address from the association list. OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0912#AN2205)

## Log sources and channels

- **networkdevice:syslog** — deauthentication targeting more than mass deauth threshold enrolled devices within deauth time window, or Media Access Control (MAC) address filter config change excluding enrolled devices, from source not in approved wireless admin list · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **ApprovedWirelessAdminList** — Accounts/sources authorized to modify wireless infrastructure configuration.
- **DeauthTimeWindow** — Time window within which multiple deauthentication events are considered a coordinated mass event.
- **MassDeauthThreshold** — Number of simultaneously deauthenticated enrolled devices that constitutes a mass event.
