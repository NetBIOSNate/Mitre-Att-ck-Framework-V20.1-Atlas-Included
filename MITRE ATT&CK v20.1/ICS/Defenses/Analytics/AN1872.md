# AN1872 - Analytic 1872

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies execution of network discovery tools (nmap, PLCScan, redpoint NSE scripts) or Industrial Control System (ICS)-specific scanners from an Industrial Control System (ICS) Windows host, from a process not associated with a recognized network management or engineering tool. OT operational-fidelity gate: Do not alert on novelty, scan/read volume, or enumeration alone. Alert when the source role is not authorized for discovery/polling and the target scope, address/tag range, protocol, or rate deviates from the established operational baseline. Suppress normal SCADA/HMI/historian polling, commissioning, asset inventory, backup, diagnostics, and approved engineering activity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0739#AN1872)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=1 of network discovery tool (nmap, PLCScan) from process not in authorized network tools list · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **ApprovedSCADAServers** — IP allowlist of legitimate engineering and SCADA systems.
- **AuthorizedNetworkTools** — Allowlist of network management/diagnostic tools authorized for use on ICS hosts.
- **DiscoveryTimeWindow** — Time window within which sequential connections across the address range are considered a single discovery sweep event.
