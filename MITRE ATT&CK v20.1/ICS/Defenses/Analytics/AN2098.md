# AN2098 - Analytic 2098

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies a Linux ICS asset bypassing designated DNS resolvers, producing tunneling-like native DNS, or connecting to unapproved DoH/DoT infrastructure from an unauthorized process/service. Require resolver-policy or asset-role violation plus corroborating process, query, or destination evidence; suppress approved package/vendor/security workflows.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0934#AN2098)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **linux:osquery** — socket_events to DNS/DoH/DoT destinations, where deployed · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **NSM:DNS** — Native DNS query/response content · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **NSM:Flow** — External DNS/HTTPS/TLS flow bypassing approved resolver/proxy · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **ApprovedResolvers** — Site DNS resolvers
- **ApprovedDoHProviders** — Permitted encrypted DNS endpoints
- **AuthorizedProcesses** — Services permitted to resolve externally
- **QueryPattern** — Tunneling-like query characteristics as corroboration
- **NoExternalConnectivityRoleList** — Assets with no legitimate external resolution
