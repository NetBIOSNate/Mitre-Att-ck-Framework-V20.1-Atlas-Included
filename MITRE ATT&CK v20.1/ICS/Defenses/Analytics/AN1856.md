# AN1856 - Analytic 1856

[ICS](../../README.md) / [Analytics](README.md)

Real-time network monitoring identifies a sustained spike in malformed or high-volume Industrial Control System (ICS) protocol traffic directed at a single field device from a source not in the approved control server list, immediately followed by that device dropping out of the supervisory poll cycle. Documented precedent: Sandworm's Industroyer malware sent a crafted 18-byte proprietary User Datagram Protocol (UDP) packet to port 50000 on Siemens Protection Technology (SIPROTEC) relays (CVE-2015-5374), causing the device to hang and require a manual reboot. OT operational-fidelity gate: Alert only when a device-specific traffic/resource threshold is exceeded and the same window shows service degradation, failed polling, device alarm/restart, resource exhaustion, or malformed/out-of-spec protocol behavior. Suppress planned load tests, maintenance, network convergence/failover, and known equipment faults after operator confirmation.

## Log sources and channels

- **netflow:ipfix** — IPFIX/NetFlow flow record (src/dst IP, src/dst port, protocol, packets/bytes/time): connection rate to device_ip exceeds Denial of Service (DoS) threshold per minute from single or distributed sources · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **operationaldb:ProcessHistory** — no new process value recorded for device_ip within 1.5x expected poll interval immediately following a flood alert · [DC0107 - Process History/Live Data](../Data%20Components/DC0107%20-%20Process%20History%20-%20Live%20Data.md)
- **NSM:Content** — malformed Protocol Data Unit (PDU) rate to device_ip exceeds threshold within detection window from source not in approved Supervisory Control and Data Acquisition (SCADA) server list · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **scada:applog** — device communication-loss alarm generated within detection window of a corresponding network flood alert · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **CPUUtilizationThreshold** — Network device CPU utilization percentage above which sustained load suggests packet-processing strain from flood traffic.
- **DoSConnectionThreshold** — Connections-per-minute threshold exceeding normal SCADA polling cadence, derived from the device's actual configured scan rate.
- **DoSDetectionWindow** — Time window over which flood rate and subsequent device silence are correlated, typically 1-5 minutes.
- **ExpectedPollInterval** — Device-specific supervisory poll interval used to determine what counts as a process historian gap.
- **InterfaceErrorThreshold** — Deviation from baseline interface error/discard rate, tuned against historical interface health data.
- **MalformedPacketThreshold** — Number of malformed/out-of-spec PDUs within the detection window constituting a flood, set above the device's documented error-tolerance baseline.
