# AN2209 - Analytic 2209

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies a process on an Industrial Control System (ICS) Windows host writing setpoint values to Open Platform Communications (OPC) Data Access (DA)/Unified Architecture (UA) tags or historian writable tags without being the recognized Supervisory Control and Data Acquisition (SCADA) or Distributed Control System (DCS) control application, with values falling outside the normal operating range. OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0776#AN2209)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **opc:applog** — write to setpoint tag from client not in approved Open Platform Communications (OPC) clients with value outside baseline value range · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **ApprovedWriteSources** — IP allowlist of sources authorized to write to parameter/setpoint registers.
- **BaselineValueRange** — Documented safe operating range for each monitored parameter.
- **ParameterDriftThreshold** — Percentage deviation from rolling baseline considered significant drift.
- **SetpointAddressRange** — Register/address ranges corresponding to parameter and setpoint values for the device type.
- **TimeWindow** — Time window over which post-write drift is measured.
