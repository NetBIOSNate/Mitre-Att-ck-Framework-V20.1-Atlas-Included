# AN2168 - Analytic 2168

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring of switch/router interface counters identifies a sudden spike in discarded or errored packets on an Industrial Control System (ICS)-facing interface combined with Central Processing Unit (CPU) utilization climbing above baseline, correlated with loss of reachability to downstream field devices on that segment within the same window. OT operational-fidelity gate: Alert only when a device-specific traffic/resource threshold is exceeded and the same window shows service degradation, failed polling, device alarm/restart, resource exhaustion, or malformed/out-of-spec protocol behavior. Suppress planned load tests, maintenance, network convergence/failover, and known equipment faults after operator confirmation.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0723#AN2168)

**Platforms**  [Network Devices](../../Platforms/Network%20Devices.md)

## Log sources and channels

- **netflow:ipfix** — IPFIX/NetFlow flow record (src/dst IP, src/dst port, protocol, packets/bytes/time): flow volume to Industrial Control Systems (ICS) device subnet exceeds Denial of Service (DoS) flow threshold per minute · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **networkdevice:snmp** — ifInErrors or ifOutDiscards rate exceeds baseline combined with cpu5min exceeding utilization threshold · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **CPUUtilizationThreshold** — Network device CPU utilization percentage above which sustained load suggests packet-processing strain from flood traffic.
- **DoSConnectionThreshold** — Connections-per-minute threshold exceeding normal SCADA polling cadence, derived from the device's actual configured scan rate.
- **DoSDetectionWindow** — Time window over which flood rate and subsequent device silence are correlated, typically 1-5 minutes.
- **ExpectedPollInterval** — Device-specific supervisory poll interval used to determine what counts as a process historian gap.
- **InterfaceErrorThreshold** — Deviation from baseline interface error/discard rate, tuned against historical interface health data.
- **MalformedPacketThreshold** — Number of malformed/out-of-spec PDUs within the detection window constituting a flood, set above the device's documented error-tolerance baseline.
