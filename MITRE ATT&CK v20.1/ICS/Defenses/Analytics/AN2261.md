# AN2261 - Analytic 2261

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies an Industrial Control System (ICS) operator/service account being granted elevated Windows privileges without a corresponding administrative logon event, or a process crash in an Industrial Control System (ICS) vendor application immediately followed by a new process inheriting elevated token privileges. Documented in PIPEDREAM's LAZYCARGO component, which drops and exploits a known vulnerable ASRock driver to elevate credentials. OT operational-fidelity gate: Alert only when execution violates an approved signer/hash/path/parent/process or tool allowlist, or originates from an unauthorized user/tool, and is tied to an OT asset or follow-on OT-relevant action. Suppress vendor-signed software, approved engineering utilities, diagnostics, patching, backup, and documented maintenance.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0738#AN2261)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — Windows Security Event ID 4624/4625: EventCode=4672 for Industrial Control Systems (ICS)-role account without corresponding admin-group logon in preceding session · [DC0088 - Logon Session Metadata](../Data%20Components/DC0088%20-%20Logon%20Session%20Metadata.md)
- **WinEventLog:Sysmon** — EventCode=6 of a known vulnerable third-party driver immediately preceding privilege escalation indicators · [DC0079 - Driver Load](../Data%20Components/DC0079%20-%20Driver%20Load.md)

## Mutable elements

- **ExploitCrashCorrelationWindow** — Time window within which a device/process crash and subsequent privileged action are considered correlated.
- **KnownVulnerableDriverSignatures** — Documented hash/name signatures of known vulnerable drivers exploitable for privilege escalation (BYOVD technique).
