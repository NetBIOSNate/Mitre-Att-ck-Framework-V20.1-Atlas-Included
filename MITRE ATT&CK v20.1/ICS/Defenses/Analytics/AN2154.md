# AN2154 - Analytic 2154

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies ptrace syscalls or /proc/pid/mem write operations targeting Industrial Control System (ICS) service processes from a process that is not a debugger or vendor diagnostic tool. OT operational-fidelity gate: Alert only when execution violates an approved signer/hash/path/parent/process or tool allowlist, or originates from an unauthorized user/tool, and is tied to an OT asset or follow-on OT-relevant action. Suppress vendor-signed software, approved engineering utilities, diagnostics, patching, backup, and documented maintenance.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0795#AN2154)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — Linux Audit SYSCALL/EXECVE/SOCKADDR records (configured audit rule): syscall=ptrace/process_vm_readv; process accesses an ICS service process PID from an image or UID not in the debugger/diagnostic allowlist · [DC0035 - Process Access](../Data%20Components/DC0035%20-%20Process%20Access.md)

## Mutable elements

- **ExploitCrashCorrelationWindow** — Time window correlating a memory access event with a subsequent crash.
- **TrustedSecurityToolList** — Allowlist of legitimate security/diagnostic tools authorized to perform cross-process memory access.
