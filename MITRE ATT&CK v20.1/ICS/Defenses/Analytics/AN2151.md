# AN2151 - Analytic 2151

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies a Linux process opening Industrial Control System (ICS) protocol master connections to multiple field device Internet Protocol (IP) addresses, from a host that is not the authorized Supervisory Control and Data Acquisition (SCADA) server. OT operational-fidelity gate: Alert only when the master/station identity or source is not authorized for the target device and command function, or when a normally authorized master violates its configured role/sequence and produces a corroborating device/process-state change. Suppress legitimate redundancy/failover, hot-standby promotion, commissioning, and approved engineering master activity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0792#AN2151)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — Linux Audit SYSCALL/EXECVE/SOCKADDR records (configured audit rule): connect syscalls show a host outside the approved SCADA/master set opening ICS-protocol connections to multiple field devices · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **ApprovedSCADAServers** — IP/identity allowlist of legitimate master/control server systems.
- **RegisteredMasterAddresses** — Inventory of authorized station/master addresses for protocols using logical addressing distinct from IP.
- **RogueMasterTimeWindow** — Time window within which command traffic to multiple devices from a single unrecognized source is considered a coordinated rogue master event.
