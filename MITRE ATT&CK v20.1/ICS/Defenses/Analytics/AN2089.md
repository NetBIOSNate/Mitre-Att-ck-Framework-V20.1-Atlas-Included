# AN2089 - Analytic 2089

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies network-device CLI or underlying Unix-like shell access from an unauthorized management source/account, followed by privileged or configuration commands outside an approved change window. Do not alert solely on CLI use. Require violation of the management matrix, command authorization, or change-control context.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0931#AN2089)

**Platforms**  [Network Devices](../../Platforms/Network%20Devices.md)

## Log sources and channels

- **networkdevice:syslog** — CLI command audit / configuration command history · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **networkdevice:auth** — SSH/Telnet/console authentication and session creation · [DC0067 - Logon Session Creation](../Data%20Components/DC0067%20-%20Logon%20Session%20Creation.md)

## Mutable elements

- **ApprovedManagementSources ** — Jump hosts, management VLANs, and administrative CIDRs 
- **AuthorizedAccounts ** — Named/network-service administrative accounts 
- **HighRiskCommands ** — Enable/configure, ACL, route, NAT, firmware, file transfer, shell escape 
- **ChangeWindow ** — Approved network maintenance/change ticket window
