# AN2099 - Analytic 2099

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies an ICS Windows asset bypassing designated DNS resolvers, generating tunneling-like DNS content, or establishing HTTPS/TLS sessions to unapproved DoH resolver/API infrastructure from a process not authorized for encrypted DNS. Require a resolver-policy or asset-role violation plus suspicious query/content/process/destination evidence; suppress approved browsers, security products, vendor cloud services, and documented maintenance.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0934#AN2099)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=3; connection to DNS/DoH destination with process identity · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **NSM:DNS** — Native DNS query/response content: long/encoded labels, TXT use, unusual query structure · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **NSM:Flow** — Direct external DNS or HTTPS/TLS flow bypassing designated resolver/proxy · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **ApprovedResolvers** — Site DNS resolvers and forwarding architecture
- **ApprovedDoHProviders** — Explicitly permitted DoH/DoT endpoints, if any
- **AuthorizedDoHProcesses** — Browsers/security/vendor software permitted to use encrypted DNS
- **QueryPattern** — Length/entropy/type/frequency patterns used only as corroboration
- **NoExternalConnectivityRoleList** — ICS assets that should not resolve/connect externally
