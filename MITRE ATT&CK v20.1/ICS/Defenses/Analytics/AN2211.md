# AN2211 - Analytic 2211

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies an Industrial Control System (ICS) protocol write specifically targeting alarm threshold/deadband configuration registers from a source not in the approved engineering list, where the new value widens the alarm deadband or shifts the trip point beyond the safe operating envelope, without operator acknowledgment. OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0777#AN2211)

## Log sources and channels

- **NSM:Content** — write to alarm threshold address range from source not in approved write sources with new value outside safe alarm threshold range · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **AlarmThresholdAddressRange** — Register addresses specifically corresponding to alarm threshold/deadband configuration.
- **ApprovedWriteSources** — IP allowlist of sources authorized to modify alarm configuration.
- **SafeAlarmThresholdRange** — Documented safe range for alarm thresholds per parameter.
