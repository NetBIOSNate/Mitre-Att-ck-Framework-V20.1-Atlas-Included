# AN1898 - Analytic 1898

[ICS](../../README.md) / [Analytics](README.md)

Configured Windows object-access monitoring identifies a write to an Industrial Control System (ICS) engineering project file by a process that is not the recognized vendor engineering software, or by the vendor engineering software immediately after loading a project file from an untrusted source. Documented mechanism in Havex (trojanized vendor software/installers distributed via compromised vendor websites). OT operational-fidelity gate: Alert only when execution violates an approved signer/hash/path/parent/process or tool allowlist, or originates from an unauthorized user/tool, and is tied to an OT asset or follow-on OT-relevant action. Suppress vendor-signed software, approved engineering utilities, diagnostics, patching, backup, and documented maintenance. Collection requirement: use Windows Security Event ID 4663 with Object Access auditing and SACLs on approved project repositories; Sysmon FileCreate events can corroborate writes/overwrites but do not report generic file-open/read activity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0766#AN1898)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — Windows Security Event ID 4663 (requires Object Access auditing/SACL): engineering process reads/opens project file from unapproved repository/removable-media/network-share path · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **WinEventLog:Sysmon** — Microsoft-Windows-Sysmon/Operational Event ID 11 FileCreate/overwrite or Event ID 2 FileCreateTime, as applicable: Engineering tool process opens project file from path not in approved project repository (removable media, email attachment cache, untrusted network share) · [DC0059 - File Metadata](../Data%20Components/DC0059%20-%20File%20Metadata.md)

## Mutable elements

- **ApprovedProjectRepository** — Documented, trusted source location(s) for project files.
- **AuthorizedEngineeringTools** — Allowlist of vendor engineering software processes authorized to modify project files.
- **ProjectFileExtensions** — File extensions used by ICS engineering project files for in-use vendor platforms.
