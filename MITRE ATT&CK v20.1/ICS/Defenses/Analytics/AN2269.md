# AN2269 - Analytic 2269

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies a Windows process enabling promiscuous or monitor mode on a wireless adapter (netsh wlan, WinPcap/Npcap driver load, etc.) on an Industrial Control System (ICS) workstation that is not a designated wireless management station, indicating preparation for wireless interception consistent with this technique's reconnaissance phase. OT operational-fidelity gate: Alert only when the account/device/session violates the approved identity + source host/jump path/zone policy and is corroborated by access to a protected OT asset, execution, configuration change, or another security-relevant follow-on event. Suppress approved shift activity, vendor support, break-glass use, commissioning, and documented remote-access windows.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0726#AN2269)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=6 for wireless capture driver on host not in designated wireless management station list · [DC0079 - Driver Load](../Data%20Components/DC0079%20-%20Driver%20Load.md)

## Mutable elements

- **ApprovedWirelessDeviceInventory** — MAC/certificate inventory of devices authorized to associate with ICS wireless infrastructure.
- **DesignatedWirelessManagementStations** — Hosts authorized to legitimately enable wireless monitor mode for diagnostics.
- **WirelessOnboardWindow** — Time window after wireless association within which ICS-directed traffic is considered part of the same onboarding event.
