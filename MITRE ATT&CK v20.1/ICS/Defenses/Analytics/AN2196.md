# AN2196 - Analytic 2196

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies network device credential changes such as Authentication, Authorization, and Accounting (AAA) password modification or Simple Network Management Protocol (SNMP) community string modification from a source not in the approved Network Management System (NMS) Classless Inter-Domain Routing (CIDR) subnet, corroborated by syslog showing authentication failures from legitimate NMS systems following the change. OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0771#AN2196)

## Log sources and channels

## Mutable elements

- **AuthorizedCredentialAdmins** — Accounts authorized to change credentials for ICS service and operator accounts.
- **CredentialChangeImpactWindow** — Time window after a credential change within which a service authentication failure is considered directly connected.
- **CredentialRotationSchedule** — Documented schedule for routine credential rotation.
