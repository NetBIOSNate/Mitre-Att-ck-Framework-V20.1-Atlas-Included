# AN2086 - Analytic 2086

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies direct PowerShell execution or indirect System.Management.Automation use with an unexpected parent, encoded/obfuscated arguments, unusual module loading, or execution followed by OT-relevant network/process activity. Alert only when the interpreter is not part of the asset's approved software/automation baseline or its execution context violates an approved signer/hash/path/parent/user rule, and require OT-relevant corroboration such as access to engineering files, ICS software/API use, communications with protected OT assets, configuration change, or another suspicious follow-on behavior. Suppress documented vendor software, engineering workflows, diagnostics, backup, patching, and approved maintenance.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0929#AN2086)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=1; powershell/pwsh or suspicious parent-child chain · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:PowerShell** — EventCode=4103/4104/4105/4106; command/script-block content  · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **WinEventLog:PowerShell** — EventCode=400/403; engine lifecycle/context · [DC0034 - Process Metadata](../Data%20Components/DC0034%20-%20Process%20Metadata.md)
- **WinEventLog:Sysmon** — EventCode=7; System.Management.Automation or unusual PowerShell-related modules · [DC0016 - Module Load](../Data%20Components/DC0016%20-%20Module%20Load.md)

## Mutable elements

- **ApprovedPowerShellUse** — Approved scripts, modules, hosts, service accounts, and vendor workflows
- **ParentProcessName** — Expected parents for engineering/administrative PowerShell
- **CommandLinePattern** — Encoded, hidden, download, reflection, remoting, or ICS/API-related arguments
- **MaintenanceWindow** — Approved change/diagnostic periods
- **ProtectedOTDestinations** — Controllers, HMIs, historians, gateways, and engineering assets where follow-on activity raises fidelity
