# AN2258 - Analytic 2258

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies successful SSH or application authentication using credentials matching known default or hardcoded vendor passwords on Industrial Control System (ICS) Linux assets. OT operational-fidelity gate: Alert only when the account/device/session violates the approved identity + source host/jump path/zone policy and is corroborated by access to a protected OT asset, execution, configuration change, or another security-relevant follow-on event. Suppress approved shift activity, vendor support, break-glass use, commissioning, and documented remote-access windows.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0905#AN2258)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **syslog:auth** — sshd Accepted for username matching default or hardcoded credential patterns from source not in approved admin Classless Inter-Domain Routing (CIDR) subnet · [DC0067 - Logon Session Creation](../Data%20Components/DC0067%20-%20Logon%20Session%20Creation.md)

## Mutable elements

- **DefaultVendorCredentialList** — Documented default username/password combinations for all device models in the environment.
- **EngineeringWorkstationList** — IP allowlist of legitimate authentication sources.
- **KnownHardcodedCredentialPatterns** — Documented hardcoded credential values for in-use ICS products.
