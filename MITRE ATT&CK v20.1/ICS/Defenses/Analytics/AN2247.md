# AN2247 - Analytic 2247

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies Industrial Control System (ICS) protocol sessions that bulk-read configuration data, program blocks, or data record objects from field devices, covering address ranges never queried by legitimate Supervisory Control and Data Acquisition (SCADA), suggesting systematic extraction of ICS design documentation. OT operational-fidelity gate: Do not alert on novelty, scan/read volume, or enumeration alone. Alert when the source role is not authorized for discovery/polling and the target scope, address/tag range, protocol, or rate deviates from the established operational baseline. Suppress normal SCADA/HMI/historian polling, commissioning, asset inventory, backup, diagnostics, and approved engineering activity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0754#AN2247)

## Mutable elements

- **ApprovedHistorianClients** — Allowlist of applications/accounts authorized to perform bulk historian queries.
- **AuthorizedEngineerAccounts** — Allowlist of accounts with documented engineering roles authorized to access ICS documentation repositories.
- **BulkDocumentAccessThreshold** — File count threshold distinguishing bulk reconnaissance from routine reference lookups.
- **BulkQueryThreshold** — Row count threshold for historian queries considered bulk export.
- **InformationRepositoryTimeWindow** — Time window within which sequential file accesses are considered part of a single bulk collection event.
