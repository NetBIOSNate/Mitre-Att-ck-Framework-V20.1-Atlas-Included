# AN2158 - Analytic 2158

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies a firmware update tool on an Industrial Control System (ICS) Linux engineering host initiating firmware-update mode activation outside a scheduled maintenance window, by a User Identifier (UID) not in the approved firmware manager UIDs. OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0802#AN2158)

## Log sources and channels

- **auditd:SYSCALL** — Linux Audit SYSCALL/EXECVE/SOCKADDR records (configured audit rule): syscall=execve; firmware-update utility invoked outside the approved maintenance window or by a UID not in the authorized firmware-management set · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **AlarmSilenceGracePeriod** — Time window within which alarm telemetry going silent following a mode-change message is considered directly connected.
- **AuthorizedFirmwareManagers** — Accounts authorized to perform firmware update mode activation.
- **ChangeControlWindow** — Scheduled maintenance periods during which firmware update mode activation is authorized.
- **EngineeringWorkstationList** — IP allowlist of workstations authorized to activate firmware update mode.
- **MaintenanceWindowSchedule** — Recurring scheduled periods when firmware update activities are expected.
