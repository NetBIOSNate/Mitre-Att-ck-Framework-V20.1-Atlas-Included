# AN2103 - Analytic 2103

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies an embedded OT/IoT device establishing MQTT/AMQP/DDS communication with a broker/service outside its device-specific profile, using an unexpected client identity/topic, or crossing an unauthorized zone boundary. Fixed-function device behavior should be compared to the documented broker/topic/destination profile rather than a generic anomaly threshold.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0935#AN2103)

**Platforms**  [Embedded](../../Platforms/Embedded.md)

## Log sources and channels

- **NSM:Content** — Pub/sub protocol, client ID, topic/queue and message metadata when observable · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **NSM:Flow** — Device-to-broker flow metadata · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **NSM:Connections** — New device-to-broker relationship outside documented profile · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **DeviceBrokerProfile** — Expected broker(s) for each device/model/site
- **ApprovedClientIDs** — Expected client identity/certificate where observable
- **ApprovedTopics** — Expected publish/subscribe topic namespace
- **ApprovedCommunicationMatrix** — Expected telemetry cadence used only as corroboration
- **ExpectedReportingInterval** — Expected telemetry cadence used only as corroboration
