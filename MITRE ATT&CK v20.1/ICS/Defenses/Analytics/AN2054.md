# AN2054 - Analytic 2054

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies a Windows network-adapter disable or administrative interface-down event on an ICS gateway or protocol-converter host outside the approved network-maintenance window. OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0911#AN2054)

**Platforms**  [Windows](../../Platforms/Windows.md)
