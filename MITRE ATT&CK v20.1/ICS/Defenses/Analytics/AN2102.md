# AN2102 - Analytic 2102

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies MQTT/AMQP/DDS sessions crossing an unexpected zone boundary, connecting an ICS client to an unapproved broker/service, or using client/topic/message behavior inconsistent with the documented pub/sub architecture. Require topology/identity/topic/destination violation; periodicity alone is not sufficient.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0935#AN2102)

**Platforms**  [Network Devices](../../Platforms/Network%20Devices.md)

## Log sources and channels

- **NSM:Content** — Protocol identification; MQTT CONNECT/SUBSCRIBE/PUBLISH, AMQP/DDS metadata where parsable · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **NSM:Flow** — Source/destination/port/session metadata · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **NetworkDevice:Syslog** — Permitted/denied connection creation where network devices record it · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **ApprovedBrokers** — Broker IP/FQDN/service inventory
- **ApprovedClientIDs** — Expected MQTT/AMQP client identities where observable
- **ApprovedTopics** — Expected publish/subscribe topic namespaces
- **ApprovedCommunicationMatrix** — Allowed zone/client/broker relationships
- **TLSProfile** — Expected encrypted/unencrypted protocol use and certificate identities
