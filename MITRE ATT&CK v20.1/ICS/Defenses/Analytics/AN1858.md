# AN1858 - Analytic 1858

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies a process or scheduled task whose displayed name matches a known Industrial Control System (ICS) vendor application but whose on-disk binary hash or file path does not match the vendor-signed baseline. The mismatch -- name says one thing, binary integrity says another -- is the defining signal. OT operational-fidelity gate: Alert only when execution violates an approved signer/hash/path/parent/process or tool allowlist, or originates from an unauthorized user/tool, and is tied to an OT asset or follow-on OT-relevant action. Suppress vendor-signed software, approved engineering utilities, diagnostics, patching, backup, and documented maintenance.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0725#AN1858)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — Windows Security Event ID 4698/4702: EventCode=4698 referencing Industrial Control Systems (ICS) vendor binary name from unauthorized process · [DC0001 - Scheduled Job Creation](../Data%20Components/DC0001%20-%20Scheduled%20Job%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=11 matching Industrial Control Systems (ICS) vendor binary name in a path outside vendor install paths · [DC0059 - File Metadata](../Data%20Components/DC0059%20-%20File%20Metadata.md)
- **WinEventLog:Sysmon** — EventCode=1 where image filename matches Industrial Control Systems (ICS) vendor process names but hash not in vendor hash baseline or current directory outside vendor install paths · [DC0034 - Process Metadata](../Data%20Components/DC0034%20-%20Process%20Metadata.md)
- **WinEventLog:System** — EventCode=7045 where ServiceName/ImagePath references Industrial Control Systems (ICS) vendor application with hash/path mismatch · [DC0060 - Service Creation](../Data%20Components/DC0060%20-%20Service%20Creation.md)

## Mutable elements

- **AssetInventoryDeviceTypes** — Maintained inventory of expected vendor/product identity strings per enrolled device IP.
- **ICSDaemonNames** — List of expected Linux ICS service daemon process names.
- **ICSVendorProcessNames** — List of known ICS vendor executable names used as the masquerade-target watchlist.
- **VendorHashBaseline** — Cryptographic hash inventory for all legitimate versions of vendor ICS binaries, updated on every patch cycle.
- **VendorInstallPaths** — Authorized installation directories for each ICS vendor application.
