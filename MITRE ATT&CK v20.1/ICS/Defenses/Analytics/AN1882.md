# AN1882 - Analytic 1882

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies an audit log clearing event or deletion/truncation of an Industrial Control System (ICS) vendor application log file, immediately preceded by other suspicious activity on the same host within a short lookback window. Documented in the CaddyWiper deployment alongside Industroyer2, explicitly intended to destroy evidence and slow forensic recovery. OT operational-fidelity gate: Alert only when execution violates an approved signer/hash/path/parent/process or tool allowlist, or originates from an unauthorized user/tool, and is tied to an OT asset or follow-on OT-relevant action. Suppress vendor-signed software, approved engineering utilities, diagnostics, patching, backup, and documented maintenance.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0750#AN1882)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — Windows Security Event ID 4688: EventCode=1102 correlated with any other Medium+ confidence alert on the same host within log clear lookback window · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **WinEventLog:Sysmon** — EventCode=23 or wevtutil/Clear-EventLog invocation deleting Industrial Control Systems (ICS) vendor application log file by process not in authorized log management tools · [DC0040 - File Deletion](../Data%20Components/DC0040%20-%20File%20Deletion.md)
- **WinEventLog:System** — EventCode=104 outside scheduled log rotation window · [DC0040 - File Deletion](../Data%20Components/DC0040%20-%20File%20Deletion.md)

## Mutable elements

- **AuthorizedLogManagementTools** — Allowlist of processes/accounts authorized to delete or truncate ICS application logs.
- **LogClearLookbackWindow** — Time window prior to a log-clear event within which other suspicious activity is considered correlated.
- **ScheduledLogRotationWindow** — Documented schedule for legitimate, automated log rotation/archival.
