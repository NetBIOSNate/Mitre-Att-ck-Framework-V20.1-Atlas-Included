# AN1866 - Analytic 1866

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies a Universal Serial Bus (USB) storage device insertion event on an Industrial Control System (ICS) engineering or Human-Machine Interface (HMI) workstation where the device's hardware identifier (ID) is not in the authorized USB allowlist, immediately followed by process execution from the removable drive's path. Documented as the primary infection vector for Stuxnet, which specifically targeted air-gapped Siemens engineering environments via infected USB drives. OT operational-fidelity gate: Alert only when the account/device/session violates the approved identity + source host/jump path/zone policy and is corroborated by access to a protected OT asset, execution, configuration change, or another security-relevant follow-on event. Suppress approved shift activity, vendor support, break-glass use, commissioning, and documented remote-access windows.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0733#AN1866)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=11 from removable media path to Industrial Control Systems (ICS) engineering working directory · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=1 with image path on removable drive letter within Universal Serial Bus (USB) execution window of insertion event · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:System** — EventCode=20001, 2003 not in authorized Universal Serial Bus (USB) allowlist on Industrial Control Systems (ICS) host · [DC0042 - Drive Creation](../Data%20Components/DC0042%20-%20Drive%20Creation.md)

## Mutable elements

- **AuthorizedUSBAllowlist** — Hardware ID inventory of USB storage devices authorized for use on ICS engineering and HMI workstations.
- **EngineeringWorkstationList** — IP allowlist of workstations authorized to perform file transfers to field devices.
- **USBExecutionWindow** — Time window after device insertion/mount within which process execution is considered directly connected to the insertion event.
