# AN1902 - Analytic 1902

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies execution of network enumeration commands (netstat, arp -a, Get-NetTCPConnection) on an Industrial Control System (ICS) host from an account not associated with documented network administration, where multiple such commands execute in sequence within a short window. OT operational-fidelity gate: Do not alert on novelty, scan/read volume, or enumeration alone. Alert when the source role is not authorized for discovery/polling and the target scope, address/tag range, protocol, or rate deviates from the established operational baseline. Suppress normal SCADA/HMI/historian polling, commissioning, asset inventory, backup, diagnostics, and approved engineering activity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0770#AN1902)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=1 network enumeration command from account not in approved network admins, with more than one distinct command within enumeration time window · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **ApprovedNetworkAdmins** — Accounts with documented network administration responsibilities.
- **ApprovedSCADAServers** — IP allowlist of legitimate sources for topology queries.
- **EnumerationTimeWindow** — Time window within which multiple enumeration commands are considered a systematic mapping sequence.
