# AN2108 - Analytic 2108

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies a write to alarm configuration files or database tables on an Human-Machine Interface (HMI)/alarm server by a process other than the recognized alarm management application, or an alarm-class-disable Application Programming Interface (API) call logged without a corresponding operator session ID in the HMI audit trail. OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0728#AN2108)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **alarmserver:ApplicationLog** — alarm class disabled or suppressed Application Programming Interface (API) event logged without operator_id field populated · [DC0108 - Device Alarm](../Data%20Components/DC0108%20-%20Device%20Alarm.md)
- **WinEventLog:Sysmon** — EventCode=11 of alarm config paths by image not in Human-Machine Interface (HMI) alarm parent allowlist · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)

## Mutable elements

- **AlarmConfigAddressRange** — Protocol register/address ranges corresponding to alarm threshold and configuration values per device type.
- **AlarmConfigPaths** — File system paths for alarm configuration files/databases on Windows alarm servers.
- **ApprovedWriteSources** — IP allowlist of sources authorized to write to ICS devices, including alarm configuration.
- **HMIAlarmParentAllowlist** — Allowlist of recognized HMI/alarm management application processes authorized to modify alarm configuration.
- **SuppressGracePeriod** — Time window within which a legitimate operator acknowledgment is expected following an alarm status change, typically 10-30 seconds.
