# AN1881 - Analytic 1881

[ICS](../../README.md) / [Analytics](README.md)

Monitor Windows Security Event ID 4663 on explicitly audited ICS data paths and correlate repeated ReadData/ListDirectory access across multiple sensitive files or directories by an account/process outside the approved engineering, backup, or application baseline. This requires Object Access auditing and SACLs on the monitored paths; Sysmon does not provide generic file-read telemetry. Alert when the bulk-read pattern occurs outside an approved backup/export window or is followed by staging, compression, or network transfer.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0749#AN1881)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — Sequential file reads across multiple Industrial Control Systems (ICS) data paths by image not in authorized ICS applications, exceeding bulk access threshold within a short window · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **WinEventLog:Sysmon** — EventCode=1 of archive utility immediately following bulk file access pattern from same parent process tree · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **AuthorizedICSApplications** — Allowlist of processes expected to perform legitimate bulk reads of ICS data.
- **BulkAccessThreshold** — Number of distinct files read within the detection window that constitutes bulk collection.
- **ICSDataPaths** — File system paths containing ICS configuration, project, and sensitive operational data.
