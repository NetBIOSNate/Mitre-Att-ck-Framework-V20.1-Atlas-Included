# AN2217 - Analytic 2217

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies field device access (Industrial Control System (ICS) protocol sessions, management interface authentication) using credentials or authentication tokens associated with a legitimate engineering account, but from a source Internet Protocol (IP) address or Media Access Control (MAC) address not enrolled as an authorized engineering workstation, where the authenticated session subsequently performs write operations the credential owner has not acknowledged via change control. OT operational-fidelity gate: Alert only when the account/device/session violates the approved identity + source host/jump path/zone policy and is corroborated by access to a protected OT asset, execution, configuration change, or another security-relevant follow-on event. Suppress approved shift activity, vendor support, break-glass use, commissioning, and documented remote-access windows.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0724#AN2217)

## Log sources and channels

- **NSM:Content** — device authentication session from source Media Access Control (MAC)/Internet Protocol (IP) address not enrolled as authorized engineering workstation, with valid credential · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **ApprovedAdminCIDR** — IP ranges from which SSH administrative access to ICS Linux assets is authorized.
- **ApprovedHostList** — Inventory of workstations/jump hosts from which ICS-role accounts are authorized to authenticate.
- **ApprovedNMSCIDR** — IP ranges from which network device administrative access is authorized.
- **AuthToDeviceWindow** — Time window after anomalous logon within which device-subnet connection is considered correlated, typically 5-15 minutes.
- **ICSRoleAccountPatterns** — Naming convention or group-membership pattern identifying accounts with engineering, operator, or ICS service roles.
- **OfficeHoursWindow** — Defined normal working hours for interactive ICS engineering activity, widened for 24/7 shift-based operations.
