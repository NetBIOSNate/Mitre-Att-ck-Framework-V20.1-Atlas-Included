# AN2248 - Analytic 2248

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies an Industrial Control System (ICS) protocol command sequence that erases device memory, from a source not in the approved engineering workstation list, where the device subsequently becomes unresponsive or requires re-commissioning. OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

## Mutable elements

- **AuthorizedDataManagementTools** — Allowlist of backup/archival/retention management tools authorized to perform bulk file operations.
- **BulkDeletionThreshold** — File count threshold across monitored directories that distinguishes bulk destruction from routine cleanup.
- **DataDestructionTimeWindow** — Time window over which bulk deletion activity is measured.
- **EngineeringWorkstationList** — IP allowlist of workstations authorized to issue memory erase commands.
- **WiperCrashWindow** — Time window after bulk deletion within which a system crash is considered part of the same destructive event.
