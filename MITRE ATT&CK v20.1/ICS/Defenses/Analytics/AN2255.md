# AN2255 - Analytic 2255

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies successful Secure Shell (SSH) or application authentication using credentials matching known default vendor passwords on Industrial Control System (ICS) Linux assets. OT operational-fidelity gate: Alert only when the account/device/session violates the approved identity + source host/jump path/zone policy and is corroborated by access to a protected OT asset, execution, configuration change, or another security-relevant follow-on event. Suppress approved shift activity, vendor support, break-glass use, commissioning, and documented remote-access windows.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0756#AN2255)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Mutable elements

- **EngineeringWorkstationList** — IP allowlist of legitimate authentication sources.
