# AN1926 - Analytic 1926

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies a Windows process generating Industrial Control System (ICS) command messages to field device tags representing physical outputs, from a process that is not the recognized Supervisory Control and Data Acquisition (SCADA) or Distributed Control System (DCS) control application, targeting safety-critical output tags. OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0794#AN1926)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **opc:applog** — command call to field device output tag from process not matching recognized Supervisory Control and Data Acquisition (SCADA)/Distributed Control System (DCS) control application · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **ApprovedSCADAServers** — IP allowlist of legitimate control sources.
- **RapidToggleWindow** — Time window within which multiple safety-critical output changes are considered a coordinated event.
- **SafetyCriticalOutputAddresses** — Documented register/IOA addresses corresponding to safety-critical outputs per device.
