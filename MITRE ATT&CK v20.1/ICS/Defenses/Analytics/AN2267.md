# AN2267 - Analytic 2267

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies Windows firewall rule additions blocking Industrial Control System (ICS) protocol ports on ICS gateway or server hosts. OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0910#AN2267)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — Windows Security Windows Filtering Platform / Firewall audit events (policy-dependent): Windows Firewall rule added blocking Industrial Control Systems (ICS) protocol ports by account not in authorized firewall admins · [DC0053 - Firewall Metadata](../Data%20Components/DC0053%20-%20Firewall%20Metadata.md)

## Mutable elements

- **ApprovedNMSCIDR** — IP ranges authorized for network infrastructure configuration changes.
- **ChangeControlWindow** — Scheduled maintenance periods during which connectivity-affecting changes are authorized.
- **CommBlockCorrelationWindow** — Time window correlating a configuration change with subsequent communication loss.
