# AN2259 - Analytic 2259

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies a vendor firmware update utility executing outside a scheduled maintenance window or invoked by an account not in the approved firmware management role, immediately followed by a network session to a field device IP on its firmware protocol port. OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0731#AN2259)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **engineeringworkstation:ApplicationLog** — firmware session initiated outside maintenance window schedule without change ticket reference · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **WinEventLog:Sysmon** — EventCode=1 firmware-update utility spawned by an account outside the authorized firmware-management set or outside the approved maintenance window · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **AuthorizedFirmwareInventory** — Cryptographic hash inventory of authorized firmware versions per device model.
- **AuthorizedFirmwareManagers** — Accounts authorized to perform firmware update operations.
- **ChangeControlWindow** — Scheduled maintenance periods during which firmware updates are authorized.
- **EngineeringWorkstationList** — IP allowlist of workstations authorized to perform firmware updates.
- **FirmwareSessionSizeThreshold** — Minimum byte count for a session to be considered a firmware transfer rather than routine configuration traffic, derived from known firmware image sizes.
- **FirmwareUpdateWindow** — Time window within which a device reboot following a large session is considered part of the same firmware update event.
- **MaintenanceWindowSchedule** — Recurring scheduled periods when firmware updates are expected to occur.
