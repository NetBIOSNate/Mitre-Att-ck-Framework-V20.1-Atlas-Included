# AN2200 - Analytic 2200

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies configuration changes to serial server or terminal server devices that alter serial port parameters for ports connected to field devices. OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.
