# AN2229 - Analytic 2229

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies an Industrial Control System (ICS) protocol file-transfer service placing a file on a field device from a source not in the approved engineering workstation list, where the transferred filename pattern matches firmware images or executable payloads inconsistent with the device's normal data exchange profile. OT operational-fidelity gate: Alert only when execution violates an approved signer/hash/path/parent/process or tool allowlist, or originates from an unauthorized user/tool, and is tied to an OT asset or follow-on OT-relevant action. Suppress vendor-signed software, approved engineering utilities, diagnostics, patching, backup, and documented maintenance.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0745#AN2229)

**Platforms**  [Embedded](../../Platforms/Embedded.md)

## Log sources and channels

- **otids:ProtocolDecoder** — Decoded DNP3/IEC 61850 file-transfer transaction: source/destination and file/object identifier where exposed; correlate with approved engineering source and change window · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **AuthorizedFileSources** — Allowlist of network shares/hosts authorized to write executable or script files to ICS Windows assets.
- **EngineeringWorkstationList** — IP allowlist of workstations authorized to perform file transfers to field devices.
- **SuspiciousFilePatterns** — Filename/extension patterns inconsistent with the device's normal configuration exchange profile.
- **ToolTransferWindow** — Time window after file creation within which execution is considered directly connected to the transfer event.
