# AN2203 - Analytic 2203

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies authentication attempts against Industrial Control System (ICS) network device management interfaces using default or hardcoded vendor credentials from sources not in the approved Network Management System (NMS) Classless Inter-Domain Routing (CIDR) subnet. OT operational-fidelity gate: Alert only when the account/device/session violates the approved identity + source host/jump path/zone policy and is corroborated by access to a protected OT asset, execution, configuration change, or another security-relevant follow-on event. Suppress approved shift activity, vendor support, break-glass use, commissioning, and documented remote-access windows.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0905#AN2203)

## Log sources and channels

- **networkdevice:syslog** — Device authentication/audit log: successful authentication using a default/hardcoded/prohibited account from a non-approved management source · [DC0002 - User Account Authentication](../Data%20Components/DC0002%20-%20User%20Account%20Authentication.md)

## Mutable elements

- **DefaultVendorCredentialList** — Documented default username/password combinations for all device models in the environment.
- **EngineeringWorkstationList** — IP allowlist of legitimate authentication sources.
- **KnownHardcodedCredentialPatterns** — Documented hardcoded credential values for in-use ICS products.
