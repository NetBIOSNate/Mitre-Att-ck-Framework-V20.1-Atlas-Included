# AN2208 - Analytic 2208

[ICS](../../README.md) / [Analytics](README.md)

Monitor OPC UA server audit events for state-changing Write or Method service invocations and compare ClientUserId, ClientApplicationUri, SourceNode/MethodId, status, and arguments with the approved client/method baseline. For servers that support auditing, AuditWriteUpdateEventType and AuditUpdateMethodEventType provide an analyst-visible record of writes and state-changing method calls. Alert on successful or attempted control operations from unapproved clients/users or against methods/nodes outside the documented engineering workflow; do not describe this as Windows OS API telemetry.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0742#AN2208)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **opcua:AuditEvent** — OPC UA AuditUpdateMethodEventType/AuditWriteUpdateEventType: ClientUserId, ClientApplicationUri, SourceNode/MethodId, Status and arguments for a state-changing method/write · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **WinEventLog:Sysmon** — EventCode=7 where an ICS/vendor DLL is loaded by an image outside the authorized ICS application baseline · [DC0016 - Module Load](../Data%20Components/DC0016%20-%20Module%20Load.md)

## Mutable elements

- **ApprovedApplicationList** — Allowlist of application identities authorized to issue OPC UA or IEC 61850 write/control service requests.
- **ApprovedOPCClients** — Allowlist of OPC client application identities authorized to invoke write/control methods.
- **AuthorizedICSApplications** — Allowlist of process executables permitted to load ICS vendor automation API libraries.
