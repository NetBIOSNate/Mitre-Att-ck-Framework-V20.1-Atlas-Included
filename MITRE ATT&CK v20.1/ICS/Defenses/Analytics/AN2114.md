# AN2114 - Analytic 2114

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies bulk file access on a Linux-hosted Industrial Control System (ICS) documentation repository (piping and instrumentation diagram stores, configuration archives) by a User Identifier (UID) not associated with documented engineering roles. OT operational-fidelity gate: Do not alert on novelty, scan/read volume, or enumeration alone. Alert when the source role is not authorized for discovery/polling and the target scope, address/tag range, protocol, or rate deviates from the established operational baseline. Suppress normal SCADA/HMI/historian polling, commissioning, asset inventory, backup, diagnostics, and approved engineering activity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0754#AN2114)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL+PATH** — Linux Audit SYSCALL+PATH records: PATH records show sequential reads of ICS documentation/configuration files by a UID not in the authorized engineering or backup account set · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)

## Mutable elements

- **ApprovedHistorianClients** — Allowlist of applications/accounts authorized to perform bulk historian queries.
- **AuthorizedEngineerAccounts** — Allowlist of accounts with documented engineering roles authorized to access ICS documentation repositories.
- **BulkDocumentAccessThreshold** — File count threshold distinguishing bulk reconnaissance from routine reference lookups.
- **BulkQueryThreshold** — Row count threshold for historian queries considered bulk export.
- **InformationRepositoryTimeWindow** — Time window within which sequential file accesses are considered part of a single bulk collection event.
