# AN2119 - Analytic 2119

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies writes to serial device configuration files or `stty` commands changing serial port parameters on Industrial Control System (ICS) Linux gateway hosts from a User Identifier (UID) not associated with authorized serial port management. OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0797#AN2119)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL+PATH** — Linux Audit SYSCALL+PATH records: PATH record shows modification of a serial-device configuration file by a UID not in the authorized serial-administration set · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)
