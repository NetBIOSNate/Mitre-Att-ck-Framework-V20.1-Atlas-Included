# AN1934 - Analytic 1934

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies an Industrial Control System (ICS) protocol message sequence placing a field device into firmware-update mode from a source not in the approved engineering workstation list, correlated with the device's alarm telemetry going silent within a short grace period without acknowledgment. Documented precedent: Industroyer exploited CVE-2015-5374 by sending a crafted packet that initiated an incomplete firmware update sequence on Siemens Protection Technology (SIPROTEC) relays. OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

- **NSM:Content** — firmware-update-mode activation service from source not in engineering workstation list outside change control window · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **engineeringworkstation:ApplicationLog** — firmware update mode entry logged without corresponding change ticket reference · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **AlarmSilenceGracePeriod** — Time window within which alarm telemetry going silent following a mode-change message is considered directly connected.
- **AuthorizedFirmwareManagers** — Accounts authorized to perform firmware update mode activation.
- **ChangeControlWindow** — Scheduled maintenance periods during which firmware update mode activation is authorized.
- **EngineeringWorkstationList** — IP allowlist of workstations authorized to activate firmware update mode.
- **MaintenanceWindowSchedule** — Recurring scheduled periods when firmware update activities are expected.
