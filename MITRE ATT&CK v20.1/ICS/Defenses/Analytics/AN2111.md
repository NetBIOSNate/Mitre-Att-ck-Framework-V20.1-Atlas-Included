# AN2111 - Analytic 2111

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies an Industrial Control System (ICS) vendor software package whose installation, via package manager, creates unexpected files or starts unrecognized services not documented in the vendor's package manifest. OT operational-fidelity gate: Alert only when execution violates an approved signer/hash/path/parent/process or tool allowlist, or originates from an unauthorized user/tool, and is tied to an OT asset or follow-on OT-relevant action. Suppress vendor-signed software, approved engineering utilities, diagnostics, patching, backup, and documented maintenance.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0730#AN2111)

**Platforms**  [Linux](../../Platforms/Linux.md)

- **auditd:SYSCALL+PATH** — Linux Audit SYSCALL+PATH records: package installation creates files outside the documented package manifest · [DC0059 - File Metadata](../Data%20Components/DC0059%20-%20File%20Metadata.md)

## Mutable elements

- **VendorInstallManifest** — Documented list of files/registry keys a legitimate vendor installer is expected to create.
- **VendorInstallProfile** — Documented expected process behavior for a legitimate vendor installer, established through lab testing.
