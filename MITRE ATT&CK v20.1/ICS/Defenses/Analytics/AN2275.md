# AN2275 - Analytic 2275

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies a Windows process holding simultaneous connections to both the field device subnet and an external destination, combined with proxy-tool process creation. OT operational-fidelity gate: Alert only when the asset's documented role does not permit the connection and the destination/proxy/service is outside the approved communications profile, with process/service identity used as corroboration where available. Suppress approved vendor support, update repositories, remote operations, failover paths, and documented temporary connectivity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0759#AN2275)

**Platforms**  [Windows](../../Platforms/Windows.md)
