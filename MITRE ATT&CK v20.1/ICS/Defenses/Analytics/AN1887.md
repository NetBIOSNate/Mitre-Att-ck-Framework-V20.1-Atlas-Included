# AN1887 - Analytic 1887

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies an Industrial Control System (ICS) protocol mode-change command targeting a field device from a source not in the approved engineering workstation list, where the transition is not immediately followed by a corresponding operator acknowledgment. Documented in Triton (the Tricon controller had to be placed in PROGRAM mode before the attack could inject its payload). OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0755#AN1887)

## Log sources and channels

- **operationaldb:AlarmEvent** — device mode-change alarm generated without corresponding operator_id entry within mode change ack window · [DC0108 - Device Alarm](../Data%20Components/DC0108%20-%20Device%20Alarm.md)
- **NSM:Content** — mode-change service from source not in engineering workstation list outside change control window · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **engineeringworkstation:ApplicationLog** — mode-change session logged without corresponding change ticket reference · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **ChangeControlWindow** — Scheduled maintenance periods during which mode changes are authorized.
- **EngineeringWorkstationList** — IP allowlist of workstations authorized to issue mode-change commands.
- **ModeChangeAckWindow** — Time window within which a legitimate operator acknowledgment is expected following a mode-change event.
