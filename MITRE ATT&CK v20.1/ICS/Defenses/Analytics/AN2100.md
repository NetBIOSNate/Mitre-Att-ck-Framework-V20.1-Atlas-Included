# AN2100 - Analytic 2100

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies a Windows ICS asset initiating MQTT/AMQP/DDS communications to a broker/service not approved for the asset role, from a process not associated with authorized vendor or telemetry software. Require both a communication-matrix violation and destination/process/protocol corroboration; suppress approved brokers, telemetry collectors, vendor applications, and maintenance.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0935#AN2100)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=3; process-to-broker connection · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **NSM:Content** — MQTT/AMQP/DDS protocol identification, broker/topic/client metadata when visible · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **NSM:Flow** — Client/broker connection metadata and periodicity · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **ApprovedBrokers** — Authorized broker/service destinations
- **AuthorizedICSApplications** — Processes/services permitted to publish/subscribe
- **ApprovedTopics** — Expected topics/queues/domains where observable
- **ApprovedCommunicationMatrix** — Allowed source-to-broker relationships
- **ExpectedReportingInterval** — Expected telemetry/reporting cadence as corroboration
