# AN2245 - Analytic 2245

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies Industrial Control System (ICS) field device event logs being cleared via ICS protocol commands from a source not in the approved engineering workstation list, occurring immediately following other suspicious ICS activity on the same device. OT operational-fidelity gate: Alert only when execution violates an approved signer/hash/path/parent/process or tool allowlist, or originates from an unauthorized user/tool, and is tied to an OT asset or follow-on OT-relevant action. Suppress vendor-signed software, approved engineering utilities, diagnostics, patching, backup, and documented maintenance.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0750#AN2245)

**Platforms**  [Embedded](../../Platforms/Embedded.md)

## Log sources and channels

- **NSM:Content** — event buffer clear or log clear service from source not in engineering workstation list, correlated with preceding suspicious activity on the same device · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **AuthorizedLogManagementTools** — Allowlist of processes/accounts authorized to delete or truncate ICS application logs.
- **LogClearLookbackWindow** — Time window prior to a log-clear event within which other suspicious activity is considered correlated.
- **ScheduledLogRotationWindow** — Documented schedule for legitimate, automated log rotation/archival.
