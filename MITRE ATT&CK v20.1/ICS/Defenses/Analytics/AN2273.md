# AN2273 - Analytic 2273

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies a registry write to Windows autorun keys or an AutoPlay/AutoRun configuration change referencing a binary path that is not part of the authorized Industrial Control System (ICS) software inventory, particularly in combination with removable media insertion. OT operational-fidelity gate: Alert only when execution violates an approved signer/hash/path/parent/process or tool allowlist, or originates from an unauthorized user/tool, and is tied to an OT asset or follow-on OT-relevant action. Suppress vendor-signed software, approved engineering utilities, diagnostics, patching, backup, and documented maintenance.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0748#AN2273)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — Windows Security Event ID 4663 (requires Object Access auditing and SACL on monitored paths): repeated ReadData/ListDirectory access across ICS data paths by an unapproved process/account · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **WinEventLog:System** — EventCode=20001 correlated with autorun registry modification within autorun modification window · [DC0042 - Drive Creation](../Data%20Components/DC0042%20-%20Drive%20Creation.md)

## Mutable elements

- **AuthorizedICSSoftwareInventory** — Inventory of binaries legitimately authorized to be referenced by autorun/startup mechanisms on ICS hosts.
- **AutorunModificationWindow** — Time window correlating removable media insertion with a subsequent autorun configuration change.
