# AN1870 - Analytic 1870

[ICS](../../README.md) / [Analytics](README.md)

Real-time network monitoring identifies a source issuing write commands to the same Input/Output (I/O) point or register address at a rate significantly exceeding the device's configured scan cycle. The write rate itself is the signature, with source identity retained as corroborating context; treat the rate deviation as suspicious only after excluding tuning, commissioning, failover, and fault-recovery activity. OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

## Log sources and channels

- **operationaldb:ProcessHistory** — I/O point value oscillates or changes state at frequency exceeding max normal state change rate, inconsistent with physical process response time · [DC0107 - Process History/Live Data](../Data%20Components/DC0107%20-%20Process%20History%20-%20Live%20Data.md)
- **NSM:Content** — write function code to same register address at rate exceeding max write rate per point within brute force detection window · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **scada:applog** — write Application Programming Interface (API) call queue depth or throughput to a single point exceeds max write queue depth · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **BruteForceDetectionWindow** — Time window over which write rate is measured for threshold comparison.
- **MaxNormalStateChangeRate** — Maximum rate at which the physical process value is expected to legitimately change state.
- **MaxWriteQueueDepth** — Maximum legitimate write queue depth for SCADA/DCS write operations to a single point.
- **MaxWriteRatePerPoint** — Maximum legitimate write rate to a single I/O point, derived from the device's configured scan cycle and physical process response time.
