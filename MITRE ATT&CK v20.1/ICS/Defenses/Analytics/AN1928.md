# AN1928 - Analytic 1928

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies inbound connections to Industrial Control System (ICS) Windows application servers from internet-routed Internet Protocol (IP) addresses. OT operational-fidelity gate: Alert only when the asset's documented role does not permit the connection and the destination/proxy/service is outside the approved communications profile, with process/service identity used as corroboration where available. Suppress approved vendor support, update repositories, remote operations, failover paths, and documented temporary connectivity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0796#AN1928)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels
