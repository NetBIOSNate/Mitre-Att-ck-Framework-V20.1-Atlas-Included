# AN1874 - Analytic 1874

[ICS](../../README.md) / [Analytics](README.md)

Real-time monitoring identifies an Industrial Control System (ICS) protocol write to a controller's task/organization-block configuration from a source not in the approved engineering workstation list, correlated against post-modification cycle timing deviation. Documented precedent: Stuxnet infected Siemens OB1 (main execution cycle block) so its malicious payload ran every cycle, and infected OB35 (watchdog/interrupt block) to suppress error reporting. OT operational-fidelity gate: Alert only when the action is not attributable to an authorized operator/engineering source for the specific target and function, and it is either outside an approved change/maintenance window or lacks matching change-control context; where telemetry permits, require corroborating device, configuration, or process-state effect. Suppress activity that fully matches approved maintenance, commissioning, failover, recovery, or tested control procedures.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0741#AN1874)

## Log sources and channels

- **assetinventory:ProgramDiff** — current task-to-block assignment table differs from last known-good baseline without corresponding change ticket · [DC0111 - Software](../Data%20Components/DC0111%20-%20Software.md)
- **NSM:Content** — task/organization-block modification service from source not in engineering workstation list outside change control window · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **device:VendorLog** — measured scan cycle time or interrupt response latency deviates from baseline cycle time by more than cycle timing deviation threshold following a task configuration change · [DC0108 - Device Alarm](../Data%20Components/DC0108%20-%20Device%20Alarm.md)

## Mutable elements

- **BaselineCycleTime** — Measured normal scan cycle time for the specific controller and program.
- **ChangeControlWindow** — Scheduled maintenance periods during which task reconfiguration is authorized.
- **CycleTimingDeviationThreshold** — Percentage or absolute deviation from baseline cycle time indicating a task reassignment.
- **EngineeringWorkstationList** — IP allowlist of workstations authorized to modify controller task configuration.
