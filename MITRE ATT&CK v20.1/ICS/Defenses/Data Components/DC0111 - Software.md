# DC0111 - Software

[ICS](../../README.md) / [Data Components](README.md)

This includes sources of current and expected software or application programs deployed to a device, along with information on the version and patch level for vendor products, full source code for any application programs, and unique identifiers (e.g., hashes, signatures).

[MITRE ATT&CK record](https://attack.mitre.org/datacomponents/DC0111)

## Log sources and channels

- **Asset** — None
- **assetinventory:ProgramDiff** — current task-to-block assignment table differs from last known-good baseline without corresponding change ticket
- **assetinventory:ProgramHash** — program hash differs from last authorized baseline without corresponding change ticket reference
