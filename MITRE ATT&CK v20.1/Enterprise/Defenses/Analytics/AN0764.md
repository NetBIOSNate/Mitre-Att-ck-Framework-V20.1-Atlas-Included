# AN0764 - Analytic 0764

[Enterprise](../../README.md) / [Analytics](README.md)

Correlation of registry key modification for Run/RunOnce with abnormal parent-child process relationships and outlier execution at user logon or system startup

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0274#AN0764)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — EventCode=4688 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=13, 14 · [DC0063 - Windows Registry Key Modification](../Data%20Components/DC0063%20-%20Windows%20Registry%20Key%20Modification.md)

## Mutable elements

- **ParentProcessName** — Customize based on expected parent-child process lineage for autostarts
- **StartupRegistryPath** — May vary based on organization policy or installed software
