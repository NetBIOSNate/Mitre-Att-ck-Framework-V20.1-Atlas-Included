# AN1007 - Analytic 1007

[Enterprise](../../README.md) / [Analytics](README.md)

Connections to exposed container services (e.g., Docker API, Kubernetes API server) from unauthorized external IPs → abnormal container creation/start → lateral activity within cluster nodes.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0354#AN1007)

**Platforms**  [Containers](../../Platforms/Containers.md)

## Log sources and channels

- **ApplicationLog:API** — Docker/Kubernetes API access from external sources · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **kubernetes:audit** — Unauthorized container creation or kubelet exec logs · [DC0088 - Logon Session Metadata](../Data%20Components/DC0088%20-%20Logon%20Session%20Metadata.md)
- **NSM:Flow** — External access to container ports (2375, 6443) · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **AllowedCIDRs** — Approved external IP ranges for container APIs.
- **TimeWindow** — Correlation window for API calls and container starts.
