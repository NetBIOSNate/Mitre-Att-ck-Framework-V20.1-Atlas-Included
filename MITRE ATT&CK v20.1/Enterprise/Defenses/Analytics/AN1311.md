# AN1311 - Analytic 1311

[Enterprise](../../README.md) / [Analytics](README.md)

Monitors Mail.app database or maildir file access, automation via AppleScript, and abnormal mail rule creation using scripting or UI automation frameworks.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0476#AN1311)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Mail or AppleScript subsystem · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **macos:endpointsecurity** — es_event_open, es_event_exec · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)

## Mutable elements

- **ScriptProcessNameList** — Script interpreters or automation tools (osascript, Automator, etc.)
- **WatchedMailFiles** — Mail.app SQLite DB or .emlx directory
