# AN1313 - Analytic 1313

[Enterprise](../../README.md) / [Analytics](README.md)

Adversaries using WinRM to remotely execute commands, launch child processes, or access WMI. The detection chain includes service use, network activity, remote session logon, and process creation within a short temporal window.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0477#AN1313)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — EventCode=4624, 4648 · [DC0067 - Logon Session Creation](../Data%20Components/DC0067%20-%20Logon%20Session%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:WinRM** — EventCode=6 · [DC0041 - Service Metadata](../Data%20Components/DC0041%20-%20Service%20Metadata.md)
- **NSM:Connections** — Inbound on ports 5985/5986 · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **TimeWindow** — Defines max time between remote shell creation and child process execution (e.g., 60 seconds)
- **UserContext** — Scope to unexpected remote user logons (non-admins, service accounts)
- **CommandLineAnomalyScore** — Score for suspicious command usage via WinRM (e.g., encoded PowerShell)
- **KnownAdminHosts** — List of trusted systems allowed to use WinRM legitimately
