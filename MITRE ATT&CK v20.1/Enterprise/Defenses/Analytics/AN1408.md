# AN1408 - Analytic 1408

[Enterprise](../../README.md) / [Analytics](README.md)

Detects downloaded SVG files followed by execution of browser processes or tools like xdg-open, and rapid follow-on network connections or process spawns to interpreters like python or bash.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0510#AN1408)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — open, write · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)
- **auditd:SYSCALL** — execve · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **NSM:Flow** — Outbound HTTP/S · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **TargetPaths** — Suspicious write locations such as /tmp/, ~/Downloads/
- **ExecutionContext** — Processes spawned by browsers or svg-viewing apps that invoke interpreters
- **NetworkDestinations** — URLs/IPs contacted post-SVG access – may reflect initial C2
