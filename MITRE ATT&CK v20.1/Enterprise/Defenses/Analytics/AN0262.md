# AN0262 - Analytic 0262

[Enterprise](../../README.md) / [Analytics](README.md)

Detects modification of ESXi cron jobs, local.sh scripts, or scheduled API calls to persist custom binaries or shell scripts.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0094#AN0262)

**Platforms**  [ESXi](../../Platforms/ESXi.md)

## Log sources and channels

- **esxi:vmkernel** — Startup script and task execution logs · [DC0001 - Scheduled Job Creation](../Data%20Components/DC0001%20-%20Scheduled%20Job%20Creation.md)
- **esxi:hostd** — shell access or job registration · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **esxi:cron** — manual edits to /etc/rc.local.d/local.sh or cron.d · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)

## Mutable elements

- **StartupScriptName** — Filename not matching expected initialization scripts.
- **ExecutionContext** — Commands run from unexpected SSH sessions or elevated shells.
- **PersistenceInterval** — Rare scheduling triggers (e.g., @reboot + hourly repetition).
