# AN1609 - Analytic 1609

[Enterprise](../../README.md) / [Analytics](README.md)

Unexpected creation or modification of files with `com.apple.ResourceFork` extended attributes containing unusually large or non-standard data. Defender perspective: detection of resource forks in contexts where they are uncommon, especially when paired with process execution or network activity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0584#AN1609)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — File creation or modification with com.apple.ResourceFork extended attribute · [DC0059 - File Metadata](../Data%20Components/DC0059%20-%20File%20Metadata.md)
- **macos:unifiedlog** — Execution of commands like `ls -l@`, `xattr -l`, or custom tools interacting with resource forks · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **macos:unifiedlog** — Process creation involving binaries interacting with resource fork data · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **ResourceForkSizeThreshold** — Adjust thresholds for 'unusually large' resource fork data based on baseline usage in the environment.
- **MonitoredDirectories** — Scope monitoring to sensitive directories such as /Users, /Applications, or temporary paths.
- **CorrelatedActivityWindow** — Time window for correlating resource fork activity with subsequent execution or network activity.
