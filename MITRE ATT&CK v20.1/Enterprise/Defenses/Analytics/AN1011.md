# AN1011 - Analytic 1011

[Enterprise](../../README.md) / [Analytics](README.md)

Monitor unified logs and Mail.app activity for repetitive incoming messages with attachments. Defenders should look for large volumes of incoming mail stored under ~/Library/Mail with unusual timing or repetitive subjects.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0355#AN1011)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Repetitive inbound email delivery activity logged within a short time window · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **fs:fsusage** — create: Attachment file creation in ~/Library/Mail directories · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)

## Mutable elements

- **FileCountThreshold** — Threshold for repetitive attachment files created within a defined interval.
