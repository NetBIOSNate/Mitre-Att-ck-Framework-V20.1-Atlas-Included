# AN1180 - Analytic 1180

[Enterprise](../../README.md) / [Analytics](README.md)

Monitor unified DNS logs for abnormal domain queries with low lexical similarity to known domains, repeated failed lookups, and random string structures. Cross-check with process logs to confirm unusual origins (non-browser apps).

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0419#AN1180)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — High entropy domain queries with multiple NXDOMAINs · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **macos:unifiedlog** — Unexpected apps performing repeated DNS lookups · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **ReputationFeedWhitelist** — Exclude trusted CDN and cloud provider domains
- **LexicalScoreThreshold** — Adjust score for word-based vs. letter-based DGAs
