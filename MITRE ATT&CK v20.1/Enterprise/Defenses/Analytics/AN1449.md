# AN1449 - Analytic 1449

[Enterprise](../../README.md) / [Analytics](README.md)

Closed-port knock sequence from a remote IP followed by on-host firewall change (iptables/nftables) or daemon starts listening (socket open) and a successful TCP/UDP connect. Optional detection of libpcap/raw-socket sniffers spawning to watch for secret values.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0524#AN1449)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve: Commands altering firewall or enabling listeners (iptables, nft, ufw, firewall-cmd, systemctl start *ssh*/*telnet*, ip route add, tcpdump, tshark) · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **auditd:SYSCALL** — socket/bind: Process binds to a new local port shortly after knock · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **NSM:Flow** — Knock pattern: multiple REJ/S0 to distinct closed ports then successful connection to service_port · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **NSM:Flow** — Packets with unusual flags or payloads outside established flows (e.g., WoL magic FF×6 + 16×MAC) · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **ServicePort** — Port that becomes available post-knock (e.g., 22/8022/2323).
- **KnockResetRatio** — Percentage of failed attempts with RST/ICMP vs SYN/SYN-ACK to qualify as closed-port probing.
- **ProcessAllowList** — Automation expected to touch firewall/daemon configs (config-mgmt agents).
