# AN0826 - Analytic 0826

[Enterprise](../../README.md) / [Analytics](README.md)

Detects unauthorized firmware or configuration changes enabling adversary-in-the-middle positioning (e.g., route injection, DNS spoofing, SSL downgrade). Behavioral analytics focus on sudden changes to routing tables or image file integrity failures.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0296#AN0826)

**Platforms**  [Network Devices](../../Platforms/Network%20Devices.md)

## Log sources and channels

- **NSM:Flow** — Unexpected route changes or duplicate gateway advertisements · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **networkdevice:config** — Configuration file modified or replaced on network device · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)

## Mutable elements

- **RoutingPolicyBaseline** — Expected routing and BGP/OSPF paths for validation.
- **FirmwareChecksum** — Baseline image checksum per device type used to detect tampering.
