# AN1092 - Analytic 1092

[Enterprise](../../README.md) / [Analytics](README.md)

Detects suspicious gratuitous ARP responses or inconsistent IP-to-MAC mappings using auditd and packet capture. Behavioral focus is on unsolicited replies overriding legitimate ARP ownership.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0387#AN1092)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — setsockopt, ioctl modifying ARP entries · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **NSM:Flow** — Gratuitous ARP replies with mismatched IP-MAC binding · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **AllowedARPUpdates** — Expected legitimate IP-to-MAC updates for servers or virtual routers.
- **AlertThreshold** — Number of anomalous ARP packets per second before triggering detection.
