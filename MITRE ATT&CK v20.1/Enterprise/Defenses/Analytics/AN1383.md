# AN1383 - Analytic 1383

[Enterprise](../../README.md) / [Analytics](README.md)

Detects non-standard compilation activity via Xcode CLI tools or bundled GCC/MONO packages writing new executable files and executing them outside dev environments (e.g., user Downloads folder).

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0501#AN1383)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — process activity, exec events · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:osquery** — file_events · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **macos:unifiedlog** — networkd or socket · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **CompilerInvocationPattern** — Detect calls to `xcodebuild`, `clang`, or `/Applications/Mono.app/...` from non-admin users
- **OutputBinaryPath** — Monitor for output files in user-writable paths (e.g., `~/Library/Caches`, `~/Downloads`)
