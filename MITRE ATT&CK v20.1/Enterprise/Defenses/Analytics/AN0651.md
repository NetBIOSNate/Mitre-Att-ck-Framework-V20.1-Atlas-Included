# AN0651 - Analytic 0651

[Enterprise](../../README.md) / [Analytics](README.md)

Detect the creation or modification of common media file formats (e.g., .jpg, .png, .wav) following suspicious process activity like compression or encryption, especially when paired with lateral movement or exfiltration behavior.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0235#AN0651)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=11 · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=3, 22 · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **NSM:Flow** — Session Transfer Content · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **FileExtensionFilter** — Allows tuning of monitored file types (e.g., .jpg, .png, .docx).
- **PayloadEntropyThreshold** — Threshold for flagging potential hidden data in outbound payloads.
- **ExecutionToExfilTimeWindow** — Time window between media creation and network transmission.
