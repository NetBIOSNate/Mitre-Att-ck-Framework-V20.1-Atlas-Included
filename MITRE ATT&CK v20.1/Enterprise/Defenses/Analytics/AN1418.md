# AN1418 - Analytic 1418

[Enterprise](../../README.md) / [Analytics](README.md)

Detects access to SSSD or Quest VAS cached credential databases using tdbdump or other file access patterns, requiring sudo/root access.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0513#AN1418)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — file · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **auditd:EXECVE** — EXECVE · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **linux:osquery** — process_events · [DC0035 - Process Access](../Data%20Components/DC0035%20-%20Process%20Access.md)

## Mutable elements

- **filepath** — SSSD and Quest cache paths differ by deployment and OS variant.
- **CommandLine** — Tunable to capture specific tools (e.g., tdbdump, cat) or scripts accessing cache files.
- **TimeWindow** — Time between elevation and file access can be adjusted to account for legitimate system behavior.
