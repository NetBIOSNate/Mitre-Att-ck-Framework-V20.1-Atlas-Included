# AN0199 - Analytic 0199

[Enterprise](../../README.md) / [Analytics](README.md)

Detects adversary use of logon script configuration via Group Policy or user object attributes, followed by script execution post-authentication. Behavior includes modification of script path or file, then process execution under user logon context.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0072#AN0199)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — EventCode=4663, 4670, 4656 · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **WinEventLog:System** — EventCode=1502, 1503 · [DC0029 - Script Execution](../Data%20Components/DC0029%20-%20Script%20Execution.md)
- **WinEventLog:Security** — EventCode=4624, 4648 · [DC0067 - Logon Session Creation](../Data%20Components/DC0067%20-%20Logon%20Session%20Creation.md)
- **WinEventLog:Security** — EventCode=4688 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **script_path_keywords** — Defenders may tune for known script locations such as NETLOGON, SYSVOL, or \domain\sysvol\*.bat/.ps1
- **execution_time_window** — May be scoped to user logon hours or first X minutes post-authentication
- **user_context** — Organizations may focus on specific users/groups with high privilege or remote access
