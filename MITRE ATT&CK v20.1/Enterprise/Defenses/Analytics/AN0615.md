# AN0615 - Analytic 0615

[Enterprise](../../README.md) / [Analytics](README.md)

Detection of ESXi escape attempts by monitoring for anomalies in hypervisor logs such as unexpected VM operations, privilege escalation events, or attempts to load malicious kernel modules within the hypervisor environment.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0219#AN0615)

**Platforms**  [ESXi](../../Platforms/ESXi.md)

## Log sources and channels

- **esxi:vmkernel** — VM exit/entry anomalies, unexpected hypercalls, or kernel module loading · [DC0031 - Kernel Module Load](../Data%20Components/DC0031%20-%20Kernel%20Module%20Load.md)

## Mutable elements

- **AllowedKernelModules** — Modules permitted in the hypervisor. Loading any module outside of this list may indicate compromise.
