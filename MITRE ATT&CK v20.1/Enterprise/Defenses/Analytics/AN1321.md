# AN1321 - Analytic 1321

[Enterprise](../../README.md) / [Analytics](README.md)

Detects tampering of IIS-based login pages (e.g., default.aspx, login.aspx) tied to VPN, OWA, or SharePoint via script injection or unexpected editor processes modifying web roots.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0480#AN1321)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=11 · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **WinEventLog:iis** — IIS Logs · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **FilePath** — Define path to monitored IIS web root (e.g., C:\inetpub\wwwroot\login.aspx)
- **ProcessName** — Exclude legitimate updates (e.g., msdeploy.exe) and alert on suspicious editors (e.g., notepad.exe, certutil.exe)
