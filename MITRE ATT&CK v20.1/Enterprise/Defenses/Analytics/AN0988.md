# AN0988 - Analytic 0988

[Enterprise](../../README.md) / [Analytics](README.md)

Identifies suspicious outbound traffic volume mismatches from processes that typically do not generate network activity, particularly over C2 protocols like HTTPS, DNS, or custom TCP/UDP ports, following file or data access.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0348#AN0988)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=3, 22 · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **NSM:Flow** — Flow/PCAP analysis for outbound payloads · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **WinEventLog:Security** — EventCode=4663, 4670, 4656 · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)

## Mutable elements

- **DataVolumeThreshold** — Set threshold for outbound transfer size exceeding typical C2 traffic (e.g., >1MB in <5min).
- **KnownBenignProcesses** — List of approved processes that may exhibit high outbound traffic (e.g., updates).
