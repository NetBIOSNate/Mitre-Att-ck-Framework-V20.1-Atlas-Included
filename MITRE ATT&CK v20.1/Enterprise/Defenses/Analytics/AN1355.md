# AN1355 - Analytic 1355

[Enterprise](../../README.md) / [Analytics](README.md)

Execution of system utilities like 'system_profiler' and 'ioreg' to enumerate hardware components or USB devices, particularly if followed by clipboard, file, or network activity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0491#AN1355)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — process exec · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:osquery** — usb_devices · [DC0054 - Drive Access](../Data%20Components/DC0054%20-%20Drive%20Access.md)

## Mutable elements

- **BinaryList** — Commands like 'system_profiler SPUSBDataType', 'ioreg -p IOUSB' that may indicate enumeration
- **TimeWindow** — Temporal grouping of enumeration with follow-on activity (e.g., clipboard capture, exfiltration)
