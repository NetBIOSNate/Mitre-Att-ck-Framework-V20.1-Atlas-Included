# AN1481 - Analytic 1481

[Enterprise](../../README.md) / [Analytics](README.md)

1) Package manager or curl/wget installs/upgrades from non-approved repos or unsigned packages; 2) new ELF written into PATH directories or replacement of existing binaries/libraries; 3) first run leads to unexpected child processes or outbound connections.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0537#AN1481)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve, unlink · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **auditd:SYSCALL** — open, rename · [DC0020 - Process Modification](../Data%20Components/DC0020%20-%20Process%20Modification.md)
- **journald:package** — dpkg/apt install, remove, upgrade events · [DC0059 - File Metadata](../Data%20Components/DC0059%20-%20File%20Metadata.md)
- **NSM:Flow** — First-time egress to unknown registries/mirrors immediately after install · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **ApprovedRepos** — Allow-listed APT/YUM repo URLs and GPG key fingerprints.
- **PathScope** — Directories to watch for new ELF writes (e.g., /usr/bin, /usr/local/bin, /lib*/, /opt/*/bin).
- **MinBinarySize** — Ignore tiny helper files; default >16KB.
- **TimeWindow** — Install→first-run correlation window (default 2h).
