# AN0243 - Analytic 0243

[Enterprise](../../README.md) / [Analytics](README.md)

Monitors suspicious usage of Windows API calls like SetWindowsHookEx, GetKeyState, or polling functions within non-UI service processes, combined with Registry or driver modifications.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0089#AN0243)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=10 · [DC0035 - Process Access](../Data%20Components/DC0035%20-%20Process%20Access.md)
- **WinEventLog:Security** — EventCode=4663, 4670, 4656 · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **WinEventLog:System** — EventCode=7045 · [DC0060 - Service Creation](../Data%20Components/DC0060%20-%20Service%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=13, 14 · [DC0063 - Windows Registry Key Modification](../Data%20Components/DC0063%20-%20Windows%20Registry%20Key%20Modification.md)

## Mutable elements

- **TargetImage** — Scope to sensitive GUI/session processes like winlogon.exe or osk.exe
- **AccessMask** — Can be tuned to 0x1fffff for full-access injection detection
- **TimeWindow** — Tunable for sustained polling or multiple registry edits in short succession
