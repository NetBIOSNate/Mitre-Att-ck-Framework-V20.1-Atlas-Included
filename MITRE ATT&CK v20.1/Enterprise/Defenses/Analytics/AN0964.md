# AN0964 - Analytic 0964

[Enterprise](../../README.md) / [Analytics](README.md)

User pastes an obfuscated command into Terminal.app/iTerm2 that decodes or downloads code and executes. Detects Terminal/iTerm2 spawning bash/zsh/python with suspicious pipeline/base64 patterns followed by file writes in ~/Library or /tmp and outbound network connections.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0340#AN0964)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — exec: ParentImage in (Terminal, iTerm2) AND Image in (/bin/zsh,/bin/bash,/usr/bin/python*) AND CommandLine matches '(curl|wget).*(\||\|\s*sh|bash)|base64 -D|python -c' · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:osquery** — Interpreter exec with suspicious arguments as above · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **macos:unifiedlog** — create: New files in /tmp or ~/Library/Application Support/* with executable or script extensions · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **NSM:Flow** — Egress to non-approved networks from host after terminal exec · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **ParentAppScope** — Terminal apps to treat as user-paste origins (Terminal, iTerm2, VSCode integrated terminal).
- **CommandPatternList** — macOS-specific one-liner traits (pbpaste|base64 -D|curl ... | sh).
- **AllowListedDevUsers** — Developers/automation accounts expected to run such commands.
