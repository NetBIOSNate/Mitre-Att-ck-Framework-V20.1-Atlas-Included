# AN1399 - Analytic 1399

[Enterprise](../../README.md) / [Analytics](README.md)

Detects process injection by correlating memory manipulation API calls (e.g., VirtualAllocEx, WriteProcessMemory), suspicious thread creation (e.g., CreateRemoteThread), and unusual DLL loads within another process's context.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0508#AN1399)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=10 · [DC0035 - Process Access](../Data%20Components/DC0035%20-%20Process%20Access.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=7 · [DC0016 - Module Load](../Data%20Components/DC0016%20-%20Module%20Load.md)
- **etw:Microsoft-Windows-Kernel-Process** — API calls · [DC0021 - OS API Execution](../Data%20Components/DC0021%20-%20OS%20API%20Execution.md)

## Mutable elements

- **AccessMask** — Specific access rights used during process handle acquisition, e.g., PROCESS_VM_WRITE
- **TimeWindow** — Time correlation window between API calls and thread creation events
- **InjectedProcessList** — Known high-value targets often abused for injection (e.g., lsass.exe, explorer.exe)
