# AN1392 - Analytic 1392

[Enterprise](../../README.md) / [Analytics](README.md)

Detects unexpected encrypted egress traffic from management services (e.g., hostd) or guest VMs utilizing symmetric encryption without traditional protocols (e.g., FTP with embedded AES ciphertext).

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0503#AN1392)

**Platforms**  [ESXi](../../Platforms/ESXi.md)

## Log sources and channels

- **esxi:vmkernel** — egress log analysis · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **esxi:hostd** — execution + payload hints · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **NSM:Flow** — host switch egress data · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **GuestVMExfilWatchlist** — VMs with data sensitivity labels or outside normal behavior.
- **ServiceEgressProfile** — Expected egress destinations and volume for core services.
