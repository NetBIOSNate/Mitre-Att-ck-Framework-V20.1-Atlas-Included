# AN0830 - Analytic 0830

[Enterprise](../../README.md) / [Analytics](README.md)

Execution of destructive CLI commands such as format flash:, format disk, or equivalent vendor-specific commands that erase filesystem structures. Detection correlates AAA logs showing privileged access with immediate format/erase commands.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0297#AN0830)

**Platforms**  [Network Devices](../../Platforms/Network%20Devices.md)

## Log sources and channels

- **networkdevice:cli** — format flash:, format disk, reformat commands · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **networkdevice:syslog** — Privileged login followed by destructive format command · [DC0002 - User Account Authentication](../Data%20Components/DC0002%20-%20User%20Account%20Authentication.md)

## Mutable elements

- **CommandPatterns** — Expand detection to cover vendor-specific destructive commands.
- **PrivilegedUsers** — Whitelist authorized maintenance sessions to reduce false positives.
