# AN0547 - Analytic 0547

[Enterprise](../../README.md) / [Analytics](README.md)

Detects modifications to authorization plugins responsible for MFA enforcement and correlates with suspicious login sessions missing MFA prompts.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0190#AN0547)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Modification of /Library/Security/SecurityAgentPlugins · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)
- **macos:unifiedlog** — Login success without MFA step · [DC0002 - User Account Authentication](../Data%20Components/DC0002%20-%20User%20Account%20Authentication.md)

## Mutable elements

- **WatchedPluginPaths** — Paths to organization-deployed MFA authorization plugins.
