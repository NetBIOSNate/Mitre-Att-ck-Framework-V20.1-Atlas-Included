# AN1013 - Analytic 1013

[Enterprise](../../README.md) / [Analytics](README.md)

Flood of spoofed SYN or ACK packets causing exhaustion of OS TCP state table, potentially via user-space utilities or kernel-level DoS agents.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0356#AN1013)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — Invocation of packet generation tools (e.g., hping3, nping) or fork bombs · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **NSM:Flow** — High volumes of SYN/ACK packets with unacknowledged TCP handshakes · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **NSM:Flow** — TCP: possible SYN flood or backlog limit exceeded · [DC0018 - Host Status](../Data%20Components/DC0018%20-%20Host%20Status.md)

## Mutable elements

- **AmplificationThreshold** — Volume of fake TCP requests before OS begins degradation
- **Interface** — Which network interface is being targeted or impacted
