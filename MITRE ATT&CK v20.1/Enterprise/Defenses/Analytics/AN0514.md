# AN0514 - Analytic 0514

[Enterprise](../../README.md) / [Analytics](README.md)

CLI tools (smbclient -L, smbmap, rpcclient, nmblookup) or custom scripts enumerate SMB shares on many internal hosts → corresponding SMB connections (445/139) captured by Zeek/Netflow within a short window.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0182#AN0514)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve of smbclient, smbmap, rpcclient, nmblookup, crackmapexec smb · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **NSM:Flow** — connection: TCP connections to ports 139/445 to multiple hosts · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **NSM:Flow** — smb_command: TreeConnectAndX to \\*\IPC$ / srvsvc or Trans2/NT_CREATE for listing shares · [DC0021 - OS API Execution](../Data%20Components/DC0021%20-%20OS%20API%20Execution.md)

## Mutable elements

- **BurstHostThreshold** — Minimum unique hosts to flag (e.g., ≥5).
- **TimeWindow** — Correlation window between tool exec and SMB fan-out (default 10m).
- **ApprovedInventoryHosts** — IPs of vulnerability scanners or config mgmt systems.
