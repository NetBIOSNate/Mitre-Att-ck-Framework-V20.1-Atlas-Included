# AN1626 - Analytic 1626

[Enterprise](../../README.md) / [Analytics](README.md)

Detects attempts to modify file timestamps via API usage (e.g., `SetFileTime`), CLI tools (e.g., `w32tm`, PowerShell), or double-timestomp behavior where $SI and $FN timestamps are mismatched or reverted.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0591#AN1626)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=15 · [DC0059 - File Metadata](../Data%20Components/DC0059%20-%20File%20Metadata.md)
- **WinEventLog:Security** — EventCode=4663, 4670, 4656 · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **EDR:file** — SetFileTime · [DC0021 - OS API Execution](../Data%20Components/DC0021%20-%20OS%20API%20Execution.md)

## Mutable elements

- **TimeWindow** — Correlate timestamp change with preceding file creation or suspicious access
- **APINamePattern** — Include SetFileTime, NtSetInformationFile, or other timestamp APIs
- **TimestampDeltaThreshold** — Trigger on excessive backdating (e.g., >90 days)
