# AN0303 - Analytic 0303

[Enterprise](../../README.md) / [Analytics](README.md)

Custom scripts or processes encode outbound traffic using gzip, Base64, or hex prior to exfiltration via curl, wget, or custom sockets. Encoding typically occurs before or during outbound connections from non-network daemons.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0108#AN0303)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **NSM:Flow** — Base64 strings or gzip in URI, headers, or POST body · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **linux:syslog** — Unusual outbound transfers from CLI tools like base64, gzip, or netcat · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **TimeWindow** — Tune duration of multi-stage encoding + transfer operations to account for script variability
- **UserContext** — Apply user allow/block list depending on which users normally perform CLI encoding
