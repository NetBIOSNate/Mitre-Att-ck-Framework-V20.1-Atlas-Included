# AN1610 - Analytic 1610

[Enterprise](../../README.md) / [Analytics](README.md)

Abuse of JamPlus.exe to launch malicious payloads via crafted .jam files, resulting in abnormal process creation, command execution, or artifact generation outside of standard development workflows.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0585#AN1610)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — EventCode=4688 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=11 · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=3, 22 · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **WinEventLog:Microsoft-Windows-CodeIntegrity/Operational** — Unsigned or untrusted modules loaded during JamPlus.exe runtime · [DC0034 - Process Metadata](../Data%20Components/DC0034%20-%20Process%20Metadata.md)

## Mutable elements

- **TimeWindow** — Correlation time window (e.g., 0–30 minutes) for JamPlus.exe execution, child processes, and file/network events.
- **AllowedBuildHosts** — Known developer systems where JamPlus.exe usage is expected; alerts are raised if executed elsewhere.
- **SuspiciousChildList** — Child processes considered anomalous (e.g., PowerShell, cmd, wscript) when spawned by JamPlus.exe.
- **RarePathRegex** — Regex patterns for non-standard or user-writable paths where JamPlus.exe drops artifacts.
