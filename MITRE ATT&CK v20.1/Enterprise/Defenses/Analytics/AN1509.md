# AN1509 - Analytic 1509

[Enterprise](../../README.md) / [Analytics](README.md)

Malicious use of webserver plugins (e.g., for nginx, PHP, Node.js) that execute AppleScript or open network sockets.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0547#AN1509)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Script interpreter invoked by nginx/apache worker process · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:unifiedlog** — Web server process initiating outbound TCP connections not tied to normal server traffic · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **ParentBinaryPath** — If homebrew or manually compiled nginx/httpd used, baseline accordingly.
