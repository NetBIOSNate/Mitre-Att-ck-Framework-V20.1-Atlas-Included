# AN0437 - Analytic 0437

[Enterprise](../../README.md) / [Analytics](README.md)

Processes such as curl, wget, or custom scripts initiating POST requests to webhook endpoints with encoded or bulk data. Defender perspective: abnormal chaining of file compression or access followed by outbound data to webhook URLs.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0153#AN0437)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:EXECVE** — curl -X POST, wget --post-data · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **auditd:SYSCALL** — read/open of sensitive files · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **NSM:Flow** — large HTTPS POST requests to webhook endpoints · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **TimeWindow** — Expected timeframe for legitimate webhook traffic (e.g., CI/CD deployments).
