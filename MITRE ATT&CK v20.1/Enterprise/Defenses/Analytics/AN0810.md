# AN0810 - Analytic 0810

[Enterprise](../../README.md) / [Analytics](README.md)

Detects login to admin consoles (e.g., Microsoft 365 Admin Center) from unrecognized users, devices, or geolocations followed by non-API data review or configuration read actions that suggest GUI dashboard use.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0291#AN0810)

**Platforms**  [Office Suite](../../Platforms/Office%20Suite.md)

## Log sources and channels

- **m365:signinlogs** — UserLoginSuccess · [DC0002 - User Account Authentication](../Data%20Components/DC0002%20-%20User%20Account%20Authentication.md)
- **m365:unified** — ViewAdminReport · [DC0067 - Logon Session Creation](../Data%20Components/DC0067%20-%20Logon%20Session%20Creation.md)
- **m365:unified** — Read-only configuration review from GUI · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **AdminRoleList** — Roles allowed to access dashboard views
- **DashboardNavigationSequence** — Pageview paths or clickstreams indicating use of GUI admin console
- **GeoLocationRisk** — List of high-risk regions or unexpected geos
