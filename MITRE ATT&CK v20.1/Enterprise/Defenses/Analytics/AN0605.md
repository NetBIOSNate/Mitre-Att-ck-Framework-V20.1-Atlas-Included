# AN0605 - Analytic 0605

[Enterprise](../../README.md) / [Analytics](README.md)

Ransomware encrypts .vmdk, .vmx, .log, or VM config files in VMFS datastores. May rename to .locked or delete/overwrite with encrypted versions. Often correlates with shell commands run through `dcui`, SSH, or vSphere.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0215#AN0605)

**Platforms**  [ESXi](../../Platforms/ESXi.md)

## Log sources and channels

- **esxi:vmkernel** — rename .vmdk to .*.locked|datastore write spike · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)
- **esxi:shell** — openssl|tar|dd · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **FileType** — Detect renames or write patterns involving .vmdk, .vmx, .nvram.
- **UserContext** — Identify shell sessions opened by root or unexpected users outside maintenance window.
