# AN1454 - Analytic 1454

[Enterprise](../../README.md) / [Analytics](README.md)

Execution of system info utilities like `systemsetup`, `sw_vers`, `uname`, or `sysctl` by terminal or scripted processes.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0525#AN1454)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — log show --predicate 'process == <utility>' · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **ParentProcess** — Determine if script or terminal executed the command.
- **FrequencyThreshold** — Number of discovery commands in a short window.
