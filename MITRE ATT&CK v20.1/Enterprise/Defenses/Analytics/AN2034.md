# AN2034 - Analytic 2034

[Enterprise](../../README.md) / [Analytics](README.md)

Detects consent grants, password resets, role changes, external sharing, or token creation shortly after user interaction with messages, invites, or help desk workflows. Emphasis is placed on unusual requester relationships, new device context, or off-hours approvals.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0899#AN2034)

**Platforms**  [SaaS](../../Platforms/SaaS.md)

## Log sources and channels

- **saas:okta** — user.account.reset_password; user.mfa.factor.activate; app.oauth2.authorize · [DC0002 - User Account Authentication](../Data%20Components/DC0002%20-%20User%20Account%20Authentication.md)
- **saas:slack** — xternal DM or workspace invite preceding credential or approval actions · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **saas:zoom** — Unexpected contact interaction preceding follow-on admin requests · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **RequesterNoveltyDays** — How long since requestor last interacted with user
- **GeoVelocityThreshold** — Distance/time anomaly for follow-on login
- **AfterHoursDefinition** — Organization-specific off-hours period
