# AN0401 - Analytic 0401

[Enterprise](../../README.md) / [Analytics](README.md)

Unexpected processes (e.g., bash, python, custom binaries) dynamically loading libcrypto or performing AES/RC4 encryption operations, then initiating outbound sessions with abnormal byte entropy or asymmetric traffic patterns.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0143#AN0401)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve or socket/connect system calls from processes using crypto libraries · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **linux:syslog** — System daemons initiating encrypted sessions with unexpected destinations · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **linux:osquery** — Process linked with libcrypto.so making external connections · [DC0016 - Module Load](../Data%20Components/DC0016%20-%20Module%20Load.md)

## Mutable elements

- **TrustedCryptoLibs** — Baseline expected crypto libraries to suppress false positives.
- **TrafficAsymmetryRatio** — Ratio of sent/received bytes indicating possible hidden C2.
