# AN1543 - Analytic 1543

[Enterprise](../../README.md) / [Analytics](README.md)

Detection of compromised or misused valid accounts via anomalous logon patterns, abnormal logon types, and inconsistent geographic or time-based activity across Windows endpoints.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0560#AN1543)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — EventCode=4624 · [DC0067 - Logon Session Creation](../Data%20Components/DC0067%20-%20Logon%20Session%20Creation.md)
- **WinEventLog:Security** — EventCode=4776, 4625 · [DC0002 - User Account Authentication](../Data%20Components/DC0002%20-%20User%20Account%20Authentication.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **LogonType** — Flag unexpected logon types (e.g., Type 10 for remote interactive logins) for sensitive accounts.
- **TimeWindow** — Define acceptable hours for interactive logon activity (e.g., 9AM-6PM local).
- **GeoIPMismatch** — Trigger on location anomalies based on prior user behavior or policy.
