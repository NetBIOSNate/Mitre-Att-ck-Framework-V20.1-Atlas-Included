# AN0450 - Analytic 0450

[Enterprise](../../README.md) / [Analytics](README.md)

Detect abnormal MFA activity within cloud service provider logs, such as repeated generation of MFA challenges for the same user session or mismatched MFA device and login origin.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0160#AN0450)

**Platforms**  [IaaS](../../Platforms/IaaS.md)

## Log sources and channels

- **AWS:CloudTrail** — AssumeRole or ConsoleLogin with repeated MFA failures followed by repeated MFA requests · [DC0002 - User Account Authentication](../Data%20Components/DC0002%20-%20User%20Account%20Authentication.md)

## Mutable elements

- **FailedLoginThreshold** — Number of failed logins before raising detection
