# AN0473 - Analytic 0473

[Enterprise](../../README.md) / [Analytics](README.md)

Adversary installs or modifies email content filters or transport scripts (e.g., Postfix milter, Sendmail milter, Exim filters) using shell access or configuration manipulation.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0166#AN0473)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — write · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)
- **linux:syslog** — milter configuration updated, transport rule initialized, unexpected script execution · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **auditd:EXECVE** — /usr/sbin/postfix, /usr/sbin/exim, /usr/sbin/sendmail · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **auditd:SYSCALL** — write · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **linux:Sysmon** — EventCode=7 · [DC0016 - Module Load](../Data%20Components/DC0016%20-%20Module%20Load.md)

## Mutable elements

- **MailTransportScriptPath** — Path to custom scripts or filters depends on mail daemon (e.g., /etc/postfix/milter/, /etc/exim4/).
- **UserContext** — Mail agents may run under different service users (postfix, exim, etc.), which should be scoped.
- **ExecFrequencyThreshold** — Frequency of filter script re-execution per daemon restart or reload may vary.
