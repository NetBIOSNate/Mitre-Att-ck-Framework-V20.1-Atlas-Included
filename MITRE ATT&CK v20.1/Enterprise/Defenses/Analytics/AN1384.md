# AN1384 - Analytic 1384

[Enterprise](../../README.md) / [Analytics](README.md)

Abuse of file/registry attributes to hide malicious files, directories, or services. Defender view: detection of attrib.exe setting hidden/system flags, creation of Alternate Data Streams, or registry keys altering file visibility.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0502#AN1384)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=11 · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=13, 14 · [DC0063 - Windows Registry Key Modification](../Data%20Components/DC0063%20-%20Windows%20Registry%20Key%20Modification.md)

## Mutable elements

- **FileExtensions** — Filter for sensitive file types likely targeted for hiding.
- **ADSDetection** — Enable or disable detection of Alternate Data Streams depending on business use.
