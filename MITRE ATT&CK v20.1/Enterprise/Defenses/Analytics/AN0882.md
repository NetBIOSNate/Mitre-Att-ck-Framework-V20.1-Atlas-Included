# AN0882 - Analytic 0882

[Enterprise](../../README.md) / [Analytics](README.md)

Processes attempting raw disk access via \\.\PhysicalDrive paths, abnormal file I/O to MBR/boot sectors, or loading of third-party drivers (e.g., RawDisk) that enable disk overwrite. Correlate process creation, privilege usage, and disk modification events within a short time window.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0316#AN0882)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — EventCode=4673 · [DC0013 - User Account Metadata](../Data%20Components/DC0013%20-%20User%20Account%20Metadata.md)
- **WinEventLog:Sysmon** — Raw disk writes targeting \\.\PhysicalDrive* or MBR locations · [DC0046 - Drive Modification](../Data%20Components/DC0046%20-%20Drive%20Modification.md)
- **WinEventLog:Sysmon** — EventCode=6 · [DC0079 - Driver Load](../Data%20Components/DC0079%20-%20Driver%20Load.md)

## Mutable elements

- **ProcessWhitelist** — Backup, forensics, or imaging tools may perform legitimate raw disk access — requires tuning per environment.
- **TimeWindow** — Correlation threshold for process execution, driver load, and raw disk writes.
