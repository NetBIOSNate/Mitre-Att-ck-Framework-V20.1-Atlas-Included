# AN0589 - Analytic 0589

[Enterprise](../../README.md) / [Analytics](README.md)

Registry read access associated with suspicious or non-interactive processes querying system config, installed software, or security settings.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0209#AN0589)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=13, 14 · [DC0063 - Windows Registry Key Modification](../Data%20Components/DC0063%20-%20Windows%20Registry%20Key%20Modification.md)
- **WinEventLog:PowerShell** — EventCode=4103, 4104, 4105, 4106 · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **TargetRegistryPath** — Focus detection on registry hives or keys likely to reveal environment info (e.g., HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion).
- **ParentProcess** — May tune for suspicious parent processes such as cmd.exe, wscript.exe, or mshta.exe.
- **TimeWindow** — Controls how closely registry access must follow process creation for correlation.
