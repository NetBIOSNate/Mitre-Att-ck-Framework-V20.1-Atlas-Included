# AN1090 - Analytic 1090

[Enterprise](../../README.md) / [Analytics](README.md)

Access to organizational directories via Google Workspace Directory API, Slack SCIM, or Okta SCIM by apps or identities outside normal roles.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0386#AN1090)

**Platforms**  [SaaS](../../Platforms/SaaS.md)

## Log sources and channels

- **Google Admin Audit** — users.list, groups.list · [DC0013 - User Account Metadata](../Data%20Components/DC0013%20-%20User%20Account%20Metadata.md)
- **saas:okta** — System API Call: user.read, group.read · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **APIRequestRate** — Detect rapid enumeration attempts or recursive group expansion.
- **AppIntegrationID** — Tag expected SCIM clients and suppress false positives from enterprise sync tools.
- **GeoContext** — Trigger alerts if enumeration occurs from anomalous IPs or regions.
