# AN0461 - Analytic 0461

[Enterprise](../../README.md) / [Analytics](README.md)

Chain: (1) privileged CLI sessions run read-only commands that dump AAA/password policies (e.g., `show aaa`, `show password-policy`); (2) same account changes AAA or user DB shortly after. Use network device AAA/command accounting or syslog.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0161#AN0461)

**Platforms**  [Network Devices](../../Platforms/Network%20Devices.md)

## Log sources and channels

- **networkdevice:syslog** — cmd='show aaa*' OR 'show running-config | include password|aaa' OR 'show aaa common-criteria policy all' · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **ApprovedNOCSources** — Jump hosts permitted to run show commands.
- **DeviceTier** — Higher risk weight on edge/critical devices.
