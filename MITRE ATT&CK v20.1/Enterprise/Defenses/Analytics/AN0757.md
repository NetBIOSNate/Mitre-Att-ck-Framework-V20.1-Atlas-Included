# AN0757 - Analytic 0757

[Enterprise](../../README.md) / [Analytics](README.md)

Detects anomalous process access to LSASS on domain controllers, suspicious module loads of authentication DLLs, and registry or file modifications indicative of Skeleton Key–style patching. Correlates LSASS access attempts with subsequent abnormal logon activity patterns.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0271#AN0757)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=10 · [DC0035 - Process Access](../Data%20Components/DC0035%20-%20Process%20Access.md)
- **WinEventLog:Sysmon** — EventCode=7 · [DC0016 - Module Load](../Data%20Components/DC0016%20-%20Module%20Load.md)
- **WinEventLog:Security** — EventCode=4624, 4648 · [DC0067 - Logon Session Creation](../Data%20Components/DC0067%20-%20Logon%20Session%20Creation.md)
- **WinEventLog:System** — Unexpected modification to lsass.exe or cryptdll.dll · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)

## Mutable elements

- **MonitoredDLLs** — Specific authentication DLLs such as cryptdll.dll and samsrv.dll monitored for tampering.
- **TimeWindow** — Correlation window between LSASS memory access, module load, and suspicious logons.
- **UserContext** — Baseline expected accounts performing domain controller logon operations.
