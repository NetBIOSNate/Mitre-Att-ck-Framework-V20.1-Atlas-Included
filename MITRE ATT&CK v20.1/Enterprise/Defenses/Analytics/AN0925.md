# AN0925 - Analytic 0925

[Enterprise](../../README.md) / [Analytics](README.md)

ESXi shell or guest VM tools initiate external connections via scripted traffic forwarding to Internet-based proxies. Detected by firewall or shell audit logs showing outbound connection spikes from hypervisor or guest VM to remote proxy nodes.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0325#AN0925)

**Platforms**  [ESXi](../../Platforms/ESXi.md)

## Log sources and channels

- **esxi:shell** — None · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **esxi:vmkernel** — None · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **NSM:Flow** — conn.log · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **VMOutboundPatterns** — Detect when VMs communicate with Internet IPs not in workload profiles.
- **ProxyHostPattern** — Regex for proxy-related tools/scripts executed on the host.
- **ConnectionDirectionality** — Outbound only connections from ESXi to new IPs.
