# AN1071 - Analytic 1071

[Enterprise](../../README.md) / [Analytics](README.md)

Adversaries using bash scripts or tools to recursively enumerate user home directories, config files, or SSH keys.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0380#AN1071)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — open · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **auditd:SYSCALL** — execve · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **TimeWindow** — Time span to correlate multiple file access events indicative of scripted or bulk access.
- **ScriptToolName** — List of tools (e.g., `find`, `grep`, `tar`, `scp`) that may be benign but are context-sensitive.
