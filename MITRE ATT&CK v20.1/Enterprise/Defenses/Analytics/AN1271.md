# AN1271 - Analytic 1271

[Enterprise](../../README.md) / [Analytics](README.md)

Anomalous creation or mounting of hidden partitions or virtual file systems. Defender view: detection of registry modifications linked to non-standard file systems, suspicious disk I/O patterns, or bootkit-like behavior where hidden volumes are accessed outside normal file system APIs.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0461#AN1271)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — EventCode=4663, 4670, 4656 · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)
- **WinEventLog:Sysmon** — EventCode=13, 14 · [DC0063 - Windows Registry Key Modification](../Data%20Components/DC0063%20-%20Windows%20Registry%20Key%20Modification.md)
- **etw:Microsoft-Windows-Kernel-Storage** — Raw disk I/O operations bypassing NTFS APIs · [DC0004 - Firmware Modification](../Data%20Components/DC0004%20-%20Firmware%20Modification.md)

## Mutable elements

- **MonitoredRegistryKeys** — Specify registry paths for mount points and hidden partition configs.
- **DiskIOThreshold** — Tune thresholds for raw disk access outside expected drivers.
- **TimeWindow** — Correlate boot-time anomalies with hidden file system mounting activity.
