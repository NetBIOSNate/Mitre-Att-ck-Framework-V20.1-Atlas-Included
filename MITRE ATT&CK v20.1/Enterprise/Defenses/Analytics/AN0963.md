# AN0963 - Analytic 0963

[Enterprise](../../README.md) / [Analytics](README.md)

User pastes a multi-line or one-liner into a terminal (bash/zsh) that downloads/decodes and executes content. Chain: terminal exec of curl/wget/bash/sh with pipe to interpreter or base64-decode → transient file under /tmp|~/.cache → immediate outbound egress.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0340#AN0963)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve: exe in (/usr/bin/bash,/usr/bin/sh,/usr/bin/zsh,/usr/bin/python*) AND cmdline matches '(curl|wget).*(\||\|\s*sh|bash)|base64\s*-d|python\s*-c' · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **auditd:SYSCALL** — open: File creation under /tmp, /var/tmp, ~/.cache with executable bit or shell shebang · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **NSM:Flow** — New egress to Internet by the same UID/host shortly after terminal exec · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **TerminalProcessNames** — Gui/tty terminals to monitor (gnome-terminal, konsole, iTerm2, tmux).
- **RiskyFilePaths** — Temp/cache paths to watch for first-stage drops.
- **AnomalousUserSet** — Users who should never run curl/wget or compilers.
- **TimeWindow** — Exec→file→egress correlation window (e.g., 10 minutes).
