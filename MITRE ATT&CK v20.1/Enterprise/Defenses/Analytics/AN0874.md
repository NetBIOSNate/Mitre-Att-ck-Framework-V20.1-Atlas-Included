# AN0874 - Analytic 0874

[Enterprise](../../README.md) / [Analytics](README.md)

Detection of HTML-based downloads via Safari/Chrome that create obfuscated files (e.g., .zip, .app, .js) in user directories and are followed by suspicious executions from preview or launch services.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0313#AN0874)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — File Events · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **macos:osquery** — process_events · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **gatekeeper/quarantine database** — LaunchServices quarantine · [DC0059 - File Metadata](../Data%20Components/DC0059%20-%20File%20Metadata.md)

## Mutable elements

- **QuarantineFlagCheck** — Whether downloaded file has a quarantine flag and is bypassed via Gatekeeper
- **BlobKeywordAlertList** — JavaScript strings that may indicate smuggling: msSaveBlob, download.href, createObjectURL
