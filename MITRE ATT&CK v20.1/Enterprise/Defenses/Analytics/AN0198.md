# AN0198 - Analytic 0198

[Enterprise](../../README.md) / [Analytics](README.md)

Detects remote write activity across cloud VMs or object storage buckets within the same region/account that correlate with data aggregation across hosts.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0071#AN0198)

**Platforms**  [IaaS](../../Platforms/IaaS.md)

## Log sources and channels

- **AWS:CloudTrail** — GetObject, CopyObject · [DC0025 - Cloud Storage Access](../Data%20Components/DC0025%20-%20Cloud%20Storage%20Access.md)
- **AWS:VPCFlowLogs** — Traffic between instances · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **esxi:hostd** — process execution across cloud VM · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **BucketNamePatterns** — Destination naming convention used for staging (e.g., temp-store)
- **IAMContext** — IAM role or user performing multi-host write ops
- **TransferWindow** — Burst of high-volume inter-VM transfers indicating staging
