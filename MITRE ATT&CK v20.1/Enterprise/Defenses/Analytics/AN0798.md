# AN0798 - Analytic 0798

[Enterprise](../../README.md) / [Analytics](README.md)

Cause→effect chain: (1) Browser/Office/reader process logs crash/segfault or abnormal sandbox message, (2) new executable/script/write occurs in $HOME (Downloads, ~/.cache, /tmp), (3) unexpected child like curl/wget/bash/python opens network connections soon after.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0287#AN0798)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **linux:syslog** — browser/office crash, segfault, abnormal termination · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **auditd:SYSCALL** — open · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **auditd:SYSCALL** — creat · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **auditd:SYSCALL** — rename,chmod · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)
- **auditd:SYSCALL** — execve · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **NetFlow:Flow** — new outbound connections from exploited process tree · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **TimeWindow** — 5–20m correlation window.
- **UserPaths** — HOME write targets: ~/Downloads, ~/.config/autostart, ~/.local/share, /tmp.
- **HighRiskChildren** — bash, sh, python, perl, node, curl, wget, socat, openssl, xxd.
- **PackageUpdaters** — Allow-list common updaters (snap, flatpak, packagekit) to reduce FP.
