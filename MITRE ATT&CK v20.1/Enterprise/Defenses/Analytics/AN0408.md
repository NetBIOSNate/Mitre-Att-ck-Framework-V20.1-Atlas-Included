# AN0408 - Analytic 0408

[Enterprise](../../README.md) / [Analytics](README.md)

Detection of PF firewall rule modifications via pfctl, socketfilterfw, or defaults write to com.apple.alf. Adversaries often disable firewall profiles entirely or whitelist malicious processes.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0145#AN0408)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — pfctl -d, socketfilterfw --setglobalstate off, or modifications to com.apple.alf · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **PFConfigFiles** — Monitor for baseline pf.conf and custom rule file modifications.
