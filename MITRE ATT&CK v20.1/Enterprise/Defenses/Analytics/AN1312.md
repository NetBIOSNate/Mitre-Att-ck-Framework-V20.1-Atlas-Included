# AN1312 - Analytic 1312

[Enterprise](../../README.md) / [Analytics](README.md)

Correlates unusual auto-forwarding rule creation via Exchange Web Services or Outlook rules engine, presence of X-MS-Exchange-Organization-AutoForwarded headers, and logon session anomalies from abnormal IPs.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0476#AN1312)

**Platforms**  [Office Suite](../../Platforms/Office%20Suite.md)

## Log sources and channels

- **m365:unified** — Set-Mailbox, New-InboxRule · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **m365:exchange** — MessageTrace logs · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **azure:ad** — SignInEvents · [DC0067 - Logon Session Creation](../Data%20Components/DC0067%20-%20Logon%20Session%20Creation.md)

## Mutable elements

- **UserAgentList** — Restrict rules from non-browser agents
- **ExternalSMTPDomainList** — Allow listing for org-sanctioned forwarding domains
- **TimeWindow** — Time delta between rule creation and suspicious sign-in
