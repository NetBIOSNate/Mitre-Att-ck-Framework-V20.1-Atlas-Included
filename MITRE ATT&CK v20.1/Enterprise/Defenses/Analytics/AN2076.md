# AN2076 - Analytic 2076

[Enterprise](../../README.md) / [Analytics](README.md)

Detect successful Office Suite access using an authentication method that does not perform the account's expected MFA flow, correlated within ASPActivityWindow with first-seen client/application access, an anomalous source/device, or an ASP-related account credential change where available.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0926#AN2076)

**Platforms**  [Office Suite](../../Platforms/Office%20Suite.md)

- **azure:signinlogs** — Successful account authentication with authentication/client properties inconsistent with normal MFA-backed access  · [DC0002 - User Account Authentication](../Data%20Components/DC0002%20-%20User%20Account%20Authentication.md)
