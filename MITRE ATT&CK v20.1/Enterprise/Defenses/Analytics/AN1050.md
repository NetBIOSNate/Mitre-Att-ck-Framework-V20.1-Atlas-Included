# AN1050 - Analytic 1050

[Enterprise](../../README.md) / [Analytics](README.md)

Execution of AppleScript, bash, or launchd jobs that invoke delay functions (e.g., sleep, delay in AppleScript) with limited parent interaction and staged follow-on commands.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0372#AN1050)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — launchd or osascript spawns process with delay command · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:unifiedlog** — delay/sleep library usage in user context · [DC0016 - Module Load](../Data%20Components/DC0016%20-%20Module%20Load.md)

## Mutable elements

- **ScriptPattern** — AppleScript vs shell scripts differ per threat and org.
- **UserContext** — Execution under user vs daemon context changes severity.
- **DelayDurationThreshold** — Amount of delay that distinguishes benign usage vs evasion.
