# AN0592 - Analytic 0592

[Enterprise](../../README.md) / [Analytics](README.md)

Domain logins using network accounts or mobile accounts via Open Directory or Active Directory plugins, especially outside business hours or on atypical endpoints.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0210#AN0592)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — log show --predicate 'eventMessage contains "Authentication"' · [DC0002 - User Account Authentication](../Data%20Components/DC0002%20-%20User%20Account%20Authentication.md)

## Mutable elements

- **UserLocation** — Geo-IP or VPN source context for abnormal remote access.
- **LogonMethod** — Control for expected services (e.g., GUI login vs. SSH).
