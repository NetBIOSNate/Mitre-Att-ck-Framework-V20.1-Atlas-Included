# AN0019 - Analytic 0019

[Enterprise](../../README.md) / [Analytics](README.md)

Login to M365 or Google Workspace from CLI tools or unexpected source IPs, followed by mailbox or document access

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0008#AN0019)

**Platforms**  [Office Suite](../../Platforms/Office%20Suite.md)

## Log sources and channels

- **m365:unified** — FileAccessed, MailboxAccessed · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **m365:unified** — UserLoggedIn · [DC0067 - Logon Session Creation](../Data%20Components/DC0067%20-%20Logon%20Session%20Creation.md)

## Mutable elements

- **DevicePlatformMismatch** — Raise alerts on login from CLI when user typically uses web-only
- **SensitiveDocumentAccessPattern** — Track access to documents labeled as internal/confidential
- **AccessFrequencyThreshold** — Tune for high-volume document reads post login
