# AN1295 - Analytic 1295

[Enterprise](../../README.md) / [Analytics](README.md)

Detection of binaries spawning encrypted sessions using OpenSSL or curl to external services with mismatched ports/protocols. Identifies behavior where internal services simulate trusted cloud service traffic patterns.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0470#AN1295)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **NSM:Flow** — Network Capture TLS/HTTP · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **ProtocolMatchConfidence** — Threshold for header-field mismatch against expected service behavior.
- **TimeWindow** — Correlation window between process spawn and encrypted session.
