# AN0342 - Analytic 0342

[Enterprise](../../README.md) / [Analytics](README.md)

Detects removable drive insertion followed by unusual file access, compression, or staging activity by unauthorized users or unexpected processes.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0123#AN0342)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=11 · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **WinEventLog:Security** — EventCode=4663, 4670, 4656 · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **WinEventLog:System** — EventCode=1006, 10001 · [DC0042 - Drive Creation](../Data%20Components/DC0042%20-%20Drive%20Creation.md)

## Mutable elements

- **DriveTypeFilter** — Filter on removable (e.g., USB) drives only.
- **ProcessNameExclusionList** — Exclude known, approved backup or sync utilities.
- **TimeWindow** — Limit correlation of file access and device mount to a defined window (e.g., <5 minutes).
