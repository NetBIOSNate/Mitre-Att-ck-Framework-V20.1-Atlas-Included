# AN1500 - Analytic 1500

[Enterprise](../../README.md) / [Analytics](README.md)

Encrypted sessions detected with asymmetric key exchange anomalies on non-standard ports or with invalid/malformed certs. Defender correlates NetFlow/IPFIX with IDS/IPS detecting RSA exchanges outside expected TLS flows.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0543#AN1500)

**Platforms**  [Network Devices](../../Platforms/Network%20Devices.md)

## Log sources and channels

- **NSM:Flow** — Flow records with RSA key exchange on unexpected port · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **IDS:TLSInspection** — Malformed certs, incomplete asymmetric handshakes, or invalid CAs · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **PortProfiles** — Define expected ports for asymmetric cryptography (e.g., 443, 993).
- **CertValidationPolicy** — Thresholds for rejecting untrusted/self-signed certs.
