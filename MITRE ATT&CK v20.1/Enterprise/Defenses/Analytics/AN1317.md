# AN1317 - Analytic 1317

[Enterprise](../../README.md) / [Analytics](README.md)

Cause→effect chain in CI/dev desktops: (1) user triggers container run/pull after opening a doc/link/script, (2) newly created image/container uses unexpected external registry or entrypoint, (3) container starts and immediately egresses to suspicious destinations.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0478#AN1317)

**Platforms**  [Containers](../../Platforms/Containers.md)

## Log sources and channels

- **docker:events** — created,started: new container from untrusted registry or unexpected entrypoint · [DC0072 - Container Creation](../Data%20Components/DC0072%20-%20Container%20Creation.md)
- **docker:events** — start · [DC0077 - Container Start](../Data%20Components/DC0077%20-%20Container%20Start.md)
- **NSM:Flow** — container egress to unknown IPs/domains · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **TrustedRegistries** — Approved registries/namespaces.
- **AllowedEntrypoints** — Expected CMD/ENTRYPOINT for known images.
- **TimeWindow** — Correlate user action → docker/podman run within 10 minutes.
