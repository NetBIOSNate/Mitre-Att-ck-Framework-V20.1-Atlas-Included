# AN1184 - Analytic 1184

[Enterprise](../../README.md) / [Analytics](README.md)

API usage or filesystem access revealing user state or browser artifacts (e.g., Safari bookmarks, CGEventState).

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0420#AN1184)

**Platforms**  [macOS](../../Platforms/macOS.md)

- **macos:unifiedlog** — Access to ~/Library/Safari/Bookmarks.plist or recent files · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)

## Mutable elements

- **TimeWindow** — Temporal correlation between login and file access
- **UserContext** — Exclude expected UI activity from login agents
