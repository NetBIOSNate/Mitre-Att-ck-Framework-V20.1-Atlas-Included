# AN1006 - Analytic 1006

[Enterprise](../../README.md) / [Analytics](README.md)

Unexpected inbound or outbound VNC/SSH/Screen Sharing connections from external sources → repeated failed logins followed by success → remote interactive sessions or abnormal file transfers.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0354#AN1006)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Remote login (ssh) or screen sharing authentication attempts · [DC0088 - Logon Session Metadata](../Data%20Components/DC0088%20-%20Logon%20Session%20Metadata.md)
- **macos:unifiedlog** — Inbound connections to VNC/SSH ports · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **PF:Logs** — External traffic to remote access services · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **KnownVNCServers** — List of approved VNC/SSH sources.
- **TimeWindow** — Time correlation between failed attempts and success.
