# AN1474 - Analytic 1474

[Enterprise](../../README.md) / [Analytics](README.md)

Unauthorized modification of TCC.db followed by elevated process execution under a trusted parent (e.g., Finder, SystemUIServer) or via launchctl environment override. Also includes identification of SIP being disabled, which is highly uncommon and a prerequisite for this abuse path.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0534#AN1474)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Execution of binaries with TCC protected access under unexpected parent processes such as Finder.app, SystemUIServer, or nsurlsessiond · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:unifiedlog** — Modification or replacement of /Library/Application Support/com.apple.TCC/TCC.db or ~/Library/Application Support/com.apple.TCC/TCC.db · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)
- **macos:unifiedlog** — Execution of launchctl with setenv or bootout targeting TCC.db or AppleScript under Finder context · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **macos:unifiedlog** — System Integrity Protection (SIP) state reported as disabled · [DC0018 - Host Status](../Data%20Components/DC0018%20-%20Host%20Status.md)

## Mutable elements

- **ParentProcessName** — May vary across macOS versions and user contexts; defenders can tune for known benign cases.
- **TCCModificationPath** — Custom user paths or redirected SQLite DBs may require alternate matching logic.
- **TimeWindow** — Temporal proximity between launchctl setenv and subsequent privileged access can be tuned.
- **SIPStateCheckInterval** — Frequency of SIP integrity checks may vary based on system hardening policies.
