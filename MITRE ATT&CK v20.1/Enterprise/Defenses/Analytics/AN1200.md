# AN1200 - Analytic 1200

[Enterprise](../../README.md) / [Analytics](README.md)

Monitors Keychain database access and suspicious invocations of security and osascript utilities. Correlates process execution with attempts to dump or unlock Keychain data.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0430#AN1200)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — access to keychain database · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **macos:unifiedlog** — execution of security or osascript · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **AllowedApplications** — Whitelist of legitimate processes accessing the Keychain
- **AlertThreshold** — Number of failed access attempts before raising an alert
