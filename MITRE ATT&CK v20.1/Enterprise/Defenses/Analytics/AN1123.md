# AN1123 - Analytic 1123

[Enterprise](../../README.md) / [Analytics](README.md)

Detects scripting environments (AppleScript, osascript, curl) or non-native tools performing DNS queries with encoded subdomains, often used for data exfiltration or beaconing.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0400#AN1123)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — log stream 'eventMessage contains "dns_request"' · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **EntropyThreshold** — Tunable threshold for randomness in subdomain labels
- **UncommonProcessContext** — Filters on user-launched or cron-based queries
