# AN0506 - Analytic 0506

[Enterprise](../../README.md) / [Analytics](README.md)

Detection of VNC-based remote control via `screensharingd` activity in Unified Logs along with concurrent remote login activity or suspicious user interaction.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0178#AN0506)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — authentication · [DC0067 - Logon Session Creation](../Data%20Components/DC0067%20-%20Logon%20Session%20Creation.md)
- **macos:osquery** — process_events · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **NSM:firewall** — inbound connection to port 5900 · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **AuthenticationPredicate** — Unified log predicate to refine suspicious screensharing access
- **TimeWindow** — Time between VNC connection and follow-on activity (e.g., 30s)
- **UserActivitySpike** — Mouse/keyboard interaction spike immediately post-VNC login
