# AN0357 - Analytic 0357

[Enterprise](../../README.md) / [Analytics](README.md)

Adversary creates disguised launch daemons or apps with misleading names and bundle metadata (e.g., Info.plist values inconsistent with binary path or icon). Launch is correlated with user logon or persistence setup.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0127#AN0357)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — process · [DC0034 - Process Metadata](../Data%20Components/DC0034%20-%20Process%20Metadata.md)
- **macos:endpointsecurity** — ES_EVENT_TYPE_NOTIFY_EXEC · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **fs:fileevents** — /var/log/install.log · [DC0059 - File Metadata](../Data%20Components/DC0059%20-%20File%20Metadata.md)

## Mutable elements

- **InfoPlistDiscrepancy** — Mismatch between bundle metadata and file system path/name
- **LaunchAgentPath** — Unusual LaunchDaemon/LaunchAgent paths can be tuned per org
- **ExecutionTrigger** — Window between install and first execution (e.g., at user login)
