# AN0938 - Analytic 0938

[Enterprise](../../README.md) / [Analytics](README.md)

Correlation of package install event with execution of postinstall scripts containing unknown binaries or abnormal CLI usage. Look for `/usr/sbin/installer` execution followed by child processes originating from postinstall script.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0330#AN0938)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Execution of /usr/sbin/installer spawning child process from within /private/tmp or package contents · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:unifiedlog** — Creation or modification of postinstall scripts within .pkg or .mpkg contents · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)

## Mutable elements

- **ScriptLocation** — Path to postinstall script varies depending on .pkg packaging and user temp directories.
- **ParentProcessName** — Installers may vary (e.g., /usr/sbin/installer, Jamf, Munki).
