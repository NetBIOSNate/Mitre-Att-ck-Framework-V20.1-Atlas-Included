# AN0171 - Analytic 0171

[Enterprise](../../README.md) / [Analytics](README.md)

Disabling or modifying the Linux Audit system through process termination (auditd killed), service management (systemctl stop auditd), or tampering with rule/configuration files (/etc/audit/audit.rules, audit.conf). Defender view: suspicious execution of auditctl/systemctl commands, file modifications to audit rules, or sudden absence of audit logs correlated with privileged execution.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0062#AN0171)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:EXECVE** — Execution of auditctl, systemctl stop auditd, or kill -9 auditd · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **auditd:SYSCALL** — kill syscalls targeting auditd process · [DC0020 - Process Modification](../Data%20Components/DC0020%20-%20Process%20Modification.md)
- **auditd:FILE** — Modification or deletion of /etc/audit/audit.rules or /etc/audit/audit.conf · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)
- **linux:syslog** — auditd service stopped or disabled · [DC0041 - Service Metadata](../Data%20Components/DC0041%20-%20Service%20Metadata.md)

## Mutable elements

- **ServiceWhitelist** — Exclude legitimate administrative service stops during system maintenance.
- **FilePathScope** — Specify monitored paths (/etc/audit/audit.rules, audit.conf) to avoid false positives from unrelated file writes.
- **TimeWindow** — Correlate suspicious commands, file modifications, and audit log gaps in short succession.
