# AN0760 - Analytic 0760

[Enterprise](../../README.md) / [Analytics](README.md)

Processes like curl, wget, python, socat, or custom binaries initiating TLS/SSL sessions to non-standard destinations. Defender sees abnormal syscalls for connect(), loading of libssl libraries, and persistent outbound encrypted traffic from daemons not normally communicating externally.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0273#AN0760)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — socket/connect with TLS context by unexpected process · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **linux:syslog** — system daemons initiating TLS sessions outside expected services · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **linux:osquery** — Processes linked with libssl or crypto libraries making outbound connections · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **WhitelistedDaemons** — Legitimate system services expected to use TLS (e.g., package updates).
- **CertificateAuthorities** — Trusted CAs; flag self-signed or unrecognized certs.
