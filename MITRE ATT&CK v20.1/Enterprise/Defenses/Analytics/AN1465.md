# AN1465 - Analytic 1465

[Enterprise](../../README.md) / [Analytics](README.md)

Unusual or suspicious processes loading critical native API DLLs (e.g., ntdll.dll, kernel32.dll) followed by direct syscall behavior, memory manipulation, or hollowing.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0529#AN1465)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=7 · [DC0016 - Module Load](../Data%20Components/DC0016%20-%20Module%20Load.md)
- **WinEventLog:Sysmon** — EventCode=10 · [DC0035 - Process Access](../Data%20Components/DC0035%20-%20Process%20Access.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **DllName** — May tune DLL filters to focus on low-level API providers (e.g., ntdll.dll)
- **Image** — Tune for expected parent processes (e.g., explorer.exe, winlogon.exe)
- **TargetProcess** — Scope to suspicious targets like LSASS, csrss, etc.
