# AN0721 - Analytic 0721

[Enterprise](../../README.md) / [Analytics](README.md)

Forged credentials on macOS may be visible through Unified Logs showing abnormal access to Keychain or browser session files. Correlated with anomalous web session usage from Safari or Chrome processes outside typical user context.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0260#AN0721)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Access to Keychain items or browser credential stores · [DC0067 - Logon Session Creation](../Data%20Components/DC0067%20-%20Logon%20Session%20Creation.md)
- **macos:unifiedlog** — Web sessions initiated with newly forged tokens · [DC0007 - Web Credential Usage](../Data%20Components/DC0007%20-%20Web%20Credential%20Usage.md)

## Mutable elements

- **AuthorizedKeychainApps** — List applications that normally request Keychain credentials.
