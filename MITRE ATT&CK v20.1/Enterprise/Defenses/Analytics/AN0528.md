# AN0528 - Analytic 0528

[Enterprise](../../README.md) / [Analytics](README.md)

Application access tokens used to call APIs (e.g., Google Workspace, Salesforce) without interactive logins, often with unusual scopes or elevated permissions.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0185#AN0528)

**Platforms**  [SaaS](../../Platforms/SaaS.md)

## Log sources and channels

- **saas:googleworkspace** — OAuthTokenGranted, APIRequest · [DC0007 - Web Credential Usage](../Data%20Components/DC0007%20-%20Web%20Credential%20Usage.md)
- **saas:salesforce** — API login using access_token without login history · [DC0002 - User Account Authentication](../Data%20Components/DC0002%20-%20User%20Account%20Authentication.md)

## Mutable elements

- **ApplicationScopeAllowlist** — Restrict allowed API scopes for enterprise applications
- **TokenLifetime** — Threshold for detecting unusually long-lived tokens
