# AN0043 - Analytic 0043

[Enterprise](../../README.md) / [Analytics](README.md)

Detects virtual disk expansion or file copy operations to cloud buckets or mounted volumes from isolated instances.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0014#AN0043)

**Platforms**  [IaaS](../../Platforms/IaaS.md)

## Log sources and channels

- **AWS:CloudTrail** — GetObject, CopyObject · [DC0025 - Cloud Storage Access](../Data%20Components/DC0025%20-%20Cloud%20Storage%20Access.md)
- **gcp:audit** — Write operations to storage · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)

## Mutable elements

- **CloudBucketList** — Staging bucket or mount point for data
- **InstanceTag** — Behavior restricted to specific ephemeral instances
- **ObjectWriteThreshold** — Volume or size of files pushed in burst
