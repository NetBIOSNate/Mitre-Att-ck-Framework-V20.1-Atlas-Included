# AN1503 - Analytic 1503

[Enterprise](../../README.md) / [Analytics](README.md)

Detects anomalous authentication activity such as sign-ins from impossible geolocations or legacy protocols from high-privileged accounts.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0546#AN1503)

**Platforms**  [Identity Provider](../../Platforms/Identity%20Provider.md)

## Log sources and channels

- **azure:signinlogs** — Sign-in activity · [DC0002 - User Account Authentication](../Data%20Components/DC0002%20-%20User%20Account%20Authentication.md)
- **saas:okta** — user.authentication.sso · [DC0088 - Logon Session Metadata](../Data%20Components/DC0088%20-%20Logon%20Session%20Metadata.md)

## Mutable elements

- **AnomalousLocationThreshold** — Defines geographic separation (e.g., impossible travel) considered suspicious.
- **ProtocolType** — Filter based on legacy or deprecated authentication mechanisms.
