# AN1371 - Analytic 1371

[Enterprise](../../README.md) / [Analytics](README.md)

Detection of adversary disabling endpoint security tools by unloading launch agents/daemons, modifying configuration profiles, or disabling Gatekeeper/XProtect/logging settings, or removing endpoint agents followed by telemetry loss.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0497#AN1371)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Execution of launchctl unload, kill, or removal of security agent daemons · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:unifiedlog** — Modification of system configuration profiles affecting security tools · [DC0041 - Service Metadata](../Data%20Components/DC0041%20-%20Service%20Metadata.md)

## Mutable elements

- **DaemonNames** — Expected security agent daemons (e.g., com.crowdstrike.falcon.Agent).
- **TimeWindow** — Detection correlation period for multiple security tool disable actions.
