# AN1141 - Analytic 1141

[Enterprise](../../README.md) / [Analytics](README.md)

Spoofed outbound packets sent to amplification services from command-line tools or scripts, combined with abnormal outbound packet volume on known reflector ports

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0408#AN1141)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — Execution of spoofing tools (e.g., hping3, nping, scapy) sending UDP packets to known amplifier ports · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **NSM:Flow** — Outbound UDP floods targeting common reflection services with spoofed IP headers · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **sar:network** — Outbound network saturation with minimal process activity · [DC0018 - Host Status](../Data%20Components/DC0018%20-%20Host%20Status.md)

## Mutable elements

- **TimeWindow** — Sliding interval for detecting volumetric anomalies
- **AmplificationProtocolList** — Which protocols to watch (e.g., DNS, NTP, SSDP, Memcached)
- **ExecutionToolList** — Set of binaries and scripts commonly abused for spoofing/reflection
