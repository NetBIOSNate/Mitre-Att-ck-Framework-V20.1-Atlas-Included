# AN1615 - Analytic 1615

[Enterprise](../../README.md) / [Analytics](README.md)

Detection of enumeration of identity entities through cloud provider APIs where principals retrieve account metadata such as IAM users or roles in rapid succession.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0587#AN1615)

**Platforms**  [IaaS](../../Platforms/IaaS.md)

## Log sources and channels

- **AWS:CloudTrail** — DescribeUsers / ListUsers / GetUser · [DC0083 - Cloud Service Enumeration](../Data%20Components/DC0083%20-%20Cloud%20Service%20Enumeration.md)

## Mutable elements

- **API_Method** — Tune based on which IAM APIs are used and their frequency.
- **CallerType** — Differentiate user-initiated from automated/scripted enumeration.
