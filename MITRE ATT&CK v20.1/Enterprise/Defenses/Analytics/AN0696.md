# AN0696 - Analytic 0696

[Enterprise](../../README.md) / [Analytics](README.md)

Identifies unauthorized access or enumeration of administrative roles, security groups, or distribution groups via Exchange/SharePoint/Teams APIs or role discovery scripts.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0251#AN0696)

**Platforms**  [Office Suite](../../Platforms/Office%20Suite.md)

## Log sources and channels

- **m365:exchange** — Get-RoleGroup, Get-DistributionGroup · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **m365:sharepoint** — Enumerate ACLs/role bindings · [DC0105 - Group Metadata](../Data%20Components/DC0105%20-%20Group%20Metadata.md)

## Mutable elements

- **AccessScope** — Adjust based on tenant-level vs. site-level group visibility.
- **ScriptExecutionContext** — Detect script-based role listing (e.g., Graph API call chains).
