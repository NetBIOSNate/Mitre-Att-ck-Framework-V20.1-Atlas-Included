# AN0003 - Analytic 0003

[Enterprise](../../README.md) / [Analytics](README.md)

Detects CLI tools (e.g., mosquitto_pub, nc, python scripts) interacting with pub/sub brokers using unusual topic names, high-frequency publication rates, or obfuscated payloads to non-standard hosts.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0002#AN0003)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **NSM:Flow** — mqtt.log or AMQP custom log · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **BrokerAllowList** — Known-good brokers used by approved apps and daemons
- **TopicAnomalyScore** — Payload length, entropy, or topic name patterns
