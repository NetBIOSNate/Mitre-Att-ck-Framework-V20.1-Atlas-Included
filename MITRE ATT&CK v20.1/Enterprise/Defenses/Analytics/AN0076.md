# AN0076 - Analytic 0076

[Enterprise](../../README.md) / [Analytics](README.md)

Detects curl, wget, Python requests, or custom HTTP clients communicating over non-standard ports, with repetitive or beacon-like patterns or POST-heavy behavior to rare domains.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0027#AN0076)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **NSM:Flow** — http.log, conn.log · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **auditd:SYSCALL** — execve · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **CommandLinePatternMatch** — curl or wget in scripts with suspicious domains or silent flags
- **BeaconIntervalWindow** — Fixed-timed HTTP callbacks with 60±5s jitter
