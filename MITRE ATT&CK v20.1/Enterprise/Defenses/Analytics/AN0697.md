# AN0697 - Analytic 0697

[Enterprise](../../README.md) / [Analytics](README.md)

Monitors API calls and service-specific logs for enumeration of organizational roles, permissions, and group structure, particularly outside of normal admin behavior baselines.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0251#AN0697)

**Platforms**  [SaaS](../../Platforms/SaaS.md)

## Log sources and channels

- **saas:salesforce** — GET /services/data/vXX.X/groups · [DC0099 - Group Enumeration](../Data%20Components/DC0099%20-%20Group%20Enumeration.md)

## Mutable elements

- **OrgScope** — Scope to cross-team access or unfamiliar org enumeration.
- **RequestRate** — Tuning for excessive group-list API calls.
