# AN0827 - Analytic 0827

[Enterprise](../../README.md) / [Analytics](README.md)

Processes attempting raw disk access to overwrite sensitive structures such as the MBR or partition table using \\.\PhysicalDrive notation. Detection relies on correlating process creation, privilege escalation, and raw sector writes in Sysmon and Security logs.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0297#AN0827)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — EventCode=4673 · [DC0013 - User Account Metadata](../Data%20Components/DC0013%20-%20User%20Account%20Metadata.md)
- **WinEventLog:Sysmon** — Raw write attempts targeting \\.\PhysicalDrive0 or sector 0 (MBR/partition table) · [DC0046 - Drive Modification](../Data%20Components/DC0046%20-%20Drive%20Modification.md)
- **WinEventLog:Sysmon** — EventCode=6 · [DC0079 - Driver Load](../Data%20Components/DC0079%20-%20Driver%20Load.md)

## Mutable elements

- **SectorRange** — Specify which sectors are considered critical (MBR, partition table) to reduce noise.
- **ProcessWhitelist** — Exclude legitimate low-level disk management or imaging tools used by administrators.
