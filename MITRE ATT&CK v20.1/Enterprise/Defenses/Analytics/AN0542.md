# AN0542 - Analytic 0542

[Enterprise](../../README.md) / [Analytics](README.md)

Detection of XProtect or AV quarantining a known tool, followed by modification (file size, hash, string) and subsequent re-execution by the same or related user.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0189#AN0542)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — quarantine or AV-related subsystem · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **macos:osquery** — file_events · [DC0059 - File Metadata](../Data%20Components/DC0059%20-%20File%20Metadata.md)

## Mutable elements

- **BinaryChangeThreshold** — File hash delta or binary string diff score to tolerate renamed/mutated variants.
- **UserContext** — User or group expected to use dev tools; reduce false positives from legitimate repacking.
