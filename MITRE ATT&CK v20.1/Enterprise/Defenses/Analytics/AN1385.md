# AN1385 - Analytic 1385

[Enterprise](../../README.md) / [Analytics](README.md)

Hidden file creation using leading '.' or file attribute changes with chattr (immutable/hidden flags). Defender view: detect execution of chattr, lsattr anomalies, and unusual hidden files appearing in system directories.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0502#AN1385)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:EXECVE** — Execution of chattr to set +i or +a attributes · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **auditd:FILE** — Creation of hidden files (.*) in sensitive directories (/etc, /var, /usr/bin) · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)

## Mutable elements

- **DirectoryScope** — Restrict hidden file detection to privileged system directories.
- **AttributeFlags** — Tune for specific chattr flags (+i immutable, +a append-only) most abused for persistence.
