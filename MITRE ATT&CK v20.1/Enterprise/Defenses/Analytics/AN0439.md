# AN0439 - Analytic 0439

[Enterprise](../../README.md) / [Analytics](README.md)

VMware services or management daemons generating HTTP POST requests to webhook endpoints, chained with unusual datastore or log access. Defender perspective: exfiltration from VM logs or disk images over webhook URLs.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0153#AN0439)

**Platforms**  [ESXi](../../Platforms/ESXi.md)

## Log sources and channels

- **esxi:hostd** — datastore file access · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **esxi:vmkernel** — HTTPS POST connections to webhook endpoints · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **DatastoreExfilThreshold** — Minimum data volume to flag exfiltration attempts from VM files.
- **ApprovedIntegrations** — Whitelisted CI/CD or automation webhooks tied to vSphere/ESXi.
