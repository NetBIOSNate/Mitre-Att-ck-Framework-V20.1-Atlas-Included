# AN2079 - Analytic 2079

[Enterprise](../../README.md) / [Analytics](README.md)

An analyst observes an AI-associated process access data outside $AuthorizedAIDataScope$, followed within $EndpointExfilWindow$ by transfer-capable execution and an outbound connection to a destination outside $AuthorizedAIEndpoints$ from the same process lineage.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0927#AN2079)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — EventCode=4663, 4670, 4656 · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **WinEventLog:PowerShell** — EventCode=4103, 4104, 4105, 4106 · [DC0029 - Script Execution](../Data%20Components/DC0029%20-%20Script%20Execution.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **AuthorizedAIDataScope** — data paths/classes the AI application/service identity is permitted to access; derive from application design, IAM and data policy
- **ExpectedAIProcessTree** — approved AI parent/child relationships from clean executions
- **AuthorizedAIEndpoints** — legitimate service/repository/API destinations
- **EndpointExfilWindow** — access→execution→egress timing derived from clean workflows
