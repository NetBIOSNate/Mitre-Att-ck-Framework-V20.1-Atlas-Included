# AN0266 - Analytic 0266

[Enterprise](../../README.md) / [Analytics](README.md)

Use of native tools or scripting (e.g., `usermod`, `passwd`, `groupmod`) to escalate permissions or persist access on existing users, correlated with login or process events.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0096#AN0266)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — usermod, groupmod, passwd · [DC0010 - User Account Modification](../Data%20Components/DC0010%20-%20User%20Account%20Modification.md)
- **auditd:PATH** — /etc/passwd or /etc/group file write · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)

## Mutable elements

- **SudoPath** — Common sudo or privilege escalation paths (e.g., `/usr/bin/passwd`).
- **ModifiedShellList** — Detect if user shell is changed to unusual one (e.g., /bin/sh -> /bin/bash).
