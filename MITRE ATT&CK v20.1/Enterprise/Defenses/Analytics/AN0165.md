# AN0165 - Analytic 0165

[Enterprise](../../README.md) / [Analytics](README.md)

Unusual or uncommon processes initiate network connections to external destinations followed by file creation (tools downloaded).

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0060#AN0165)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=3, 22 · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=11 · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **ParentProcessName** — Tune for known good updaters (e.g., ChromeUpdate, OneDrive)
- **DestinationIPCategory** — Allow filtering by internal vs external IP blocks
- **FilePathRegex** — Focus on uncommon file drop paths (e.g., C:\Users\Public\)
