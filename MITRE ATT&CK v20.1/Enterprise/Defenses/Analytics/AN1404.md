# AN1404 - Analytic 1404

[Enterprise](../../README.md) / [Analytics](README.md)

Detects unauthorized access to browser cookie paths (e.g., `~/Library/Application Support/Google/Chrome/Default/Cookies`) or `task_for_pid`/`vm_read` calls to Safari/Chrome memory space.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0509#AN1404)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — vm_read, task_for_pid, or file open to cookie databases · [DC0035 - Process Access](../Data%20Components/DC0035%20-%20Process%20Access.md)
- **fs:fsusage** — file open for known browser cookie paths · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)

## Mutable elements

- **TargetBrowserList** — List of processes considered web browsers on macOS
- **BrowserCookiePathList** — Cookie database paths specific to each browser
