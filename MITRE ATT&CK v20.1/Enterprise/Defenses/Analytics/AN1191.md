# AN1191 - Analytic 1191

[Enterprise](../../README.md) / [Analytics](README.md)

Detects user agents or background services making unauthorized or unscheduled web API calls to cloud/web services over HTTPS.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0425#AN1191)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — process + network activity · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **macos:osquery** — process_events, socket_events · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **ProcessSignature** — Unsigned or user-modified apps communicating with cloud services
- **ConnectionInterval** — Beacon-like pattern of regular outbound communication
