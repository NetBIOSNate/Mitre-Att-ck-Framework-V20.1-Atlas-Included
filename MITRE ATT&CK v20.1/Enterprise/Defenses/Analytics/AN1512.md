# AN1512 - Analytic 1512

[Enterprise](../../README.md) / [Analytics](README.md)

Processes (tar, curl, python scripts) accessing large file sets and initiating outbound HTTPS POST requests with payload sizes inconsistent with baseline activity. Defender perspective: detect abnormal sequence of file archival followed by encrypted uploads to external web services.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0548#AN1512)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:EXECVE** — curl or wget with POST/PUT options · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **auditd:SYSCALL** — open/read of sensitive directories (/etc, /home/*) · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **NSM:Flow** — sustained outbound HTTPS sessions with high data volume · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **MonitoredTools** — Suspicious command-line utilities used for exfiltration (curl, wget, python).
- **DataVolumeThreshold** — Bytes transferred threshold per session to flag unusual uploads.
