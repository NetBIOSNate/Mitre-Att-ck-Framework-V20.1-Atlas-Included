# AN1074 - Analytic 1074

[Enterprise](../../README.md) / [Analytics](README.md)

Adversaries accessing datastore or configuration files via `vim-cmd`, `esxcli`, or SCP to extract logs, VMs, or host configurations.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0380#AN1074)

**Platforms**  [ESXi](../../Platforms/ESXi.md)

## Log sources and channels

- **esxis:vmkernel** — Datastore Access · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **esxi:hostd** — Command Execution · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **AccessPathRegex** — Regex for filtering targeted VM paths or files like *.vmdk, *.vmx.
- **InteractiveShellUsage** — Tune to distinguish between interactive and script-driven data access.
