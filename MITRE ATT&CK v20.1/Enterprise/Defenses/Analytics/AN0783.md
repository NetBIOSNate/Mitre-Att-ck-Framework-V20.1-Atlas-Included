# AN0783 - Analytic 0783

[Enterprise](../../README.md) / [Analytics](README.md)

Detects sequential command-line compression utilities (e.g., gzip, tar, zip, 7z) followed by execution of unpacked files, especially in temp directories or under non-standard locations like /dev/shm or /tmp with ELF binaries.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0281#AN0783)

**Platforms**  [Linux](../../Platforms/Linux.md)

- **auditd:SYSCALL** — execve · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **auditd:SYSCALL** — write · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **auditd:SYSCALL** — openat · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **auditd:SYSCALL** — chmod · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)

## Mutable elements

- **PathRegex** — Flag compressed archives extracted to /tmp, /dev/shm, or user’s home dir
- **CompressionToolPatterns** — gzip, tar, bzip2, xz, 7z – tune to suppress admin packaging workflows
- **ExecutionAfterUnpackWindow** — How soon a new file is executed after it’s unpacked
