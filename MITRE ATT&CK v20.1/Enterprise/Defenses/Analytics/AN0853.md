# AN0853 - Analytic 0853

[Enterprise](../../README.md) / [Analytics](README.md)

Cloud workload exploitation leads to repeated container, service, or VM termination/restart, typically associated with CVE-based crash triggers or fuzzed payloads.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0304#AN0853)

**Platforms**  [IaaS](../../Platforms/IaaS.md)

## Log sources and channels

- **AWS:CloudTrail** — TerminateInstances · [DC0089 - Instance Stop](../Data%20Components/DC0089%20-%20Instance%20Stop.md)
- **AWS:CloudWatch** — Repeated crash pattern within container or instance logs · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **AWS:VPCFlowLogs** — Large volume of malformed or synthetic payloads to application endpoints prior to failure · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **CrashThreshold** — Number of repeated crashes or terminations observed before triggering alert
- **ServiceID** — Cloud service name, workload, or container ID to scope alerting
