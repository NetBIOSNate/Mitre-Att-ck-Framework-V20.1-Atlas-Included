# AN1316 - Analytic 1316

[Enterprise](../../README.md) / [Analytics](README.md)

Cause→effect chain: (1) unified logs show application open/click or crash for Safari/Chrome/Office/Preview/archiver, (2) file write/extraction into ~/Downloads, /private/var/folders/* or ~/Library, (3) parent app spawns osascript/bash/zsh/curl/python or opens a quarantined app with Gatekeeper prompts, (4) network egress from child.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0478#AN1316)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — opened document|clicked link|EXC_BAD_ACCESS|abort|LSQuarantine · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **fs:fileevents** — create/write/rename in user-writable paths · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **macos:osquery** — exec · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **NSM:Flow** — new outbound connection from exploited lineage · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **TimeWindow** — 10–30 minute correlation window.
- **HighRiskChildren** — osascript, bash, zsh, curl, python, open -a Terminal, installer, tccutil misuse.
- **QuarantineSignals** — Flag new apps lacking com.apple.quarantine or with quarantine='0081' (downloaded then auto-opened).
