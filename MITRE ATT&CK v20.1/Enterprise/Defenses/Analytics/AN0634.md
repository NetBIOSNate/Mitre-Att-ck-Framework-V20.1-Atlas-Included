# AN0634 - Analytic 0634

[Enterprise](../../README.md) / [Analytics](README.md)

Unusual daemons or user processes binding/listening on ports outside of standard ranges, or initiating client connections using mismatched protocol/port pairings.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0227#AN0634)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — socket/connect syscalls · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **linux:syslog** — processes binding to non-standard ports or sshd configured on unexpected port · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **linux:osquery** — process listening or connecting on non-standard ports · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **AllowedServices** — Exclude ports intentionally configured for enterprise apps.
- **PayloadEntropyThreshold** — Define thresholds for anomalous payload entropy to catch tunneled traffic.
