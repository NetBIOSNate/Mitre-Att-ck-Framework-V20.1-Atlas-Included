# AN0016 - Analytic 0016

[Enterprise](../../README.md) / [Analytics](README.md)

Adversary uses nltest, PowerShell, or Win32/.NET API to enumerate domain trust relationships (via DSEnumerateDomainTrusts, GetAllTrustRelationships, or LDAP queries), followed by discovery or authentication staging.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0007#AN0016)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=7 · [DC0016 - Module Load](../Data%20Components/DC0016%20-%20Module%20Load.md)
- **WinEventLog:Sysmon** — EventCode=10 · [DC0035 - Process Access](../Data%20Components/DC0035%20-%20Process%20Access.md)
- **WinEventLog:PowerShell** — Get-ADTrust|GetAllTrustRelationships · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **WinEventLog:Security** — EventCode=4662 · [DC0071 - Active Directory Object Access](../Data%20Components/DC0071%20-%20Active%20Directory%20Object%20Access.md)

## Mutable elements

- **ParentImage** — Tune based on expected script hosts or authorized administrators invoking trust enumeration.
- **TimeWindow** — Correlate enumeration + subsequent Kerberos activity or DC interaction within a bounded window.
- **UserContext** — Prioritize detection for non-admin or unexpected user accounts performing enumeration.
- **API_Name** — Flag uncommon or low-prevalence API calls like DSEnumerateDomainTrusts for inspection.
