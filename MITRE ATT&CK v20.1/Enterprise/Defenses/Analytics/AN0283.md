# AN0283 - Analytic 0283

[Enterprise](../../README.md) / [Analytics](README.md)

Detects use of tools/scripts accessing input devices like /dev/input/* or evdev via suspicious processes lacking GUI context.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0102#AN0283)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — open, read · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **auditd:SYSCALL** — write · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)
- **auditd:SYSCALL** — ptrace, ioctl · [DC0021 - OS API Execution](../Data%20Components/DC0021%20-%20OS%20API%20Execution.md)

## Mutable elements

- **ProcessName** — Unusual process accessing device files
- **DevicePath** — Typically /dev/input/*, but tunable to exact endpoint config
