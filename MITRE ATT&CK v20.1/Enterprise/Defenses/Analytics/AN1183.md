# AN1183 - Analytic 1183

[Enterprise](../../README.md) / [Analytics](README.md)

Access to shell history or GUI input state (xdotool, xinput) for presence validation prior to payload execution.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0420#AN1183)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — Reads of ~/.bash_history, ~/.mozilla, or access to /dev/input · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **auditd:SYSCALL** — Execution of xev, xdotool, or input activity emulators · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **ArtifactCountThreshold** — Number of distinct user files accessed before trigger
- **KnownToolSignatures** — Suppress expected automation tools
