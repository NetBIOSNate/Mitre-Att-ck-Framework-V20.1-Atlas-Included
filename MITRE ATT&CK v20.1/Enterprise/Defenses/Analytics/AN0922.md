# AN0922 - Analytic 0922

[Enterprise](../../README.md) / [Analytics](README.md)

Unusual process (e.g., `rundll32`, `mshta`, `wscript`, or custom payloads) initiates network connection to external IPs/domains that proxy C2 traffic, often over uncommon ports or high entropy HTTP/S connections.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0325#AN0922)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=3, 22 · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Microsoft-Windows-Windows Defender/Operational** — Unusual external domain access · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **DestinationASN** — Adjust for known benign but high-risk infrastructure (e.g., hosting providers like DigitalOcean, OVH, etc.).
- **ParentProcess** — Detect suspicious lineage—proxy tools launched from script interpreters or LOLBins.
- **EntropyThreshold** — Tune based on expected randomness in outbound request payloads.
