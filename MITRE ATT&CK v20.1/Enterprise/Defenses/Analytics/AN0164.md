# AN0164 - Analytic 0164

[Enterprise](../../README.md) / [Analytics](README.md)

Detect manipulation of system or application files in `/Library`, `/System`, or user data directories using FSEvents and Unified Logs. Identify anomalous process execution modifying plist files, structured data, or logs outside expected update cycles.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0059#AN0164)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Anomalous plist modifications or sensitive file overwrites by non-standard processes · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)
- **macos:osquery** — open, execve: Unexpected processes accessing or modifying critical files · [DC0021 - OS API Execution](../Data%20Components/DC0021%20-%20OS%20API%20Execution.md)

## Mutable elements

- **AllowedPlistEditors** — Whitelisted processes authorized to modify plist or configuration files.
- **FileIntegrityBaseline** — Baseline hash values for key files to support integrity validation.
