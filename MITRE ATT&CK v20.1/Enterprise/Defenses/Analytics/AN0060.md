# AN0060 - Analytic 0060

[Enterprise](../../README.md) / [Analytics](README.md)

Correlates zsh shell configuration file changes (e.g., ~/.zshrc, ~/.zlogin, /etc/zprofile) with execution of unauthorized binaries or unexpected network activity triggered on Terminal.app launch.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0020#AN0060)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — launch of Terminal.app or shell with non-standard environment setup · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:endpointsecurity** — ES_EVENT_TYPE_NOTIFY_WRITE, targeting .zshrc, .zlogin, .zprofile · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)

## Mutable elements

- **FileTargetList** — Customizable list of shell config files considered sensitive for detection.
- **PayloadEntropyThreshold** — Used to distinguish benign from potentially obfuscated commands written to config files.
- **UserContext** — Scoping based on user login class, e.g., administrative vs standard users.
