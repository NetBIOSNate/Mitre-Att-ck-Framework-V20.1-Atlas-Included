# AN0346 - Analytic 0346

[Enterprise](../../README.md) / [Analytics](README.md)

Shell/utility (base64, xxd -p, od, openssl enc -base64, python/perl base64 libraries) encodes data → subsequent outbound connections (curl/wget/bash TCP, socat, python requests) with high asymmetry or Base64/MIME blobs in HTTP/DNS payloads.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0124#AN0346)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve of base64|openssl|xxd|python|perl with arguments matching Base64 flags · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=3, 22 · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **NSM:Flow** — http: HTTP body or headers contain long Base64 sections; gzip/deflate + Base64 · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **EncodingToolsAllowList** — Build/backup jobs that legitimately call base64/openssl.
- **EntropyThreshold** — Shannon entropy for payloads (e.g., >4.5).
- **TimeWindow** — Join window between exec and egress (default 10m).
- **OutInRatio** — Bytes_out / bytes_in threshold (default 4).
