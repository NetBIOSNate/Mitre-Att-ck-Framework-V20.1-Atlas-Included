# AN1102 - Analytic 1102

[Enterprise](../../README.md) / [Analytics](README.md)

Adversary runs 'system_profiler SPApplicationsDataType' or queries plist files to enumerate software via Terminal or scripts.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0392#AN1102)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Execution of system_profiler or osascript invoking enumeration · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **auditd:SYSCALL** — Command line arguments including SPApplicationsDataType · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **AppScope** — Whether enumeration targets user apps or system apps.
- **ProcessGroup** — Parent process or scripting environment (e.g., Python, osascript).
