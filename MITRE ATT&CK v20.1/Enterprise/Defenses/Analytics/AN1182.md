# AN1182 - Analytic 1182

[Enterprise](../../README.md) / [Analytics](README.md)

Process execution that probes user activity artifacts (e.g., desktop files, registry history) following recent user login/unlock events.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0420#AN1182)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=10 · [DC0035 - Process Access](../Data%20Components/DC0035%20-%20Process%20Access.md)
- **WinEventLog:Security** — EventCode=4800, 4801 · [DC0088 - Logon Session Metadata](../Data%20Components/DC0088%20-%20Logon%20Session%20Metadata.md)

## Mutable elements

- **TimeWindow** — Window between user unlock and access to user history
- **UserContext** — Focus on non-system accounts doing user activity probing
