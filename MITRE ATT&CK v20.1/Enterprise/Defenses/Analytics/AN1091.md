# AN1091 - Analytic 1091

[Enterprise](../../README.md) / [Analytics](README.md)

Detects anomalous ARP traffic or cache modifications on Windows endpoints that indicate ARP poisoning. Behavioral focus is on multiple IP addresses resolving to a single MAC, or unsolicited ARP replies from unauthorized devices.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0387#AN1091)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=3, 22 · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **WinEventLog:Security** — ARP cache modification attempts observed through event tracing or security baselines · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **TrustedGatewayMAC** — Expected MAC address for default gateways; deviations may indicate poisoning.
- **TimeWindow** — Correlation interval for repeated unsolicited ARP replies.
