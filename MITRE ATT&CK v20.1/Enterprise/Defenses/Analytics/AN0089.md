# AN0089 - Analytic 0089

[Enterprise](../../README.md) / [Analytics](README.md)

Execution of binaries with invalid digital signatures, where metadata claims code is signed but validation fails. Behavior is often correlated with suspicious parent processes or unexpected execution paths.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0031#AN0089)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Windows Defender** — Operational log · [DC0059 - File Metadata](../Data%20Components/DC0059%20-%20File%20Metadata.md)
- **WinEventLog:PowerShell** — EventCode=4103, 4104, 4105, 4106 · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **SignatureValidationResult** — Allow tuning to include 'invalid', 'expired', or 'untrusted root' based on environment tolerance
- **ParentProcessName** — Helps tune false positives by limiting to suspicious parent process executions
- **TimeWindow** — Defines correlation window between metadata check and process execution
