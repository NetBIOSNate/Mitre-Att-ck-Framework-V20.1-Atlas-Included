# AN1290 - Analytic 1290

[Enterprise](../../README.md) / [Analytics](README.md)

Detects rogue DHCP server activity and anomalous DHCP OFFER/ACK messages assigning unexpected DNS or gateway values. Detection correlates DHCP server role changes, DHCP exhaustion warnings, and sudden network configuration changes across endpoints.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0468#AN1290)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:System** — EventCode=1341, 1342, 1020, 1063 · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **NSM:Flow** — DHCP OFFER or ACK with unauthorized DNS/gateway parameters · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **AuthorizedDHCPServers** — List of known DHCP servers; unexpected sources are suspicious.
- **TimeWindow** — Interval to correlate DHCP OFFER/ACK anomalies with subsequent misconfigurations.
