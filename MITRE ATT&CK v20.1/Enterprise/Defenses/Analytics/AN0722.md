# AN0722 - Analytic 0722

[Enterprise](../../README.md) / [Analytics](README.md)

SaaS platforms may show forged credentials as unusual API keys, tokens, or session cookies being used without corresponding authentication. Correlated patterns include simultaneous valid sessions from multiple geographies, unusual API calls with new tokens, or bypass of expected MFA enforcement.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0260#AN0722)

**Platforms**  [SaaS](../../Platforms/SaaS.md)

## Log sources and channels

- **m365:unified** — Session creation without MFA or login event · [DC0006 - Web Credential Creation](../Data%20Components/DC0006%20-%20Web%20Credential%20Creation.md)
- **saas:auth** — API requests made with tokens not associated with expected user logins · [DC0007 - Web Credential Usage](../Data%20Components/DC0007%20-%20Web%20Credential%20Usage.md)

## Mutable elements

- **GeoLocationAlerts** — Trigger on logins from unusual or high-risk geographies.
- **TokenReplayThreshold** — Detect multiple simultaneous uses of the same forged credential.
