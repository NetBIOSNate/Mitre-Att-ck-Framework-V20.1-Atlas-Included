# AN1131 - Analytic 1131

[Enterprise](../../README.md) / [Analytics](README.md)

Configuration changes to virtual TAP/mirror policies that forward traffic to unapproved destinations. Detection correlates management plane API calls with mirrored traffic observation.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0403#AN1131)

**Platforms**  [IaaS](../../Platforms/IaaS.md)

## Log sources and channels

- **AWS:CloudTrail** — CreateTrafficMirrorSession or ModifyTrafficMirrorTarget · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **AWS:VPCFlowLogs** — Traffic observed on mirror destination instance · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **TimeWindow** — Detect mirror session creation followed by mirrored traffic within X seconds (e.g., 60s)
- **MirrorDestinationCIDR** — Define suspicious or external mirror targets (e.g., non-enterprise ranges)
- **UserIdentity** — Flag traffic mirror activity by non-privileged or unexpected IAM roles
