# AN0841 - Analytic 0841

[Enterprise](../../README.md) / [Analytics](README.md)

Execution of files originating from removable media after drive mount, with correlation to file write activity, autorun usage, or lateral spread via staged tools.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0301#AN0841)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:System** — EventCode=1006 · [DC0042 - Drive Creation](../Data%20Components/DC0042%20-%20Drive%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=11 · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Microsoft-Windows-Windows Defender/Operational** — Suspicious file execution on removable media path · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)

## Mutable elements

- **DriveLetterMatch** — Detect activity on mounted drives typically used by USB (e.g., E:, F:, G:). Tune based on enterprise usage.
- **FileExecutionWindow** — Set timing threshold for execution shortly after drive mount (e.g., < 5 minutes).
- **ParentProcess** — Restrict detection to suspicious process lineage like explorer.exe, powershell.exe, or unsigned binaries.
- **FileEntropy** — Use entropy thresholding to detect packed/obfuscated payloads dropped to removable media.
