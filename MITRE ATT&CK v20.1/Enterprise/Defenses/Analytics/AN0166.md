# AN0166 - Analytic 0166

[Enterprise](../../README.md) / [Analytics](README.md)

Shell-based tools (curl, wget, scp) initiate connections to external domains followed by creation of executable files on disk.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0060#AN0166)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — connect, execve, write · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **auditd:SYSCALL** — file creation/modification · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **iptables:LOG** — TCP connections · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **ToolName** — Match on curl, wget, rsync, etc. based on environment
- **DownloadExtension** — Tunable filter to limit to suspicious file types (.sh, .bin, .elf)
