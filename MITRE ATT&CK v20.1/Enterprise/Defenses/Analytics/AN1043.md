# AN1043 - Analytic 1043

[Enterprise](../../README.md) / [Analytics](README.md)

Execution of esxcli commands to enumerate datastore, configuration files, or directory structures by unauthorized or remote users.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0370#AN1043)

**Platforms**  [ESXi](../../Platforms/ESXi.md)

## Log sources and channels

- **esxi:shell** — Shell Access/Command Execution · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **esxi:hostd** — vSphere File API Access · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)

## Mutable elements

- **CLICommandPattern** — Match on esxcli storage|filesystem commands
- **AccessSource** — Limit alerting to non-vCenter or remote IPs
