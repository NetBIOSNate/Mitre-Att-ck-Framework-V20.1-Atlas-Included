# AN0452 - Analytic 0452

[Enterprise](../../README.md) / [Analytics](README.md)

Monitor PAM and syslog entries for unusual frequency of login attempts that trigger MFA prompts, particularly when MFA challenges do not match expected user behavior.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0160#AN0452)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:AUTH** — pam_unix or pam_google_authenticator invoked repeatedly within short interval · [DC0002 - User Account Authentication](../Data%20Components/DC0002%20-%20User%20Account%20Authentication.md)

## Mutable elements

- **AuthRetryThreshold** — Number of retries per user allowed before detection is triggered
