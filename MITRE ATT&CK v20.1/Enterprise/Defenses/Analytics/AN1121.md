# AN1121 - Analytic 1121

[Enterprise](../../README.md) / [Analytics](README.md)

Detects high-frequency or anomalous DNS queries initiated by non-browser, non-system processes (e.g., PowerShell, rundll32, python.exe) used to establish command and control via DNS tunneling.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0400#AN1121)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=3, 22 · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **NSM:Flow** — dns.log · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **QueryLengthThreshold** — Subdomain length for detecting base32/base64-encoded payloads
- **ProcessImageFilter** — Flag non-standard executables making DNS queries
- **TimeWindow** — Rate of queries in short interval per process
