# AN0791 - Analytic 0791

[Enterprise](../../README.md) / [Analytics](README.md)

A remote DCOM invocation by a privileged account using RPC (port 135), followed by abnormal process instantiation or module loading on the remote system indicative of code execution.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0285#AN0791)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — EventCode=4624, 4648 · [DC0067 - Logon Session Creation](../Data%20Components/DC0067%20-%20Logon%20Session%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=3, 22 · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=7 · [DC0016 - Module Load](../Data%20Components/DC0016%20-%20Module%20Load.md)

## Mutable elements

- **TimeWindow** — Correlate RPC activity with remote process creation within a configurable time window (e.g., 300s)
- **UserContext** — Identify rare or first-time DCOM invocations by specific accounts
- **ProcessName** — List of suspicious executables commonly abused via DCOM (e.g., excel.exe, wmiprvse.exe)
- **RemoteHostList** — Known set of systems that should or should not be invoking DCOM activity
