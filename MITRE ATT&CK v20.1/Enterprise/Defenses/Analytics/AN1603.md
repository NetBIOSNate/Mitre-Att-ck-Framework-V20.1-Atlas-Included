# AN1603 - Analytic 1603

[Enterprise](../../README.md) / [Analytics](README.md)

Detection of unauthorized changes to boot configurations pointing to TFTP servers, unusual firmware loads during netbooting, or suspicious TFTP traffic. Correlation of boot config modifications, command history logs, and unexpected system image hashes provides detection coverage for adversaries attempting to persist via malicious TFTP boot images.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0582#AN1603)

**Platforms**  [Network Devices](../../Platforms/Network%20Devices.md)

## Log sources and channels

- **networkdevice:config** — Configuration changes referencing 'boot system tftp' or modification of startup-config pointing to external TFTP servers · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **networkdevice:syslog** — Boot information log showing image loaded from TFTP server instead of local storage · [DC0004 - Firmware Modification](../Data%20Components/DC0004%20-%20Firmware%20Modification.md)
- **NSM:Flow** — Unexpected inbound/outbound TFTP traffic for device image files · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **ApprovedTFTPServers** — Whitelist of TFTP servers authorized for netbooting in the environment
- **TimeWindow** — Detection correlation window between config change, TFTP activity, and system reboot
- **BaselineBootImageHash** — Expected system image hashes to validate integrity of boot images loaded via TFTP
