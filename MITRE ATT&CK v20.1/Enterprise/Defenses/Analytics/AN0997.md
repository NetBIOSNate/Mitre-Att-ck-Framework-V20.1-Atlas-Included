# AN0997 - Analytic 0997

[Enterprise](../../README.md) / [Analytics](README.md)

Detection of execution of legacy scripting runtimes (e.g., older versions of Python, Bash, or PowerShell Core) lacking auditing. Monitoring for changes to EFI or system boot files indicative of downgrade-based persistence or bypass of integrity features.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0350#AN0997)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Execution of older or non-standard interpreters · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:unifiedlog** — Modifications or writes to EFI system partition for downgraded bootloaders · [DC0034 - Process Metadata](../Data%20Components/DC0034%20-%20Process%20Metadata.md)

## Mutable elements

- **ApprovedInterpreterVersions** — Defines the minimal version of interpreters expected; older versions flagged as downgrade attempts.
