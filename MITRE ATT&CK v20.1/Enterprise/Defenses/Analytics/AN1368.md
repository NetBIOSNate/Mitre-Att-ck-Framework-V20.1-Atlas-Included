# AN1368 - Analytic 1368

[Enterprise](../../README.md) / [Analytics](README.md)

Electron/GUI or headless RAT execution followed by LaunchAgent/Daemon persistence and persistent external connections; interactive children (osascript/sh/curl) spawned by parent.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0496#AN1368)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Process exec of remote-control apps or binaries with headless/connect flags · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:osquery** — CREATE/MODIFY: Creation of LaunchAgents/Daemons plists in user/system locations · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **macos:osquery** — CONNECT: Long-lived connections from remote-control parents to external IPs/domains · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **AllowedAppBundlePaths** — Legitimate remote-support apps under /Applications.
- **LaunchdAllowlist** — Known-good LaunchAgents/Daemons identifiers.
- **TimeWindow** — Window for correlating exec→launchd→egress events.
- **EgressHeuristics** — Duration/volume thresholds for persistent sessions.
