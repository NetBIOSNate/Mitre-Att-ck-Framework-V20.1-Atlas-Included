# AN1165 - Analytic 1165

[Enterprise](../../README.md) / [Analytics](README.md)

Repeated invocation of high-resource application endpoints or GUI components causing CPU and memory spikes, logged as elevated request volumes, prolonged handle locks, or frequent crash recoveries.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0415#AN1165)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Application** — High-frequency errors or hangs from resource-intensive application components (e.g., .NET, IIS, Office Suite) · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **Windows:perfmon** — Sudden spikes in CPU/Memory usage linked to specific application processes · [DC0018 - Host Status](../Data%20Components/DC0018%20-%20Host%20Status.md)

## Mutable elements

- **CPUThreshold** — Define what percentage of CPU usage indicates abnormal behavior.
- **MemoryConsumptionWindow** — Window (e.g., 5 mins) during which sustained memory usage may be abnormal.
- **AppCrashFrequency** — Threshold for frequency of application faults within a specific interval.
