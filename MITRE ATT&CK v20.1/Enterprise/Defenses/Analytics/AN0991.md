# AN0991 - Analytic 0991

[Enterprise](../../README.md) / [Analytics](README.md)

Detects VMs sending outbound traffic through non-standard services or to unknown destinations. Exfiltration over reverse shells tunneled via VMkernel or custom payloads routed via hostd/vpxa.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0348#AN0991)

**Platforms**  [ESXi](../../Platforms/ESXi.md)

## Log sources and channels

- **esxi:vpxa** — connection attempts and data transmission logs · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **esxi:vmkernel** — network stack module logs · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **esxi:syslog** — guest OS outbound transfer logs · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)

## Mutable elements

- **GuestOSAllowList** — Limit detection to sensitive or externally-exposed VMs handling confidential data.
- **TransferSizeThresholdMB** — Minimum outbound transfer size before flagging anomalous C2-based exfiltration.
- **ProtocolAllowList** — Define expected protocols for outbound data (e.g., disallow FTP/SCP over high ports).
