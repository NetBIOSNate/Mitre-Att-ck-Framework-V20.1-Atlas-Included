# AN0740 - Analytic 0740

[Enterprise](../../README.md) / [Analytics](README.md)

Detects Exchange Online or on-prem transport rule changes (e.g., header stripping) and mailbox export cleanup via `Remove-MailboxExportRequest`, as well as admin actions via Exchange PowerShell sessions.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0266#AN0740)

**Platforms**  [Office Suite](../../Platforms/Office%20Suite.md)

## Log sources and channels

- **m365:exchange** — Admin Audit Logs, Transport Rules · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **WinEventLog:PowerShell** — Exchange Cmdlets · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **CmdletFilter** — Include `New-TransportRule`, `Set-TransportRule`, `Remove-*` actions
- **UserRoleScope** — Track role assignments for admins performing deletions
