# AN0863 - Analytic 0863

[Enterprise](../../README.md) / [Analytics](README.md)

A compromised package/update (deb/rpm/tarball/AppImage/vendor updater) is installed, writing/overwriting files in /usr/local/bin, /usr/bin, /opt, or ~/.local; first run executes unexpected shells/curl/wget and connects to unapproved hosts. Correlate package/updater execution → file writes/replace → first-run child processes → egress.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0309#AN0863)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **journald:package** — dpkg/apt/yum/dnf transaction logs; vendor updaters in systemd journals · [DC0059 - File Metadata](../Data%20Components/DC0059%20-%20File%20Metadata.md)
- **NSM:Flow** — New outbound flows to non-approved vendor hosts post install · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **PathScope** — Monitored install paths (/usr/local, /usr/bin, /opt/*, ~/.local/bin, /var/lib/systemd).
- **ApprovedRepos** — Allow-listed APT/YUM repos and GPG keys for vendor updates.
- **TimeWindow** — Default 90 minutes.
