# AN0662 - Analytic 0662

[Enterprise](../../README.md) / [Analytics](README.md)

Adversary modifies website or application-hosted content via unauthorized file changes or script injections, often by exploiting web servers or CMS access.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0238#AN0662)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — EventCode=4663, 4670, 4656 · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Application** — Unexpected web application errors or CMS logs showing modification to index.html, default.aspx, or other public-facing files · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **target_filenames** — Environment-specific naming of defacement-prone files like 'index.html', 'main.css', 'app.js'.
- **TimeWindow** — Detection based on rapid sequence of file writes and script injections within short time intervals.
