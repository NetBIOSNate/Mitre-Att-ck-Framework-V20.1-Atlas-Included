# AN0974 - Analytic 0974

[Enterprise](../../README.md) / [Analytics](README.md)

Detects usage of shared memory directories (/dev/shm, /run/shm) for temporary storage of obfuscated, encoded, or executable data without persistence to disk.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0344#AN0974)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — open, write, unlink · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **linux:osquery** — file_events.path · [DC0059 - File Metadata](../Data%20Components/DC0059%20-%20File%20Metadata.md)

## Mutable elements

- **PathPrefix** — Shared memory mount path used (e.g., /dev/shm/ or /run/shm/)
- **FilenameRegex** — Regex to match non-standard, suspicious, or encoded filenames
- **ExecCorrelationWindow** — Time window to correlate process execution from shared memory directories
