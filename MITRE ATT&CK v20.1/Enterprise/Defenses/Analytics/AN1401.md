# AN1401 - Analytic 1401

[Enterprise](../../README.md) / [Analytics](README.md)

Detects memory-based injection by monitoring `task_for_pid`, `mach_vm_write`, and dylib injection patterns through `DYLD_INSERT_LIBRARIES` or manual memory mapping.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0508#AN1401)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — subsystem=com.apple.security, library=libsystem_kernel.dylib · [DC0035 - Process Access](../Data%20Components/DC0035%20-%20Process%20Access.md)
- **macos:endpointsecurity** — ES_EVENT_TYPE_NOTIFY_EXEC, ES_EVENT_TYPE_NOTIFY_MMAP · [DC0034 - Process Metadata](../Data%20Components/DC0034%20-%20Process%20Metadata.md)
- **macos:syslog** — DYLD_INSERT_LIBRARIES anomalies · [DC0016 - Module Load](../Data%20Components/DC0016%20-%20Module%20Load.md)

## Mutable elements

- **TargetProcessSignature** — Expected signing identity or origin of process being injected
- **MachSyscallContext** — Observed syscall combinations (e.g., task_for_pid followed by vm_write)
