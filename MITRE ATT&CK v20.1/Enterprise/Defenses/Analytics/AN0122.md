# AN0122 - Analytic 0122

[Enterprise](../../README.md) / [Analytics](README.md)

Detection of queries to instance metadata services (e.g., AWS IMDS, Azure Metadata Service) for availability zone, region, or network geolocation details. Correlation with non-management accounts or non-standard workloads may indicate adversary reconnaissance.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0043#AN0122)

**Platforms**  [IaaS](../../Platforms/IaaS.md)

## Log sources and channels

- **AWS:CloudTrail** — GetMetadata, DescribeInstanceIdentity · [DC0021 - OS API Execution](../Data%20Components/DC0021%20-%20OS%20API%20Execution.md)
- **azure:vpcflow** — HTTP requests to 169.254.169.254 or Azure Metadata endpoints · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **MetadataQueryAllowList** — Expected services that query cloud metadata APIs. Any additional sources may be malicious.
