# AN1012 - Analytic 1012

[Enterprise](../../README.md) / [Analytics](README.md)

Burst of incomplete TCP handshakes (e.g., SYN floods) or uncorrelated ACK packets targeting the state table resulting in OS resource exhaustion.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0356#AN1012)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Microsoft-Windows-TCPIP** — Connection queue overflow or failure to allocate TCP state object · [DC0018 - Host Status](../Data%20Components/DC0018%20-%20Host%20Status.md)
- **NSM:Firewall** — High rate of inbound TCP SYN or ACK packets with missing 3-way handshake completion · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **TimeWindow** — Threshold for burst traffic over short period (e.g., 30s - 2min)
- **ConnectionRateThreshold** — SYN/ACK packet rate threshold that triggers investigation
- **ProcessParentCheck** — Whether parent process of flooding tool is a known admin shell or unexpected context
