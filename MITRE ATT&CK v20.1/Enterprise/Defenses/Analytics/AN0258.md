# AN0258 - Analytic 0258

[Enterprise](../../README.md) / [Analytics](README.md)

Detects creation or modification of scheduled tasks using schtasks.exe, at.exe, or COM objects followed by execution of outlier processes tied to the scheduled job.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0094#AN0258)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — EventCode=4698 · [DC0001 - Scheduled Job Creation](../Data%20Components/DC0001%20-%20Scheduled%20Job%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=2 · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)

## Mutable elements

- **TaskAuthor** — Unexpected user or account context initiating the task.
- **CommandLineRegex** — Suspicious binaries or script usage tied to scheduled tasks.
- **ExecutionWindow** — Lookback window to correlate process execution after task registration.
