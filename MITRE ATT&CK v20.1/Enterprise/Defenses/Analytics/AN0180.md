# AN0180 - Analytic 0180

[Enterprise](../../README.md) / [Analytics](README.md)

Behavioral chain: (1) Safari/Chrome/Firefox/Office handles a URL; unified logs show open/click or LSQuarantine assignment, (2) outbound connection to untrusted domain, (3) a new file appears in ~/Downloads or /private/var/folders/* with quarantine flag.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0066#AN0180)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — open URL|clicked link|LSQuarantineAttach · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **NSM:Connections** — New outbound connection from Safari/Chrome/Firefox/Word · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **fs:fsevents** — Create in /Users/*/Downloads or /private/var/folders/* with quarantine attribute · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)

## Mutable elements

- **TimeWindow** — 10–30m correlation.
- **QuarantinePolicy** — Alert when com.apple.quarantine missing on newly downloaded executables.
- **SuspiciousTLDs** — Org-specific risky domains/TLDs.
