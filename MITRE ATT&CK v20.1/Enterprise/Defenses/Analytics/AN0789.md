# AN0789 - Analytic 0789

[Enterprise](../../README.md) / [Analytics](README.md)

Processes such as osascript, curl, or office applications sending data to text storage APIs/domains. Defender perspective: anomalous clipboard or file reads by unexpected applications immediately followed by outbound HTTPS requests to pastebin-like services.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0284#AN0789)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — execution of curl, osascript, or unexpected Office processes · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:unifiedlog** — file read of sensitive directories · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **macos:unifiedlog** — HTTPS POST requests to pastebin.com or similar · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **WatchedApps** — Processes not normally associated with data uploads (e.g., Preview, Calculator).
- **EntropyThreshold** — High entropy detection to flag encoded or encrypted data exfiltration.
