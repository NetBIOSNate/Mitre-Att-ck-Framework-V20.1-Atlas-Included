# AN0654 - Analytic 0654

[Enterprise](../../README.md) / [Analytics](README.md)

Suspicious modification of file artifacts (e.g., logs, ISO templates) on ESXi datastores, followed by beaconing or POST operations to external IPs potentially hiding payloads in file-like traffic.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0235#AN0654)

**Platforms**  [ESXi](../../Platforms/ESXi.md)

## Log sources and channels

- **esxi:vmkernel** — Storage access and file ops · [DC0059 - File Metadata](../Data%20Components/DC0059%20-%20File%20Metadata.md)
- **esxi:hostd** — Service initiated connections · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **NSM:Flow** — Transferred file observations · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **FilenamePattern** — Tune for likely stego file names (e.g., wallpaper.jpg, template.iso).
- **UnusualDestinationIP** — Destination outside vCenter management subnet.
