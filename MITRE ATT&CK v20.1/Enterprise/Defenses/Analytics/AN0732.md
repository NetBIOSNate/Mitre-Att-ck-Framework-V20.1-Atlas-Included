# AN0732 - Analytic 0732

[Enterprise](../../README.md) / [Analytics](README.md)

Anomalous or bulk download activity from private or restricted repositories by non-developer or privileged accounts, often preceded by unusual login behavior (e.g., unfamiliar geo, OAuth token use, elevated API rate).

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0263#AN0732)

**Platforms**  [SaaS](../../Platforms/SaaS.md)

## Log sources and channels

- **saas:github** — repo.download, repo.clone, oauth.authorize, repo.getContent · [DC0070 - Cloud Service Metadata](../Data%20Components/DC0070%20-%20Cloud%20Service%20Metadata.md)
- **saas:github** — Login from unusual IP, device fingerprint, or location; access token creation from new client · [DC0067 - Logon Session Creation](../Data%20Components/DC0067%20-%20Logon%20Session%20Creation.md)
- **saas:github** — Bulk access to multiple files or large volume of repo requests within short time window · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **TimeWindow** — Threshold for file access volume over short duration (e.g., 10+ repos accessed in <5 min)
- **UserContext** — Role or permission profile expected to interact with repositories (e.g., developers vs. admins)
- **GeoAnomalyThreshold** — Distance or variance allowed before a login is flagged as anomalous
- **RepoSensitivityTag** — Whether a repository is labeled sensitive or restricted
