# AN0231 - Analytic 0231

[Enterprise](../../README.md) / [Analytics](README.md)

Modification of user desktop backgrounds, login screen messages, or system banners by adversaries using admin privileges or script execution. May coincide with tampering in /Library/Desktop Pictures/ or use of AppleScript.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0082#AN0231)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — loginwindow or desktopservices modified settings or files · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)
- **macos:unifiedlog** — osascript or AppleScript invocation modifying UI · [DC0029 - Script Execution](../Data%20Components/DC0029%20-%20Script%20Execution.md)

## Mutable elements

- **ScriptNames** — Uncommon scripts like AppleScript variants or osascript for wallpaper changes
- **UserContext** — Normal users should not alter global visual settings
