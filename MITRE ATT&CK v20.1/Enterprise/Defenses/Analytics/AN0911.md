# AN0911 - Analytic 0911

[Enterprise](../../README.md) / [Analytics](README.md)

Execution of virtualization binaries (Parallels, VMware Fusion, VirtualBox) with arguments to hide UI. File monitoring for plist modifications indicating hidden virtualization behavior. Defender perspective: tracking process lineage and file modifications in system configs.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0321#AN0911)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Process execution for VBoxHeadless, prl_vm_app, vmware-vmx · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:unifiedlog** — Plist modifications containing virtualization run configurations · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)

## Mutable elements

- **PlistKeyScope** — Focus monitoring on UI suppression or VM auto-run keys.
