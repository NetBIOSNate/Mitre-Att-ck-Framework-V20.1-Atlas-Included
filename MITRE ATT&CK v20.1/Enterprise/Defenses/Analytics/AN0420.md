# AN0420 - Analytic 0420

[Enterprise](../../README.md) / [Analytics](README.md)

Forged SAML tokens may be used on Windows systems to authenticate to federated apps without normal Kerberos activity. Defenders may detect anomalous event correlation, where access to SaaS/O365 via SAML occurs without prior TGT requests or user logons.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0148#AN0420)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — EventCode=4624, 4648 · [DC0067 - Logon Session Creation](../Data%20Components/DC0067%20-%20Logon%20Session%20Creation.md)
- **WinEventLog:ADFS** — Token issuance events showing anomalous claims or issuers · [DC0006 - Web Credential Creation](../Data%20Components/DC0006%20-%20Web%20Credential%20Creation.md)

## Mutable elements

- **ClaimAnomalyThreshold** — Number of unusual claims in a SAML token (e.g., excessive privileges).
