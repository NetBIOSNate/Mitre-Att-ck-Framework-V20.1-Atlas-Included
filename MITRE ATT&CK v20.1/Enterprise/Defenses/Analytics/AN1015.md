# AN1015 - Analytic 1015

[Enterprise](../../README.md) / [Analytics](README.md)

Execution of utilities (e.g., ping, tracert, Test-NetConnection) or scripted methods to test Internet connectivity by interacting with external IPs/domains.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0357#AN1015)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:PowerShell** — EventCode=4103, 4104, 4105, 4106 · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **WinEventLog:Security** — EventCode=5156, 5157 · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **DestinationIP** — Tunable external IP ranges or domains used to verify Internet access (e.g., 8.8.8.8, example.com)
- **TimeWindow** — Cluster rapid test connections with command execution in < 60 seconds
- **UserContext** — Filter out known admin/script contexts to reduce false positives
