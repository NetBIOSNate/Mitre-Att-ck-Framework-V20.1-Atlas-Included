# AN0814 - Analytic 0814

[Enterprise](../../README.md) / [Analytics](README.md)

Detects injection or tampering of DLLs in hybrid identity agents (e.g., AzureADConnectAuthenticationAgentService), registry or configuration changes tied to PTA/AD FS, and anomalous LSASS or AD FS module loads correlated with authentication anomalies.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0293#AN0814)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=7 · [DC0016 - Module Load](../Data%20Components/DC0016%20-%20Module%20Load.md)
- **WinEventLog:Security** — EventCode=5136 · [DC0066 - Active Directory Object Modification](../Data%20Components/DC0066%20-%20Active%20Directory%20Object%20Modification.md)
- **WinEventLog:Security** — Anomalous logon without MFA enforcement · [DC0067 - Logon Session Creation](../Data%20Components/DC0067%20-%20Logon%20Session%20Creation.md)

## Mutable elements

- **WatchedServices** — Hybrid identity services monitored for tampering, e.g., PTA agent, AD FS.
- **TimeWindow** — Window correlating DLL/module load events with logon anomalies.
