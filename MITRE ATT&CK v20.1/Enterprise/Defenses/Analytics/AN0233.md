# AN0233 - Analytic 0233

[Enterprise](../../README.md) / [Analytics](README.md)

Execution of container orchestration commands (e.g., `docker exec`, `kubectl exec`) or API-driven interactions with running containers from unauthorized hosts or non-standard user contexts. Defender sees programmatic or interactive command execution within containers outside expected CI/CD tools or automation frameworks, often followed by file writes, privilege escalation, or lateral discovery.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0083#AN0233)

**Platforms**  [Containers](../../Platforms/Containers.md)

## Log sources and channels

- **auditd:SYSCALL** — execve: Execution of container management CLIs (docker, crictl, kubectl) or interpreted shells (sh, bash, python) within container context · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **docker:events** — exec_create: docker exec events targeting running containers from non-CI sources · [DC0077 - Container Start](../Data%20Components/DC0077%20-%20Container%20Start.md)
- **kubernetes:apiserver** — create/exec: Kubernetes API calls to exec into containers or create pods from curl, kubectl, or SDK clients · [DC0072 - Container Creation](../Data%20Components/DC0072%20-%20Container%20Creation.md)
- **AWS:CloudTrail** — CreatePod: Programmatic creation of new pod resources using container images not seen before in the environment · [DC0019 - Pod Creation](../Data%20Components/DC0019%20-%20Pod%20Creation.md)
- **kubernetes:audit** — Shell process (e.g., /bin/sh, /bin/bash) spawned in a container without an interactive session attached (i.e., automation anomaly) · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **AuthorizedUserAgents** — List of CI/CD pipeline runners, SRE tools, or cluster mgmt agents allowed to invoke API/CLI commands in containers.
- **NewImageThreshold** — Threshold for alerting on unseen container images pulled and executed. Adjust to reduce noise from frequent deploys.
- **TimeWindow** — Temporal window to correlate container exec with shell spawn and network activity (default: 2 minutes).
- **InteractiveSessionExpectation** — Set whether shell spawns without TTY or PTY should be flagged — based on org deployment model.
