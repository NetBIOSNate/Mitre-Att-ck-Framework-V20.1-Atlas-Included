# AN0158 - Analytic 0158

[Enterprise](../../README.md) / [Analytics](README.md)

Detection of a process or script that accesses a common web service to retrieve content containing obfuscated indicators of a secondary C2 server (dead drop resolver behavior).

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0058#AN0158)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=3, 22 · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **etw:Microsoft-Windows-NDIS-PacketCapture** — TLS Handshake/Network Flow · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **TargetDomain** — FQDN or IP for the hosting site of the dead drop (e.g., pastebin.com, twitter.com)
- **TimeWindow** — Defines how close in time the suspicious network and process behavior must occur
- **UserContext** — Filter by user or system accounts to reduce noise
