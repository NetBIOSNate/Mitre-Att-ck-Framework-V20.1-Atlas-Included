# AN0678 - Analytic 0678

[Enterprise](../../README.md) / [Analytics](README.md)

Execution of Java-based or CLI database tools (e.g., DBeaver, Beekeeper, mysql, psql) from user profiles not tied to dev/admin roles, especially when followed by file writes and cloud sync activity. Defender correlates GUI tool launches, file write events in ~/Downloads or ~/Documents, and outbound API calls to known cloud services.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0242#AN0678)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Process start of Java or native DB client tools · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:unifiedlog** — Writes of .sql/.csv/.xlsx files to user documents/downloads · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **NSM:Flow** — HTTPS API requests to Dropbox, iCloud, Google Drive, OneDrive shortly after DB tool usage · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **CloudSyncDomainList** — FQDNs of sync services used to detect likely outbound DB leakages
- **UserPrivilegeLevel** — Whether to treat low-privilege users accessing DB tools as higher risk
