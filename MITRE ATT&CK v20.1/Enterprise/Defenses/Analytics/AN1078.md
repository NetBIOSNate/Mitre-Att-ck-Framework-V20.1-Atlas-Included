# AN1078 - Analytic 1078

[Enterprise](../../README.md) / [Analytics](README.md)

Detects creation or renaming of accounts with names that closely match known service, root, or admin accounts. Behavior often follows account discovery or deletion, attempting to blend into system activity logs using trusted name conventions.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0383#AN1078)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — adduser · [DC0014 - User Account Creation](../Data%20Components/DC0014%20-%20User%20Account%20Creation.md)
- **auditd:SYSCALL** — usermod, or account rename system calls · [DC0010 - User Account Modification](../Data%20Components/DC0010%20-%20User%20Account%20Modification.md)
- **linux:osquery** — Listing of /etc/passwd and /etc/shadow metadata · [DC0013 - User Account Metadata](../Data%20Components/DC0013%20-%20User%20Account%20Metadata.md)

## Mutable elements

- **AllowedSystemAccounts** — Whitelist of legitimate service accounts used for validation.
- **LevenshteinThreshold** — Edit distance sensitivity between created account and existing account names.
- **ScriptInitiatorDetection** — Whether to flag account creation events triggered from suspicious scripts or shell histories.
