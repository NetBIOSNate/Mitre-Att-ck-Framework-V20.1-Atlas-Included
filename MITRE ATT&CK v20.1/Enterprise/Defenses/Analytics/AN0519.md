# AN0519 - Analytic 0519

[Enterprise](../../README.md) / [Analytics](README.md)

Identify lateral transfer via datastore file uploads or internal scp/ssh sessions that result in new VMX/VMDK or script files. Correlate transfer with VM execution or datastore modification.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0183#AN0519)

**Platforms**  [ESXi](../../Platforms/ESXi.md)

## Log sources and channels

- **esxi:vmkernel** — Upload of file to datastore · [DC0059 - File Metadata](../Data%20Components/DC0059%20-%20File%20Metadata.md)
- **esxi:hostd** — scp/ssh used to move file across hosts · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **DatastoreWhitelist** — Known authorized paths for legitimate VM operations
- **TransferProtocol** — Protocols allowed for intra-VM host transfers
