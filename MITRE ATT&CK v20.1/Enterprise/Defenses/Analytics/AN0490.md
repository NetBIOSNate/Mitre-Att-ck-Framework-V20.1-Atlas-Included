# AN0490 - Analytic 0490

[Enterprise](../../README.md) / [Analytics](README.md)

Excessive inbound HTTP or TLS connections to services such as Apache or Nginx, causing worker thread exhaustion or segmentation faults.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0173#AN0490)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — High frequency of accept(), read(), or SSL_read() syscalls tied to nginx/apache processes · [DC0035 - Process Access](../Data%20Components/DC0035%20-%20Process%20Access.md)
- **NSM:Flow** — Sudden spike in incoming flows to web service ports from single/multiple IPs · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **linux:syslog** — Repetitive HTTP 408, 500, or 503 errors logged within short timeframe · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **ErrorCodeWindow** — Tunable count of specific HTTP error codes in timeframe
- **ConnectionRateThreshold** — Defines number of connections per second considered anomalous
