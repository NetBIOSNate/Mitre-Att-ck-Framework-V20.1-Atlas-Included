# AN0053 - Analytic 0053

[Enterprise](../../README.md) / [Analytics](README.md)

A process loads a shared object (.so) via dlopen/LD_PRELOAD/open from non-standard or temporary locations (e.g., /tmp, /dev/shm), especially shortly after that .so is written or fetched, or linked via manipulated environment variables (LD_PRELOAD/LD_LIBRARY_PATH).

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0018#AN0053)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — openat/read/mmap: Open/mmap .so files from non-standard paths · [DC0016 - Module Load](../Data%20Components/DC0016%20-%20Module%20Load.md)
- **auditd:EXECVE** — execve: Processes launched with LD_PRELOAD/LD_LIBRARY_PATH pointing to non-system dirs · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **linux:syslog** — sudo or service accounts invoking loaders with suspicious env vars · [DC0034 - Process Metadata](../Data%20Components/DC0034%20-%20Process%20Metadata.md)
- **NSM:Flow** — http/file-xfer: Inbound/outbound transfer of ELF shared objects · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **SuspiciousDirs** — (/tmp, /dev/shm, /var/tmp, user home dirs) – adjust to your environment.
- **TimeWindow** — Correlate write/fetch of .so to its load (e.g., 0–30 minutes).
- **EnvVarWatchlist** — LD_PRELOAD, LD_LIBRARY_PATH, LD_AUDIT.
- **AllowedSigning/HashList** — Known-good signed or hashed shared objects.
