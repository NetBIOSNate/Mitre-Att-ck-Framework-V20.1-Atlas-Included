# AN0123 - Analytic 0123

[Enterprise](../../README.md) / [Analytics](README.md)

Installation of a new browser extension followed by suspicious file writes or outbound network connections to untrusted domains by the browser process.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0044#AN0123)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=11 · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **WinEventLog:Security** — EventCode=4688 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=3, 22 · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=13, 14 · [DC0063 - Windows Registry Key Modification](../Data%20Components/DC0063%20-%20Windows%20Registry%20Key%20Modification.md)

## Mutable elements

- **UserContext** — Extension installation by privileged or domain users may require higher scrutiny
- **BrowserExecutablePath** — Custom or portable browsers may not match default paths
- **ExtensionInstallPath** — Installation paths may vary by version or user profile
