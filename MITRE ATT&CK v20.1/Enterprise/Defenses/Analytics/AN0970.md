# AN0970 - Analytic 0970

[Enterprise](../../README.md) / [Analytics](README.md)

Kernel or userland processes generating high-rate network traffic (ICMP, UDP, TCP SYN) beyond expected interface throughput or user behavior norms.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0343#AN0970)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — connect or sendto system call with burst pattern · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **auditd:SYSCALL** — execve · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **SyscallBurstCount** — Threshold of repeated socket calls within a short interval indicating flood behavior.
- **UserContext** — Restrict to non-admin user traffic unless elevated access is detected.
