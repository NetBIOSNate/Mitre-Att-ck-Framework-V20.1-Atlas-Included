# AN0305 - Analytic 0305

[Enterprise](../../README.md) / [Analytics](README.md)

ESXi daemons (e.g., hostd, vpxa) are wrapped or impersonated to send large outbound traffic using gzip/Base64 encoding over SSH or HTTP. These actions follow suspicious logins or shell access.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0108#AN0305)

**Platforms**  [ESXi](../../Platforms/ESXi.md)

## Log sources and channels

- **esxi:shell** — base64 or gzip use within shell session · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **esxi:vmkernel** — Outbound traffic using encoded payloads post-login · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **ESXiLogs:authlog** — Unexpected login followed by encoding commands · [DC0002 - User Account Authentication](../Data%20Components/DC0002%20-%20User%20Account%20Authentication.md)

## Mutable elements

- **AuthSourceTrustLevel** — Use to scope encoded traffic suspicion to accounts that should not initiate transfers
- **ExfilBurstThreshold** — Threshold for bursty outbound traffic size deviation from baseline
