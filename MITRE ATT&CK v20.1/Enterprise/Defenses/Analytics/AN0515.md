# AN0515 - Analytic 0515

[Enterprise](../../README.md) / [Analytics](README.md)

Use of native/mac tools (sharing -l, smbutil view, mount_smbfs) or scripts to enumerate SMB shares across many hosts, followed by outbound SMB connections observed in PF/Zeek logs.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0182#AN0515)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:endpointsecurity** — ES_EVENT_TYPE_NOTIFY_EXEC: Process execution of "sharing -l", "smbutil view", "mount_smbfs" · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:unifiedlog** — Command line contains smbutil view //, mount_smbfs // · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **NSM:Firewall** — Outbound connections to 139/445 to multiple destinations · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **NSM:Flow** — connection: SMB connections to multiple internal hosts · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **BurstHostThreshold** — Minimum unique SMB destinations (e.g., ≥3–5 in smaller mac fleets).
- **TimeWindow** — Correlation window between exec and SMB connections (default 10m).
- **AllowedMgmtTools** — Jamf/IT scripts legitimately running smbutil/mount_smbfs.
