# AN1063 - Analytic 1063

[Enterprise](../../README.md) / [Analytics](README.md)

Execution of unsigned kernel extensions (KEXTs), tampering with LaunchDaemons, or userspace hooks into system libraries.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0377#AN1063)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — subsystem=com.apple.kextd · [DC0016 - Module Load](../Data%20Components/DC0016%20-%20Module%20Load.md)
- **macos:osquery** — launch_daemons · [DC0060 - Service Creation](../Data%20Components/DC0060%20-%20Service%20Creation.md)
- **fs:fsevents** — Extensions · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)

## Mutable elements

- **KextSignatureStatus** — Allowable level of unsigned/3rd-party kernel extensions varies by organization.
- **KextLoadOrigin** — Detect whether the extension was loaded by an untrusted process or non-root user.
- **AnomalousLaunchAgent** — Detection tuned based on deviation from known/approved LaunchDaemon plist files.
