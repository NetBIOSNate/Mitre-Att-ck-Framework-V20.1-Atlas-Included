# AN0503 - Analytic 0503

[Enterprise](../../README.md) / [Analytics](README.md)

Malicious HTML or script is rendered as a Home Page for a specific Outlook folder. Outlook accesses that folder, loads remote content, and executes embedded JavaScript or ActiveX/COM logic resulting in unauthorized actions or local execution.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0177#AN0503)

**Platforms**  [Office Suite](../../Platforms/Office%20Suite.md)

## Log sources and channels

- **m365:unified** — Folder configuration updated with external or HTML-formatted Home Page via Set-MailboxFolder · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **m365:messagetrace** — Inbound email triggering Outlook to auto-access folder tied to malicious Home Page · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **AuditPolicyScope** — Home Page customization may not be audited unless detailed message or folder auditing is enabled
- **FolderAccessRate** — Anomalous access to folders not usually interacted with can signal triggering of malicious view
- **ExternalURLAllowlist** — Mail clients may restrict remote Home Page content unless domain is explicitly allowed
