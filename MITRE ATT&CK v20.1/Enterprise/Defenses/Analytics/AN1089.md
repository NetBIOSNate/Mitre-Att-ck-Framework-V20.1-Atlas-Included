# AN1089 - Analytic 1089

[Enterprise](../../README.md) / [Analytics](README.md)

Bulk enumeration of cloud user email identities through `Get-Recipient`, `Get-Mailbox`, `Get-User`, or Graph API directory listings by abnormal accounts or suspicious sessions.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0386#AN1089)

**Platforms**  [Office Suite](../../Platforms/Office%20Suite.md)

## Log sources and channels

- **WinEventLog:PowerShell** — CmdletName: Get-Recipient, Get-User · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **Microsoft Graph API Logs** — users.list, directoryObjects.getByIds · [DC0013 - User Account Metadata](../Data%20Components/DC0013%20-%20User%20Account%20Metadata.md)

## Mutable elements

- **CmdletVolume** — Tune threshold for recipient/mailbox queries by volume per hour.
- **UserAgent** — Match known admin consoles and exclude sanctioned tools like MSOL PowerShell.
- **SessionContext** — Elevate sessions from unmanaged or external endpoints.
