# AN0029 - Analytic 0029

[Enterprise](../../README.md) / [Analytics](README.md)

Detects macros or VBA triggers set to execute on document open or close events, often correlating with embedded payloads or C2 traffic shortly after execution.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0010#AN0029)

**Platforms**  [Office Suite](../../Platforms/Office%20Suite.md)

## Log sources and channels

- **m365:office** — VBA auto_open, auto_close, or document_open events · [DC0029 - Script Execution](../Data%20Components/DC0029%20-%20Script%20Execution.md)
- **m365:office** — External HTTP/DNS connection from Office binary shortly after macro trigger · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **MacroFunctionNames** — Names of event-bound functions like Auto_Open that initiate execution
- **TimeDeltaMacroToC2** — Time threshold to correlate macro execution with outbound connections
