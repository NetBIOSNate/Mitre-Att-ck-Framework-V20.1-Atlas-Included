# AN1300 - Analytic 1300

[Enterprise](../../README.md) / [Analytics](README.md)

Detects modification of shared network folders via .app bundles or scripting files with hidden extensions (e.g., double extensions like docx.app).

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0471#AN1300)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **fs:fsevents** — Directory events (kFSEventStreamEventFlagItemCreated) · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **macos:unifiedlog** — file writes · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)

## Mutable elements

- **FileExtensionDeception** — Monitors use of hidden extensions or double extensions.
- **TargetSharedFolder** — Defines sensitive shared folders (e.g., /Users/Shared/HR).
