# AN1578 - Analytic 1578

[Enterprise](../../README.md) / [Analytics](README.md)

Detects creation of new container system processes via `docker run --restart`, `kubectl exec` to init containers, or modification of container init specs. Flags container images that override entrypoints to embed persistence behaviors.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0571#AN1578)

**Platforms**  [Containers](../../Platforms/Containers.md)

## Log sources and channels

- **docker:events** — docker run with restart=always or modifying init · [DC0072 - Container Creation](../Data%20Components/DC0072%20-%20Container%20Creation.md)
- **auditd:SYSCALL** — modification of entrypoint scripts or init containers · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)

## Mutable elements

- **EntrypointOverridePattern** — Patterns used to detect modified container start scripts
- **RestartPolicyMatch** — Policy values triggering alert (e.g., always, on-failure)
- **KubeInitModPath** — Path filters for `/etc/init.d/`-like behaviors inside containers
