# AN1318 - Analytic 1318

[Enterprise](../../README.md) / [Analytics](README.md)

Cause→effect chain in cloud consoles: (1) user clicks link then invokes instance/image creation via API, (2) instance/image originates from external AMI or unknown image, (3) instance immediately egresses or retrieves payloads.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0478#AN1318)

**Platforms**  [IaaS](../../Platforms/IaaS.md)

## Log sources and channels

- **AWS:CloudTrail** — RunInstances,CreateImage · [DC0076 - Instance Creation](../Data%20Components/DC0076%20-%20Instance%20Creation.md)
- **AWS:CloudTrail** — StartInstances · [DC0080 - Instance Start](../Data%20Components/DC0080%20-%20Instance%20Start.md)
- **gcp:vpcflow** — first 5m egress to unknown ASNs · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **ApprovedImages** — AMI/image allow-list with owners.
- **UserContext** — High-risk identities (federated, external IdP).
- **TimeWindow** — 5–30 minutes from console/API action to network egress.
