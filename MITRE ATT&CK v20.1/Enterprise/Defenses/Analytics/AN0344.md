# AN0344 - Analytic 0344

[Enterprise](../../README.md) / [Analytics](README.md)

Detects mounting of external volumes followed by high-volume or sensitive file access via Finder, terminal, or third-party apps (e.g., rsync, zip).

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0123#AN0344)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Volume Mount + File Read · [DC0042 - Drive Creation](../Data%20Components/DC0042%20-%20Drive%20Creation.md)
- **macos:osquery** — file_events · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **fs:fsusage** — file system activity monitor · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **VolumeNamePattern** — Detect suspicious or unrecognized drive labels (e.g., UNTITLED, BACKUP_VOL).
- **ProcessOrigin** — Detect CLI-based copy operations vs. expected GUI usage.
- **UserSessionCheck** — Alert if process and session context are mismatched (e.g., script from screensaver context).
