# AN0230 - Analytic 0230

[Enterprise](../../README.md) / [Analytics](README.md)

Adversary leverages root or sudo access to alter system banners, web content directories (e.g., /var/www/html), or login configurations (/etc/issue). File creation or overwrites may coincide with suspicious script execution or cron job activity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0082#AN0230)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — open/write/unlink · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)
- **auditd:SYSCALL** — execve · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **linux:syslog** — sudo or su access prior to content change · [DC0010 - User Account Modification](../Data%20Components/DC0010%20-%20User%20Account%20Modification.md)

## Mutable elements

- **TargetDirectories** — Paths like /var/www/html, /etc/issue, or /etc/motd may vary across distros
- **UserContext** — Non-web-admin users modifying site content or banners should be rare
- **TimeWindow** — Defacement often happens outside normal maintenance hours
