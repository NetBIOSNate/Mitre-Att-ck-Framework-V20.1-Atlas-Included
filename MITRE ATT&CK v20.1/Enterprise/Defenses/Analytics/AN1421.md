# AN1421 - Analytic 1421

[Enterprise](../../README.md) / [Analytics](README.md)

Detects use of vulnerable kernel extensions or entitlements abused via setuid or AppleScript injection chains.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0514#AN1421)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — process:exec and kext load events · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:endpointsecurity** — ES_EVENT_TYPE_NOTIFY_KEXTLOAD · [DC0016 - Module Load](../Data%20Components/DC0016%20-%20Module%20Load.md)

## Mutable elements

- **EntitlementList** — Entitlements vary by app and OS version; some allow unexpected behavior.
- **TimeWindow** — Correlate SUID execution or AppleScript injection with privilege gain or module load.
