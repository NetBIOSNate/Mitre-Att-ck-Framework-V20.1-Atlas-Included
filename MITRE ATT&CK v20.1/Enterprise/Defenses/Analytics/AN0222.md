# AN0222 - Analytic 0222

[Enterprise](../../README.md) / [Analytics](README.md)

Adversary exploits containerized app via ingress or service. Chain: (1) suspicious request in ingress/app logs → (2) container process spawns a shell/exec/sidecar (kubectl exec/docker exec) → (3) egress to Internet or metadata service (169.254.169.254).

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0080#AN0222)

**Platforms**  [Containers](../../Platforms/Containers.md)

## Log sources and channels

- **ApplicationLog:Ingress** — Kubernetes NGINX/Envoy ingress controller logs with anomalous payloads and 5xx spikes · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **docker:events** — Docker/Kubernetes audit of exec/attach (kubectl exec) or unexpected child processes inside container · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **NSM:Flow** — Requests towards cloud metadata or command & control from pod IPs · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **IngressNamespaces** — Namespaces that are Internet-facing.
- **MetadataEndpoints** — Cloud metadata IPs/hostnames for exfil of credentials.
- **TimeWindow** — Join period between ingress request and pod exec/egress.
