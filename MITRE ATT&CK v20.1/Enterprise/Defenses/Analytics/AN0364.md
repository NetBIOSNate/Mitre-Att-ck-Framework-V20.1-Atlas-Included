# AN0364 - Analytic 0364

[Enterprise](../../README.md) / [Analytics](README.md)

Domain account enumeration using ldapsearch, samba tools (e.g., 'wbinfo -u'), or winbindd lookups.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0129#AN0364)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **linuxsyslog** — nslcd or winbind logs · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **NSM:Flow** — LDAP Query · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **ProcessName** — Detect suspicious use of ldapsearch, wbinfo, getent passwd, or samba enumeration tools.
- **LDAPSearchFilter** — Tune for high-volume or broad-scope LDAP queries.
- **UserContext** — Apply filters for unexpected users or service accounts executing the behavior.
