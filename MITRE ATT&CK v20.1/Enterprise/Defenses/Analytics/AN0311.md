# AN0311 - Analytic 0311

[Enterprise](../../README.md) / [Analytics](README.md)

Monitoring modification and execution of user or system logon scripts such as in registry Run keys or startup folders.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0112#AN0311)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — EventCode=4688 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Security** — EventCode=4657 · [DC0063 - Windows Registry Key Modification](../Data%20Components/DC0063%20-%20Windows%20Registry%20Key%20Modification.md)
- **WinEventLog:TaskScheduler** — EventCode=106 · [DC0001 - Scheduled Job Creation](../Data%20Components/DC0001%20-%20Scheduled%20Job%20Creation.md)

## Mutable elements

- **TargetObject** — Registry path that may vary by user or policy configuration.
- **ParentProcessName** — Can be tuned to known parent processes to reduce false positives.
- **TimeWindow** — Logon activity clustered during specific user shifts.
