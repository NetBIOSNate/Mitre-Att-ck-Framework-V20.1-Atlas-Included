# AN0347 - Analytic 0347

[Enterprise](../../README.md) / [Analytics](README.md)

Processes use base64/xxd/openssl/python Objective‑C APIs to encode data (seen in EndpointSecurity exec events or Unified Logs) → quick outbound connections with large bytes_out or HTTP POSTs carrying Base64/MIME bodies.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0124#AN0347)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — process command line contains base64, -enc, openssl enc -base64 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **PF:Logs** — outbound flows with bytes_out >> bytes_in · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **NSM:Flow** — http: HTTP body contains long Base64 sections · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
