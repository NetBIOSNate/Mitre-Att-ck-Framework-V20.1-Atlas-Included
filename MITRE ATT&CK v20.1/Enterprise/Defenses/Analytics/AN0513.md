# AN0513 - Analytic 0513

[Enterprise](../../README.md) / [Analytics](README.md)

Process or script enumerates network shares via CLI (net view/net share, PowerShell Get-SmbShare/WMI) or OS APIs (NetShareEnum/ srvsvc.NetShareEnumAll RPC) → bursts of outbound SMB/RPC connections (445/139, \\host\IPC$ / srvsvc) to many hosts inside a short window → optional follow-on file listing or copy operations.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0182#AN0513)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — EventCode=4688 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=3, 22 · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=17 · [DC0048 - Named Pipe Metadata](../Data%20Components/DC0048%20-%20Named%20Pipe%20Metadata.md)
- **WinEventLog:PowerShell** — EventCode=4103, 4104, 4105, 4106 · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **etw:Microsoft-Windows-RPC** — rpc_call: srvsvc.NetShareEnum / NetShareEnumAll from non-admin or unusual processes · [DC0021 - OS API Execution](../Data%20Components/DC0021%20-%20OS%20API%20Execution.md)

## Mutable elements

- **BurstHostThreshold** — Minimum number of unique destination hosts over SMB within TimeWindow to treat as scanning (e.g., ≥5).
- **TimeWindow** — Correlation window between the discovery process start and SMB fan-out (default 10m).
- **AllowedDiscoveryAccounts** — Service/admin accounts legitimately running inventory scripts.
- **PipeNameAllowList** — Pipes (e.g., \PIPE\spoolss) normally accessed by management agents; exclude from alerts.
