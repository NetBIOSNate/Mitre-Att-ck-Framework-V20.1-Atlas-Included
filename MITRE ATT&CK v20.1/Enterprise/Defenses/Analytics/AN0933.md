# AN0933 - Analytic 0933

[Enterprise](../../README.md) / [Analytics](README.md)

Process chains that use native utilities (vssadmin, wbadmin, diskshadow, bcdedit, REAgentC, wmic) with arguments to delete shadow copies, disable recovery, or remove backup catalogs

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0329#AN0933)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Microsoft-Windows-Backup** — Windows Backup Catalog deletion or catalog corruption · [DC0040 - File Deletion](../Data%20Components/DC0040%20-%20File%20Deletion.md)
- **WinEventLog:System** — Service stopped or RecoveryDisabled set via REAgentC · [DC0041 - Service Metadata](../Data%20Components/DC0041%20-%20Service%20Metadata.md)
- **WinEventLog:Sysmon** — EventCode=13, 14 · [DC0063 - Windows Registry Key Modification](../Data%20Components/DC0063%20-%20Windows%20Registry%20Key%20Modification.md)

## Mutable elements

- **TimeWindow** — Used to track rapid recovery feature changes over short intervals
- **CommandLinePattern** — Can be tuned to catch variations in destructive flags (/all, /quiet, -delete)
- **ParentProcessContext** — Tune based on common parent-child chains (e.g., powershell → diskshadow)
