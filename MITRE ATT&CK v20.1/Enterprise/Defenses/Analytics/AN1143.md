# AN1143 - Analytic 1143

[Enterprise](../../README.md) / [Analytics](README.md)

Cloud-hosted VM or container generates spoofed UDP requests to third-party services on known amplifier ports, with high outbound-to-inbound traffic ratios in VPC Flow Logs

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0408#AN1143)

**Platforms**  [IaaS](../../Platforms/IaaS.md)

## Log sources and channels

- **AWS:CloudTrail** — Create egress rule allowing UDP to port 53, 123, 11211 · [DC0051 - Firewall Rule Modification](../Data%20Components/DC0051%20-%20Firewall%20Rule%20Modification.md)
- **AWS:VPCFlowLogs** — Large outbound UDP traffic to multiple public reflector IPs · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **AWS:CloudWatch** — Sudden spike in network output without a corresponding inbound request ratio · [DC0018 - Host Status](../Data%20Components/DC0018%20-%20Host%20Status.md)

## Mutable elements

- **EgressRulePorts** — Cloud security group rules permitting UDP to reflector protocols
- **OutboundToInboundRatio** — Ratio threshold to flag traffic as potential reflection behavior
- **VMInstanceTagContext** — Cloud metadata that can help scope anomalous behavior to development, testing, or external-facing services
