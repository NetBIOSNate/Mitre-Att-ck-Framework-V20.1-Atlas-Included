# AN0555 - Analytic 0555

[Enterprise](../../README.md) / [Analytics](README.md)

Identify unauthorized creation, deletion, or modification of business-critical stored data such as Office documents, database files, and log archives. Detect anomalous processes modifying stored data outside of expected workflows (e.g., non-database processes modifying database files).

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0193#AN0555)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=11 · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=23 · [DC0040 - File Deletion](../Data%20Components/DC0040%20-%20File%20Deletion.md)
- **WinEventLog:Sysmon** — EventCode=15 · [DC0059 - File Metadata](../Data%20Components/DC0059%20-%20File%20Metadata.md)
- **WinEventLog:Security** — EventCode=4663, 4670, 4656 · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)

## Mutable elements

- **MonitoredDirectories** — Paths to sensitive stored data files such as database directories or email archives.
- **AuthorizedProcesses** — List of legitimate processes expected to create, delete, or modify stored data.
- **TimeWindow** — Threshold for correlating multiple suspicious file operations within a short period.
