# AN0710 - Analytic 0710

[Enterprise](../../README.md) / [Analytics](README.md)

Suspicious reuse of SSH agent sockets across multiple users or processes, anomalous access to ~/.ssh/ or /tmp/ssh-* sockets, and abnormal patterns of lateral movement via SSH without new authentication events. Defender view: detect when one process accesses another user's SSH agent or when an existing SSH connection is used to pivot unexpectedly.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0256#AN0710)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — open or connect syscalls on /tmp/ssh-* or $SSH_AUTH_SOCK · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **auditd:EXECVE** — Execution of ssh/scp/sftp without corresponding authentication log · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **NSM:Connections** — Missing new login event but session activity continues · [DC0067 - Logon Session Creation](../Data%20Components/DC0067%20-%20Logon%20Session%20Creation.md)

## Mutable elements

- **UserContext** — Tune alerts for cross-user access to SSH agent sockets.
- **TimeWindow** — Correlate lack of authentication with lateral SSH activity within a short timeframe.
