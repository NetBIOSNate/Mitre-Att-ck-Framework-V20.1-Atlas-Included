# AN0679 - Analytic 0679

[Enterprise](../../README.md) / [Analytics](README.md)

Database enumeration and export activity (e.g., `SELECT * FROM`, `SHOW DATABASES`) issued via ephemeral VMs, admin APIs, or cloud shell from non-monitoring accounts. Defender correlates audit logs (CloudTrail, GCP Admin, AzureDiagnostics), storage write ops, and cross-region transfers by identities not tied to DB operations.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0242#AN0679)

**Platforms**  [IaaS](../../Platforms/IaaS.md)

## Log sources and channels

- **AWS:CloudTrail** — rds:ExecuteStatement: Large data access via RDS or Aurora with unknown session context · [DC0070 - Cloud Service Metadata](../Data%20Components/DC0070%20-%20Cloud%20Service%20Metadata.md)
- **AWS:CloudTrail** — PutObject: S3 writes with .sql/.csv extension by same identity or within 5 min of DB access · [DC0025 - Cloud Storage Access](../Data%20Components/DC0025%20-%20Cloud%20Storage%20Access.md)
- **AWS:VPCFlowLogs** — Large transfer volume (>20MB) from RDS IP range to external public IPs · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **IAMAccessPatterns** — Define which IAM roles/accounts are allowed DB operations
- **S3ExportThreshold** — Size threshold (MB) or file pattern for S3-based exfil monitoring
- **DBQueryVerbosityThreshold** — Number of rows/columns or duration to flag long-running queries
