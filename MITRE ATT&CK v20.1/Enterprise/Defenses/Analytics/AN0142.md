# AN0142 - Analytic 0142

[Enterprise](../../README.md) / [Analytics](README.md)

Correlate command executions involving 'sudo' with elevated effective user ID (euid=0), especially when tty_tickets is disabled or timestamp_timeout is actively abused.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0052#AN0142)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve call for sudo where euid != uid · [DC0034 - Process Metadata](../Data%20Components/DC0034%20-%20Process%20Metadata.md)
- **auditd:SYSCALL** — execve call for modification of /etc/sudoers or writing to /var/db/sudo · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)

## Mutable elements

- **timestamp_timeout_threshold** — Tune the valid sudo session duration to reduce false positives
- **command_allowlist** — Filter benign sudo usage (e.g., approved admin scripts)
