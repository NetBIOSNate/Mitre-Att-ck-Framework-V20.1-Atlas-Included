# AN0386 - Analytic 0386

[Enterprise](../../README.md) / [Analytics](README.md)

Abnormal invocation of diskutil, asr, or low-level APIs (IOKit) to erase/partition drives. Correlate process execution with unified log entries showing destructive disk operations.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0137#AN0386)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — diskutil eraseDisk / asr restore with destructive flags · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **macos:unifiedlog** — IOKit disk write calls targeting raw devices · [DC0046 - Drive Modification](../Data%20Components/DC0046%20-%20Drive%20Modification.md)

## Mutable elements

- **AdminToolWhitelist** — System administrators may legitimately use diskutil/asr for provisioning — whitelist by user or context.
