# AN0725 - Analytic 0725

[Enterprise](../../README.md) / [Analytics](README.md)

Detects aggregation of files from different directories into /tmp, /mnt, or user-specified directories with archiving tools like tar or gzip.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0261#AN0725)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — open · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **auditd:SYSCALL** — execve · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **StagingDirs** — e.g., /tmp, /var/tmp, custom user dirs
- **ArchiveUtilities** — tar, gzip, zip, 7z
- **UserThreshold** — Number of files or size written in short time
