# AN0869 - Analytic 0869

[Enterprise](../../README.md) / [Analytics](README.md)

Monitoring for discrepancies between system daemon/service state and reported health messages (e.g., syslog shows AV/IDS daemon stopped, but spoofed messages claim it is still running). Detects userland processes impersonating AV/IDS command-line outputs or modifying log forwarding configurations.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0311#AN0869)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve: Execution of binaries/scripts presenting false health messages for security daemons · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **linux:syslog** — Service stop or disable messages for security tools not reflected in SIEM alerts · [DC0018 - Host Status](../Data%20Components/DC0018%20-%20Host%20Status.md)

## Mutable elements

- **SecurityDaemonList** — Names of AV/IDS/EDR daemons monitored in Linux environments.
