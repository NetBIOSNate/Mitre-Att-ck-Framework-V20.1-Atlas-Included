# AN1066 - Analytic 1066

[Enterprise](../../README.md) / [Analytics](README.md)

Monitors use of archive or encryption tools (zip, openssl) tied to user-scripted activity or binaries writing encoded payloads under /Users or /Volumes.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0378#AN1066)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — log stream --predicate 'processImagePath contains "zip" OR "base64"' · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **macos:osquery** — file_events · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)

## Mutable elements

- **FilenameExtensionList** — Tunable to identify uncommon or encrypted file formats (e.g., .enc, .b64, .xz)
- **UserContext** — Tune to prioritize unexpected file access by service accounts
