# AN0096 - Analytic 0096

[Enterprise](../../README.md) / [Analytics](README.md)

Detects execution of common process enumeration utilities (e.g., ps, top, htop) or access to /proc with suspicious ancestry. Correlates command usage with interactive shell context and user role.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0034#AN0096)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **auditd:SYSCALL** — openat · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **linux:osquery** — Process State · [DC0035 - Process Access](../Data%20Components/DC0035%20-%20Process%20Access.md)

## Mutable elements

- **AccessedPath** — Filter based on suspicious /proc directory enumeration or high-volume ls/readlink usage
- **UserContext** — Helps tune for root vs. low-priv users during interactive vs. scripted activity
