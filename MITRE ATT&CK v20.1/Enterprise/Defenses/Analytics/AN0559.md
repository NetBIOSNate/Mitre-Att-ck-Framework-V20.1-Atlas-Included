# AN0559 - Analytic 0559

[Enterprise](../../README.md) / [Analytics](README.md)

Execution of built-in tools (e.g., ipconfig, route, netsh) or PowerShell/WMI queries to enumerate IP, MAC, interface status, or routing configuration.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0195#AN0559)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:PowerShell** — EventCode=4103, 4104, 4105, 4106 · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **ParentProcess** — Filter known/legit CLI chains (e.g., explorer.exe → cmd.exe) to reduce FP
- **UserContext** — Target executions by non-admin or unexpected users
- **TimeWindow** — Cluster enumeration commands within short time windows
