# AN0765 - Analytic 0765

[Enterprise](../../README.md) / [Analytics](README.md)

Correlates creation/modification of systemd service files or /etc/init.d scripts with outlier process behavior during boot

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0274#AN0765)

**Platforms**  [Linux](../../Platforms/Linux.md)

- **auditd:SYSCALL** — creat · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)

- **auditd:SYSCALL** — Execution of binaries located in /etc/init.d/ or systemd service paths · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **FilePath** — Organizations may use different init systems or custom startup paths
- **UserContext** — Autostart scripts should run as root or system users; deviations are suspect
