# AN1498 - Analytic 1498

[Enterprise](../../README.md) / [Analytics](README.md)

Applications or launchd services invoking RSA or public-key routines from the Security framework, followed by outbound SSL/TLS sessions with unrecognized certs or anomalous handshakes. Defender observes unified logs of API calls and suspicious network entropy.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0543#AN1498)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Process invoking SecKeyCreateRandomKey or asymmetric crypto APIs · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:unifiedlog** — TLS connections with abnormal handshake sequence or self-signed cert · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **TrustedDoHEndpoints** — Known legitimate DoH/SSL endpoints.
- **PayloadEntropyThreshold** — Entropy scoring for outbound payloads.
