# AN0908 - Analytic 0908

[Enterprise](../../README.md) / [Analytics](README.md)

Detects enumeration of cloud network interfaces, VPCs, subnets, or peer connections using CLI or SDKs (e.g., AWS CLI, Azure CLI, GCloud CLI).

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0320#AN0908)

**Platforms**  [IaaS](../../Platforms/IaaS.md)

## Log sources and channels

- **AWS:CloudTrail** — Describe* or List* API calls · [DC0021 - OS API Execution](../Data%20Components/DC0021%20-%20OS%20API%20Execution.md)
- **azure:activity** — networkInsightsLogs · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **ServicePrincipalAllowlist** — Allow certain automation roles to perform discovery during provisioning.
- **BurstQueryThreshold** — Unusual number of Describe* or List* network API calls in a short timeframe.
