# AN0619 - Analytic 0619

[Enterprise](../../README.md) / [Analytics](README.md)

Unusual or unauthorized processes accessing microphone APIs (e.g., winmm.dll, avrt.dll) followed by audio file writes to user-accessible or temp directories.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0221#AN0619)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=10 · [DC0035 - Process Access](../Data%20Components/DC0035%20-%20Process%20Access.md)
- **WinEventLog:Sysmon** — EventCode=11 · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **WinEventLog:Security** — EventCode=4688 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **TimeWindow** — Time span in which the process accesses audio APIs and writes files, to reduce false positives.
- **TargetProcess** — Set of approved processes known to legitimately use microphone (e.g., Zoom, Teams).
- **WriteDirectory** — Allowlist of paths where legitimate apps store audio (e.g., user media folders).
