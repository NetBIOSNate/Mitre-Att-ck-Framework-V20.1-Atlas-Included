# AN1635 - Analytic 1635

[Enterprise](../../README.md) / [Analytics](README.md)

Detects exploitation of macOS security and integrity services, such as Gatekeeper, XProtect, or EDR agents. Defender observations include unsigned processes attempting privileged operations, abnormal termination of security daemons, or modification of system integrity logs.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0595#AN1635)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Abnormal terminations of com.apple.security.* or 3rd-party security daemons · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **macos:osquery** — execve: Unsigned or unnotarized processes launched with high privileges · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **SecurityDaemons** — Monitored Apple and third-party EDR/AV daemon names.
- **UnsignedProcessThreshold** — Number of unsigned high-privilege executions before alerting.
