# AN0517 - Analytic 0517

[Enterprise](../../README.md) / [Analytics](README.md)

Monitor scp, rsync, curl, sftp, or ftp processes initiating transfers to internal systems combined with file creation events in unusual directories. Correlate transfer activity with subsequent execution of those binaries.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0183#AN0517)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve: Invocation of scp, rsync, curl, or sftp · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **auditd:FILE** — create: New file created in system binaries or temp directories · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)

## Mutable elements

- **AllowedTools** — Define legitimate transfer utilities expected in the environment
- **DestinationDirectories** — Restrict to suspicious or non-standard directories for transferred files
