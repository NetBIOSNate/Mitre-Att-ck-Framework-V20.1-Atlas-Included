# AN2032 - Analytic 2032

[Enterprise](../../README.md) / [Analytics](README.md)

Observation of scripted network requests (e.g., using osascript, curl, or python) that include mismatched or spoofed browser User-Agent strings compared to the typical macOS Safari or Chrome baseline, especially when triggered by non-interactive launch agents, login hooks, or background daemons.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0898#AN2032)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — network connection events · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **NSM:Flow** — Inbound HTTP POST with suspicious payload size or user-agent · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **macos:unifiedlog** — exec logs · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **UserAgentFingerprint** — Flag browser-based sessions
- **HeaderSignatureMatch** — Specific HTTP header anomalies or patterns (e.g., spoofed User-Agent).
