# AN0601 - Analytic 0601

[Enterprise](../../README.md) / [Analytics](README.md)

Detection of Mach-O binaries or AppleScripts that contain nested, encoded, or run-only embedded payloads dropped at runtime.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0214#AN0601)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — logd:file write · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **macos:endpointsecurity** — ES_EVENT_TYPE_NOTIFY_EXEC · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:osquery** — mach_o_info, file_metadata · [DC0059 - File Metadata](../Data%20Components/DC0059%20-%20File%20Metadata.md)

## Mutable elements

- **ScriptFormatType** — Run-only AppleScripts or signed scripting payloads may require scoped detection
- **DroppedBinaryCount** — Threshold on number of binaries created by the parent payload
- **ParentProcessName** — Allows focusing on suspicious interpreter or staging tools
