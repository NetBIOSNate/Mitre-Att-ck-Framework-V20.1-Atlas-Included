# AN0896 - Analytic 0896

[Enterprise](../../README.md) / [Analytics](README.md)

Processes like git, curl, or python scripts executing commands that package files (tar, gzip) followed by HTTPS uploads to code repository endpoints. Defender view: detect unusual git push activity or scripted HTTPS requests outside normal developer work hours.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0318#AN0896)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:EXECVE** — git push, curl -X POST · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **auditd:SYSCALL** — open/read of sensitive directories · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **NSM:Flow** — large outbound HTTPS uploads to repo domains · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **WorkHours** — Baseline normal developer activity periods to reduce false positives.
- **RepoDomainList** — Known allowed internal or external repository domains.
