# AN1099 - Analytic 1099

[Enterprise](../../README.md) / [Analytics](README.md)

Monitor for runtime manipulation by observing changes in application bundles, unexpected signing modifications, and runtime API calls that inject or alter how data is displayed. Detect alterations in CFNetwork or CoreFoundation frameworks responsible for rendering data.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0391#AN1099)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Unexpected application binary modifications or altered signing status · [DC0059 - File Metadata](../Data%20Components/DC0059%20-%20File%20Metadata.md)
- **macos:osquery** — CALCULATE: Mismatch in file integrity of critical macOS applications · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)

## Mutable elements

- **AllowedApps** — Whitelisted applications expected to handle sensitive runtime data.
- **SignatureEnforcement** — Policy enforcement for validating application code signing integrity.
