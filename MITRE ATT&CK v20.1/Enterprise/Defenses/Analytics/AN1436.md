# AN1436 - Analytic 1436

[Enterprise](../../README.md) / [Analytics](README.md)

Adversaries inject VBA macros into Office templates such as Normal.dotm or Personal.xlsb or redirect Office template load path via registry key (GlobalDotName) to gain persistence. Template macros trigger execution of malicious code on application startup.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0519#AN1436)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=11 · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=15 · [DC0059 - File Metadata](../Data%20Components/DC0059%20-%20File%20Metadata.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=13, 14 · [DC0063 - Windows Registry Key Modification](../Data%20Components/DC0063%20-%20Windows%20Registry%20Key%20Modification.md)
- **WinEventLog:Microsoft-Office-Alerts** — Office application warning or alert on macro execution from template · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **TemplatePath** — Path to Normal.dotm, Personal.xlsb, or Excel/Word startup templates may vary by Office version and user
- **RegistryPath** — GlobalDotName or equivalent registry keys may differ across Office versions or deployments
- **TimeWindow** — Office process creation and macro execution timing after system or user login
- **UserContext** — May be scoped to high-value users or those with access to sensitive templates
