# AN0930 - Analytic 0930

[Enterprise](../../README.md) / [Analytics](README.md)

ESXi shell or scripts produce long, high-entropy tokens (non-standard alphabets) in shell.log/hostd, followed by outbound flows (NSX/Zeek) with asymmetric ratios or protocol mismatches to non-management endpoints.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0326#AN0930)

**Platforms**  [ESXi](../../Platforms/ESXi.md)

## Log sources and channels

- **esxi:shell** — commands containing long non-standard tokens or custom lookup tables · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **esxi:hostd** — unexpected script invocations producing long encoded strings · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **NSM:Flow** — network_flow: bytes_out >> bytes_in, fixed packet sizes/intervals to non-approved CIDRs · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **NSM:Flow** — http: HTTP bodies from ESXi host IPs containing long, non-standard tokens · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **MgmtCIDRs** — CIDRs allowed for normal ESXi mgmt/backup.
- **BytesOutToInRatio** — Asymmetry cutoff (e.g., ≥3).
- **TokenLengthThreshold** — Minimum token length.
- **TimeWindow** — Correlation window.
