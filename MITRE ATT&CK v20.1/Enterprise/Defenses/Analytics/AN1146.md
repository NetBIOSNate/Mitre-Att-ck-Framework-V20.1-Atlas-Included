# AN1146 - Analytic 1146

[Enterprise](../../README.md) / [Analytics](README.md)

Unusual access or copying of files from mounted network drives (e.g., NFS, CIFS/SMB) by user shells or scripts followed by large data transfer.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0410#AN1146)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — open,read · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **linux:syslog** — mount/umount or file copy logs · [DC0054 - Drive Access](../Data%20Components/DC0054%20-%20Drive%20Access.md)

## Mutable elements

- **MountPoint** — Organization-specific share mount paths may vary (/mnt/share1, /srv/data etc.)
- **UID** — May need to scope to service accounts or user ID patterns specific to enterprise policy.
