# AN2038 - Analytic 2038

[Enterprise](../../README.md) / [Analytics](README.md)

Detects suspicious interactions with security products followed by service crashes, unexpected restarts, driver unloads, telemetry gaps, or tamper-state changes. Correlates exploit precursor behavior with immediate degradation of defensive services and follow-on process execution.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0900#AN2038)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:System** — EventCode=7035 · [DC0041 - Service Metadata](../Data%20Components/DC0041%20-%20Service%20Metadata.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=6 · [DC0079 - Driver Load](../Data%20Components/DC0079%20-%20Driver%20Load.md)
- **WinEventLog:Security** — EventCode=4688 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **CrashCorrelationWindow** — Time between suspicious interaction and security service failure
- **ProtectedServiceList** — Security agents/services expected to remain stable
- **TelemetryGapThreshold** — Acceptable heartbeat silence duration
