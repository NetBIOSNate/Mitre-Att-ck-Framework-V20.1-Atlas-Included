# AN0007 - Analytic 0007

[Enterprise](../../README.md) / [Analytics](README.md)

Adversary with access to domain management tools (e.g., `realmd`, `samba-tool`, `ldapmodify`) creates a new domain user via command-line utilities. Behavior chain: LDAP command or script triggers → user entry added in AD via Kerberos/LDAP traffic.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0003#AN0007)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execution of realmd, samba-tool, or ldapmodify with user-related arguments · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **NSM:Flow** — TGS-REQ and AS-REQ seen for new user shortly after domain-modifying process · [DC0002 - User Account Authentication](../Data%20Components/DC0002%20-%20User%20Account%20Authentication.md)

## Mutable elements

- **DomainToolUsed** — realmd, samba-tool, ldapmodify or custom script
- **TrafficWindow** — Expected Kerberos traffic from new domain account within X minutes of command
- **SessionType** — Script execution from interactive shell vs scheduled task
