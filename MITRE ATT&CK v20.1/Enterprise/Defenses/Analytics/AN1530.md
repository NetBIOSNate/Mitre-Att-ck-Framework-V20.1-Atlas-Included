# AN1530 - Analytic 1530

[Enterprise](../../README.md) / [Analytics](README.md)

Monitors for anomalous binary files written to disk with padded size and subsequent execution by user or service context.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0553#AN1530)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — process:spawn · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **fs:fsusage** — file write · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)

## Mutable elements

- **FileSizeThresholdMB** — Padded binary threshold for file size
- **TimeWindow** — Detection correlation window for execution after file creation
- **UserContext** — Filters for specific users or groups such as admin or service accounts
