# AN0103 - Analytic 0103

[Enterprise](../../README.md) / [Analytics](README.md)

Adversary registers new devices to compromised user accounts to bypass MFA or conditional access policies via Azure Entra ID, Okta, or Duo self-enrollment portals.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0036#AN0103)

**Platforms**  [Identity Provider](../../Platforms/Identity%20Provider.md)

## Log sources and channels

- **azure:audit** — Operation IN ("Add device", "Add registered users to device", "Add registered owner to device") · [DC0010 - User Account Modification](../Data%20Components/DC0010%20-%20User%20Account%20Modification.md)
- **ApplicationLog:EntraIDPortal** — DeviceRegistration events · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **azure:audit** — New device object creation · [DC0087 - Active Directory Object Creation](../Data%20Components/DC0087%20-%20Active%20Directory%20Object%20Creation.md)

## Mutable elements

- **ActorUserPrincipalName** — Define expected admin users to exclude known enrollment behavior
- **IP Address** — Scope internal vs. external device enrollment sources
- **TimeWindow** — Adjust for expected hours of legitimate self-enrollment
