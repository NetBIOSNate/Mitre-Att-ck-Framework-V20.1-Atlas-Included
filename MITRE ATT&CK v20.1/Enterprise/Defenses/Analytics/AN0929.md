# AN0929 - Analytic 0929

[Enterprise](../../README.md) / [Analytics](README.md)

EndpointSecurity/Unified Logs show processes generating custom alphabets or long high-entropy, non-standard tokens → network logs (PF/Zeek/EDR) show asymmetric beacons, protocol mismatches, or periodic fixed-size posts.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0326#AN0929)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:endpointsecurity** — ES_EVENT_TYPE_NOTIFY_EXEC: arguments contain long, non-standard tokens / custom alphabets · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **PF:Logs** — high out:in ratio or fixed-size periodic flows · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **NSM:Flow** — http: suspicious long tokens with custom alphabets in body/headers · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **EntropyThreshold** — Payload entropy minimum.
- **TokenLengthThreshold** — Minimum suspicious token length.
- **BytesOutToInRatio** — Asymmetry threshold.
- **TimeWindow** — Correlation window.
- **AllowedSignedBinaries** — Signed binaries that legitimately implement custom encoders.
