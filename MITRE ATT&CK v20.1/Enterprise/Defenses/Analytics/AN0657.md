# AN0657 - Analytic 0657

[Enterprise](../../README.md) / [Analytics](README.md)

Phishing attachment detection on macOS through correlation of Mail app logs, file creation in user directories, and abnormal process execution (e.g., Preview.app or Mail.app spawning Terminal or scripting binaries). Network traffic after attachment interaction is also monitored.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0236#AN0657)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Inbound messages with attachments from suspicious domains · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **macos:unifiedlog** — Execution of Terminal, osascript, or other interpreters originating from Mail or Preview · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:unifiedlog** — Attachment files written to ~/Downloads or temporary folders · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)

## Mutable elements

- **ExecutionDelayThreshold** — Time delay between attachment download and execution considered suspicious.
- **SuspiciousParentApps** — Parent processes expected to rarely spawn child processes (e.g., Mail.app, Preview.app).
