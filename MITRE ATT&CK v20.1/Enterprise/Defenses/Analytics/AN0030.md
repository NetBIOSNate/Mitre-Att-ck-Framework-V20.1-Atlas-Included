# AN0030 - Analytic 0030

[Enterprise](../../README.md) / [Analytics](README.md)

Processes generating large outbound connections with disproportionate send/receive ratios, often to uncommon ports or hosts, potentially inserting meaningless data into protocol payloads.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0011#AN0030)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=3, 22 · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=10 · [DC0035 - Process Access](../Data%20Components/DC0035%20-%20Process%20Access.md)
- **NSM:Flow** — TCP/UDP · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **PayloadEntropyThreshold** — Tunable threshold for Shannon entropy of network payloads.
- **TimeWindow** — Duration of outbound data transfer to evaluate disproportionate upload size.
- **UserContext** — Filter based on user accounts allowed to generate outbound traffic.
