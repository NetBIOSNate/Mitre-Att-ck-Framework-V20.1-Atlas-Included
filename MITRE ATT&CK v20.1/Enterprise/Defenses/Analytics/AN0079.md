# AN0079 - Analytic 0079

[Enterprise](../../README.md) / [Analytics](README.md)

Detects Web protocol misuse such as encoded HTTP headers, WebSocket upgrade requests with abnormal payloads, or TLS handshake anomalies suggesting embedded C2 channels.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0027#AN0079)

**Platforms**  [Network Devices](../../Platforms/Network%20Devices.md)

## Log sources and channels

- **NSM:Flow** — http.log, ssl.log, websocket.log · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **HeaderEncodingPattern** — Base64, hex, or UTF-16 encoding in URI, cookie, or host
- **TLSFingerprintMismatch** — JA3 hash deviation from known clients
