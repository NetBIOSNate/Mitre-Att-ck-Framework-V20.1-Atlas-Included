# AN1030 - Analytic 1030

[Enterprise](../../README.md) / [Analytics](README.md)

A non-privileged or abnormal process attempts to open a handle with full access (0x1F0FFF) to lsass.exe and subsequently invokes memory dump, file creation, or registry modification indicative of credential scraping. This behavior chain reflects staged credential theft activity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0363#AN1030)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=10 · [DC0035 - Process Access](../Data%20Components/DC0035%20-%20Process%20Access.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=11 · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **WinEventLog:Security** — EventCode=4673 · [DC0013 - User Account Metadata](../Data%20Components/DC0013%20-%20User%20Account%20Metadata.md)
- **WinEventLog:Sysmon** — EventCode=13, 14 · [DC0063 - Windows Registry Key Modification](../Data%20Components/DC0063%20-%20Windows%20Registry%20Key%20Modification.md)

## Mutable elements

- **AccessMask** — Set to 0x1F0FFF to detect full memory access attempts; can be scoped down to reduce noise.
- **TimeWindow** — Defines time between LSASS access and dump file creation or registry modification (e.g., 5 minutes).
- **ParentProcessName** — Allowlist known legitimate tools (e.g., AV/EDR) accessing lsass.exe.
- **DumpFilePath** — Paths where memory dumps are written, e.g., %TEMP%, C:\Windows\Temp.
- **CommandLinePattern** — Common dumping syntax like rundll32, procdump, comsvcs.dll, Invoke-Mimikatz.
