# AN0476 - Analytic 0476

[Enterprise](../../README.md) / [Analytics](README.md)

EFI updates executed via system processes or binaries outside of expected patch windows or using unsigned firmware packages.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0167#AN0476)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — com.apple.firmwareupdater activity or update-firmware binary invoked · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:unifiedlog** — boot failure events or SMC validation errors · [DC0004 - Firmware Modification](../Data%20Components/DC0004%20-%20Firmware%20Modification.md)

## Mutable elements

- **UpdateTimeWindow** — Firmware updates usually occur after OS update; out-of-band patterns may indicate compromise
