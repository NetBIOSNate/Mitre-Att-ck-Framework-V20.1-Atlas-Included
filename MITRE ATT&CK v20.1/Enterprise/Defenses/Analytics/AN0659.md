# AN0659 - Analytic 0659

[Enterprise](../../README.md) / [Analytics](README.md)

Detection of edits or additions to /etc/rc.common, /Library/StartupItems, or /System/Library/StartupItems and associated script execution during login or reboot.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0237#AN0659)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — process events · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **fs:fsusage** — file activity · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)

## Mutable elements

- **script_name** — Name of script or LaunchDaemon plist is tunable across environments
- **event_interval** — Time window between modification and reboot/login
- **file_permission** — Permissions on modified RC files can vary between systems
