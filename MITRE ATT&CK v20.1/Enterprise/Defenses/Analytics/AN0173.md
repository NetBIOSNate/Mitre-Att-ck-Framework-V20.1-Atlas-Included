# AN0173 - Analytic 0173

[Enterprise](../../README.md) / [Analytics](README.md)

Detects native Python or framework-based execution from Terminal, embedded apps, or launchd jobs. Flags network calls, persistence writes, or system enumeration after Python launch.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0063#AN0173)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — log stream --predicate 'eventMessage contains "python"' · [DC0029 - Script Execution](../Data%20Components/DC0029%20-%20Script%20Execution.md)
- **macos:osquery** — process_events · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:syslog** — system.log · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **ExecutionPath** — Detects python scripts from ~/Downloads/, /Volumes/, or /tmp/.
- **ScriptName** — Obfuscated or high entropy script names.
- **SpawnChain** — Chained behavior: Python → bash → curl or Python → osascript.
