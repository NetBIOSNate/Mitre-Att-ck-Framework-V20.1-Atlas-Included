# AN0994 - Analytic 0994

[Enterprise](../../README.md) / [Analytics](README.md)

Monitor unified logs for processes spawned from Safari or other browsers that immediately load scripts or executables. Detect file drops in ~/Library/Caches or ~/Downloads that execute shortly after being written.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0349#AN0994)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Child processes of Safari, Chrome, or Firefox executing scripting interpreters · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:unifiedlog** — File creation of unsigned binaries/scripts in user cache or download directories · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **NSM:Flow** — Content injection observed in HTTPS responses with mismatched certificates or altered payloads · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **MonitoredDirectories** — macOS-specific directories where malicious payloads may be written.
