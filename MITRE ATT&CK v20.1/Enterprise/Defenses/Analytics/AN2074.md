# AN2074 - Analytic 2074

[Enterprise](../../README.md) / [Analytics](README.md)

An analyst observes a supported security artifact/task enter an autonomous defensive-analysis workflow, the analysis begin successfully, and the same workflow subsequently record an explicit failure, refusal, termination, or abnormal terminal state inconsistent with $AuthorizedAnalysisStopConditions$.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0925#AN2074)

## Mutable elements

- **SupportedArtifactClasses** — artifact/task classes expected to complete the analysis workflow; derive from product capabilities and clean executions
- **AuthorizedAnalysisStopConditions** — known legitimate refusal/failure/cancellation states from product documentation and operational baseline
- **AnalysisCompletionWindow** — normal completion duration by task/artifact type
