# AN0242 - Analytic 0242

[Enterprise](../../README.md) / [Analytics](README.md)

Defender detects execution of `mdfind`, `launchctl`, or GUI-based enumeration (e.g., `/Applications/Time Machine.app`) along with command-line usage of `find`, `grep`, or `system_profiler` to identify installed backup tools like Time Machine, Carbon Copy Cloner, or Backblaze. Often triggered from Terminal sessions or within post-exploitation scripts.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0088#AN0242)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Process execution logs showing discovery commands like mdfind, system_profiler, or launchctl list · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:unifiedlog** — Read access to Time Machine plist files or CCC configurations in ~/Library/Preferences/ · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)

## Mutable elements

- **InstallLocationScope** — Directories or bundles where backup tools are commonly installed
- **KnownAppPlistPaths** — Plist files related to backup software configurations
