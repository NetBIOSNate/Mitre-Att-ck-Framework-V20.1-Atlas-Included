# AN0809 - Analytic 0809

[Enterprise](../../README.md) / [Analytics](README.md)

Detects successful login to cloud identity portals (e.g., Okta, Azure AD, Google Identity) from atypical geolocations, devices, or user agents immediately followed by dashboard/portal navigation to sensitive pages such as user or app configuration.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0291#AN0809)

**Platforms**  [Identity Provider](../../Platforms/Identity%20Provider.md)

## Log sources and channels

- **azure:signinlogs** — Sign-in with unfamiliar location/device + portal navigation · [DC0002 - User Account Authentication](../Data%20Components/DC0002%20-%20User%20Account%20Authentication.md)
- **saas:okta** — user.session.start · [DC0067 - Logon Session Creation](../Data%20Components/DC0067%20-%20Logon%20Session%20Creation.md)
- **saas:okta** — WebUI access to administrator dashboard · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **GeoIPAnomalyThreshold** — Threshold for location anomalies per user profile
- **UserAgentReputation** — Unknown browser/device fingerprint list
- **PrivilegedPageAccess** — List of sensitive dashboard views for alerting
