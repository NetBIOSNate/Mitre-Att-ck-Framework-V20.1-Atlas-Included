# AN0387 - Analytic 0387

[Enterprise](../../README.md) / [Analytics](README.md)

Execution of destructive CLI commands such as 'erase startup-config', 'erase flash:' or 'format disk' on routers/switches. Detect privilege level escalation preceding destructive commands.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0137#AN0387)

**Platforms**  [Network Devices](../../Platforms/Network%20Devices.md)

## Log sources and channels

- **networkdevice:cli** — erase flash:, erase startup-config, format disk · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **networkdevice:syslog** — User privilege escalation to level 15/root prior to destructive commands · [DC0002 - User Account Authentication](../Data%20Components/DC0002%20-%20User%20Account%20Authentication.md)

## Mutable elements

- **PrivilegedUsers** — Tune to exclude approved maintenance sessions by known administrators.
- **CommandPatterns** — Adjust monitored destructive command list depending on device vendor and OS.
