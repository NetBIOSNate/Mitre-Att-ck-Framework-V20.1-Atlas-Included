# AN0194 - Analytic 0194

[Enterprise](../../README.md) / [Analytics](README.md)

Detects file transfers or mounting operations from remote hosts followed by write actions into a local staging directory, often using SMB or remote shell activity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0071#AN0194)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=11 · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **WinEventLog:Microsoft-Windows-SMBClient/Security** — EventCode=31001 · [DC0102 - Network Share Access](../Data%20Components/DC0102%20-%20Network%20Share%20Access.md)
- **WinEventLog:PowerShell** — CommandLine=copy-item or robocopy from UNC path · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **StagingDirectory** — Common directories such as C:\Temp, Downloads, or hidden folders used for remote staging
- **RemotePathPatterns** — UNC paths like \\10.* or \\domain\share indicating lateral data staging
- **CopyToolPatterns** — Usage of robocopy, xcopy, copy-item, or scheduled tasks performing cross-host copies
