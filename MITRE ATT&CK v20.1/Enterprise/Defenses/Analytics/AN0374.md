# AN0374 - Analytic 0374

[Enterprise](../../README.md) / [Analytics](README.md)

User-mode application uses flock() or NSDistributedLock to gain exclusive access to a resource file (e.g., /tmp/guard.lock), conditional logic alters execution if already locked.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0132#AN0374)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — flock|NSDistributedLock|FileHandle.*lockForWriting · [DC0021 - OS API Execution](../Data%20Components/DC0021%20-%20OS%20API%20Execution.md)
- **macos:unifiedlog** — process.*exit.*code · [DC0033 - Process Termination](../Data%20Components/DC0033%20-%20Process%20Termination.md)

## Mutable elements

- **lockfile_path** — Path to mutex file (e.g., /tmp/*, /private/tmp/*), tune per environment.
- **user_context** — Flag non-user processes using these APIs.
- **TimeWindow** — Detection correlation across short time intervals between lock attempt and process exit.
