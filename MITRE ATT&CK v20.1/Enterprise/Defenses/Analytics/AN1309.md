# AN1309 - Analytic 1309

[Enterprise](../../README.md) / [Analytics](README.md)

Correlates creation of email forwarding rules or header anomalies (e.g., X-MS-Exchange-Organization-AutoForwarded) with suspicious process execution, file access of .pst/.ost files, and network connections to external SMTP servers.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0476#AN1309)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — EventCode=5145 · [DC0102 - Network Share Access](../Data%20Components/DC0102%20-%20Network%20Share%20Access.md)
- **WinEventLog:PowerShell** — EventCode=4103, 4104, 4105, 4106 · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **WinEventLog:Application** — Exchange logs or header artifacts · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **WinEventLog:Sysmon** — EventCode=3, 22 · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **TimeWindow** — Defines correlation window across email rule creation and outbound SMTP.
- **UserContext** — Filters for admin or service accounts to reduce false positives.
- **SMTPDomainList** — Allows tuning based on expected external email domains.
