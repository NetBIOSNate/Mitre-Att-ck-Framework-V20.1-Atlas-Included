# AN0302 - Analytic 0302

[Enterprise](../../README.md) / [Analytics](README.md)

Atypical processes (e.g., powershell.exe, regsvr32.exe) encode large outbound traffic using Base64 or other character encodings; this traffic is sent over uncommon ports or embedded in protocol fields (e.g., HTTP cookies or headers).

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0108#AN0302)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=3, 22 · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **NSM:Flow** — Unusual Base64-encoded content in URI, headers, or POST body · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **PayloadEntropyThreshold** — Adjust to accommodate legitimate compression or encryption patterns in normal web traffic
- **ProcessAllowlist** — Define expected processes initiating outbound traffic to reduce false positives
- **AnomalyScoreThreshold** — Set threshold for how far traffic deviates from baseline protocol structure or size
