# AN0496 - Analytic 0496

[Enterprise](../../README.md) / [Analytics](README.md)

Detects exploitation of vulnerabilities in cloud identity providers (IdPs) such as Azure AD or Okta for credential access. Defender perspective includes anomalous token creation or renewal, authentication bypass events, and API abuse to mint unauthorized tokens. Correlation highlights exploitation attempts tied to absent or inconsistent audit logs.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0174#AN0496)

**Platforms**  [Identity Provider](../../Platforms/Identity%20Provider.md)

## Log sources and channels

- **azure:signinlogs** — TokenIssued, TokenRenewed: Unexpected or anomalous token issuance events · [DC0002 - User Account Authentication](../Data%20Components/DC0002%20-%20User%20Account%20Authentication.md)
- **m365:unified** — ConsentGranted: Abuse of application integrations to mint tokens bypassing MFA · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **TokenAnomalyThreshold** — Threshold for anomalous token creation or renewal before alerting.
- **MonitoredAppIntegrations** — Applications with privileged access that should be tightly monitored for misuse.
