# AN1613 - Analytic 1613

[Enterprise](../../README.md) / [Analytics](README.md)

Enumeration of users and groups through suspicious shell commands or unauthorized access to /etc/passwd or /etc/shadow.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0587#AN1613)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — PATH · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **linux:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **AccessedFile** — Tune based on file paths such as '/etc/passwd', '/etc/group', '/etc/shadow'.
- **ParentProcessName** — Filter known admin processes to reduce false positives.
