# AN0600 - Analytic 0600

[Enterprise](../../README.md) / [Analytics](README.md)

Detection of shell scripts, ELF binaries, or archives containing embedded secondary payloads, self-extracting components, or unusual compression behavior during runtime.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0214#AN0600)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — open, write · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)
- **linux:osquery** — elf_info, hash, yara_matches · [DC0059 - File Metadata](../Data%20Components/DC0059%20-%20File%20Metadata.md)
- **ebpf:syscalls** — container_file_activity · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)

## Mutable elements

- **FileSectionCount** — Tuning value for ELF binaries with appended sections or resources
- **ScriptLength** — Threshold for long shell scripts with base64-encoded binary content
- **ExtractedFileCount** — Number of files written from a single script execution
