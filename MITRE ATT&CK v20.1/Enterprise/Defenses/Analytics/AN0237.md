# AN0237 - Analytic 0237

[Enterprise](../../README.md) / [Analytics](README.md)

Detection of processes that load or decode encrypted/encoded files in memory and subsequently execute or inject them, indicating payload unpacking or memory-resident malware.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0087#AN0237)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=7 · [DC0016 - Module Load](../Data%20Components/DC0016%20-%20Module%20Load.md)
- **WinEventLog:Sysmon** — EventCode=10 · [DC0035 - Process Access](../Data%20Components/DC0035%20-%20Process%20Access.md)
- **WinEventLog:Security** — EventCode=4688 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **Image** — Path of decoder utilities (e.g., certutil.exe, powershell.exe) can vary across environments.
- **CommandLine** — Base64/hex strings used may change per encoded payload.
- **TimeWindow** — The duration between file decode and execution may differ across implementations.
