# AN0082 - Analytic 0082

[Enterprise](../../README.md) / [Analytics](README.md)

Suspicious long-lived or high-throughput connections by non-Apple signed apps or processes not commonly associated with network uploads. Detect background processes using open sockets for data egress.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0028#AN0082)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — process + network metrics correlation for bandwidth saturation · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **macos:unifiedlog** — exec or spawn calls to proxy tools or torrent clients · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **ProcessSignedStatus** — Non-signed or non-Apple signed binaries can raise confidence levels.
- **DataRateThreshold** — Observed data rate per process over time (e.g., MB/s).
