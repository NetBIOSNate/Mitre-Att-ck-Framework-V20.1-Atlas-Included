# AN1109 - Analytic 1109

[Enterprise](../../README.md) / [Analytics](README.md)

File creation of unauthorized script (e.g., .php, .sh) in /var/www/html followed by execution of unexpected system utilities (e.g., curl, bash, nc) by apache/nginx

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0394#AN1109)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — new file created in /var/www/html, /srv/http, or similar web root · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **auditd:SYSCALL** — apache2 or nginx spawning sh, bash, or python interpreter · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **NSM:Flow** — POST requests to .php, .jsp, .aspx files with high entropy body · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **WebRootPath** — Web server root varies by distro and hosting configuration
- **PayloadEntropyThreshold** — Base64 or XOR encoded shells may exceed this value
- **TimeWindow** — Correlate file creation with process spawn within X seconds
