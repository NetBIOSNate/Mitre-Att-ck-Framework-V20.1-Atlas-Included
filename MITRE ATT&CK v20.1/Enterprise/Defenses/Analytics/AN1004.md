# AN1004 - Analytic 1004

[Enterprise](../../README.md) / [Analytics](README.md)

Unusual or unauthorized external remote access attempts (e.g., RDP, VPN, Citrix) → repeated failed logins followed by a successful session from uncommon geolocations or outside business hours → subsequent internal lateral movement or data exfiltration activities.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0354#AN1004)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — EventCode=4776, 4625 · [DC0002 - User Account Authentication](../Data%20Components/DC0002%20-%20User%20Account%20Authentication.md)
- **WinEventLog:Application** — VPN, Citrix, or remote access gateway logs showing external IP addresses · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **WinEventLog:Sysmon** — EventCode=3, 22 · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **BusinessHours** — Normal business hours for logon activity.
- **KnownRemoteIPs** — List of approved external IPs or VPN endpoints.
- **FailedLogonThreshold** — Number of failed logons before raising suspicion (e.g., >5).
- **GeoIPWhitelist** — Geographic regions allowed for remote access.
- **TimeWindow** — Time window to correlate failed attempts and success (e.g., 15m).
