# AN0440 - Analytic 0440

[Enterprise](../../README.md) / [Analytics](README.md)

Suspicious SaaS tenant activity involving webhook configurations pointing to external or untrusted domains. Defender perspective: repeated automated exports or suspicious webhook endpoint registrations.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0153#AN0440)

**Platforms**  [SaaS](../../Platforms/SaaS.md)

## Log sources and channels

- **m365:unified** — Set-Mailbox, Add-InboxRule, RegisterWebhook · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **saas:api** — Webhook registrations or repeated POST activity · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **WebhookRegistrations** — Monitor new webhook creation events in SaaS environments.
- **ExternalDomains** — Flag webhooks pointing to domains not owned by the enterprise.
