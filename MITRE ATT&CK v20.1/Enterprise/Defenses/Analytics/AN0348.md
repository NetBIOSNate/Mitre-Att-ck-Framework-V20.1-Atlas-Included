# AN0348 - Analytic 0348

[Enterprise](../../README.md) / [Analytics](README.md)

ESXi shell (BusyBox) or VMware utilities (openssl, python if present) used to Base64/hex encode data from datastore or config files → followed by abnormal egress from the host (NSX/flow logs) with asymmetric bytes_out or HTTPS posts to non-management endpoints.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0124#AN0348)

**Platforms**  [ESXi](../../Platforms/ESXi.md)

## Log sources and channels

- **esxi:shell** — commands containing base64, openssl enc -base64, xxd -p · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **esxi:hostd** — unexpected script/command invocations via hostd · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **NSX:FlowLogs** — network_flow: bytes_out >> bytes_in to external · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **NSM:Flow** — http: Base64/MIME looking payloads from ESXi host IP · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **MgmtCIDRs** — CIDRs for legitimate vCenter/NSX/backup endpoints.
- **BytesRatio** — Out:In ratio deemed suspicious (e.g., ≥3 on ESXi).
- **TimeWindow** — Correlation window between shell command and egress.
