# AN0546 - Analytic 0546

[Enterprise](../../README.md) / [Analytics](README.md)

Detects PAM module modifications or removal of MFA hooks in /etc/pam.d/ configurations, correlated with successful authentications lacking MFA prompts.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0190#AN0546)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — open/write to /etc/pam.d/* · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)
- **NSM:Connections** — Successful login without expected MFA challenge · [DC0002 - User Account Authentication](../Data%20Components/DC0002%20-%20User%20Account%20Authentication.md)

## Mutable elements

- **MFAHooks** — Paths to organization-specific PAM modules enforcing MFA.
