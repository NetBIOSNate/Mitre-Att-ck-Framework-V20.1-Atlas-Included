# AN0232 - Analytic 0232

[Enterprise](../../README.md) / [Analytics](README.md)

Adversary modifies ESXi host login banner or MOTD file (/etc/motd), either through SSH or host console access. May involve configuration file overwrite or API calls from compromised vSphere clients.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0082#AN0232)

**Platforms**  [ESXi](../../Platforms/ESXi.md)

## Log sources and channels

- **ESXiLogs:messages** — changes to /etc/motd or /etc/vmware/welcome · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)
- **esxi:hostd** — modification of config files or shell command execution · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **LoginBannerFilePath** — Target file paths (e.g., /etc/motd) may be changed via symbolic link or override
- **AccessOrigin** — ESXi hostd vs. SSH-based defacement origin may affect visibility
