# AN1358 - Analytic 1358

[Enterprise](../../README.md) / [Analytics](README.md)

Detects abuse of UNIX domain sockets, pipes, or message queues for unauthorized code execution. Correlates unexpected socket creation with suspicious binaries, abnormal shell pipelines, or injected processes establishing IPC channels.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0493#AN1358)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — socket: Suspicious creation of AF_UNIX sockets outside expected daemons · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **auditd:SYSCALL** — open: Access to named pipes or FIFO in /tmp or /dev/shm by unexpected processes · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)

## Mutable elements

- **SocketPathBaseline** — Expected UNIX socket paths used by system services and applications.
- **FIFOAccessPatterns** — Legitimate processes expected to open pipes in shared directories.
