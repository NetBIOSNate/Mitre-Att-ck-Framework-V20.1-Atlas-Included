# AN1515 - Analytic 1515

[Enterprise](../../README.md) / [Analytics](README.md)

ESXi guest OS or management interface processes establishing unexpected external HTTPS connections. Defender perspective: monitor vmx or hostd processes making outbound web requests with significant data transfer.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0548#AN1515)

**Platforms**  [ESXi](../../Platforms/ESXi.md)

## Log sources and channels

- **esxi:vmkernel** — network session initiation with external HTTPS services · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **esxi:hostd** — file copy or datastore upload via HTTPS · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)

## Mutable elements

- **DatastoreTransferThreshold** — Threshold for outbound transfers from ESXi datastores.
