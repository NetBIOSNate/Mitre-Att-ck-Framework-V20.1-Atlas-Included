# AN0738 - Analytic 0738

[Enterprise](../../README.md) / [Analytics](README.md)

Detects the use of mail utilities like `mail` or `mailx` to delete mailbox content, or file-level deletion of inbox files from `/var/spool/mail/` or `/var/mail/` following suspicious sessions.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0266#AN0738)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **auditd:SYSCALL** — unlink/unlinkat · [DC0040 - File Deletion](../Data%20Components/DC0040%20-%20File%20Deletion.md)

## Mutable elements

- **MailFolderPath** — Common inbox file locations like /var/spool/mail/, /var/mail/
- **CommandPattern** — Usage of mailx or echo piped to mail followed by deletion
