# AN1516 - Analytic 1516

[Enterprise](../../README.md) / [Analytics](README.md)

A process (non-system or user-initiated) accesses private key files in user profile paths or system certificate stores followed by potential network connections or compression activity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0549#AN1516)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=11 · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **WinEventLog:Security** — EventCode=5145 · [DC0102 - Network Share Access](../Data%20Components/DC0102%20-%20Network%20Share%20Access.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **FilePathRegex** — Regex for matching key file extensions (.pem, .pfx, .ppk, etc.) or known certificate directories like C:\Users\*\.ssh\
- **ParentProcessName** — Set of known benign certificate management tools to exclude (e.g., certutil.exe, ssh.exe)
