# AN0489 - Analytic 0489

[Enterprise](../../README.md) / [Analytics](README.md)

High-frequency, repetitive service requests (e.g., HTTP, TLS renegotiation) originating from a single or small set of source IPs targeting endpoint web services or application ports, leading to exhaustion of CPU or memory on targeted Windows services.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0173#AN0489)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Application** — Unexpected spikes in request volume, application-level errors, or thread pool exhaustion in web or API logs · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **WinEventLog:Sysmon** — EventCode=3, 22 · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **Windows:perfmon** — Sustained CPU/memory exhaustion by service process (e.g., w3wp.exe) · [DC0018 - Host Status](../Data%20Components/DC0018%20-%20Host%20Status.md)

## Mutable elements

- **TimeWindow** — Defines burst threshold (e.g., 1 min, 5 min) for connection spikes
- **TargetServicePort** — Specific ports/services likely to be abused (e.g., 80, 443, 8080)
- **CPUThreshold** — Level of sustained CPU usage considered anomalous for a given service
