# AN0585 - Analytic 0585

[Enterprise](../../README.md) / [Analytics](README.md)

Malicious script or binary causes repeated kernel panics, OOM kills, or systemd service restarts targeting services like nginx, httpd, sshd.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0208#AN0585)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **linux:syslog** — Out of memory killer invoked or kernel panic entries · [DC0018 - Host Status](../Data%20Components/DC0018%20-%20Host%20Status.md)
- **journald:systemd** — Repeated service restart attempts or unit failures · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **ServiceName** — Targeted daemon/service such as sshd, nginx, mysql
- **RestartThreshold** — Number of restarts in short succession to trigger alert
- **OOMKillCount** — Count of OOM kills over a time window
