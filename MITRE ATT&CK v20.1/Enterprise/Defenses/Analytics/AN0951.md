# AN0951 - Analytic 0951

[Enterprise](../../README.md) / [Analytics](README.md)

Monitors binary modification in /Applications and system library paths. Detects unsigned or improperly signed binaries executed after modification. Tracks Gatekeeper or notarization bypass attempts tied to modified binaries.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0336#AN0951)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — binary modified or replaced · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)
- **macos:unifiedlog** — execution of modified binary without valid signature · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **ApplicationPaths** — Tune which application and library directories are monitored for tampering
- **SignatureVerificationDepth** — Define strictness of code-signing validation checks
