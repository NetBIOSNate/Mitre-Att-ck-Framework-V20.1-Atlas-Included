# AN0044 - Analytic 0044

[Enterprise](../../README.md) / [Analytics](README.md)

Detects snapshots or data stored in VMFS volumes from root CLI or remote agents.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0014#AN0044)

**Platforms**  [ESXi](../../Platforms/ESXi.md)

## Log sources and channels

- **esxi:vmkernel** — VMFS access logs · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **esxi:shell** — snapshot create/copy, esxcli · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **SnapshotFrequency** — Number of snapshots in short time period
- **AccessUserList** — Non-admins or automation accounts writing to datastores
- **CLIContext** — Manual or unexpected API calls triggering snapshots
