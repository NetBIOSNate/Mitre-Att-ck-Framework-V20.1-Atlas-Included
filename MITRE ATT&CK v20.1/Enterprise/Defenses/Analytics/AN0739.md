# AN0739 - Analytic 0739

[Enterprise](../../README.md) / [Analytics](README.md)

Detects removal of Apple Mail artifacts via AppleScript or direct deletion of mailbox content in ~/Library/Mail/, especially when preceded by Remote Login or C2-related API access.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0266#AN0739)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — log stream · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **macos:osquery** — file_events · [DC0040 - File Deletion](../Data%20Components/DC0040%20-%20File%20Deletion.md)

## Mutable elements

- **ScriptCommandMatch** — AppleScript references to Mail.app and delete commands
- **LibraryPathMatch** — Files within ~/Library/Mail/V*/ folders
