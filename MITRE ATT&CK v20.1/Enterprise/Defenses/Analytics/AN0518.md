# AN0518 - Analytic 0518

[Enterprise](../../README.md) / [Analytics](README.md)

Detect anomalous use of scp, rsync, curl, or third-party sync apps transferring executables into user directories. Correlate new file creation with immediate execution events.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0183#AN0518)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Execution of scp, rsync, curl with remote destination · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:unifiedlog** — File created in ~/Library/LaunchAgents or executable directories · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)

## Mutable elements

- **SyncApplications** — Whitelisted apps like Dropbox or OneDrive if sanctioned
- **EntropyThreshold** — Adjust threshold for unusual filenames/hashes transferred internally
