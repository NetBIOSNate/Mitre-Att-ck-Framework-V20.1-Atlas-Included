# AN0084 - Analytic 0084

[Enterprise](../../README.md) / [Analytics](README.md)

Virtual instances or workloads generating sustained outbound data rates, often to TOR, VPN, or proxy endpoints. Often coincides with unusual IAM usage or deployed scripts (e.g., cron jobs using proxy clients).

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0028#AN0084)

**Platforms**  [IaaS](../../Platforms/IaaS.md)

## Log sources and channels

- **AWS:CloudTrail** — StartInstances · [DC0080 - Instance Start](../Data%20Components/DC0080%20-%20Instance%20Start.md)
- **AWS:VPCFlowLogs** — egress > 90th percentile or frequent connection reuse · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **InstanceType** — High-throughput instance types are more likely to be targeted for hijacking.
- **TrafficEgressThreshold** — Customize detection thresholds based on cloud provider quotas or billing alerts.
