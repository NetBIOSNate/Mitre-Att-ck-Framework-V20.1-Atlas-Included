# AN0611 - Analytic 0611

[Enterprise](../../README.md) / [Analytics](README.md)

Abuse of DYLD_INSERT_LIBRARIES or hijacking framework paths for malicious libraries. Defender observes processes invoking abnormal dylibs, modified plist files, or persistence entries pointing to altered binaries.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0218#AN0611)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Execution of process with DYLD_INSERT_LIBRARIES set · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:unifiedlog** — Modified application plist or binary replacement in /Applications · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)
- **macos:unifiedlog** — Dylib loaded from abnormal location · [DC0016 - Module Load](../Data%20Components/DC0016%20-%20Module%20Load.md)

## Mutable elements

- **AllowedDylibPaths** — Baseline directories for dylib loading.
- **PlistMonitors** — Specific plist files used for persistence monitoring.
