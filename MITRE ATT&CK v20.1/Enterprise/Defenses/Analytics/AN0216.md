# AN0216 - Analytic 0216

[Enterprise](../../README.md) / [Analytics](README.md)

Detection of anomalous RDP or remote service session activity where a logon session is hijacked rather than newly created. Indicators include mismatched user credentials vs. active session tokens, service session takeovers without corresponding successful logon events, or RDP shadowing activity without user consent.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0079#AN0216)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — EventCode=4624, 4648 · [DC0067 - Logon Session Creation](../Data%20Components/DC0067%20-%20Logon%20Session%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=3, 22 · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **ExpectedUserSessionMap** — Mapping of users to hosts they are expected to access; deviations indicate possible hijacking.
- **TimeWindow** — Threshold for detecting rapid pivoting via hijacked sessions.
