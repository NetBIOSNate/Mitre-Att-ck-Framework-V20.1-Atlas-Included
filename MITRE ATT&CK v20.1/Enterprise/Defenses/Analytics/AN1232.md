# AN1232 - Analytic 1232

[Enterprise](../../README.md) / [Analytics](README.md)

Direct use of `nc`, `socat`, or reverse tunnel scripts initiated by abnormal user contexts or unauthorized VIBs initiating connections from hypervisor to external systems.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0445#AN1232)

**Platforms**  [ESXi](../../Platforms/ESXi.md)

## Log sources and channels

- **esxi:shell** — None · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **esxi:vmkernel** — None · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **NSM:Flow** — conn.log · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **CLICommand** — Custom proxy or port forwarding scripts executed from ESXi shell.
- **DestinationIP** — Unusual outbound connections from ESXi host, particularly to internet.
- **UserContext** — Root or elevated users initiating unexpected tunnels.
