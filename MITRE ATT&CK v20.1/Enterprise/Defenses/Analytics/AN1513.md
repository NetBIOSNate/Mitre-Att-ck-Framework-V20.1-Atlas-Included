# AN1513 - Analytic 1513

[Enterprise](../../README.md) / [Analytics](README.md)

Office apps or scripts writing files followed by xattr manipulation (to evade quarantine) and subsequent HTTPS uploads. Defender perspective: anomalous file modification + outbound TLS traffic originating from non-networking apps (Word, Excel, Preview).

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0548#AN1513)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — execution of Office binaries with network activity · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:unifiedlog** — read/write of user documents prior to upload · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **macos:unifiedlog** — outbound TLS connections to cloud storage providers · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **WatchedApplications** — Applications not expected to perform bulk data transfers (Office apps, Preview).
