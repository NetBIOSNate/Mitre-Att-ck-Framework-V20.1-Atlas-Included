# AN1541 - Analytic 1541

[Enterprise](../../README.md) / [Analytics](README.md)

Detect commands such as 'esxcli system shutdown' or 'vim-cmd vmsvc/power.shutdown' executed outside of maintenance windows or via unusual users. Reboot logs in hostd.log and shell logs should be correlated.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0559#AN1541)

**Platforms**  [ESXi](../../Platforms/ESXi.md)

## Log sources and channels

- **esxi:hostd** — Powering off or restarting host · [DC0018 - Host Status](../Data%20Components/DC0018%20-%20Host%20Status.md)
- **esxi:shell** — esxcli system shutdown or reboot invoked · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **AccountRole** — Administrative account context validation.
- **MaintenanceWindow** — Expected times for reboot/shutdown behavior.
