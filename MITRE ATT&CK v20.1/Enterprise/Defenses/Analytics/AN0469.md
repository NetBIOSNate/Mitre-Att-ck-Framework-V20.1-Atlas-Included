# AN0469 - Analytic 0469

[Enterprise](../../README.md) / [Analytics](README.md)

Detects PowerShell `Clear-History` invocation or deletion of `ConsoleHost_history.txt` to erase past PowerShell session history.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0165#AN0469)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:PowerShell** — EventCode=4103, 4104, 4105, 4106 · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **WinEventLog:Sysmon** — EventCode=23 · [DC0040 - File Deletion](../Data%20Components/DC0040%20-%20File%20Deletion.md)
- **WinEventLog:Security** — EventCode=4663, 4670, 4656 · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)

## Mutable elements

- **HistoryFilePath** — Path to PSReadLine file, typically in APPDATA.
- **UserContext** — User account or role performing deletion (e.g., low-priv user deleting history).
- **CommandPattern** — Support detection of `Clear-History` and variations.
