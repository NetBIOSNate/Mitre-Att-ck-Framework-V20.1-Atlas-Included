# AN1410 - Analytic 1410

[Enterprise](../../README.md) / [Analytics](README.md)

Adversary mounts a USB device and begins enumerating, copying, or compressing files using scripting engines, cmd, or remote access tools.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0511#AN1410)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — EventCode=4663, 4670, 4656 · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **WinEventLog:System** — EventCode=2003 · [DC0042 - Drive Creation](../Data%20Components/DC0042%20-%20Drive%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **VolumeLabel** — Can tune based on known removable device labels or whitelist
- **TimeWindow** — Controls timing between device mount and sensitive file access
- **TargetFileType** — Tune for sensitive file extensions (e.g., .docx, .pdf, .csv)
