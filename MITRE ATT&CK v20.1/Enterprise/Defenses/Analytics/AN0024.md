# AN0024 - Analytic 0024

[Enterprise](../../README.md) / [Analytics](README.md)

Correlates unexpected modifications to WMI event filters, scheduled task triggers, or registry autorun keys with subsequent execution of non-standard binaries by SYSTEM-level processes.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0010#AN0024)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — EventCode=4698 · [DC0001 - Scheduled Job Creation](../Data%20Components/DC0001%20-%20Scheduled%20Job%20Creation.md)
- **WinEventLog:WMI** — Creation or modification of __EventFilter, __FilterToConsumerBinding, or CommandLineEventConsumer · [DC0008 - WMI Creation](../Data%20Components/DC0008%20-%20WMI%20Creation.md)
- **WinEventLog:Security** — EventCode=4657 · [DC0063 - Windows Registry Key Modification](../Data%20Components/DC0063%20-%20Windows%20Registry%20Key%20Modification.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **UserContext** — Filters triggering on SYSTEM or LOCAL SERVICE vs. user-initiated triggers
- **TimeWindow** — Correlates trigger definition and execution timing (e.g., within 5 minutes)
- **PathAnomalyThreshold** — Process or binary path deviation scoring for execution anomalies
