# AN0491 - Analytic 0491

[Enterprise](../../README.md) / [Analytics](README.md)

Flood of incoming TLS or HTTP(S) connections to macOS-hosted services (e.g., MAMP, Apache), causing high CPU usage and system unresponsiveness.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0173#AN0491)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Web service process (e.g., httpd) entering crash loop or consuming excessive CPU · [DC0018 - Host Status](../Data%20Components/DC0018%20-%20Host%20Status.md)
- **macos:unifiedlog** — Rapid incoming TLS handshakes or HTTP requests in quick succession · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **TLSHandshakeRate** — Number of renegotiations per minute considered suspicious
- **ServiceCrashFrequency** — Threshold of crashes before alerting on instability
