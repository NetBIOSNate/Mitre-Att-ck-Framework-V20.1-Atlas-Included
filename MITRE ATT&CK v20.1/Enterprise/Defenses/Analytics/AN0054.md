# AN0054 - Analytic 0054

[Enterprise](../../README.md) / [Analytics](README.md)

A process loads a non-system .dylib/.so via dyld (dlopen/dlsym) from user-writable locations (~/Library, /tmp) or after the library was recently created/downloaded, often followed by network egress or persistence.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0018#AN0054)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — dyld/unified log entries indicating image load from non-system paths · [DC0016 - Module Load](../Data%20Components/DC0016%20-%20Module%20Load.md)
- **macos:endpointsecurity** — exec: Process execution context for loaders calling dlopen/dlsym · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:endpointsecurity** — ES_EVENT_TYPE_NOTIFY_OPEN: Open of .dylib/.so in user-writable locations · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)

## Mutable elements

- **SuspiciousDirs** — ~/Library, /tmp, /Users/*/.* (hidden dirs) – tune to enterprise layout.
- **UnsignedOnly** — Alert only when code-signing is invalid or absent.
- **TimeWindow** — Correlate write/open to module load within N minutes.
