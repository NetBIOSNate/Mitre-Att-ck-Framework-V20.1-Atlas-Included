# AN0709 - Analytic 0709

[Enterprise](../../README.md) / [Analytics](README.md)

Monitor ESXi shell or API access to host logs under /var/log/. Abnormal enumeration of vmkernel.log, hostd.log, or vpxa.log by unauthorized accounts should be flagged.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0255#AN0709)

**Platforms**  [ESXi](../../Platforms/ESXi.md)

## Log sources and channels

- **esxi:shell** — Execution of cat, tail, grep targeting /var/log/vmkernel.log or /var/log/hostd.log · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **esxi:hostd** — read: Access to sensitive log files by non-admin users · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)

## Mutable elements

- **AdminSessions** — Correlate with legitimate administrator access sessions to reduce noise.
