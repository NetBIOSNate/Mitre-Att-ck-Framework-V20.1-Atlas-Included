# AN1088 - Analytic 1088

[Enterprise](../../README.md) / [Analytics](README.md)

Use of AWS CLI (`aws iam list-users`, `list-roles`), Azure CLI (`az ad user list`), or GCP CLI (`gcloud iam service-accounts list`) from endpoints or cloud shells where such activity is unexpected.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0386#AN1088)

**Platforms**  [IaaS](../../Platforms/IaaS.md)

## Log sources and channels

- **AWS:CloudTrail** — AWS IAM: ListUsers, ListRoles · [DC0002 - User Account Authentication](../Data%20Components/DC0002%20-%20User%20Account%20Authentication.md)
- **azure:activity** — Azure CLI Operation: Microsoft.Graph/users/read · [DC0013 - User Account Metadata](../Data%20Components/DC0013%20-%20User%20Account%20Metadata.md)

## Mutable elements

- **CallerType** — Suppress known admin accounts and alert on developer/test/service identities.
- **CLIUserAgent** — Correlate unexpected CLI user-agents and geolocation anomalies.
- **CloudRegion** — Suppress noise from known IP ranges or whitelisted accounts per region.
