# AN0398 - Analytic 0398

[Enterprise](../../README.md) / [Analytics](README.md)

Use of `usleep`, `nanosleep`, or `NSTimer` calls in executables or binaries with no GUI interaction, especially followed by disk/network activity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0141#AN0398)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — application logs referencing NSTimer, sleep, or launchd delays · [DC0021 - OS API Execution](../Data%20Components/DC0021%20-%20OS%20API%20Execution.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **AppBundleIdentifier** — Correlate with known/expected signed apps vs. unsigned binaries to reduce noise.
- **TimeToNextEvent** — Minimum time expected between process start and observable I/O for normal apps.
