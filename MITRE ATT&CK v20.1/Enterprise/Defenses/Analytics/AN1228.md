# AN1228 - Analytic 1228

[Enterprise](../../README.md) / [Analytics](README.md)

Detects application-layer tunneling or unauthorized app protocols like DNS-over-HTTPS, embedded C2 in TLS/HTTP headers, or misused SMB traffic crossing VLANs.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0444#AN1228)

**Platforms**  [Network Devices](../../Platforms/Network%20Devices.md)

## Log sources and channels

- **NSM:Flow** — conn.log, http.log, dns.log, ssl.log · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **AppProtocolAbusePattern** — Detects DNS tunneling, encrypted HTTP C2, or malformed headers
- **NorthSouthEgressFilter** — Monitor internal hosts talking externally using internal protocols (e.g., SMB)
