# AN1215 - Analytic 1215

[Enterprise](../../README.md) / [Analytics](README.md)

Detects custom archiving by monitoring execution of Swift/Objective-C apps or scripts producing high-entropy files with non-standard headers. Correlates unified logs of abnormal NSFileHandle/NSData operations, memory use of XOR/bitwise operations, and file creation events.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0438#AN1215)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Suspicious Swift/Objective-C or scripting processes writing archive-like outputs · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:unifiedlog** — Creation of files with anomalous headers and entropy values · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **macos:unifiedlog** — Abnormal memory operations (XOR/bitwise loops) during archive generation · [DC0020 - Process Modification](../Data%20Components/DC0020%20-%20Process%20Modification.md)

## Mutable elements

- **UserContext** — Flag if archiving occurs under privileged/system accounts.
- **EntropyThreshold** — Entropy score cutoff for identifying custom compressed or encrypted files.
- **AllowedApps** — Applications legitimately using custom archiving for business purposes.
