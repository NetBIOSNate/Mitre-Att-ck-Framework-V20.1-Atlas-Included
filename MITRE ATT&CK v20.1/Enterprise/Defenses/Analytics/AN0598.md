# AN0598 - Analytic 0598

[Enterprise](../../README.md) / [Analytics](README.md)

Processes on macOS initiate external connections that consistently transmit data in fixed sizes using LaunchAgents or unexpected users.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0213#AN0598)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — com.apple.network · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **macos:endpointsecurity** — ES_EVENT_TYPE_NOTIFY_CONNECT · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **LaunchdJobContext** — Agent context in which transfer occurs (e.g., user/privileged)
- **TransferSizeMedian** — Used to define what constitutes 'fixed size' chunks
- **TransferProtocolOutlier** — Detect if protocol usage deviates from common apps for given destination
