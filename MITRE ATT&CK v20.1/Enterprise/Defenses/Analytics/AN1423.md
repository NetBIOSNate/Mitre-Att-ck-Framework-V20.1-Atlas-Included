# AN1423 - Analytic 1423

[Enterprise](../../README.md) / [Analytics](README.md)

Access and retrieval of container service account tokens followed by unauthorized API requests using those tokens to interact with the Kubernetes API server or internal services.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0515#AN1423)

**Platforms**  [Containers](../../Platforms/Containers.md)

## Log sources and channels

- **kubernetes:audit** — GET or LIST requests to /var/run/secrets/kubernetes.io/serviceaccount/ followed by access to the Kubernetes API server · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)

## Mutable elements

- **TimeWindow** — Adjust based on how quickly tokens are expected to be used post-access
- **UserContext** — Tuning for known service accounts that legitimately access the API
