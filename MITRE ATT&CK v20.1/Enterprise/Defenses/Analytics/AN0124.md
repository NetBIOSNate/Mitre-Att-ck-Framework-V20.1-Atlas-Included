# AN0124 - Analytic 0124

[Enterprise](../../README.md) / [Analytics](README.md)

Installation of malicious .mobileconfig profiles or browser extension plist entries followed by abnormal browser child process activity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0044#AN0124)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — profiles install -type=configuration · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **macos:unifiedlog** — Creation or modification of browser extension .plist files · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **macos:unifiedlog** — Unexpected child process of Safari or Chrome · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **PlistPath** — Different versions may store extensions in variant preference folders
- **CommandLineFlags** — May vary with OS version; some install flags deprecated in macOS 11+
