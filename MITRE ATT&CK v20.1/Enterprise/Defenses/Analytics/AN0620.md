# AN0620 - Analytic 0620

[Enterprise](../../README.md) / [Analytics](README.md)

Processes accessing ALSA/PulseAudio devices or executing audio capture binaries like 'arecord', followed by file creation or suspicious child process spawning.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0221#AN0620)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — open · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **linux:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **auditd:SYSCALL** — write · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)

## Mutable elements

- **ExecutableName** — Capture binaries like arecord, parecord, or ffmpeg.
- **DevicePath** — Log attempts to access /dev/snd/*, /dev/dsp, /proc/asound/*.
- **UserContext** — Whether the user has audio access rights or is running under elevated privileges.
