# AN0832 - Analytic 0832

[Enterprise](../../README.md) / [Analytics](README.md)

Detects execution of archiving utilities (tar, gzip, bzip2, xz, zip, openssl) followed by suspicious archive file creation. Correlates archive creation in temporary or staging directories with execution of commands involving compression or encryption options.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0298#AN0832)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve: Execution of tar, gzip, bzip2, xz, zip, or openssl with compression/encryption arguments · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **auditd:FILE** — create: Creation of archive files in /tmp, /var/tmp, or user home directories · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)

## Mutable elements

- **ArchiveCommands** — List of archiving utilities considered suspicious.
- **MonitoredDirectories** — Paths where archive creation is flagged as unusual (e.g., /tmp, /var/tmp).
- **TimeWindow** — Correlation window for linking utility execution with archive creation.
