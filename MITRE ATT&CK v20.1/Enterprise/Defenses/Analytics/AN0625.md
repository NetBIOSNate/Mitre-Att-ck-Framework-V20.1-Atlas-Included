# AN0625 - Analytic 0625

[Enterprise](../../README.md) / [Analytics](README.md)

Detects script or binary execution initiated via JAMF, Munki, or custom MDM agents outside of baseline, or JAMF launching new Terminal or osascript processes from remote command payloads.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0223#AN0625)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — process and signing chain events · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:jamf** — RemoteCommandExecution · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **SigningAuthorityList** — Expected signing authorities for JAMF and MDM scripts
- **RemoteCommandInterval** — Frequency of remote execution from MDM servers
