# AN0011 - Analytic 0011

[Enterprise](../../README.md) / [Analytics](README.md)

Modification of PATH or HOME environment variables through shell config files, launchctl, or /etc/paths.d entries, combined with process execution from attacker-controlled directories. Defender correlates file changes in /etc/paths.d with process execution resolving to malicious binaries.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0004#AN0011)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — File modification in /etc/paths.d or user shell rc files · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)
- **macos:unifiedlog** — Process execution path inconsistent with baseline PATH directories · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **WatchedPathsDirs** — Monitor /etc/paths.d and $HOME for unauthorized entries.
- **TrustedExecutables** — Baseline applications expected in user PATH directories.
