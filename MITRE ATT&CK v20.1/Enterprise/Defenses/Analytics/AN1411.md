# AN1411 - Analytic 1411

[Enterprise](../../README.md) / [Analytics](README.md)

Adversary mounts external drive to /media or /mnt then accesses or copies targeted data via shell, cp, or tar.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0511#AN1411)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — open, read, mount · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **journald:systemd** — udisks2 or udevd logs · [DC0042 - Drive Creation](../Data%20Components/DC0042%20-%20Drive%20Creation.md)
- **auditd:SYSCALL** — execve · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **MountPathRegex** — Filter for unexpected or user-defined mount locations (e.g., /media/usb*)
- **AccessMask** — Tune based on read/write access types seen during collection
