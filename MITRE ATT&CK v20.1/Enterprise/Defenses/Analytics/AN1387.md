# AN1387 - Analytic 1387

[Enterprise](../../README.md) / [Analytics](README.md)

Abuse of VMFS or ESXi shell to hide datastore files, renaming/moving VMDK or VMX files into hidden directories. Defender view: anomalous ESXi shell commands or file operations obscuring VM artifacts.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0502#AN1387)

**Platforms**  [ESXi](../../Platforms/ESXi.md)

## Log sources and channels

- **esxi:shell** — mv, rename, or chmod commands moving VM files into hidden directories · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **esxi:syslog** — Datastore file hidden or renamed unexpectedly · [DC0059 - File Metadata](../Data%20Components/DC0059%20-%20File%20Metadata.md)

## Mutable elements

- **VMFileScope** — Restrict to VMDK, VMX, or log files critical for VM operations.
