# AN1442 - Analytic 1442

[Enterprise](../../README.md) / [Analytics](README.md)

Detects AppleScript or Objective-C usage to generate fake authentication windows (e.g., using display dialog or NSAlert) from user-launched or persistence-related processes.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0521#AN1442)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — subsystem=com.apple.Security or com.apple.applescript · [DC0029 - Script Execution](../Data%20Components/DC0029%20-%20Script%20Execution.md)
- **macos:osquery** — process_events · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **ScriptContent** — AppleScript snippets like 'display dialog' or 'with hidden answer'
- **ProcessPath** — Tune out Apple-signed and expected automation tasks
