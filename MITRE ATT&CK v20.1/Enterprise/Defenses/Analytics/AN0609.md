# AN0609 - Analytic 0609

[Enterprise](../../README.md) / [Analytics](README.md)

Unusual modifications to service binary paths, registry keys, or DLL load paths resulting in alternate execution flow. Defender observes registry key modifications, suspicious file writes into system directories, and processes loading libraries from abnormal paths.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0218#AN0609)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=7 · [DC0016 - Module Load](../Data%20Components/DC0016%20-%20Module%20Load.md)
- **WinEventLog:Security** — EventCode=4657 · [DC0063 - Windows Registry Key Modification](../Data%20Components/DC0063%20-%20Windows%20Registry%20Key%20Modification.md)
- **WinEventLog:Sysmon** — EventCode=11 · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)

## Mutable elements

- **ServiceBaseline** — Expected registry keys and service paths for comparison.
- **AllowedDllPaths** — Directories considered valid for DLL loading.
- **TimeWindow** — Correlation interval between registry/file modification and process execution.
