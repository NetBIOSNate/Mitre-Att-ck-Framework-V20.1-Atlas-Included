# AN0078 - Analytic 0078

[Enterprise](../../README.md) / [Analytics](README.md)

Detects HTTP or HTTPS communication initiated by shell-based scripts or management daemons, especially those reaching public IPs over ports 80/443 using embedded curl or wget.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0027#AN0078)

**Platforms**  [ESXi](../../Platforms/ESXi.md)

## Log sources and channels

- **NSM:Flow** — SPAN or port-mirrored HTTP/S · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **esxi:shell** — /root/.ash_history or /etc/init.d/* · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **ShellScriptMatch** — Match on commands like `wget https://*`, `curl -s`
- **ExternalConnectionFilter** — Public IPs or external DNS hostnames
