# AN0039 - Analytic 0039

[Enterprise](../../README.md) / [Analytics](README.md)

Scripting or CLI tool access to ~/Library/Application Support/Google/Chrome or ~/Library/Safari bookmarks, cookies, or history databases. Detection relies on unexpected processes accessing or reading from these locations.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0013#AN0039)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Access to ~/Library/*/Safari or Chrome directories by non-browser processes · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **macos:osquery** — process reading browser configuration paths · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **BrowserDBPath** — System-specific paths to browser databases in user Library folders
- **NonBrowserProcessList** — Processes not expected to touch browser DBs (e.g., curl, bash, python)

## Detection strategies

- [DET0013 - Detection of Local Browser Artifact Access for Reconnaissance](../Detection%20Strategies/DET0013%20-%20Detection%20of%20Local%20Browser%20Artifact%20Access%20for%20Reconnaissance.md)
