# AN1110 - Analytic 1110

[Enterprise](../../README.md) / [Analytics](README.md)

Web servers (e.g., httpd) spawning abnormal processes post file upload into /Library/WebServer/Documents or /usr/local/var/www

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0394#AN1110)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — httpd spawning bash, zsh, python, or osascript · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **auditd:SYSCALL** — file write operations in /Library/WebServer/Documents · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)

## Mutable elements

- **InterpreterName** — Adversary may use different scripting environments
- **ExecutionParent** — Not all web servers are named httpd; may differ in custom deployments
