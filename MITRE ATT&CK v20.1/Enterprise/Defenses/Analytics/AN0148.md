# AN0148 - Analytic 0148

[Enterprise](../../README.md) / [Analytics](README.md)

Delivery of suspicious internal communication (e.g., Thunderbird, Evolution) using compromised internal accounts. Sequence of: unexpected user activity + mail transfer logs + download or execution of attachments.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0054#AN0148)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **Application:Mail** — smtpd$.*$: .*from=[.*@internaldomain.com](mailto:.*@internaldomain.com) to=[.*@internaldomain.com](mailto:.*@internaldomain.com) · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **linux:syslog** — curl|wget|python .*http · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **SubjectLineAnomaly** — Deviation from typical internal email subjects
- **AttachmentType** — Executable types allowed or flagged by mail relay
