# AN0421 - Analytic 0421

[Enterprise](../../README.md) / [Analytics](README.md)

Forged SAML tokens can appear as SaaS logins where authentication succeeded without MFA, or where tokens contain claims inconsistent with the user profile. Look for concurrent sessions across different geographies with the same SAML assertion ID.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0148#AN0421)

**Platforms**  [SaaS](../../Platforms/SaaS.md)

## Log sources and channels

- **saas:access** — SAML token accepted without preceding login challenge · [DC0007 - Web Credential Usage](../Data%20Components/DC0007%20-%20Web%20Credential%20Usage.md)
- **m365:unified** — Abnormal user claims or unexpected elevated role assignment in SAML assertion · [DC0088 - Logon Session Metadata](../Data%20Components/DC0088%20-%20Logon%20Session%20Metadata.md)

## Mutable elements

- **GeoVelocityThreshold** — Triggers when same SAML token used in different geographies within short timeframe.
