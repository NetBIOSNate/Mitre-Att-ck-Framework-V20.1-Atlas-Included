# AN0806 - Analytic 0806

[Enterprise](../../README.md) / [Analytics](README.md)

Detects crontab job additions or modifications via `crontab` utility or direct edits, especially those created by interactive users executing hidden or renamed scripts.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0290#AN0806)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — process: crontab edits, launch of cron job · [DC0001 - Scheduled Job Creation](../Data%20Components/DC0001%20-%20Scheduled%20Job%20Creation.md)
- **fs:fsusage** — file access to /usr/lib/cron/tabs/ and cron output files · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)

## Mutable elements

- **ScriptPath** — Match scheduled binary path to trusted directory baseline.
- **CronScheduleSyntax** — Flags excessive frequency or wildcard-heavy cron expressions.
- **InteractiveUserContext** — Limit cron job writes from interactive shells.
