# AN0133 - Analytic 0133

[Enterprise](../../README.md) / [Analytics](README.md)

Detects attempts to clear RDP/network history and modify network configuration artifacts through command execution, registry key deletion, firewall rule changes, and suspicious file deletions (e.g., Default.rdp, registry edits to Terminal Server Client keys).

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0049#AN0133)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — EventCode=4663, 4670, 4656 · [DC0063 - Windows Registry Key Modification](../Data%20Components/DC0063%20-%20Windows%20Registry%20Key%20Modification.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **EDR:cli** — Command Line Telemetry · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **WinEventLog:Security** — Firewall Rule Modification · [DC0051 - Firewall Rule Modification](../Data%20Components/DC0051%20-%20Firewall%20Rule%20Modification.md)

## Mutable elements

- **TargetPathRegex** — Filter file/registry paths like *\Terminal Server Client\* or *Default.rdp*
- **TimeWindow** — Correlate command/registry edits within close proximity to suspicious connection activity
- **UserContext** — Detect cleanup behavior from non-interactive or SYSTEM accounts
