# AN0225 - Analytic 0225

[Enterprise](../../README.md) / [Analytics](README.md)

Adversary exploits public admin services on routers/firewalls/switches. Chain: anomalous HTTP/SNMP/SmartInstall inputs → device syslog errors/restarts → config changes/CLI spawn → egress to attacker C2.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0080#AN0225)

**Platforms**  [Network Devices](../../Platforms/Network%20Devices.md)

## Log sources and channels

- **networkdevice:controlplane** — Syslog from edge devices with HTTP 500s on mgmt portal, SmartInstall events, unexpected CLI commands · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **NSM:Flow** — NetFlow/sFlow for odd egress to Internet from mgmt plane · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **MgmtPorts** — List of admin services to watch (8443, 443, 161/udp, 4786, 22).
- **TrustedAdmins** — Admin source ranges to allow.
