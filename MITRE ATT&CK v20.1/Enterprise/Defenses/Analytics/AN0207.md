# AN0207 - Analytic 0207

[Enterprise](../../README.md) / [Analytics](README.md)

ESXi shell execution of tools/scripts (`nc`, `socat`, `perl`) relaying network traffic to other internal hosts, especially when initiated by unauthorized users or VMs.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0075#AN0207)

**Platforms**  [ESXi](../../Platforms/ESXi.md)

## Log sources and channels

- **esxi:shell** — /var/log/shell.log · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **esxi:vmkernel** — /var/log/vmkernel.log · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **NSM:Flow** — conn.log · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **CLICommandPattern** — Watch for chained shell commands building local-to-local connections.
- **VMInitiator** — Correlate to which VM initiated the traffic tunnel; unexpected VM behavior may be suspicious.
- **ConnectionDirectionality** — Unusual east-west communication patterns among VMs.
