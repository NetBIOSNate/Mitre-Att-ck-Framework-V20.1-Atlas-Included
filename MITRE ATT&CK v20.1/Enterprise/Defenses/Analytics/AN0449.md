# AN0449 - Analytic 0449

[Enterprise](../../README.md) / [Analytics](README.md)

Monitor for excessive or anomalous MFA push notifications or token requests, especially when login attempts originate from unusual IPs or geolocations and do not correspond to legitimate user-initiated sessions.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0160#AN0449)

**Platforms**  [Identity Provider](../../Platforms/Identity%20Provider.md)

## Log sources and channels

- **azure:signinlogs** — Multiple MFA challenge requests without successful primary login · [DC0002 - User Account Authentication](../Data%20Components/DC0002%20-%20User%20Account%20Authentication.md)
- **NSM:Connections** — PushNotificationSent · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **TimeWindow** — Threshold of MFA prompts per user within a short time period
- **GeoIPAllowList** — Expected login locations for workforce; deviations can be tuned
