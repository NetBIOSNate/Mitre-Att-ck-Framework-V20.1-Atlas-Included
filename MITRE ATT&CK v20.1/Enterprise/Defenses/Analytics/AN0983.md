# AN0983 - Analytic 0983

[Enterprise](../../README.md) / [Analytics](README.md)

Detects processes or binaries executed from trusted directories (e.g., System32) or using trusted names (e.g., svchost.exe) where the metadata, hash, or parent process does not align with legitimate activity patterns.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0347#AN0983)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — EventCode=4688 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=11 · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)

## Mutable elements

- **trusted_directory_list** — Paths such as C:\Windows\System32 that adversaries may abuse
- **process_baseline_age** — Time window to determine process novelty (e.g., 30 days)
