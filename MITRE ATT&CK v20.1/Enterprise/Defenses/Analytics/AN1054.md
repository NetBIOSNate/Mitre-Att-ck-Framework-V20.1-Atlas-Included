# AN1054 - Analytic 1054

[Enterprise](../../README.md) / [Analytics](README.md)

Monitor for creation of new Power Automate flows or equivalent automation scripts that trigger on user or file events. Detect anomalous actions performed by these automations, such as email forwarding, anonymous link creation, or unexpected API calls to external endpoints.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0374#AN1054)

**Platforms**  [Office Suite](../../Platforms/Office%20Suite.md)

## Log sources and channels

- **m365:unified** — AddFlow / UpdateFlow: New automation or workflow creation events · [DC0069 - Cloud Service Modification](../Data%20Components/DC0069%20-%20Cloud%20Service%20Modification.md)
- **m365:exchange** — New-InboxRule: Automation that triggers abnormal forwarding or external link generation · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **UserContext** — Business units or users where automation creation is expected (developers, admins)
- **FlowActions** — Specific automation actions (email forwarding, file sharing) that should be considered suspicious
