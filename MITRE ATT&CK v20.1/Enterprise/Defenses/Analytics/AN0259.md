# AN0259 - Analytic 0259

[Enterprise](../../README.md) / [Analytics](README.md)

Detects creation or modification of cron jobs via crontab, /etc/cron.* directories, or systemd timer units with execution by unusual users or non-standard intervals.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0094#AN0259)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — write, rename · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)
- **auditd:SYSCALL** — execve · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **linux:osquery** — crontab, systemd_timers · [DC0001 - Scheduled Job Creation](../Data%20Components/DC0001%20-%20Scheduled%20Job%20Creation.md)

## Mutable elements

- **CronSchedulePattern** — Look for high-frequency or off-hour scheduling patterns.
- **ServiceUser** — Unusual users scheduling jobs (e.g., www-data, nobody).
- **BinaryEntropy** — Abnormal scripts or binaries tied to the scheduled job.
