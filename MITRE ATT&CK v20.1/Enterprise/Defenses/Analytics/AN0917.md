# AN0917 - Analytic 0917

[Enterprise](../../README.md) / [Analytics](README.md)

Detection of suspicious use of ioctl/sysfs calls to access device firmware, unexpected flashing tools execution, and anomalous firmware checksums logged by SMART or kernel audit mechanisms.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0323#AN0917)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — ioctl/write: Direct firmware update or device memory manipulation syscalls · [DC0004 - Firmware Modification](../Data%20Components/DC0004%20-%20Firmware%20Modification.md)
- **linux:syslog** — Driver load events or firmware load failures for hardware devices · [DC0079 - Driver Load](../Data%20Components/DC0079%20-%20Driver%20Load.md)

## Mutable elements

- **FirmwareImageBaseline** — Baseline firmware checksums for comparison
- **AlertThresholds** — Tolerance levels for SMART errors before triggering alerts
