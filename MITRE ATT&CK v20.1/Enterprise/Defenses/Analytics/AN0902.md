# AN0902 - Analytic 0902

[Enterprise](../../README.md) / [Analytics](README.md)

Adversaries leverage M365 or Google Workspace APIs to create users, service accounts, or guest accounts. Follow-on behaviors include login activity, role escalation, or service principal token generation.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0319#AN0902)

**Platforms**  [Office Suite](../../Platforms/Office%20Suite.md)

## Log sources and channels

- **m365:unified** — Add user · [DC0014 - User Account Creation](../Data%20Components/DC0014%20-%20User%20Account%20Creation.md)
- **m365:unified** — Add member to group · [DC0094 - Group Modification](../Data%20Components/DC0094%20-%20Group%20Modification.md)

## Mutable elements

- **GroupSensitivity** — Only alert on additions to high-value groups (e.g., Domain Admins)
- **GuestFlag** — Tune alerts based on guest vs internal user creation
