# AN0778 - Analytic 0778

[Enterprise](../../README.md) / [Analytics](README.md)

Monitor for abnormal creation or modification of Windows services (e.g., via sc.exe, PowerShell, or API calls) that load non-standard executables. Correlate registry changes in service keys with service creation events and process execution to detect service abuse for persistence or execution.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0279#AN0778)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — EventCode=4697 · [DC0060 - Service Creation](../Data%20Components/DC0060%20-%20Service%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=13, 14 · [DC0063 - Windows Registry Key Modification](../Data%20Components/DC0063%20-%20Windows%20Registry%20Key%20Modification.md)

## Mutable elements

- **ServiceAllowlist** — Known good services and installers that regularly modify or create services
- **TimeWindow** — Threshold for correlating service creation with unusual process execution
