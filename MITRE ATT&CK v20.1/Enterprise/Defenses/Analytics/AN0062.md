# AN0062 - Analytic 0062

[Enterprise](../../README.md) / [Analytics](README.md)

Adversary executes systemctl or service stop targeting high-value services (e.g., mysql, sshd), possibly followed by rm or shred against data stores. Behavioral chain: sudo/su usage + stop command + /var/log/messages or syslog entries + file access/delete.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0021#AN0062)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve of systemctl or service stop · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **auditd:SYSCALL** — unlink/unlinkat on service binaries or data targets · [DC0040 - File Deletion](../Data%20Components/DC0040%20-%20File%20Deletion.md)
- **linux:syslog** — service stopped messages · [DC0041 - Service Metadata](../Data%20Components/DC0041%20-%20Service%20Metadata.md)

## Mutable elements

- **TimeWindow** — Window between service stop and suspicious file deletion
- **ExecUser** — Username or UID executing service stop command
