# AN0891 - Analytic 0891

[Enterprise](../../README.md) / [Analytics](README.md)

Cloud control plane actions disabling security services (CloudTrail logging, GuardDuty, Security Hub). Detect IAM role abuse correlating with service disable events.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0317#AN0891)

**Platforms**  [IaaS](../../Platforms/IaaS.md)

## Log sources and channels

- **AWS:CloudTrail** — StopLogging, DeleteTrail, or DisableSecurityService · [DC0090 - Cloud Service Disable](../Data%20Components/DC0090%20-%20Cloud%20Service%20Disable.md)

## Mutable elements

- **ServiceScope** — Specify which cloud services (logging, monitoring, threat detection) must never be disabled.
