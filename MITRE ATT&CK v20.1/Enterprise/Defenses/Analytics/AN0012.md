# AN0012 - Analytic 0012

[Enterprise](../../README.md) / [Analytics](README.md)

Execution of binaries where the on-disk filename does not match PE metadata such as OriginalFilename or InternalName. Often observed with renamed LOLBAS or system binaries like rundll32, powershell, or psexec.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0005#AN0012)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=11 · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **EDR:AMSI** — None · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **ImagePath** — Filter by suspicious or non-standard directory paths
- **PEInternalNameMismatch** — Enable tuning based on mismatch rules between metadata and disk filename
- **CommandLinePattern** — Flag unusual or rare argument combinations for LOLBAS-like tools
