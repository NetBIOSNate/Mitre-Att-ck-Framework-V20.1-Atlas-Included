# AN0569 - Analytic 0569

[Enterprise](../../README.md) / [Analytics](README.md)

A process opens/reads /dev/video* (V4L2), performs ioctl/read loops, writes large/continuous video artifacts to disk, and/or quickly establishes outbound connections for exfiltration.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0197#AN0569)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — openat/read/ioctl: openat/read/ioctl on /dev/video* by uncommon user/process · [DC0021 - OS API Execution](../Data%20Components/DC0021%20-%20OS%20API%20Execution.md)
- **auditd:SYSCALL** — PATH records referencing /dev/video* · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **linux:osquery** — select: path LIKE '/dev/video%' · [DC0034 - Process Metadata](../Data%20Components/DC0034%20-%20Process%20Metadata.md)
- **linux:syslog** — sudo execution of ffmpeg/gst-launch/v4l2-ctl by non-standard user · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **NSM:Flow** — http/file-xfer: Outbound transfer of large video-like MIME types soon after capture · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **SyscallSet** — Which syscalls to audit (openat, read, ioctl) – performance sensitive.
- **AllowedCallers** — Legitimate processes (e.g., motion, Zoom, Chrome) that access /dev/video*.
- **VideoExtensions** — List of file extensions to flag (.mp4/.avi/.mov/.mkv/.yuv/.h264).
- **MinContinuousReadCount** — Minimum read/ioctl count to infer continuous capture.
- **TimeWindow** — Correlate device open → file write → network exfil (e.g., 30m).
