# AN0616 - Analytic 0616

[Enterprise](../../README.md) / [Analytics](README.md)

Detects USB device insertion followed by high-volume or sensitive file access and staging activity by suspicious processes or accounts.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0220#AN0616)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=11 · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **WinEventLog:Security** — EventCode=4663, 4670, 4656 · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **WinEventLog:System** — EventCode=2003 · [DC0042 - Drive Creation](../Data%20Components/DC0042%20-%20Drive%20Creation.md)

## Mutable elements

- **SensitiveFilePathRegex** — Match data staging or export paths (e.g., *.docx, *.csv, *.db) to USB volume letters.
- **UserContext** — Limit to users who do not normally use removable devices (e.g., service accounts).
- **TimeWindow** — Correlate events within a short period following USB insert (e.g., 5–10 minutes).
