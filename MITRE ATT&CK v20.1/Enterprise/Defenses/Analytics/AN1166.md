# AN1166 - Analytic 1166

[Enterprise](../../README.md) / [Analytics](README.md)

Automated scripts or repeated CLI/API requests that trigger application backends to consume high CPU or memory (e.g., Apache/PHP, MySQL, mail servers), resulting in syslog errors and excessive process spawning.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0415#AN1166)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **linux:syslog** — Error/warning logs from services indicating load spike or worker exhaustion · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **NSM:Flow** — Sustained abnormal inbound request rate targeting application ports (e.g., 80/443/25) · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **SyslogErrorRate** — Defines number of critical errors in logs within time window.
- **PortRequestSpikeThreshold** — Spike rate on monitored service port triggering alert.
- **ProcessSpawnRate** — Rate of process creation that may overwhelm the system.
