# AN0499 - Analytic 0499

[Enterprise](../../README.md) / [Analytics](README.md)

Correlated evidence of browser or webview fetches to uncommon domains or mutated JS resources (proxy/NGFW logs + Zeek/HTTP logs) followed by unexpected interpreters or script engines executing (python, ruby, sh) spawned from browser processes or user sessions, rapid on-disk staging in /tmp, and outbound connections that deviate from baseline. Defender sees: uncommon resource fetch → short-lived child process executions from user browser context → file writes in temp directories → anomalous outbound C2-like connections.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0176#AN0499)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve: execve calls where a browser/webview process is parent and child is interpreter (python, sh, ruby) or downloader (curl, wget) · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **linux:syslog** — Application or browser logs (webview errors, plugin enumerations) indicating suspicious script evaluation or plugin loads · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **NSM:Flow** — http::response: HTTP responses with suspicious content-type for scripts, long obfuscated javascript bodies, or redirects to exploit kit domains · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **linux:Sysmon** — New files in /tmp, /var/tmp, $HOME/.cache, executed within TimeWindow after browser HTTP fetch · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **NSM:Connections** — Outbound connections from newly spawned child processes or from the browser to uncommon endpoints or on anomalous ports · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **TempPathPatterns** — Paths used for staging differ by distro and package manager; tune to include company-specific temp paths or exclude known benign build machines.
- **UserShellWhitelist** — Whitelist known server/service accounts or CI/CD runners where shell executions are expected.
- **DomainRarityThreshold** — Threshold for flagging domains based on internal popularity vs global rarity.
