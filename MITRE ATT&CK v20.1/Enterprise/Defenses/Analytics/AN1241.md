# AN1241 - Analytic 1241

[Enterprise](../../README.md) / [Analytics](README.md)

Detects the redirection of syscall execution flow via modification of VDSO code stubs or GOT entries to load and execute a malicious shared object through mmap and ptrace.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0448#AN1241)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — ptrace, mmap, mprotect, open, dlopen · [DC0021 - OS API Execution](../Data%20Components/DC0021%20-%20OS%20API%20Execution.md)
- **auditd:memprotect** — change from PROT_READ|PROT_WRITE to PROT_EXEC · [DC0020 - Process Modification](../Data%20Components/DC0020%20-%20Process%20Modification.md)
- **auditd:file-events** — open of suspicious .so from non-standard paths · [DC0016 - Module Load](../Data%20Components/DC0016%20-%20Module%20Load.md)
- **linux:osquery** — child process invoking dynamic linker post-ptrace · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **SuspiciousSharedObjectPathRegex** — Regex to filter dynamic library paths outside of `/lib`, `/usr/lib`, etc. (e.g., `/tmp`, `/dev/shm`)
- **TimeWindow_PtraceToMmap** — Max delay allowed between ptrace attach and mmap/mprotect execution in target process
- **ExecMemoryProtectionThreshold** — Flag when executable memory mappings deviate from normal runtime behavior
- **AnomalousParentProcessList** — Parent processes unlikely to legitimately call ptrace (e.g., nginx, apache2, sshd)
