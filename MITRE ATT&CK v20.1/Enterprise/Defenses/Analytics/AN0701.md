# AN0701 - Analytic 0701

[Enterprise](../../README.md) / [Analytics](README.md)

Detects the creation or modification of `.service` unit files in system/user-level directories, combined with execution of `systemctl`, `service`, or dynamically created drop-ins via systemd generators. Detects persistence by analyzing the `ExecStart` path, file entropy, and symlink usage, especially when paired with execution from `/tmp`, `/dev/shm`, or unmounted volumes.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0253#AN0701)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — write, open, or rename to /etc/systemd/system/*.service · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **auditd:SYSCALL** — modification of existing .service file · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)
- **auditd:SYSCALL** — execution of systemctl or service with enable/start parameters · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **auditd:SYSCALL** — fork/exec of service via PID 1 (systemd) · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **linux:osquery** — newly registered unit file with ExecStart pointing to unknown binary · [DC0060 - Service Creation](../Data%20Components/DC0060%20-%20Service%20Creation.md)

## Mutable elements

- **ServicePathRegex** — Regex filters for systemd unit locations (e.g., `/etc/systemd/system/*.service`, `/lib/systemd/system/`)
- **ExecStartPathAllowlist** — Allowlist of trusted `ExecStart` binary paths (e.g., `/usr/bin/`, `/bin/`)
- **UserContextFilter** — List of usernames that are authorized to define user-level services
- **FileEntropyThreshold** — Entropy level of binaries referenced in `ExecStart` to detect packed or obfuscated payloads
- **SystemctlOperationSet** — Flags suspicious combinations such as `systemctl enable` + `systemctl start` within short interval
