# AN0451 - Analytic 0451

[Enterprise](../../README.md) / [Analytics](README.md)

Detect repeated failed login events followed by MFA challenges triggered in rapid succession, especially if originating from service accounts or anomalous IP addresses.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0160#AN0451)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — EventCode=4625 · [DC0002 - User Account Authentication](../Data%20Components/DC0002%20-%20User%20Account%20Authentication.md)

## Mutable elements

- **ServiceAccountExclusion** — Exclude specific accounts where automated MFA requests are legitimate
