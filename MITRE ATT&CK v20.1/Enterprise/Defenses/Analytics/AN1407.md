# AN1407 - Analytic 1407

[Enterprise](../../README.md) / [Analytics](README.md)

Detects suspicious SVG file creation or download events followed by script engine execution (e.g., wscript.exe, mshta.exe, rundll32.exe), network callbacks, or browser-based credential collection.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0510#AN1407)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=11 · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=3, 22 · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **TimeWindow** — Threshold between SVG file write and script execution (e.g., < 60s)
- **ParentProcessWhitelist** — Allowlisted script engines that may invoke browsers or JS in benign cases
- **FileExtensionPattern** — Regex or string match for .svg, .svgz, or embedded .svg inside HTML or PDF
