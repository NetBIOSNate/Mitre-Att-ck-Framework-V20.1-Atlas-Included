# AN1068 - Analytic 1068

[Enterprise](../../README.md) / [Analytics](README.md)

Detects encoded PowerCLI or Base64-encoded payloads staged via datastore uploads or shell access (e.g., ESXi Shell or backdoored VIBs).

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0378#AN1068)

**Platforms**  [ESXi](../../Platforms/ESXi.md)

## Log sources and channels

- **esxi:vmkernel** — Datastore modification events · [DC0059 - File Metadata](../Data%20Components/DC0059%20-%20File%20Metadata.md)
- **esxi:hostd** — Remote access API calls and file uploads · [DC0021 - OS API Execution](../Data%20Components/DC0021%20-%20OS%20API%20Execution.md)

## Mutable elements

- **StagingLocation** — Tune based on observed adversary paths (e.g., /vmfs/volumes/...)
- **EncodedLengthThreshold** — Tune length of encoded payloads before triggering detection
