# AN0120 - Analytic 0120

[Enterprise](../../README.md) / [Analytics](README.md)

Detection of commands accessing locale, timezone, or language settings such as 'locale', 'timedatectl', or parsing /etc/timezone. Anomalous execution by unusual users or automation scripts should be flagged.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0043#AN0120)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve calls to locale, timedatectl, or cat /etc/timezone · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **linux:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **UserContext** — Unexpected users running location discovery commands may indicate malicious behavior.
