# AN0197 - Analytic 0197

[Enterprise](../../README.md) / [Analytics](README.md)

Detects remote writes or snapshots mounted from other systems into a central ESXi VMFS path or NFS store used for remote staging of files before exfiltration.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0071#AN0197)

**Platforms**  [ESXi](../../Platforms/ESXi.md)

## Log sources and channels

- **esxi:vmkernel** — VMFS file creation · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **esxi:vob** — NFS/remote access logs · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **esxi:shell** — invoked remote scripts (esxcli) · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **SnapshotFrequency** — How often snapshots are mounted or restored from peer nodes
- **RemoteWriteVolume** — Threshold for staging behavior vs. backup/operational activity
- **StorageMountPaths** — Common local destinations for incoming data
