# AN0041 - Analytic 0041

[Enterprise](../../README.md) / [Analytics](README.md)

Detects script or user activity copying files to a central temp or /mnt directory followed by archive/compression utilities.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0014#AN0041)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — creat · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **auditd:SYSCALL** — execve · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **StagingDirectoryList** — e.g., /tmp/, /var/tmp/, /mnt/
- **ArchivingCommandPatterns** — grep for 'tar', 'zip', 'gzip', '7z'
- **UserContext** — Interactive or elevated shells running archiving commands
