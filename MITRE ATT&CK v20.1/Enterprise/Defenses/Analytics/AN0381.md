# AN0381 - Analytic 0381

[Enterprise](../../README.md) / [Analytics](README.md)

Detects email-sending behavior via Terminal, AppleScript, or Automator that interfaces with SMTP or IMAP, typically using curl or mail-related APIs in unsanctioned contexts.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0135#AN0381)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — log stream --predicate 'processImagePath CONTAINS "curl" OR "osascript"' · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:osquery** — socket_events · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **UserContext** — Monitor non-mail client users initiating SMTP/IMAP
- **TimeWindow** — Look for execution of mail commands during off-hours
