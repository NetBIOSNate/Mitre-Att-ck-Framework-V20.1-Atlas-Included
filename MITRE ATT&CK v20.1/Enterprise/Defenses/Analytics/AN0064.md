# AN0064 - Analytic 0064

[Enterprise](../../README.md) / [Analytics](README.md)

Attacker disables VM-related services or stops VMs forcibly to target vmdk or logs. Behavioral chain: esxcli or vim-cmd stop + audit log showing user privilege use + datastore file manipulation.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0021#AN0064)

**Platforms**  [ESXi](../../Platforms/ESXi.md)

## Log sources and channels

- **esxi:hostd** — Stop VM or disable service events via vim-cmd · [DC0041 - Service Metadata](../Data%20Components/DC0041%20-%20Service%20Metadata.md)
- **esxi:hostd** — Log entries indicating VM powered off or forcibly terminated · [DC0033 - Process Termination](../Data%20Components/DC0033%20-%20Process%20Termination.md)

## Mutable elements

- **VMName** — Targeted virtual machine name
- **InitiatorUser** — User who issued stop or disable command
