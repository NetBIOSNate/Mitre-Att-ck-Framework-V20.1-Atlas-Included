# AN0248 - Analytic 0248

[Enterprise](../../README.md) / [Analytics](README.md)

Detection of file write-access to USB-mount directories (e.g., /media/, /run/media/) followed by same-file access or execution on another host.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0090#AN0248)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — write/open, FIM audit · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **auditd:SYSCALL** — Removable media mount notification · [DC0042 - Drive Creation](../Data%20Components/DC0042%20-%20Drive%20Creation.md)

## Mutable elements

- **MountPathPattern** — Typical mount paths to monitor (e.g., /media/usb*, /run/media/username/*).
- **TimeWindowBetweenHosts** — Tunable detection window to correlate read/write between different hosts within a short interval (e.g., <15m).
