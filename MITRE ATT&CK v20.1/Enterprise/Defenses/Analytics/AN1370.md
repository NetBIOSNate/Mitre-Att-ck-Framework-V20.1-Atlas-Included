# AN1370 - Analytic 1370

[Enterprise](../../README.md) / [Analytics](README.md)

Detects kill/systemctl/service commands against EDR, auditd, falco, osquery, rsyslog, journald, or agent processes; configuration edits disabling startup; module unload attempts; abrupt cessation of logs after privileged shell execution.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0497#AN1370)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve: systemctl stop, service stop, or kill -9 on security daemons (e.g., falcon-sensor, auditd) · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **auditd:CONFIG_CHANGE** — delete: Modification of systemd unit files or config for security agents · [DC0041 - Service Metadata](../Data%20Components/DC0041%20-%20Service%20Metadata.md)

## Mutable elements

- **AgentServiceNames** — List of endpoint protection service names (varies across deployments).
- **AllowedAdminAccounts** — Accounts permitted to legitimately stop or reconfigure services.
