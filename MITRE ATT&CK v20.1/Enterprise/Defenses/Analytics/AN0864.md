# AN0864 - Analytic 0864

[Enterprise](../../README.md) / [Analytics](README.md)

A tampered app/pkg/notarized update is installed via installer, softwareupdated, Homebrew, or vendor updater; new Mach-O or bundle contents appear in /Applications, /Library, /usr/local or /opt/homebrew; first run spawns sh/zsh/osascript/curl and makes egress to unfamiliar domains; AMFI/Gatekeeper may log signature/notarization problems.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0309#AN0864)

**Platforms**  [macOS](../../Platforms/macOS.md)

- **macos:unifiedlog** — pkginstalld/softwareupdated/Homebrew install transactions · [DC0059 - File Metadata](../Data%20Components/DC0059%20-%20File%20Metadata.md)
- **macos:endpointsecurity** — exec · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
