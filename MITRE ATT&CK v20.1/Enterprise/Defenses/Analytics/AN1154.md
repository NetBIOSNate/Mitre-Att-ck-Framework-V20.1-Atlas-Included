# AN1154 - Analytic 1154

[Enterprise](../../README.md) / [Analytics](README.md)

Reading of sensitive files like .bash_history, /etc/shadow, or private key directories by unauthorized users or unusual processes.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0412#AN1154)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — open/read system calls to ~/.bash_history or /etc/shadow · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **auditd:SYSCALL** — execution of tools like cat, grep, or awk on credential files · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **SensitivePaths** — Paths to credential files such as /etc/shadow or ~/.bash_history
- **UserContext** — Whether the process runs under a privileged or non-interactive session
