# AN0326 - Analytic 0326

[Enterprise](../../README.md) / [Analytics](README.md)

Creation of LaunchAgents or LaunchDaemons with names resembling known system services but executing non-Apple signed code or scripts.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0117#AN0326)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **fs:fileevents** — /Library/LaunchDaemons/*.plist, ~/Library/LaunchAgents/*.plist · [DC0005 - Scheduled Job Metadata](../Data%20Components/DC0005%20-%20Scheduled%20Job%20Metadata.md)
- **macos:endpointsecurity** — ES_EVENT_TYPE_NOTIFY_EXEC · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:unifiedlog** — subsystem=com.apple.launchservices · [DC0041 - Service Metadata](../Data%20Components/DC0041%20-%20Service%20Metadata.md)

## Mutable elements

- **PlistLabelSimilarity** — Detect plists with labels that closely resemble legitimate ones (e.g., `com.apple.updates.plist`)
- **UnsignedBinaryExecution** — Toggle sensitivity for unsigned binaries or scripts launched by daemons
- **UserContext** — Scope detection based on whether LaunchAgent ran in user or system context
