# AN0883 - Analytic 0883

[Enterprise](../../README.md) / [Analytics](README.md)

Execution of destructive utilities (dd, shred, wipe) targeting block devices, or processes invoking syscalls to directly overwrite /dev/sd* or /dev/nvme* partitions. Correlate abnormal file write attempts with shell process execution and block device access.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0316#AN0883)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — open/write syscalls to block devices (/dev/sd*, /dev/nvme*) · [DC0054 - Drive Access](../Data%20Components/DC0054%20-%20Drive%20Access.md)
- **auditd:EXECVE** — Execution of dd, shred, or wipe with arguments targeting block devices · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **TargetDevices** — Exclude removable drives or designated partitions that may be overwritten during maintenance.
- **EntropyThreshold** — Tune detection for pseudorandom write patterns to reduce false positives during high-volume I/O.
