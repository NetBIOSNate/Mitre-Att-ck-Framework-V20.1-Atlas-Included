# AN0118 - Analytic 0118

[Enterprise](../../README.md) / [Analytics](README.md)

Detects abuse of verclsid.exe to execute COM objects by monitoring process creation, CLSID arguments, DLLs or scriptlet engines loaded into memory, and If the CLSID points to remote SCT/HTA content, verclsid.exe makes outbound connections.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0042#AN0118)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=7 · [DC0016 - Module Load](../Data%20Components/DC0016%20-%20Module%20Load.md)
- **WinEventLog:Sysmon** — EventCode=13, 14 · [DC0063 - Windows Registry Key Modification](../Data%20Components/DC0063%20-%20Windows%20Registry%20Key%20Modification.md)
- **WinEventLog:Sysmon** — EventCode=3, 22 · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **AllowedCLSIDs** — Baseline CLSIDs frequently invoked by verclsid.exe in normal shell extension verification.
- **ParentProcessFilter** — Unusual parents (e.g., winword.exe, excel.exe) spawning verclsid.exe should be treated as suspicious.
- **TimeWindow** — Correlation window between verclsid.exe start, module load, and network activity.
- **ExternalIPRange** — Restrict detection to external IPs not in approved ranges to cut noise.
