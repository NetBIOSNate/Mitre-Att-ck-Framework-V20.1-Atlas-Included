# AN1377 - Analytic 1377

[Enterprise](../../README.md) / [Analytics](README.md)

Creation of outbound connections on alternate ports or using covert transport (e.g., ICMP, DNS) from non-network-intensive processes, following known disruption or blocked traffic.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0499#AN1377)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — outbound connections · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **NSM:Flow** — alternate ports · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **ProtocolType** — Can filter for rare fallback channel types (e.g., ICMP, DNS over HTTP).
- **UserContext** — Tuning by user (e.g., root vs. service account) helps suppress noise.
