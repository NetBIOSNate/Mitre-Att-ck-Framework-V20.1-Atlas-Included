# AN0052 - Analytic 0052

[Enterprise](../../README.md) / [Analytics](README.md)

A process (often LOLBin or user-launched program) loads a DLL from a user-writable/UNC/Temp path or unsigned/invalid signer. Within a short window the DLL is (a) newly written to disk, (b) spawned as follow-on execution (rundll32/regsvr32), or (c) establishes outbound C2.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0018#AN0052)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=7 · [DC0016 - Module Load](../Data%20Components/DC0016%20-%20Module%20Load.md)
- **WinEventLog:Sysmon** — EventCode=11 · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **WinEventLog:Security** — EventCode=4688 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=3, 22 · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **WinEventLog:Microsoft-Windows-CodeIntegrity/Operational** — CodeIntegrity/WDAC events indicating unsigned/invalid DLL loads · [DC0034 - Process Metadata](../Data%20Components/DC0034%20-%20Process%20Metadata.md)

## Mutable elements

- **TimeWindow** — Correlation window between file write → module load → network (e.g., 0–20 minutes).
- **SuspiciousPathRegex** — Regex for user-writable/UNC/temp paths to flag (e.g., %TEMP%, %APPDATA%, \\*\share\).
- **UnsignedOnly** — Alert only when SignatureStatus != Valid to reduce noise.
- **RareSignerThreshold** — Frequency threshold for unseen/rare signers in last N days.
- **MinFileSizeKB** — Ignore tiny DLL stubs to cut noise.
