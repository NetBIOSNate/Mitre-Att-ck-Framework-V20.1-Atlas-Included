# AN1577 - Analytic 1577

[Enterprise](../../README.md) / [Analytics](README.md)

Detects creation or modification of `LaunchDaemon` or `LaunchAgent` plist files under `/Library/LaunchDaemons/`, `~/Library/LaunchAgents/`, or similar. Monitors execution of `launchctl`, property list edits, and file permission changes.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0571#AN1577)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — launchctl load/unload or plist file modification · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **fs:fsusage** — file write to launchd plist paths · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)

## Mutable elements

- **PlistPathList** — Watched directories for LaunchDaemons and LaunchAgents
- **PlistKeyMonitor** — Monitored keys such as `RunAtLoad`, `KeepAlive`, or `ProgramArguments`
- **UnsignedBinaryAlert** — Flag execution of unsigned or non-Apple-signed binaries within plist
