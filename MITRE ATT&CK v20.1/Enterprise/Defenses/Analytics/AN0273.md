# AN0273 - Analytic 0273

[Enterprise](../../README.md) / [Analytics](README.md)

Processes that utilize AppleScript, `CGWindowListCopyWindowInfo`, or `NSRunningApplication` APIs to list active application windows and foreground processes.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0097#AN0273)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — None · [DC0021 - OS API Execution](../Data%20Components/DC0021%20-%20OS%20API%20Execution.md)
- **macos:osquery** — process_events · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **AppleScriptTarget** — Tunable to ignore benign scripting like automation by known apps.
- **ParentProcess** — Useful to suppress expected automation processes.
