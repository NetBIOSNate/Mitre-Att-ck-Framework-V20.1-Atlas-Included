# AN1441 - Analytic 1441

[Enterprise](../../README.md) / [Analytics](README.md)

Detects GUI-based credential prompts invoked via zenity/kdialog/dialog or X11 APIs from non-user-facing scripts or background shell sessions, often with authentication-related text.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0521#AN1441)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **linux:cli** — Terminal Command History · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **ExecutableName** — Filter zenity/kdialog prompts launched from unexpected parent shells
- **PromptString** — Look for 'password', 'authentication required', or similar tokens
