# AN0370 - Analytic 0370

[Enterprise](../../README.md) / [Analytics](README.md)

Detects access to cloud APIs or CLI tools to move or sync files from sensitive buckets to external endpoints using protocols like HTTPS or S3 APIs.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0131#AN0370)

**Platforms**  [IaaS](../../Platforms/IaaS.md)

## Log sources and channels

- **AWS:CloudTrail** — GetObject, CopyObject · [DC0025 - Cloud Storage Access](../Data%20Components/DC0025%20-%20Cloud%20Storage%20Access.md)
- **AWS:VPCFlowLogs** — Outbound data flows · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **IAMRoleContext** — Detect unauthorized use of roles for cloud storage manipulation.
- **GeoDestinationThreshold** — Alert on outbound flows to geo-locations not seen in training baseline.
