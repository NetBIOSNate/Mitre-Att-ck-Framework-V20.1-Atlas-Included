# AN0993 - Analytic 0993

[Enterprise](../../README.md) / [Analytics](README.md)

Detect curl/wget commands saving executable/script payloads to /tmp or /var/tmp followed by execution. Monitor packet captures or IDS/IPS alerts for injected responses or mismatched content types.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0349#AN0993)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve: Execution of curl or wget writing files to /tmp/* followed by chmod or execution · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **WinEventLog:Sysmon** — File creation of suspicious scripts/binaries in temporary directories · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **NSM:Flow** — Injected content responses with unexpected script/malware signatures · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **TempDirectories** — Directories such as /tmp and /var/tmp where injected files are often written.
