# AN1362 - Analytic 1362

[Enterprise](../../README.md) / [Analytics](README.md)

Monitor server and endpoint logs for unusual outbound network connections to cryptocurrency nodes, unauthorized scripts accessing financial systems, or automation targeting payment file formats. Detect curl/wget activity aimed at exfiltrating transaction data or credentials from financial apps.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0495#AN1362)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve: Execution of curl, wget, or custom scripts accessing financial endpoints · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **linux:syslog** — Authentication attempts into finance-related servers from unusual IPs or times · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **KnownFinanceIPs** — Whitelisted IPs for finance-related traffic to reduce noise.
