# AN0866 - Analytic 0866

[Enterprise](../../README.md) / [Analytics](README.md)

Detects unexpected use of usermod, gpasswd, or direct modification of /etc/group to elevate user group membership.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0310#AN0866)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — SYSCALL for usermod or /etc/group file modification · [DC0010 - User Account Modification](../Data%20Components/DC0010%20-%20User%20Account%20Modification.md)

## Mutable elements

- **GroupName** — Focus on 'sudo', 'wheel', or custom high-privilege groups
- **UserContext** — Account that initiated the change (e.g., service account or unrecognized user)
- **TimeWindow** — Detect elevation outside change windows
