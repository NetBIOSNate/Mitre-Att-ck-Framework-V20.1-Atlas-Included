# AN0290 - Analytic 0290

[Enterprise](../../README.md) / [Analytics](README.md)

Detects suspicious configuration changes in IdP authentication flows such as enabling reversible password encryption, MFA bypass, or policy weakening. Correlates policy modification events with unusual administrative activity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0104#AN0290)

**Platforms**  [Identity Provider](../../Platforms/Identity%20Provider.md)

## Log sources and channels

- **azure:policy** — UpdatePolicy · [DC0069 - Cloud Service Modification](../Data%20Components/DC0069%20-%20Cloud%20Service%20Modification.md)
- **m365:unified** — Set-ADUser OR Set-ADAccountControl · [DC0010 - User Account Modification](../Data%20Components/DC0010%20-%20User%20Account%20Modification.md)

## Mutable elements

- **PolicyBaseline** — Expected authentication-related policy configurations to compare against.
