# AN0763 - Analytic 0763

[Enterprise](../../README.md) / [Analytics](README.md)

Unusual TLS tunnels through ports not normally encrypted (e.g., TLS on port 8080, 53). Defender sees NetFlow/IPFIX or packet inspection indicating high-entropy traffic volumes and asymmetric client/server exchange ratios.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0273#AN0763)

**Platforms**  [Network Devices](../../Platforms/Network%20Devices.md)

## Log sources and channels

- **NSM:Flow** — Session records with TLS-like byte patterns · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **NSM:Connections** — Abnormal certificate chains or non-standard ports carrying TLS · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **PortProfiles** — Define expected TLS port usage to flag anomalies.
- **TrafficAsymmetryRatio** — Sent/received byte thresholds to catch hidden C2.
