# AN1582 - Analytic 1582

[Enterprise](../../README.md) / [Analytics](README.md)

Detects use of built-in SaaS sharing mechanisms to transfer ownership or share access of critical data to external tenants or untrusted users through API calls or link generation features.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0573#AN1582)

**Platforms**  [SaaS](../../Platforms/SaaS.md)

## Log sources and channels

- **saas:googledrive** — drive.permission.add · [DC0023 - Cloud Storage Modification](../Data%20Components/DC0023%20-%20Cloud%20Storage%20Modification.md)
- **saas:box** — collaboration.invite · [DC0027 - Cloud Storage Metadata](../Data%20Components/DC0027%20-%20Cloud%20Storage%20Metadata.md)

## Mutable elements

- **UserContext** — Whether the user is in a high-privileged or VIP group
- **DomainReputationList** — Allowlist or blocklist of external SaaS domains
- **PayloadVolumeThreshold** — Size or number of shared files triggering alert
