# AN0504 - Analytic 0504

[Enterprise](../../README.md) / [Analytics](README.md)

Detection of VNC service or executable starting unexpectedly, followed by user session creation and interactive desktop activity (mouse/keyboard simulation).

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0178#AN0504)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Security** — EventCode=4624, 4648 · [DC0067 - Logon Session Creation](../Data%20Components/DC0067%20-%20Logon%20Session%20Creation.md)
- **NSM:Flow** — port 5900 inbound · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **TimeWindow** — Correlate VNC process with user logon activity within defined time span
- **VNCBinaryList** — Trackable VNC executable names (e.g., vncserver.exe, winvnc.exe)
- **LogonType** — Limit detection to interactive logons (type 10)
