# AN0790 - Analytic 0790

[Enterprise](../../README.md) / [Analytics](README.md)

ESXi services (vmx, hostd) generating outbound HTTPS POST requests to text storage sites. Defender perspective: anomalous datastore or log reads chained with traffic to pastebin-like destinations.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0284#AN0790)

**Platforms**  [ESXi](../../Platforms/ESXi.md)

## Log sources and channels

- **esxi:hostd** — datastore/log file access · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **esxi:vmkernel** — HTTPS POST connections to pastebin-like domains · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **DatastoreExfilThreshold** — Threshold of bytes exfiltrated from ESXi datastore files.
- **ApprovedDestinations** — Whitelist of domains approved for API communication to prevent false positives.
