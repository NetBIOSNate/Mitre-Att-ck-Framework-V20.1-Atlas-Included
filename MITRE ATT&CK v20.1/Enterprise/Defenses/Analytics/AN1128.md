# AN1128 - Analytic 1128

[Enterprise](../../README.md) / [Analytics](README.md)

Enumeration of directories, applications, or service principals through APIs such as Microsoft Graph or Okta API. Defender perspective includes unexpected listing of users, roles, applications, and abnormal access to identity management endpoints.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0402#AN1128)

**Platforms**  [Identity Provider](../../Platforms/Identity%20Provider.md)

## Log sources and channels

- **azure:audit** — ListApplications, ListServicePrincipals: Large-scale queries against identity or application objects · [DC0083 - Cloud Service Enumeration](../Data%20Components/DC0083%20-%20Cloud%20Service%20Enumeration.md)
- **azure:signinlogs** — InteractiveUserLogin: Discovery behavior linked to privileged logins from atypical IP ranges · [DC0067 - Logon Session Creation](../Data%20Components/DC0067%20-%20Logon%20Session%20Creation.md)

## Mutable elements

- **QueryVolumeThreshold** — Threshold for number of object enumeration calls before triggering detection.
- **PrivilegedRoleList** — High-value identity roles (Global Admin, Application Admin) for targeted discovery monitoring.
