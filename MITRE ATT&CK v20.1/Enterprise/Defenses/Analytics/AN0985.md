# AN0985 - Analytic 0985

[Enterprise](../../README.md) / [Analytics](README.md)

Detects binaries or launch daemons in /System/Library or /Applications with mismatched bundle names, unexpected metadata, or improper installation origin.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0347#AN0985)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — log collect from launchd and process start · [DC0034 - Process Metadata](../Data%20Components/DC0034%20-%20Process%20Metadata.md)
- **fs:fsusage** — filesystem monitoring of exec/open · [DC0059 - File Metadata](../Data%20Components/DC0059%20-%20File%20Metadata.md)

## Mutable elements

- **expected_bundle_names** — List of known application names and paths to validate against
- **signed_by_apple_check** — Toggle to enforce checks for Apple-signed binaries in trusted directories
