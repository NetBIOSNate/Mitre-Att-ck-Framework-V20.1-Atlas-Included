# AN0711 - Analytic 0711

[Enterprise](../../README.md) / [Analytics](README.md)

Unusual access to SSH agent sockets in /tmp/ or /private/tmp, process access to another user’s $SSH_AUTH_SOCK, and lateral SSH activity without corresponding login events. Defender view: correlation of socket access with anomalous network flows to internal systems.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0256#AN0711)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Process opening SSH_AUTH_SOCK or /tmp/ssh-* socket not owned by same UID · [DC0034 - Process Metadata](../Data%20Components/DC0034%20-%20Process%20Metadata.md)
- **macos:unifiedlog** — Execution of ssh or sftp without corresponding login event · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:unifiedlog** — Session reuse without new auth event · [DC0067 - Logon Session Creation](../Data%20Components/DC0067%20-%20Logon%20Session%20Creation.md)
