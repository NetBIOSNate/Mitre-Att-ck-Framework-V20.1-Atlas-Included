# AN0409 - Analytic 0409

[Enterprise](../../README.md) / [Analytics](README.md)

Detection of firewall changes using esxcli network firewall set or vSphere API modifications. Sudden disabling of firewall rules across management interfaces is a strong adversarial signal.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0145#AN0409)

**Platforms**  [ESXi](../../Platforms/ESXi.md)

## Log sources and channels

- **esxi:hostd** — esxcli network firewall set commands · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **esxi:hostd** — vSphere API calls modifying firewall settings · [DC0051 - Firewall Rule Modification](../Data%20Components/DC0051%20-%20Firewall%20Rule%20Modification.md)

## Mutable elements

- **APIMethods** — Whitelist of authorized vSphere API methods for firewall configuration.
