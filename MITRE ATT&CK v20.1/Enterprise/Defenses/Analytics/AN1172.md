# AN1172 - Analytic 1172

[Enterprise](../../README.md) / [Analytics](README.md)

Detects file movement or outbound TFTP/FTP transfers from ESXi host initiated via shell commands or injected scripts, particularly from scratch partitions or /tmp.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0416#AN1172)

**Platforms**  [ESXi](../../Platforms/ESXi.md)

## Log sources and channels

- **esxi:shell** — /root/.ash_history · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **NSM:Flow** — mirror/SPAN port · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **TransferTargetDomainOrIP** — Public IPs or domains not belonging to known ESXi mgmt infra
- **SourceDirectoryFilter** — Monitor transfers from /tmp/, /etc/, /vmfs/volumes/
