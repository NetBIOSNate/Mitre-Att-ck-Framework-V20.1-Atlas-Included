# AN0811 - Analytic 0811

[Enterprise](../../README.md) / [Analytics](README.md)

Detects SaaS web login followed by dashboard or web GUI page views from unfamiliar locations, devices, or access patterns. Identifies use of sensitive reporting or configuration consoles accessed from high-risk accounts.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0291#AN0811)

**Platforms**  [SaaS](../../Platforms/SaaS.md)

## Log sources and channels

- **saas:zoom** — Zoom Admin Dashboard accessed from unfamiliar IP/device · [DC0067 - Logon Session Creation](../Data%20Components/DC0067%20-%20Logon%20Session%20Creation.md)
- **saas:salesforce** — Login · [DC0002 - User Account Authentication](../Data%20Components/DC0002%20-%20User%20Account%20Authentication.md)
- **saas:box** — User navigated to admin interface · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **SaaSDashboardViewList** — List of GUI pages or endpoints considered sensitive
- **IPReputationThreshold** — Reputation score or allowlist of source IPs
- **LoginBehaviorBaseline** — Typical user/device login pairings or login frequency
