# AN0886 - Analytic 0886

[Enterprise](../../README.md) / [Analytics](README.md)

Unusual service stop events, termination of AV/EDR processes, registry modifications disabling security tools, and firewall/defender configuration changes. Correlate process creation with service stop requests and registry edits.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0317#AN0886)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — EventCode=4688 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:System** — EventCode=7045 · [DC0060 - Service Creation](../Data%20Components/DC0060%20-%20Service%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=12 · [DC0056 - Windows Registry Key Creation](../Data%20Components/DC0056%20-%20Windows%20Registry%20Key%20Creation.md)

## Mutable elements

- **ProcessWhitelist** — Exclude authorized administrative tools that stop services during maintenance.
- **ServiceNamePatterns** — Refine which services are considered security-critical (e.g., AV, EDR, firewall).
