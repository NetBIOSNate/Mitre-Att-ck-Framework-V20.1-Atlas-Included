# AN0179 - Analytic 0179

[Enterprise](../../README.md) / [Analytics](README.md)

Behavioral chain: (1) browser/office/GUI mail client opens a URL, (2) outbound connection to untrusted domain, (3) a new file is saved in $HOME/Downloads, /tmp, or cache immediately after.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0066#AN0179)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve: Execs of chromium, google-chrome, firefox, libreoffice with http(s) in cmdline · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **auditd:SYSCALL** — open,creat,rename: Writes in $HOME/Downloads, /tmp, ~/.cache with exe/script/archive/office extensions · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **NSM:Flow** — Suspicious URL patterns, uncommon TLDs, URL shorteners · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **TimeWindow** — Typical 10–20m between click and write.
- **UserPaths** — $HOME/Downloads, /tmp, ~/.cache, ~/.local/share.
- **HighRiskExtensions** — exe, elf, sh, js, py, jar, iso, img, zip, rar, xlsm, docm, xll.
- **DomainRiskScore** — Heuristic or TI score threshold for domains.
