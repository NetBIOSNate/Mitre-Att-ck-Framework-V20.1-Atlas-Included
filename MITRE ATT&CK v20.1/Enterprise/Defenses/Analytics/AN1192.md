# AN1192 - Analytic 1192

[Enterprise](../../README.md) / [Analytics](README.md)

Detects guest VMs or management agents issuing HTTP(S) traffic to external services without a valid patch management or backup justification.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0425#AN1192)

**Platforms**  [ESXi](../../Platforms/ESXi.md)

## Log sources and channels

- **esxi:vmkernel** — network activity · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **vpxd.log** — API communication · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **RemoteIPRange** — Filter to detect only external/public destinations
- **VMContext** — Exclude known backup or patch automation services
