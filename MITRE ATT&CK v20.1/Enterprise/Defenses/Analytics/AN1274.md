# AN1274 - Analytic 1274

[Enterprise](../../README.md) / [Analytics](README.md)

Detects anomalous network traffic on UDP 5355 (LLMNR) and UDP 137 (NBT-NS) combined with unauthorized SMB relay attempts, registry modifications re-enabling multicast name resolution, or suspicious service creation indicative of adversary-in-the-middle credential interception.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0462#AN1274)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — EventCode=4697 · [DC0060 - Service Creation](../Data%20Components/DC0060%20-%20Service%20Creation.md)
- **WinEventLog:Security** — Registry key modification HKLM\Software\Policies\Microsoft\Windows NT\DNSClient\EnableMulticast · [DC0063 - Windows Registry Key Modification](../Data%20Components/DC0063%20-%20Windows%20Registry%20Key%20Modification.md)
- **NSM:Flow** — Unusual responses to LLMNR (UDP 5355) or NBT-NS (UDP 137) queries from unauthorized hosts · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **NSM:Flow** — Abnormal SMB authentication attempts correlated with poisoned LLMNR/NBT-NS sessions · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **TrustedResponderList** — Defines expected LLMNR/NBT-NS responders to tune out legitimate services.
- **TimeWindow** — Correlation period for linking poisoned name resolution with SMB relay attempts.
- **SMBServiceBaseline** — Normal services and SMB relay patterns in the enterprise environment.
