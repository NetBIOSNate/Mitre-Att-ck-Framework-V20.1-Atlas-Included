# AN0716 - Analytic 0716

[Enterprise](../../README.md) / [Analytics](README.md)

Initiation of remote desktop sessions via AnyDesk, TeamViewer, or Chrome Remote Desktop accompanied by unexpected user logins or system modifications

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0259#AN0716)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — launch of remote desktop app or helper binary · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:unifiedlog** — network sessions initiated by remote desktop apps · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **process_signature** — App may be notarized and signed differently depending on distribution method (App Store vs .pkg)
- **sandbox_exception** — If the remote desktop tool circumvents sandbox, it may produce additional telemetry in local TCC logs
