# AN0522 - Analytic 0522

[Enterprise](../../README.md) / [Analytics](README.md)

Detects clearing of unified logs, deletion of plist files tied to persistence, and manipulation of Terminal history after initial execution.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0184#AN0522)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — log stream cleared or truncated · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **fs:fsusage** — unlink, fs_delete · [DC0040 - File Deletion](../Data%20Components/DC0040%20-%20File%20Deletion.md)
- **macos:osquery** — File modifications in ~/Library/Preferences/ · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)

## Mutable elements

- **PlistTargetPaths** — Define which plist paths relate to LaunchAgents or LaunchDaemons
- **ExecutionChainDepth** — Allow tuning for multi-process persistence chains
