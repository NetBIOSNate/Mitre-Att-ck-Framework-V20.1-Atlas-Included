# AN0104 - Analytic 0104

[Enterprise](../../README.md) / [Analytics](README.md)

Adversary registers a Windows device to Entra ID or bypasses conditional access by adding device via Intune registration pipeline using stolen credentials.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0036#AN0104)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — Device Object Creation · [DC0087 - Active Directory Object Creation](../Data%20Components/DC0087%20-%20Active%20Directory%20Object%20Creation.md)
- **ApplicationLog:Intune/MDM Logs** — Enrollment events (e.g., MDMDeviceRegistration) · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **DeviceNamePattern** — Adjust pattern matching logic for unusual or non-corporate device names
- **UserContext** — Correlate with prior logon location or device usage behavior
- **EnrollmentMethod** — Distinguish between MDM vs manual onboarding vs automated scripts
