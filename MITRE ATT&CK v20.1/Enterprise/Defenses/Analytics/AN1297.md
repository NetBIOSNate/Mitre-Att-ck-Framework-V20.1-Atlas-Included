# AN1297 - Analytic 1297

[Enterprise](../../README.md) / [Analytics](README.md)

ESXi hosts initiating connections from non-standard daemons mimicking HTTP/HTTPS or SNMP traffic, but with irregular payload formats or expired/unsigned TLS certificates.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0470#AN1297)

**Platforms**  [ESXi](../../Platforms/ESXi.md)

## Log sources and channels

- **esxi:hostd** — Service-Based Network Connection · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **NSM:Content** — TLS Fingerprint and Certificate Analysis · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **TLSFingerprintMatch** — Allows matching against known-good or known-bad JA3/JA3S hashes.
- **AllowedServicePorts** — Tune for expected network ports per ESXi role.
