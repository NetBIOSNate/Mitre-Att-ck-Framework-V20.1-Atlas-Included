# AN0474 - Analytic 0474

[Enterprise](../../README.md) / [Analytics](README.md)

Firmware flash utility invoked with elevated privileges followed by raw access to firmware device path or changes to boot configuration.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0167#AN0474)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — EventCode=4688 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=6 · [DC0079 - Driver Load](../Data%20Components/DC0079%20-%20Driver%20Load.md)
- **WinEventLog:Microsoft-Windows-Kernel-Boot** — Firmware integrity validation failed or boot configuration tampered · [DC0004 - Firmware Modification](../Data%20Components/DC0004%20-%20Firmware%20Modification.md)

## Mutable elements

- **ParentImage** — Common legitimate flash tool chains can be allowlisted
- **CommandLine** — Flags indicating silent or forced flash may vary
