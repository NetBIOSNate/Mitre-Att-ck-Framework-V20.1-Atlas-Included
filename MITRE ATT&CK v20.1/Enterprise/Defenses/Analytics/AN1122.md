# AN1122 - Analytic 1122

[Enterprise](../../README.md) / [Analytics](README.md)

Detects local daemons or scripts generating outbound DNS queries with long or frequent subdomains, indicative of DNS tunneling via tools like `iodine`, `dnscat2`, or `dig` from cronjobs or reverse shells.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0400#AN1122)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **NSM:Flow** — dns.log · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **SubdomainEntropyScore** — Detects encoded payloads or randomness in DNS labels
- **DaemonAllowList** — Allowlisted system daemons expected to perform frequent lookups
