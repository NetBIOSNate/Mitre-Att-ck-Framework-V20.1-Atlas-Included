# AN0724 - Analytic 0724

[Enterprise](../../README.md) / [Analytics](README.md)

Detects file reads across locations followed by writes to temp or staging directories, often compressed or encrypted, indicating local staging behavior.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0261#AN0724)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=11 · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Security** — EventCode=4663, 4670, 4656 · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)

## Mutable elements

- **StagingDirList** — Paths such as C:\Temp, C:\Windows\Tasks, etc.
- **ArchivingToolPatterns** — Matches to 7z.exe, rar.exe, zip.exe, or custom scripts.
- **TimeWindow** — How long to correlate file reads followed by compression.
