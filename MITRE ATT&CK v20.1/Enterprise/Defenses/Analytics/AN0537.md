# AN0537 - Analytic 0537

[Enterprise](../../README.md) / [Analytics](README.md)

Abnormal use of `lsblk`, `fdisk -l`, `lshw -class disk`, or `parted` by non-admin users or within non-interactive shells suggests suspicious disk enumeration activity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0188#AN0537)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve call with argv matching known disk enumeration commands (lsblk, parted, fdisk) · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **auditd:EXECVE** — command line arguments containing lsblk, fdisk, parted · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **TTY_type** — Detection can exclude interactive TTY sessions to reduce false positives from admin usage
- **shell_parent** — Differentiate between interactive user shells vs. script-based execution
