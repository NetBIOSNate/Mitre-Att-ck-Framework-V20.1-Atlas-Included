# AN0754 - Analytic 0754

[Enterprise](../../README.md) / [Analytics](README.md)

vSphere API logins (vimService) or SSH to ESXi host followed by unauthorized shell commands or lateral remote logins from the ESXi host.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0269#AN0754)

**Platforms**  [ESXi](../../Platforms/ESXi.md)

## Log sources and channels

- **esxi:vmkernel** — vim.fault.*, DCUI login, SSH shell · [DC0067 - Logon Session Creation](../Data%20Components/DC0067%20-%20Logon%20Session%20Creation.md)
- **esxi:shell** — Command execution trace · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **SessionType** — Filter by DCUI, SSH, vSphere API
- **CommandPattern** — Watch for remote access tool invocations (e.g., netcat, ssh)
