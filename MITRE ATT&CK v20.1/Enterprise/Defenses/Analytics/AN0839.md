# AN0839 - Analytic 0839

[Enterprise](../../README.md) / [Analytics](README.md)

Monitor for in-process mmap + mprotect + execve/execveat activity where memory permissions are changed from writable to executable inside the same process without a corresponding ELF on disk.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0300#AN0839)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **auditd:MMAP** — memory region with RWX permissions allocated · [DC0021 - OS API Execution](../Data%20Components/DC0021%20-%20OS%20API%20Execution.md)

## Mutable elements

- **ProcessNameScope** — Uncommon for service binaries to call memfd_create; detection tuned for high-risk processes.
- **RWXMemoryThreshold** — Adjust threshold for allowed RWX allocations to reduce false positives in JIT runtimes.
