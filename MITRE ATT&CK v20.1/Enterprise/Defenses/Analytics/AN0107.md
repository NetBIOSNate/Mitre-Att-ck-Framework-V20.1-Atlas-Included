# AN0107 - Analytic 0107

[Enterprise](../../README.md) / [Analytics](README.md)

Detects abnormal access to Safari credential stores (Keychain-backed) or Chrome/Firefox login databases. Observes processes executing `security dump-keychain` or directly reading credential files in `~/Library/Application Support`. Correlates file access with suspicious process ancestry or unsigned binaries.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0037#AN0107)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — execution of security, sqlite3, or unauthorized binaries · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:unifiedlog** — ~/Library/Application Support/Google/Chrome/*/Login Data OR ~/Library/Application Support/Firefox/*/logins.json · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)

## Mutable elements

- **PrivilegedUsers** — Expected user context authorized to unlock Keychain or browser databases
- **TimeWindow** — Correlation window for process execution and credential file access
