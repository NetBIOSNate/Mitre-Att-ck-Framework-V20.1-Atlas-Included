# AN0788 - Analytic 0788

[Enterprise](../../README.md) / [Analytics](README.md)

Use of curl, wget, or custom scripts to POST data to pastebin-like services. Defender perspective: identify chained behavior where files are compressed/read followed by HTTPS POST requests to text-sharing endpoints.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0284#AN0788)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:EXECVE** — curl -d, wget --post-data · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **auditd:SYSCALL** — read/open of sensitive file directories · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **NSM:Flow** — large HTTPS POST requests to text storage domains · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **AllowedTools** — Whitelist of tools (e.g., curl for package repos) to reduce false positives.
- **WorkHours** — Expected time ranges for developer interactions with external paste sites.
