# AN0520 - Analytic 0520

[Enterprise](../../README.md) / [Analytics](README.md)

Monitors sequences involving deletion/modification of logs, registry keys, scheduled tasks, or prefetch files following suspicious process activity or elevated access escalation.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0184#AN0520)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=23 · [DC0040 - File Deletion](../Data%20Components/DC0040%20-%20File%20Deletion.md)
- **WinEventLog:Security** — EventCode=1102 · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **WinEventLog:Sysmon** — EventCode=13, 14 · [DC0063 - Windows Registry Key Modification](../Data%20Components/DC0063%20-%20Windows%20Registry%20Key%20Modification.md)

## Mutable elements

- **TimeWindow** — Correlate indicator removal within X mins after persistence/setup activities
- **TargetFilePathPattern** — Customize detection to log file paths or common registry hives
