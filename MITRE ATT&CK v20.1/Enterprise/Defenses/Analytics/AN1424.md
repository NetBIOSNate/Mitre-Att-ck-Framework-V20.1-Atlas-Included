# AN1424 - Analytic 1424

[Enterprise](../../README.md) / [Analytics](README.md)

Token retrieval from instance metadata endpoints such as AWS IMDS or Azure IMDS, followed by API usage using the obtained token from non-standard applications.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0515#AN1424)

**Platforms**  [IaaS](../../Platforms/IaaS.md)

## Log sources and channels

- **AWS:CloudTrail** — GetInstanceIdentityDocument or IMDSv2 token requests · [DC0083 - Cloud Service Enumeration](../Data%20Components/DC0083%20-%20Cloud%20Service%20Enumeration.md)
- **AWS:CloudTrail** — Use of temporary credentials issued from IMDS access · [DC0069 - Cloud Service Modification](../Data%20Components/DC0069%20-%20Cloud%20Service%20Modification.md)

## Mutable elements

- **UserAgent** — May need tuning for known automation tools versus unexpected curl usage
- **TimeWindow** — Correlate retrieval and use of token within expected timeout window
