# AN1531 - Analytic 1531

[Enterprise](../../README.md) / [Analytics](README.md)

Detection of non-interactive or suspicious processes accessing Bluetooth interfaces and transmitting outbound traffic following file access or staging activity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0554#AN1531)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:System** — EventCode=8001 · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=11 · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **TimeWindow** — Defines how quickly a file access and Bluetooth activity must occur to be correlated.
- **InterfaceType** — May focus on Bluetooth-specific interfaces or drivers like 'bthport.sys'.
- **FileSizeThreshold** — Tune to trigger only on significant exfiltratable file reads.
