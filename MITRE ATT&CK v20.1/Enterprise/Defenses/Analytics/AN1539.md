# AN1539 - Analytic 1539

[Enterprise](../../README.md) / [Analytics](README.md)

Detect 'shutdown', 'reboot', or 'systemctl poweroff' executions with auditd/syslog and absence of scheduled maintenance windows or approved user context.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0559#AN1539)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve=/sbin/shutdown or /sbin/reboot · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **linux:syslog** — system is powering down · [DC0018 - Host Status](../Data%20Components/DC0018%20-%20Host%20Status.md)

## Mutable elements

- **CommandLineMatch** — Supports multiple binary names or symlinked utilities.
- **UserContext** — Privileged user (e.g., root or via sudo) context matching expected roles.
