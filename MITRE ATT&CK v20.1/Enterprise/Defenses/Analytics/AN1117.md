# AN1117 - Analytic 1117

[Enterprise](../../README.md) / [Analytics](README.md)

Startup-based persistence mechanisms within Microsoft Office Suite like template macros and home page redirects being configured through internal automation or client-side settings.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0398#AN1117)

**Platforms**  [Office Suite](../../Platforms/Office%20Suite.md)

## Log sources and channels

- **m365:unified** — Set-Mailbox, Set-InboxRule, Set-MailboxFolderPermission · [DC0010 - User Account Modification](../Data%20Components/DC0010%20-%20User%20Account%20Modification.md)
- **m365:mailboxaudit** — Outlook rule creation or custom form deployment · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **RuleAction** — Identify rule actions that execute scripts, forward emails externally, or start external content
- **MailboxTarget** — Focus on users with sensitive roles or shared mailboxes
- **TimeWindow** — Detect persistence artifacts created shortly after credential access or login from an unusual location
