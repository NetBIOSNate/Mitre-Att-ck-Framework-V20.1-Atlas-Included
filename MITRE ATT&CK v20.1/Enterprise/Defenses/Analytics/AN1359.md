# AN1359 - Analytic 1359

[Enterprise](../../README.md) / [Analytics](README.md)

Detects anomalous use of Mach ports, Apple Events, or XPC services for inter-process execution or code injection. Focuses on unexpected processes attempting to send privileged Apple Events (e.g., automation scripts injecting into security-sensitive apps).

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0493#AN1359)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Unusual Mach port registration or access attempts between unrelated processes · [DC0035 - Process Access](../Data%20Components/DC0035%20-%20Process%20Access.md)
- **macos:osquery** — exec: Unexpected execution of osascript or AppleScript targeting sensitive apps · [DC0029 - Script Execution](../Data%20Components/DC0029%20-%20Script%20Execution.md)

## Mutable elements

- **AllowedAppleEventTargets** — Whitelisted app-to-app Apple Event communications (e.g., Finder automation).
- **MachPortBaseline** — Baseline of Mach ports and XPC services normally used in the environment.
