# AN0800 - Analytic 0800

[Enterprise](../../README.md) / [Analytics](README.md)

Correlates suspicious removal or modification of the com.apple.quarantine extended attribute, manipulation of LSFileQuarantineEnabled values in Info.plist, and unexpected process execution of unsigned or non-notarized binaries. Also monitors abnormal trust validation failures in unified logs and unusual activity in QuarantineEvents database entries.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0288#AN0800)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — xattr -d com.apple.quarantine or similar attribute removal commands · [DC0059 - File Metadata](../Data%20Components/DC0059%20-%20File%20Metadata.md)
- **macos:unifiedlog** — Trust validation failures or bypass attempts during notarization and code signing checks · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:osquery** — Changes to LSFileQuarantineEnabled field in Info.plist · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)

## Mutable elements

- **QuarantineBypassAllowList** — Legitimate enterprise update tools or deployment frameworks that may strip quarantine flags
- **CertificateAuthorityList** — Baseline trusted Apple Developer IDs and enterprise certs used for code signing
- **TimeWindow** — Time correlation window for xattr modification followed by suspicious process execution
