# AN0335 - Analytic 0335

[Enterprise](../../README.md) / [Analytics](README.md)

Password changes or account deletions via 'passwd', 'userdel', or 'chage' preceded by interactive shell or remote command execution from non-privileged accounts.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0120#AN0335)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — SYSCALL record where exe contains passwd/userdel/chage and auid != root · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **NSM:Connections** — Accepted password or publickey for user from remote IP · [DC0002 - User Account Authentication](../Data%20Components/DC0002%20-%20User%20Account%20Authentication.md)

## Mutable elements

- **ExecPath** — Binary path for passwd or userdel, which may vary by distro
- **NonRootUIDThreshold** — Alert only if auid != root or expected service account
