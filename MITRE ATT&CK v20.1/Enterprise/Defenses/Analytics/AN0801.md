# AN0801 - Analytic 0801

[Enterprise](../../README.md) / [Analytics](README.md)

Cloud API events where logging services are stopped, deleted, or modified in a way that disables audit visibility. Defender view: unauthorized StopLogging, DeleteTrail, or UpdateSink operations correlated with privileged user activity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0289#AN0801)

**Platforms**  [IaaS](../../Platforms/IaaS.md)

## Log sources and channels

- **AWS:CloudTrail** — Stop logging for an existing CloudTrail · [DC0090 - Cloud Service Disable](../Data%20Components/DC0090%20-%20Cloud%20Service%20Disable.md)
- **gcp:config** — UpdateSink request modifying log export destinations · [DC0069 - Cloud Service Modification](../Data%20Components/DC0069%20-%20Cloud%20Service%20Modification.md)

## Mutable elements

- **AdminRoles** — Define which roles are authorized to stop or modify logging.
- **RegionScope** — Adjust monitoring to ensure multi-region logging tampering is caught.
