# AN0223 - Analytic 0223

[Enterprise](../../README.md) / [Analytics](README.md)

Adversary targets cloud-hosted public endpoints. Chain: (1) ALB/ELB/Cloud LB logs show exploit-like inputs or error spikes → (2) workload spawns shell or reaches metadata API → (3) egress to new external hosts.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0080#AN0223)

**Platforms**  [IaaS](../../Platforms/IaaS.md)

## Log sources and channels

- **ALB:HTTPLogs** — AWS ALB/ELB/GCP/Azure Application Gateway HTTP logs with unusual methods, long URIs, serialized payloads, 4xx/5xx bursts · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **AWS:VPCFlowLogs** — VPC/NSG flow logs for pod/instance egress to Internet or metadata · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **LBProjects** — Cloud accounts/subscriptions/regions to include.
- **ErrorBurst** — 5xx/4xx per client threshold.
