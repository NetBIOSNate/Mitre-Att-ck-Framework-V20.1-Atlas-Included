# AN0363 - Analytic 0363

[Enterprise](../../README.md) / [Analytics](README.md)

Adversary enumeration of domain accounts using net.exe, PowerShell, WMI, or LDAP queries from non-domain controllers or non-admin endpoints.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0129#AN0363)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:PowerShell** — EventCode=4103, 4104, 4105, 4106 · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **NSM:Flow** — LDAP Bind/Search · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **CommandLinePattern** — Detect variations of 'net user /domain', 'Get-ADUser', 'Get-ADGroupMember'.
- **TimeWindow** — Tune detection for bursts of enumeration commands or search queries.
- **SourceHost** — Restrict detection to non-DC or non-admin systems where such commands are unexpected.
