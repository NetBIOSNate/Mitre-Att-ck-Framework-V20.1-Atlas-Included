# AN0359 - Analytic 0359

[Enterprise](../../README.md) / [Analytics](README.md)

Adversary places scripts or binaries with misleading names in /etc/rc.local.d or /var/spool/cron, or registers services with legitimate-sounding names not present in default ESXi builds.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0127#AN0359)

**Platforms**  [ESXi](../../Platforms/ESXi.md)

## Log sources and channels

- **esxi:hostd** — registers services with legitimate-sounding names · [DC0041 - Service Metadata](../Data%20Components/DC0041%20-%20Service%20Metadata.md)
- **esxi:shell** — scripts or binaries with misleading names · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **ServiceNameBaseline** — Tune based on default service names vs. suspicious new entries
- **ScriptFilePath** — Watch for new binaries/scripts in boot or cron folders
- **ExecutionContext** — Determine if execution happens at boot or scheduled interval
