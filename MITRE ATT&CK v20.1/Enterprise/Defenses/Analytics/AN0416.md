# AN0416 - Analytic 0416

[Enterprise](../../README.md) / [Analytics](README.md)

Container process executes destructive file operations inside volume mounts or host paths. Includes `rm -rf /mnt/volumes/`, container breakout followed by host deletion attempts.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0146#AN0416)

**Platforms**  [Containers](../../Platforms/Containers.md)

## Log sources and channels

- **auditd:SYSCALL** — unlink, unlinkat, rmdir · [DC0040 - File Deletion](../Data%20Components/DC0040%20-%20File%20Deletion.md)
- **docker:events** — container exec rm|container stop --force · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **MountPoint** — Identify when deletions occur inside persistent or shared volume paths.
- **ContainerImage** — Correlate destructive behavior with unknown or untrusted container sources.
