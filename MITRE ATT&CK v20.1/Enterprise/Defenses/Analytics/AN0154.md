# AN0154 - Analytic 0154

[Enterprise](../../README.md) / [Analytics](README.md)

Detection of unexpected additions or modifications to system-wide certificate stores or execution of commands adding certificates to trusted stores.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0056#AN0154)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — open, write: File modifications under /etc/ssl/certs, /usr/local/share/ca-certificates, or /etc/pki/ca-trust/source/anchors · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)
- **auditd:EXECVE** — execve: Execution of update-ca-certificates or trust anchor modification commands · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **CertificatePaths** — Paths monitored for certificate modifications; can be tuned depending on Linux distribution.
- **AdminAccounts** — Expected user accounts with privileges to install root certificates; anomalies outside this context are suspicious.
