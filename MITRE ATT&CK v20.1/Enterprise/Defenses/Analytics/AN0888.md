# AN0888 - Analytic 0888

[Enterprise](../../README.md) / [Analytics](README.md)

Execution of commands or APIs that disable Gatekeeper, XProtect, or system integrity protections. Detect configuration changes through unified logs. Monitor termination of system security daemons (e.g., syspolicyd).

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0317#AN0888)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — spctl --master-disable, csrutil disable, or defaults write to disable Gatekeeper · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **macos:unifiedlog** — Termination of syspolicyd or XProtect processes · [DC0033 - Process Termination](../Data%20Components/DC0033%20-%20Process%20Termination.md)

## Mutable elements

- **AdminToolWhitelist** — Developers may legitimately disable Gatekeeper; whitelist approved contexts.
