# AN0703 - Analytic 0703

[Enterprise](../../README.md) / [Analytics](README.md)

Detect alterations of transmitted data via monitoring syscalls (`send`, `recv`, `write`) or middleware interception. Identify mismatched file hashes when compared at origin vs. destination. Watch for anomalous activity from processes interacting with secure transmission services (e.g., OpenSSL, scp).

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0254#AN0703)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — send, recv, write: Abnormal interception or alteration of transmitted data · [DC0021 - OS API Execution](../Data%20Components/DC0021%20-%20OS%20API%20Execution.md)
- **linux:syslog** — Integrity mismatch warnings or malformed packets detected · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **WatchedProcesses** — List of processes authorized to handle transmitted data (e.g., sshd, nginx).
- **HashCheckInterval** — Frequency of out-of-band integrity verification checks.
