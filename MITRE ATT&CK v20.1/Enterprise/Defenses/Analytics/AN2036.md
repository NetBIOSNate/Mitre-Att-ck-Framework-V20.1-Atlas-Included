# AN2036 - Analytic 2036

[Enterprise](../../README.md) / [Analytics](README.md)

Detects user-authorized execution of downloaded content or scripts after communication prompts, including browser downloads followed by osascript, shell, or installer execution and subsequent network activity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0899#AN2036)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Execution of osascript, sh, bash, zsh, installer, open · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **NSM:Connections** — Outbound connection after script or installer launch · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **macos:unifiedlog** — Recent download opened or executed · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)

## Mutable elements

- **DownloadToExecutionWindow** — Time between download and launch
- **InstallerParentAllowlist** — Legitimate software deployment parents
