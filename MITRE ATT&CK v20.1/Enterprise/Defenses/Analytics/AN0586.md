# AN0586 - Analytic 0586

[Enterprise](../../README.md) / [Analytics](README.md)

Adversary launches high-entropy process or malformed app bundle causing repeated application crashes and system slowdowns.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0208#AN0586)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Repeated process crashes logged by CrashReporter or system instability logs in com.apple.console · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **macos:unifiedlog** — Spike in CPU or memory use from non-user-initiated processes · [DC0018 - Host Status](../Data%20Components/DC0018%20-%20Host%20Status.md)

## Mutable elements

- **CrashCountThreshold** — Number of app crashes within monitoring window
- **PayloadEntropyThreshold** — Used for high-entropy binaries often observed in DoS malware samples
