# AN1227 - Analytic 1227

[Enterprise](../../README.md) / [Analytics](README.md)

Detects applications using abnormal protocols or high volume traffic not previously associated with the process image, such as Automator or AppleScript invoking curl or python sockets.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0444#AN1227)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:osquery** — socket_events · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **macos:unifiedlog** — log stream · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **SocketParentProcessMatch** — Non-browser processes opening sockets to external IPs
- **DataFlowImbalanceRatio** — High outbound/inbound ratio indicating C2 beacon
