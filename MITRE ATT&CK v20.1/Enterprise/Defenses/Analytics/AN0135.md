# AN0135 - Analytic 0135

[Enterprise](../../README.md) / [Analytics](README.md)

Detects removal of Remote Login or Screen Sharing logs in Unified Logging, deletion of `com.apple.UTun`, or suspicious Terminal use of `rm`, `sudo pfctl -F all` to clear network state/config history.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0049#AN0135)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — log stream --predicate 'eventMessage contains "loginwindow" or "pfctl"' · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **macos:osquery** — file_events · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)

## Mutable elements

- **FilenameMatch** — e.g., *com.apple.UTun*, *RemoteManagement* log files
- **TimeDeltaFromLogin** — Correlate deletion with recent SSH or GUI remote login session
