# AN1233 - Analytic 1233

[Enterprise](../../README.md) / [Analytics](README.md)

Dynamic or static port forwarding rules added to route traffic through an internal host, or configuration changes to proxy firewall rules not aligned with baselined policy.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0445#AN1233)

**Platforms**  [Network Devices](../../Platforms/Network%20Devices.md)

## Log sources and channels

- **NSM:Firewall** — Policy Change / Rule Update · [DC0051 - Firewall Rule Modification](../Data%20Components/DC0051%20-%20Firewall%20Rule%20Modification.md)
- **NSM:Flow** — Flow Creation (NetFlow/sFlow) · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **networkdevice:cli** — Interface commands · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **RuleType** — Focus on new allow/permit rules with dynamic NAT or port forwarders.
- **ChangeUser** — Flag any non-admins initiating proxy config changes.
- **FlowVolumeDelta** — Detect sharp changes in bi-directional traffic patterns.
