# AN0540 - Analytic 0540

[Enterprise](../../README.md) / [Analytics](README.md)

Detection of known tools or malware flagged by antivirus, followed by a near-term drop of a similar binary with modified signature and resumed activity (execution, C2, or persistence).

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0189#AN0540)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Application** — EventCode=1000 · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=11 · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)

## Mutable elements

- **AVAlertMessage** — Vendor-specific signature string or detection message that can be correlated to threat intel context.
- **TimeWindow** — The time between AV alert and similar file/process activity (e.g., 5–30 minutes)
- **FilenameSimilarityThreshold** — String or hash similarity thresholds between original and modified binary.
