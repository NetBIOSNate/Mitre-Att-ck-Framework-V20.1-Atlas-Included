# AN0256 - Analytic 0256

[Enterprise](../../README.md) / [Analytics](README.md)

Adversary uses `dscl`, `who`, or environment variables like `$USER` to identify accounts or sessions via Terminal or malicious LaunchAgents.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0093#AN0256)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — subsystem:com.apple.Terminal · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **macos:endpointsecurity** — ES_EVENT_TYPE_NOTIFY_EXEC · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **LaunchAgentPersistence** — Correlate dscl usage with known persistence vectors
- **CommandExecutionPath** — Distinguish between user-initiated terminal vs. script execution
- **UsernameEnumerationPattern** — Regex-based pattern tuning for `dscl . -list /Users` + grep filters
