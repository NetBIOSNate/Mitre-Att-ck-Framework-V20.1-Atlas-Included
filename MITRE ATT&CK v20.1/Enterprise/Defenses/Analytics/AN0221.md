# AN0221 - Analytic 0221

[Enterprise](../../README.md) / [Analytics](README.md)

Adversary targets macOS-hosted public services (e.g., nginx, node). Chain: suspicious inbound request → service crash/5xx → service spawns shell or writes file → new outbound connection.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0080#AN0221)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — App/web server logs ingested via unified logging or filebeat (nginx/apache/node). · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **macos:unifiedlog** — exec events where web process starts a shell/tooling · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **NSM:Flow** — outbound egress from web host after suspicious request · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **ServiceList** — Names/paths of public daemons on macOS (httpd, nginx, node, java).
- **TimeWindow** — Correlation window for request → exec → egress.
