# AN0038 - Analytic 0038

[Enterprise](../../README.md) / [Analytics](README.md)

Unauthorized shell or script-based access to browser config or SQLite history files, typically in ~/.config/google-chrome/, ~/.mozilla/, or ~/.var/app folders, indicating enumeration of bookmarks or saved credentials.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0013#AN0038)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — open, read, or stat of browser config files · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **linux:syslog** — Suspicious script or command execution targeting browser folders · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **BrowserProfilePath** — User-specific browser data folders, e.g., ~/.config/chromium/Default/History
- **ShellRegex** — Shell pattern detecting suspicious access to .sqlite or .json files
