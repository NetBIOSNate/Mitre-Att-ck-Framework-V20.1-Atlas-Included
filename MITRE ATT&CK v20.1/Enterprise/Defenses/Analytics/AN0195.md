# AN0195 - Analytic 0195

[Enterprise](../../README.md) / [Analytics](README.md)

Detects inbound SCP, rsync, or NFS mounts from remote systems followed by aggregation of files into known staging paths like /mnt/staging or /var/tmp.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0071#AN0195)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — open · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **auditd:SYSCALL** — execve · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **NSM:Flow** — SSH logins or scp activity · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **RemoteHosts** — Expected inbound transfer hosts to filter normal activity from staging behavior
- **MountTargets** — Directory destinations used as centralized locations
- **TransferVolumeThreshold** — Threshold of transferred files or data volume over time
