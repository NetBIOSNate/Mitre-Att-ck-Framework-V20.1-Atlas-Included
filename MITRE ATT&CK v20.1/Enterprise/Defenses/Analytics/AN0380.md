# AN0380 - Analytic 0380

[Enterprise](../../README.md) / [Analytics](README.md)

Detects non-interactive or script-driven email transmission using tools like `sendmail`, `mailx`, or custom SMTP scripts by background processes, especially when sending attachments or large payloads.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0135#AN0380)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **NSM:Flow** — smtp.log, conn.log · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **TransferSizeThreshold** — Bytes transferred via SMTP session
- **ScriptNameFilter** — e.g., base64 encoded mailer scripts or one-liners in cron
