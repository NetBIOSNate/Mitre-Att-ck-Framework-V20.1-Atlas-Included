# AN1098 - Analytic 1098

[Enterprise](../../README.md) / [Analytics](README.md)

Detect runtime manipulation by monitoring system calls for modifications to shared libraries, ELF binaries, or environment variables that affect how data is displayed. Look for suspicious writes to application directories and mismatch in binary integrity baselines.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0391#AN1098)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — open, write: File writes to application binaries or libraries at runtime · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)
- **linux:syslog** — Execution of modified binaries or abnormal library load sequences · [DC0021 - OS API Execution](../Data%20Components/DC0021%20-%20OS%20API%20Execution.md)

## Mutable elements

- **WatchedBinaries** — Specific critical application binaries or libraries to monitor for unauthorized changes.
- **IntegrityCheckFrequency** — Interval for verifying hashes of executables and libraries.
