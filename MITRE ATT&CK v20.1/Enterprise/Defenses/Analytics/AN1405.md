# AN1405 - Analytic 1405

[Enterprise](../../README.md) / [Analytics](README.md)

Detects automation macros or VBA scripts in documents that access browser file paths, read cookie data, or attempt to exfiltrate browser session tokens over HTTP.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0509#AN1405)

**Platforms**  [Office Suite](../../Platforms/Office%20Suite.md)

## Log sources and channels

- **m365:unified** — RunMacro · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **WinEventLog:Sysmon** — EventCode=2 · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)

## Mutable elements

- **MacroTargetPath** — Files or directories macros are attempting to access
- **HTTPDestinationIPList** — List of IPs or domains that are uncommon for macro-based HTTP POSTs
