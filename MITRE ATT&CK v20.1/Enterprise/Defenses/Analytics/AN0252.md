# AN0252 - Analytic 0252

[Enterprise](../../README.md) / [Analytics](README.md)

Installation of configuration profiles or plist entries associated with malicious or unauthorized browser extensions

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0092#AN0252)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Execution of 'profiles install -type=configuration' · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **macos:unifiedlog** — Creation of .plist under /Library/Managed Preferences/ · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **macos:unifiedlog** — Suspicious outbound traffic from browser binary to non-standard domains · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **PlistPath** — Directory path for user-specific extension configuration files
- **CommandLine** — Usage of profiles CLI tool—can be modified by legitimate tools or MDMs
- **TimeWindow** — Correlation window between configuration install and observable extension behavior
