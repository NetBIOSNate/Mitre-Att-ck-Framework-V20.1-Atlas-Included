# AN1116 - Analytic 1116

[Enterprise](../../README.md) / [Analytics](README.md)

Office-based persistence via Office template macros, Outlook forms/rules/homepage, or registry-persistent scripts. Adversary modifies registry keys or Office application directories to load malicious scripts at startup.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0398#AN1116)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=11 · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=13, 14 · [DC0063 - Windows Registry Key Modification](../Data%20Components/DC0063%20-%20Windows%20Registry%20Key%20Modification.md)
- **WinEventLog:Application** — Outlook rule creation, form load, or homepage redirection · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **ParentProcessName** — Tune based on expected Office process tree (e.g., WINWORD.EXE spawning cmd.exe)
- **RegistryPath** — Specific keys related to Office startup such as Outlook Today, AddIns, or Template Macros
- **TimeWindow** — Window of process execution after user login or Outlook launch
- **UserContext** — Detect persistence within high-value user mailboxes (e.g., admin, finance, C-suite)
