# AN1639 - Analytic 1639

[Enterprise](../../README.md) / [Analytics](README.md)

SSH login detected via Unified Logs, followed by unusual process execution, especially outside normal user behavior patterns.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0596#AN1639)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — process = 'sshd' · [DC0088 - Logon Session Metadata](../Data%20Components/DC0088%20-%20Logon%20Session%20Metadata.md)
- **macos:unifiedlog** — process = 'ssh' OR eventMessage CONTAINS 'ssh' · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **macos:osquery** — process_events · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **TimeWindow** — Time range to correlate post-SSH activities (e.g., 45s)
- **UserContext** — Define authorized users to reduce false positives
- **CommandLineKeywords** — Suspicious terms like reverse shells, base64, curl
