# AN0189 - Analytic 0189

[Enterprise](../../README.md) / [Analytics](README.md)

Monitor for malicious payload delivery through phishing where attachments or URLs in email clients (e.g., Thunderbird, mutt) result in unusual file creation or outbound network connections. Focus on correlation between mail logs, file writes, and execution activity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0070#AN0189)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **Application:Mail** — Inbound messages with anomalous headers, spoofed SPF/DKIM failures · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **auditd:SYSCALL** — execve: Execution of scripts or binaries sourced from mail directories (/var/mail, ~/Maildir) · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **MonitoredMailPaths** — System or user directories where emails/attachments are stored.
- **AttachmentHashBaseline** — Known good hashes for common business document templates.
