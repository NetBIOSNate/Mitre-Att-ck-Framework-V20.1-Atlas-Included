# AN0191 - Analytic 0191

[Enterprise](../../README.md) / [Analytics](README.md)

Phishing via Office documents containing embedded macros or links that spawn processes. Detection relies on correlating Office application logs with suspicious child process execution and outbound network connections.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0070#AN0191)

**Platforms**  [Office Suite](../../Platforms/Office%20Suite.md)

## Log sources and channels

- **m365:unified** — FileAccessed: Access of email attachments by Office applications · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **ParentProcessList** — Parent processes expected to execute child processes (e.g., Office apps).
- **MacroExecutionThreshold** — Threshold for number of macros executed before raising alerts.
