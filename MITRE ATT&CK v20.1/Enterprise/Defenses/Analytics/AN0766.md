# AN0766 - Analytic 0766

[Enterprise](../../README.md) / [Analytics](README.md)

Observes creation or modification of LaunchAgent/LaunchDaemon property list files combined with anomalous plist payload execution after user logon

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0274#AN0766)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Observed loading of new LaunchAgent or LaunchDaemon plist · [DC0041 - Service Metadata](../Data%20Components/DC0041%20-%20Service%20Metadata.md)
- **macos:unifiedlog** — write · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)
- **macos:unifiedlog** — Execution of binary listed in newly modified LaunchAgent plist · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **PlistKey** — Organizations may use specific keys or additional payload parameters
- **TimeWindow** — Tunable based on expected delay between plist write and execution
