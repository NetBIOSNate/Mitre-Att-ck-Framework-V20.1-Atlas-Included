# AN0337 - Analytic 0337

[Enterprise](../../README.md) / [Analytics](README.md)

Invocation of esxcli 'system account remove' from vCLI, SSH, or vSphere API with anomalous user access or outside maintenance windows.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0120#AN0337)

**Platforms**  [ESXi](../../Platforms/ESXi.md)

## Log sources and channels

- **esxi:hostd** — method=RemoveUser or esxcli system account remove invocation · [DC0009 - User Account Deletion](../Data%20Components/DC0009%20-%20User%20Account%20Deletion.md)
- **esxi:vpxa** — user login from unexpected IP or non-admin user role · [DC0002 - User Account Authentication](../Data%20Components/DC0002%20-%20User%20Account%20Authentication.md)

## Mutable elements

- **RemoteUserRole** — ESXi role triggering the change (e.g., Administrator vs. Viewer)
- **ExpectedIPs** — IP ranges authorized to conduct admin-level actions
