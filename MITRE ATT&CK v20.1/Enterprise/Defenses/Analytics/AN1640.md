# AN1640 - Analytic 1640

[Enterprise](../../README.md) / [Analytics](README.md)

SSH login via hostd or `/var/log/auth.log`, followed by CLI access to host shell or file manipulation in restricted areas.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0596#AN1640)

**Platforms**  [ESXi](../../Platforms/ESXi.md)

## Log sources and channels

- **esxi:auth** — None · [DC0088 - Logon Session Metadata](../Data%20Components/DC0088%20-%20Logon%20Session%20Metadata.md)
- **esxi:shell** — None · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **esxi:vmkernel** — port 22 access · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **AllowedUsers** — Legitimate SSH users to this host
- **TimeWindow** — Correlate SSH login and unauthorized commands or shell access
- **CommandList** — Flag commands like esxcli, rm, chmod post-login
