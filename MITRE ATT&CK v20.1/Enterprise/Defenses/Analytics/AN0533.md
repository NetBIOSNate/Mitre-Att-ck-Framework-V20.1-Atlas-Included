# AN0533 - Analytic 0533

[Enterprise](../../README.md) / [Analytics](README.md)

Use of pbpaste, AppleScript, or third-party automation frameworks (e.g., Automator) to collect clipboard or file content in bursts. Observable via unified logs.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0186#AN0533)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — logMessage contains pbpaste or osascript · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:unifiedlog** — subsystem=launchservices · [DC0029 - Script Execution](../Data%20Components/DC0029%20-%20Script%20Execution.md)

## Mutable elements

- **AutomationTool** — Detectable script interpreters or clipboard tools (pbpaste, osascript).
- **ClipboardCheckRate** — Threshold for how often clipboard access occurs within a given time window.
