# AN0844 - Analytic 0844

[Enterprise](../../README.md) / [Analytics](README.md)

A source performs a closed-port sequence; the endpoint enables a PF/socketfilterfw rule or a background process binds a port; then a successful connection completes from the same source.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0302#AN0844)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — exec: Execution of pfctl, socketfilterfw, launchctl start ssh/telnet, libpcap consumers. · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:unifiedlog** — Firewall/PF anchor load or rule change events. · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **NSM:Flow** — Sequence of REJ/S0 then SF success from same src_ip within TimeWindow. · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **PFAnchorPaths** — Anchors/confs to monitor (/etc/pf.conf, /etc/pf.anchors/*).
- **DevMode** — Suppress expected PF testing on developer devices.
