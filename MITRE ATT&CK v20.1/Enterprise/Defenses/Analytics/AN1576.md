# AN1576 - Analytic 1576

[Enterprise](../../README.md) / [Analytics](README.md)

Detects creation or modification of `systemd` service units, addition of cron jobs that invoke binaries on boot, or suspicious writes to `/etc/init.d/`. Monitors `chmod +x` and `systemctl` execution paths, especially from non-root parent processes.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0571#AN1576)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — write or rename to /etc/systemd/system or /etc/init.d · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)
- **auditd:SYSCALL** — execution of systemctl or service with enable/start/modify · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **ServicePathRegex** — Path-based filters to identify service unit files or init scripts
- **UserContextList** — List of expected user contexts that normally perform service changes
- **CommandNameList** — Binaries used to register/modify services
