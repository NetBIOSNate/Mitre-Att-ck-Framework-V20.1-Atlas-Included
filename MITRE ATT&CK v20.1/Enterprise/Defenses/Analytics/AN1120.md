# AN1120 - Analytic 1120

[Enterprise](../../README.md) / [Analytics](README.md)

LaunchAgent or launchd recurring jobs initiating data transfer to consistent external IPs or domains with repeat timing signatures.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0399#AN1120)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:endpointsecurity** — ES_EVENT_TYPE_NOTIFY_EXEC · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:launchd** — launchd.plist and logs · [DC0005 - Scheduled Job Metadata](../Data%20Components/DC0005%20-%20Scheduled%20Job%20Metadata.md)
- **macos:unifiedlog** — networkd or com.apple.network · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **AgentPathPatterns** — Regex for job locations like ~/Library/LaunchAgents/
- **RepeatIntervalDelta** — Time-based logic to determine schedule (e.g., ~24h ± 5m)
- **UserHomeJobs** — Transfers originating from non-admin user context
