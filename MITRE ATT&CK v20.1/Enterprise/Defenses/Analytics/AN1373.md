# AN1373 - Analytic 1373

[Enterprise](../../README.md) / [Analytics](README.md)

Detects disabling container runtime security controls, removing sidecar sensors, modifying seccomp/AppArmor profiles, mounting host proc/sys paths to interfere with host logging, or killing in-container monitoring agents.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0497#AN1373)

**Platforms**  [Containers](../../Platforms/Containers.md)

## Log sources and channels

- **kubernetes:audit** — kubectl delete or patch of security pods/admission controllers · [DC0041 - Service Metadata](../Data%20Components/DC0041%20-%20Service%20Metadata.md)

## Mutable elements

- **NamespaceExclusions** — Exclusion of namespaces where temporary deletion of monitoring tools is legitimate (e.g., staging).
