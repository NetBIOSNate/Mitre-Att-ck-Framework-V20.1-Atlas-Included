# AN1087 - Analytic 1087

[Enterprise](../../README.md) / [Analytics](README.md)

Enumeration of identity roles and users via API calls such as `Get-MsolRoleMember`, `az ad user list`, or Graph API tokens from unauthorized users or automation accounts.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0386#AN1087)

**Platforms**  [Identity Provider](../../Platforms/Identity%20Provider.md)

## Log sources and channels

- **Microsoft Entra ID Audit Logs** — RoleManagement.Read.Directory or Directory.Read.All · [DC0013 - User Account Metadata](../Data%20Components/DC0013%20-%20User%20Account%20Metadata.md)
- **azure:signinlogs** — Interactive/Non-Interactive Sign-In · [DC0002 - User Account Authentication](../Data%20Components/DC0002%20-%20User%20Account%20Authentication.md)
- **m365:defender** — Activity Log: Command Invocation · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **TokenScope** — Flags excessive or abnormal use of directory read scopes by unexpected principals.
- **AppContext** — Differentiate authorized automation from rogue access tokens or external tools.
- **TimeWindow** — Trigger correlation across short bursts of high-volume enumeration.
