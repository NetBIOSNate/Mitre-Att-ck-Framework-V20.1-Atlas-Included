# AN0926 - Analytic 0926

[Enterprise](../../README.md) / [Analytics](README.md)

Changes to NAT/firewall policies enabling outbound port forwarding from internal IPs to Internet-based proxy endpoints. Log spikes in outbound flows to CDN, VPS, or anomalous ASNs with few return packets.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0325#AN0926)

**Platforms**  [Network Devices](../../Platforms/Network%20Devices.md)

## Log sources and channels

- **Firewall Audit Logs** — Outbound NAT Rule Changes · [DC0051 - Firewall Rule Modification](../Data%20Components/DC0051%20-%20Firewall%20Rule%20Modification.md)
- **NSM:Flow** — Outbound flow records · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **networkdevice:syslog** — Dynamic route changes · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **FlowThreshold** — Number of flows or bytes transferred per minute—flag surges to unrecognized ASNs.
- **DestinationIPCategory** — Proxy destination categories: CDN, TOR exit node, anonymous hosting.
- **ConfigChangeUser** — Track if unexpected user or automation changed NAT/forwarding rules.
