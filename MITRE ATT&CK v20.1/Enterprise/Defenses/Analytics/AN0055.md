# AN0055 - Analytic 0055

[Enterprise](../../README.md) / [Analytics](README.md)

Executable or script payloads lacking symbol information and readable strings that are created or dropped by unusual or short-lived processes.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0019#AN0055)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=11 · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **EDR:file** — File Metadata Inspection (Low String Entropy, Missing PDB) · [DC0059 - File Metadata](../Data%20Components/DC0059%20-%20File%20Metadata.md)

## Mutable elements

- **EntropyThreshold** — Payloads with extremely low string entropy may indicate stripped or obfuscated binaries
- **ParentProcessName** — Used to scope or whitelist common system builders, compilers, or admin tools
- **TimeWindow** — Correlates file creation and process spawning within a short timeframe
