# AN1622 - Analytic 1622

[Enterprise](../../README.md) / [Analytics](README.md)

Adversary modifies externally-facing web content by accessing and overwriting hosted HTML/JS/CSS files, typically following web shell deployment, credential abuse, or exploitation of web application vulnerabilities.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0590#AN1622)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — EventCode=4663, 4670, 4656 · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)
- **NSM:Connections** — Unusual POST requests to admin or upload endpoints · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **target_directory** — Web root folder varies by environment, e.g., C:\inetpub\wwwroot
- **UserContext** — May vary based on which service account hosts the website
- **TimeWindow** — Time between webshell upload and file overwrite may vary
