# AN0072 - Analytic 0072

[Enterprise](../../README.md) / [Analytics](README.md)

Abuse of Linux Electron binaries by modifying app.asar or config JS files and spawning unexpected child processes (bash, curl, python).

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0025#AN0072)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve: Electron-based binary spawning shell or script interpreter · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=11 · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)

## Mutable elements

- **AsarIntegrityCheck** — Baseline of expected asar package signatures per app.
- **SuspiciousChildProcesses** — Flag shells/python spawned from Electron parent.
