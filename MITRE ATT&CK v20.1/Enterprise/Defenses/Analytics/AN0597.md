# AN0597 - Analytic 0597

[Enterprise](../../README.md) / [Analytics](README.md)

Outbound connections from non-network-facing processes repeatedly send similarly sized payloads within uniform time intervals.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0213#AN0597)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — connect/sendto · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **NSM:Flow** — Outbound Network Flow · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **ProcessNetworkBaseline** — Whitelist of typical binaries expected to generate outbound connections (e.g., wget, curl)
- **PayloadLengthVariance** — Deviation threshold to consider data 'fixed size' (e.g., ±5% size delta)
- **RepeatFrequencyThreshold** — Number of observed transfers per minute/hour that signals anomalous repetition
