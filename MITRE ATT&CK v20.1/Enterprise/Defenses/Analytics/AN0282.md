# AN0282 - Analytic 0282

[Enterprise](../../README.md) / [Analytics](README.md)

Monitors for abnormal process behavior and API calls like SetWindowsHookEx, GetAsyncKeyState, or device input polling commonly used for keystroke logging.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0102#AN0282)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=10 · [DC0035 - Process Access](../Data%20Components/DC0035%20-%20Process%20Access.md)
- **WinEventLog:Security** — EventCode=4663, 4670, 4656 · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)

## Mutable elements

- **TargetImage** — Can be scoped to sensitive GUI processes like explorer.exe or winlogon.exe
- **TimeWindow** — Time threshold for detecting multiple suspicious accesses
