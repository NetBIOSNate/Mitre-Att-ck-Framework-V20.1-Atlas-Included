# AN0779 - Analytic 0779

[Enterprise](../../README.md) / [Analytics](README.md)

Detect unusual invocations of systemctl, service, or init scripts creating or modifying daemons. Monitor audit logs for execution of binaries from unexpected paths linked to service start/stop activity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0279#AN0779)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **linux:syslog** — systemctl start/enable with uncommon binary paths · [DC0060 - Service Creation](../Data%20Components/DC0060%20-%20Service%20Creation.md)
- **auditd:SYSCALL** — write · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)

## Mutable elements

- **ServiceBinaryPaths** — Valid directories for service binaries to filter out benign changes
- **UserContext** — Expected accounts performing service management (e.g., root/admin)
