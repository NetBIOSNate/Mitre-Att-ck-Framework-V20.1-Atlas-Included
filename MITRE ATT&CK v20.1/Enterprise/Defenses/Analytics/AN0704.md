# AN0704 - Analytic 0704

[Enterprise](../../README.md) / [Analytics](README.md)

Monitor system APIs such as CFNetwork and SecureTransport for anomalies in transmitted data streams. Detect mismatches in file hashes or SSL/TLS downgrade attempts that enable manipulation of transmitted data.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0254#AN0704)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Suspicious anomalies in transmitted data integrity during application network operations · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **macos:osquery** — CALCULATE: Integrity validation of transmitted data via hash checks · [DC0021 - OS API Execution](../Data%20Components/DC0021%20-%20OS%20API%20Execution.md)

## Mutable elements

- **TLSValidationRules** — Custom rules for enforcing HTTPS/TLS integrity checks to prevent downgrade manipulation.
- **AllowedApps** — Whitelisted macOS apps permitted to transmit critical data.
