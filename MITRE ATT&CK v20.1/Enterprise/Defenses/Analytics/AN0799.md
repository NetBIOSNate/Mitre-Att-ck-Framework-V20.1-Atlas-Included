# AN0799 - Analytic 0799

[Enterprise](../../README.md) / [Analytics](README.md)

Cause→effect chain: (1) App crash/abnormal termination in unified logs for Safari/Chrome/Office/Preview, (2) new files/scripts in ~/Library, ~/Downloads, /private/var/folders/*, (3) unexpected child (osascript, zsh, bash, curl) spawned by those apps, (4) new outbound connections.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0287#AN0799)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — process crash, abort, code signing violations · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **fs:fsevents** — create/write/rename under user-writable paths · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)
- **macos:osquery** — exec · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **NSM:Connections** — new connections from exploited lineage · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **TimeWindow** — 10–30m correlation window.
- **HighRiskChildren** — osascript, bash, zsh, curl, python, pbpaste/pbcopy, open -a Terminal.
- **UserPaths** — ~/Library/LaunchAgents, ~/Library/Containers/*/Data, /private/var/folders/*.
- **QuarantineBypass** — Flag files with missing com.apple.quarantine extended attribute when sourced from internet.
