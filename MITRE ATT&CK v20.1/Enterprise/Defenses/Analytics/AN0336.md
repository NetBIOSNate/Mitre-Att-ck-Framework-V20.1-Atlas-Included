# AN0336 - Analytic 0336

[Enterprise](../../README.md) / [Analytics](README.md)

Execution of dscl or sysadminctl commands to disable, delete, or modify users combined with anomalous process ancestry or terminal session launch.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0120#AN0336)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — command includes dscl . delete or sysadminctl --deleteUser · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **macos:unifiedlog** — successful sudo or authentication for account not normally associated with admin actions · [DC0002 - User Account Authentication](../Data%20Components/DC0002%20-%20User%20Account%20Authentication.md)

## Mutable elements

- **CommandLinePattern** — Allow variation in dscl/sysadminctl command structure
- **AnomalousUserFlag** — Detect new or rarely seen users performing user removal
