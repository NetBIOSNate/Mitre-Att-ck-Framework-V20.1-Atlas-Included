# AN0750 - Analytic 0750

[Enterprise](../../README.md) / [Analytics](README.md)

Logon via RDP or WMI by a user account followed by uncommon command execution, file manipulation, or lateral network connections.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0269#AN0750)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — EventCode=4624, 4648 · [DC0067 - Logon Session Creation](../Data%20Components/DC0067%20-%20Logon%20Session%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=3, 22 · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **TimeWindow** — Correlation window between remote login and post-access activity
- **LogonUser** — Limit to service accounts or privileged users for higher fidelity
- **RemoteHostList** — Allowlisting known admin jumpboxes or deployment tools
