# AN1190 - Analytic 1190

[Enterprise](../../README.md) / [Analytics](README.md)

Detects command-line tools, agents, or scripts making outbound HTTPS connections to popular web services like Discord, Slack, Dropbox, or Graph API in an unusual context.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0425#AN1190)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — connect/sendto · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **NSM:Flow** — conn.log, ssl.log · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **ParentProcess** — Unusual parent-child process behavior initiating external comms (e.g., bash > curl)
- **HostnamePattern** — Destination hostnames (e.g., *.dropboxapi.com, *.graph.microsoft.com)
- **RequestFrequency** — Repeated requests at unusual intervals, suggesting beaconing
