# AN2035 - Analytic 2035

[Enterprise](../../README.md) / [Analytics](README.md)

Detects user execution of newly received content or instructions shortly after external communication, including script launches, Office child process spawning, browser-to-script execution chains, or credential prompts followed by new logon sessions.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0899#AN2035)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=3, 22 · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **WinEventLog:Security** — EventCode=4624, 4648 · [DC0067 - Logon Session Creation](../Data%20Components/DC0067%20-%20Logon%20Session%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=11 · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)

## Mutable elements

- **EmailToExecutionWindow** — Time between message delivery and process launch
- **OfficeChildProcessAllowlist** — Approved Office child process patterns
- **NewLogonWindow** — Time after credential prompt to monitor new sessions
