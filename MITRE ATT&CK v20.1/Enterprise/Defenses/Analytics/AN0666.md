# AN0666 - Analytic 0666

[Enterprise](../../README.md) / [Analytics](README.md)

Adversary uses compromised instance credentials or web application access to deface content hosted in S3 buckets, Azure Blob Storage, or GCP Buckets.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0238#AN0666)

**Platforms**  [IaaS](../../Platforms/IaaS.md)

## Log sources and channels

- **CloudTrail:PutObject** — PutObject · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **AWS:CloudTrail** — GetObject, CopyObject · [DC0025 - Cloud Storage Access](../Data%20Components/DC0025%20-%20Cloud%20Storage%20Access.md)

## Mutable elements

- **BucketNameRegex** — Patterns of S3 or GCP buckets used for static website hosting may vary by organization.
- **IAMRoleContext** — Some uploads may appear benign unless enriched with user/role metadata.
