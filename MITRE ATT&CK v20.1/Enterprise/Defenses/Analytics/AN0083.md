# AN0083 - Analytic 0083

[Enterprise](../../README.md) / [Analytics](README.md)

Containerized apps or sidecar containers generating excessive outbound traffic or being leveraged for proxy networks. Includes sudden increases in network interface stats, especially in dormant or low-util apps.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0028#AN0083)

**Platforms**  [Containers](../../Platforms/Containers.md)

## Log sources and channels

- **containers:osquery** — bandwidth-intensive command execution from within a container namespace · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **docker:stats** — unusual network TX/RX byte deltas · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **ContainerBaselineNetworkUsage** — Baseline per container must be defined by app purpose and normal traffic.
- **ImageName** — Certain image names or registries may be prone to abuse (e.g., public image hosting mining or proxyware).
