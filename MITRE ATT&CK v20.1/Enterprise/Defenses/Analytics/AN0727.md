# AN0727 - Analytic 0727

[Enterprise](../../README.md) / [Analytics](README.md)

Detects local staging behavior via snapshot creation or files written into VMFS partitions by scripts or unauthorized shell access.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0261#AN0727)

**Platforms**  [ESXi](../../Platforms/ESXi.md)

## Log sources and channels

- **esxi:vmkernel** — snapshot create/write events · [DC0057 - Snapshot Creation](../Data%20Components/DC0057%20-%20Snapshot%20Creation.md)
- **esxi:shell** — CLI usage logs · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **SnapshotThreshold** — Rapid creation or deletion of snapshots
- **CLIInvoker** — Unexpected CLI/script invocation outside maintenance windows
- **VMFSWriteRate** — Volume of data written locally in short time
