# AN0729 - Analytic 0729

[Enterprise](../../README.md) / [Analytics](README.md)

Inspect resolver and audit logs for processes initiating outbound connections to ports calculated from DNS response IPs. Abnormal ephemeral port usage shortly after DNS queries can indicate DNS calculation behavior.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0262#AN0729)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — connect · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **linux:syslog** — DNS response IPs followed by connections to non-standard calculated ports · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **EphemeralPortRange** — Configured ephemeral port ranges per environment to reduce false positives
- **ResolverWhitelist** — Exclude trusted resolvers or internal services from analysis
