# AN0674 - Analytic 0674

[Enterprise](../../README.md) / [Analytics](README.md)

Monitor for abnormal certificate enrollment events in identity platforms, unexpected use of token-signing certificates, and unusual CA configuration modifications.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0240#AN0674)

**Platforms**  [Identity Provider](../../Platforms/Identity%20Provider.md)

## Log sources and channels

- **azure:signinlogs** — Add certificate credential, Update certificate credential · [DC0066 - Active Directory Object Modification](../Data%20Components/DC0066%20-%20Active%20Directory%20Object%20Modification.md)
- **m365:unified** — certificate added or modified in application credentials · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **GeoContext** — Detect certificate-related changes occurring from unusual geographic locations.
- **Thresholds** — Adjust enrollment/issuance request volume thresholds per tenant size.
