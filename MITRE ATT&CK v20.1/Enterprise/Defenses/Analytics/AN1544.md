# AN1544 - Analytic 1544

[Enterprise](../../README.md) / [Analytics](README.md)

Detection of valid account misuse through SSH logins, sudo/su abuse, and service account anomalies outside expected patterns.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0560#AN1544)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **NSM:Connections** — sshd or PAM logins · [DC0002 - User Account Authentication](../Data%20Components/DC0002%20-%20User%20Account%20Authentication.md)

## Mutable elements

- **UserContext** — Identify logins to root or sudoers not aligned with normal usage profiles.
- **HostDensityThreshold** — Number of unique systems a user authenticates to in a time window.
- **LoginMethod** — Trigger on rarely used access methods such as password instead of SSH key.
