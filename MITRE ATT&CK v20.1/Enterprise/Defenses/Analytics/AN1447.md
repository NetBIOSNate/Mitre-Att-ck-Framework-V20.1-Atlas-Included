# AN1447 - Analytic 1447

[Enterprise](../../README.md) / [Analytics](README.md)

Detects modification of System Integrity Protection (SIP) or code signing enforcement policies through csrutil or kernel variable tampering. Correlates execution of csrutil disable commands with subsequent policy state changes and anomalous unsigned process executions.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0523#AN1447)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — csrutil disable · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **macos:unifiedlog** — g_CiOptions modification or SIP state change · [DC0063 - Windows Registry Key Modification](../Data%20Components/DC0063%20-%20Windows%20Registry%20Key%20Modification.md)
- **macos:unifiedlog** — Unsigned binary execution following SIP change · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **PolicyPaths** — Track configuration files and kernel extensions tied to SIP enforcement
- **AllowedUsers** — Restrict or expand which privileged accounts are monitored for SIP/CSRUTIL changes
- **TimeWindow** — Define correlation between csrutil execution and unsigned process activity
