# AN1623 - Analytic 1623

[Enterprise](../../README.md) / [Analytics](README.md)

Adversary compromises a Linux-based web server and modifies hosted web files by exploiting upload vulnerabilities, remote code execution, or replacing index.html via SSH/webshell.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0590#AN1623)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — open/write syscalls targeting web directory files · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)
- **NSM:Connections** — Successful sudo or ssh from unknown IPs · [DC0088 - Logon Session Metadata](../Data%20Components/DC0088%20-%20Logon%20Session%20Metadata.md)
- **NSM:Flow** — Suspicious POSTs to upload endpoints · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **web_root** — May differ (e.g., /var/www/html, /srv/http, etc.)
- **payload_hash** — Adversary content hash may change across campaigns
- **UserContext** — Can range from apache/nginx user to root if escalated
