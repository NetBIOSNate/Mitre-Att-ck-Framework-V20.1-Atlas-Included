# AN2037 - Analytic 2037

[Enterprise](../../README.md) / [Analytics](README.md)

Detects users executing commands copied from chats, tickets, or emails, including curl|bash patterns, shell script launches from temp directories, credential changes, or SSH key additions shortly after communication events.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0899#AN2037)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **NSM:Connections** — Outbound connection after script or installer launch · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **auditd:EXECVE** — execve of curl,wget,bash,sh,python with piped or remote content · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **auditd:PATH** — odification of ~/.ssh/authorized_keys or credential files · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)

## Mutable elements

- **RemoteScriptExecutionPatterns** — Organization-specific admin automation patterns to exclude
- **TicketToExecutionWindow** — Time from help desk/chat event to command execution
