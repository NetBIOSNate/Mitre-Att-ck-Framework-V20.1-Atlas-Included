# AN1514 - Analytic 1514

[Enterprise](../../README.md) / [Analytics](README.md)

Abnormal API calls from user accounts invoking file upload endpoints outside normal baselines (M365, Google Drive, Box). Defender perspective: monitor unified audit logs for elevated frequency of Upload, Create, or Copy operations from compromised accounts.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0548#AN1514)

**Platforms**  [SaaS](../../Platforms/SaaS.md)

## Log sources and channels

- **m365:unified** — FileUploaded or FileCopied events · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **saas:box** — API calls exceeding baseline thresholds · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **APICallThreshold** — Maximum number of API calls per user/session before triggering alert.
- **UserBaselineProfiles** — Baseline normal data transfer patterns by user/role.
