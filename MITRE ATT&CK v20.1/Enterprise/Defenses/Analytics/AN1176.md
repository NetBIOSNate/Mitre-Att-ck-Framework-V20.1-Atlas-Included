# AN1176 - Analytic 1176

[Enterprise](../../README.md) / [Analytics](README.md)

Monitor pmset command executions altering sleep/hibernate/standby parameters. Unexpected modifications to /Library/Preferences/SystemConfiguration/com.apple.PowerManagement.plist or similar files should be correlated with process activity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0417#AN1176)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Process creation events where command line = pmset with arguments affecting sleep, hibernatemode, displaysleep · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:unifiedlog** — write: File modification to com.apple.PowerManagement.plist or related system preference files · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)

## Mutable elements

- **AdminWhitelists** — Allowlist expected pmset invocations by IT administrators for power policy enforcement.
