# AN1333 - Analytic 1333

[Enterprise](../../README.md) / [Analytics](README.md)

Use unified logs to identify processes issuing repeated DNS queries where the resolved IP addresses change frequently within very short TTL values. Correlate with outbound network traffic to validate C2-like patterns.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0485#AN1333)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Rapid domain-to-IP resolution changes for same domain · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **macos:unifiedlog** — Unexpected apps generating frequent DNS queries · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **DNSRotationRate** — Rate of IP churn per domain to trigger detection
- **NewDomainThreshold** — Flag if domain was registered recently (e.g., < 30 days)
