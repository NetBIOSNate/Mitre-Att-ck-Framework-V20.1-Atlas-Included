# AN0218 - Analytic 0218

[Enterprise](../../README.md) / [Analytics](README.md)

Detection of hijacked VNC or SSH sessions on macOS where adversaries take over an existing session rather than authenticating directly. Indicators include process execution from active sessions without new logon events, manipulation of TTY sessions, or anomalous network activity tied to dormant sessions.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0079#AN0218)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Authentication inconsistencies where commands are executed without corresponding login events · [DC0067 - Logon Session Creation](../Data%20Components/DC0067%20-%20Logon%20Session%20Creation.md)
- **macos:unifiedlog** — Execution of processes linked to hijacked sessions (e.g., anomalous parent-child process lineage) · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **NSM:Flow** — Suspicious long-lived or reattached remote desktop sessions from unexpected IPs · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **SessionIdleThreshold** — Time threshold for inactive sessions flagged as suspicious when commands suddenly resume.
