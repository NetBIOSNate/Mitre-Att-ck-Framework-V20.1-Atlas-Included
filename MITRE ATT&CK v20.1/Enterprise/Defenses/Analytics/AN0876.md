# AN0876 - Analytic 0876

[Enterprise](../../README.md) / [Analytics](README.md)

Correlates interface mode changes to promiscuous with execution of sniffing tools like tcpdump, tshark, or custom pcap libraries. Detects abnormal NIC configurations and unauthorized sniffing from non-root sessions.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0314#AN0876)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve, setifflags · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **auditd:SYSCALL** — promiscuous mode transitions (ioctl or ifconfig) · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **networkconfig ** — interface flag PROMISC, netstat | ip link | ethtool · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **InterfaceList** — Limit analysis to external interfaces (e.g., eth0, wlan0) and exclude virtual adapters.
- **PromiscuousSessionThreshold** — Raise alerts if interface remains in PROMISC longer than threshold duration.
