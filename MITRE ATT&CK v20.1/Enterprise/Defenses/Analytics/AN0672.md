# AN0672 - Analytic 0672

[Enterprise](../../README.md) / [Analytics](README.md)

Monitor for file access to certificate directories, commands invoking OpenSSL or PKCS#12 utilities to export or modify certificates, and processes accessing sensitive key storage paths.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0240#AN0672)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — open, read: /etc/ssl/, /etc/pki/, ~/.pki/nssdb/ · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **auditd:SYSCALL** — execve: openssl pkcs12, certutil, keytool · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **PathExclusions** — Exempt trusted automated services regularly accessing PKI stores.
- **UserContext** — Differentiate root/system accounts versus user-level access to key material.
