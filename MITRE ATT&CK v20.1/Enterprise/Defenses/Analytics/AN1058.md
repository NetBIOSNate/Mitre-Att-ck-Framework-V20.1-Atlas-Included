# AN1058 - Analytic 1058

[Enterprise](../../README.md) / [Analytics](README.md)

Detects use of network scanning utilities or scripts performing rapid connections to multiple services or hosts using auditd and netflow/pcap telemetry.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0376#AN1058)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **NSM:Flow** — Outbound TCP SYN or UDP to multiple ports/hosts · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **PortScanThreshold** — Defines number of ports targeted per host within a short period.
- **ToolPatternRegex** — Regex to match common scanner arguments (e.g., `nmap -sS`, `nc -zv`).
- **ExpectedScanSources** — Trusted IPs or systems performing routine discovery.
