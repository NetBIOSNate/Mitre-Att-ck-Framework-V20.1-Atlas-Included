# AN0584 - Analytic 0584

[Enterprise](../../README.md) / [Analytics](README.md)

Excessive resource exhaustion or service crash induced by processes launched by users or scripts that rapidly consume CPU/memory or attempt malformed service interactions.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0208#AN0584)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Application** — Service crash, unhandled exception, or application hang warnings for critical services (e.g., IIS, DNS, SQL Server) · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **WinEventLog:System** — System shutdowns due to bugcheck (Event ID 1001) or watchdog timer expirations · [DC0018 - Host Status](../Data%20Components/DC0018%20-%20Host%20Status.md)

## Mutable elements

- **TimeWindow** — Number of service crashes or high-CPU events within a defined time period
- **ServiceTarget** — Specific service name or executable targeted for DoS (e.g., svchost.exe, w3wp.exe)
- **CPUThresholdPercent** — CPU usage percent considered anomalous over duration
