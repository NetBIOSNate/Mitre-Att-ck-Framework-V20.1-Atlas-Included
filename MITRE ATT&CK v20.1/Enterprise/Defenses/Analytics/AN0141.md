# AN0141 - Analytic 0141

[Enterprise](../../README.md) / [Analytics](README.md)

Suspicious file creation or modification in directories ignored by XProtect or AV exclusions (e.g., ~/Library, temporary cache directories). Defender perspective: monitor file events in ignored paths with correlation to execution or persistence activity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0051#AN0141)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — file creation in AV exclusion directories · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **macos:unifiedlog** — process writes or modifies files in excluded paths · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **AVExclusionPaths** — Paths ignored by AV/XProtect that should be monitored for abnormal writes.
- **ProcessContext** — Expected user or application context writing to excluded directories.
