# AN0004 - Analytic 0004

[Enterprise](../../README.md) / [Analytics](README.md)

Detects osascript, curl, or custom binaries interacting with XMPP/MQTT brokers in unapproved destinations with encrypted payloads or frequent POST-like requests to broker URIs.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0002#AN0004)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — log stream 'eventMessage contains pubsub or broker' · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:osquery** — socket_events · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **AppContextFilter** — Applications not known to use pub/sub protocols
- **URIPathRegex** — Custom path patterns to message brokers over HTTPS
