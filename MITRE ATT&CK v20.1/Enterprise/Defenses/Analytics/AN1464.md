# AN1464 - Analytic 1464

[Enterprise](../../README.md) / [Analytics](README.md)

Execution of PubPrn.vbs via cscript.exe using the 'script:' moniker to load and execute a remote .sct scriptlet file, bypassing signature validation and proxying remote payloads through a signed Microsoft script host.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0528#AN1464)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:PowerShell** — EventCode=4103, 4104, 4105, 4106 · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **WinEventLog:Sysmon** — EventCode=3, 22 · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=7 · [DC0016 - Module Load](../Data%20Components/DC0016%20-%20Module%20Load.md)

## Mutable elements

- **CommandLineRegex** — Detects 'script:' moniker with HTTP/HTTPS URI as argument to pubprn.vbs
- **ParentProcessName** — May vary between cscript.exe, wscript.exe, or cmd.exe depending on execution method
- **NetworkDestinationDomain** — Used to detect external domains being contacted for remote scriptlet execution
- **TimeWindow** — Maximum allowed time delta between pubprn.vbs invocation and network connection or child process
