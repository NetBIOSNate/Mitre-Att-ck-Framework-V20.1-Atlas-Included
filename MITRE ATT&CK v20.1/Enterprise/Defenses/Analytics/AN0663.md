# AN0663 - Analytic 0663

[Enterprise](../../README.md) / [Analytics](README.md)

Adversary gains shell access or uploads a malicious script to deface hosted web content in Nginx, Apache, or other services.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0238#AN0663)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — write · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)
- **apache:access_log** — Unusual HTTP POST or PUT requests to paths such as '/uploads/', '/admin/', or CMS plugin folders · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **linux:syslog** — Unauthorized sudo or shell access, especially leading to file changes in /var/www or /srv/http · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **UploadPathRegex** — Regex for CMS-specific upload directories subject to defacement (e.g., wp-content/uploads).
- **FileExtensionScope** — Types of files to monitor for defacement (e.g., .html, .php, .jsp).
