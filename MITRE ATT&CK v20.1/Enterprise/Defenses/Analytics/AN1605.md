# AN1605 - Analytic 1605

[Enterprise](../../README.md) / [Analytics](README.md)

Adversary invokes 'useradd', 'adduser', or equivalent system commands or scripts to create local users. Detection focuses on command execution and audit trail of passwd/shadow file modifications.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0583#AN1605)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — useradd or adduser executed · [DC0014 - User Account Creation](../Data%20Components/DC0014%20-%20User%20Account%20Creation.md)
- **auditd:SYSCALL** — chmod/chown to /etc/passwd or /etc/shadow · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)

## Mutable elements

- **BinaryPath** — Custom scripts or renamed binaries may evade simple path-based detection
- **ExecutionTime** — Account creation outside maintenance windows may indicate compromise
