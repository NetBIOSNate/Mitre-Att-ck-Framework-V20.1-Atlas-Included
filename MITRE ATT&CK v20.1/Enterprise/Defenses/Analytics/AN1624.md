# AN1624 - Analytic 1624

[Enterprise](../../README.md) / [Analytics](README.md)

Adversary modifies web-facing content on macOS via web development environments like MAMP or misconfigured Apache instances, typically with access to the hosting user account or via persistence tools.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0590#AN1624)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Terminal/Editor processes modifying web folder · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)
- **macos:unifiedlog** — loginwindow or sshd events with external IP · [DC0088 - Logon Session Metadata](../Data%20Components/DC0088%20-%20Logon%20Session%20Metadata.md)

## Mutable elements

- **web_root_dir** — May include ~/Sites or custom Apache paths
- **editor_name** — Text editor or script modifying the files may vary (e.g., nano, VS Code)
