# AN0272 - Analytic 0272

[Enterprise](../../README.md) / [Analytics](README.md)

Scripted or binary usage of X11 utilities (e.g., xdotool, wmctrl) or direct /proc/*/window mappings to discover open GUI windows and active desktops.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0097#AN0272)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:EXECVE** — execve · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **linux:syslog** — None · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **ExecutableName** — Common window management utilities can be tuned to reduce noise (e.g., xprop, xwininfo).
- **DisplayContext** — Restrict detection to processes executing under graphical sessions (e.g., DISPLAY=:0).
