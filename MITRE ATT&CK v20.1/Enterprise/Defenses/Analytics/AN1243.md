# AN1243 - Analytic 1243

[Enterprise](../../README.md) / [Analytics](README.md)

Monitor kernel module load/unload activity via modprobe, insmod, rmmod, or direct manipulation of /lib/modules. Correlate with installation of kernel headers, compilation commands, or downloads of .ko files. Detect anomalies in unsigned module loading or repeated module load attempts under non-root users.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0450#AN1243)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — Execution of insmod, modprobe, or rmmod commands by non-standard users or outside expected timeframes · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **auditd:SYSCALL** — Access or modification to /lib/modules or creation of .ko files · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **linux:osquery** — New or modified kernel object files (.ko) within /lib/modules directory · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)

## Mutable elements

- **UserContext** — Scope detection to non-root or unexpected users performing module-related activity
- **TimeWindow** — Limit alerts to module activity outside approved change windows
- **FilePathRegex** — Adjust regex pattern for directories to monitor depending on kernel version or distro
