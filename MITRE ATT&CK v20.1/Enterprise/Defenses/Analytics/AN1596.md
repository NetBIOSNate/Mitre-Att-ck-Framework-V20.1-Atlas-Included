# AN1596 - Analytic 1596

[Enterprise](../../README.md) / [Analytics](README.md)

Detect attempts to enumerate kernel modules through lsmod, modinfo, or inspection of /proc/modules and /dev entries. Focus on unusual execution contexts such as unprivileged users or processes outside expected administrative workflows.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0579#AN1596)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve: Execution of lsmod, modinfo, or cat /proc/modules · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **auditd:FS** — read: File access to /proc/modules or /sys/module/ · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)

## Mutable elements

- **KnownAdminUsers** — Limit detection noise by filtering expected kernel module inspection by root or system maintenance scripts.
