# AN1638 - Analytic 1638

[Enterprise](../../README.md) / [Analytics](README.md)

SSH login from a remote system (via sshd), followed by user context execution of suspicious binaries or privilege escalation behavior.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0596#AN1638)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:EXECVE** — EXECVE · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **linux:syslog** — None · [DC0067 - Logon Session Creation](../Data%20Components/DC0067%20-%20Logon%20Session%20Creation.md)
- **NSM:Flow** — TCP port 22 traffic · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **TimeWindow** — Defines correlation window from login to first post-SSH process (e.g., 60s)
- **SuspiciousProcessList** — List of binaries considered unusual in SSH context (e.g., nc, base64, bash -i)
- **UsernameFilter** — Accounts of interest for SSH logins (e.g., root, admin)
