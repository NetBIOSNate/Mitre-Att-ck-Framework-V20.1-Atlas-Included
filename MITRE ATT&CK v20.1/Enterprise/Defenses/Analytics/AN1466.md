# AN1466 - Analytic 1466

[Enterprise](../../README.md) / [Analytics](README.md)

Userland processes invoking syscall-heavy libraries (libc, glibc) followed by fork, mmap, or ptrace behavior commonly associated with code injection or memory manipulation.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0529#AN1466)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve, fork, mmap, ptrace · [DC0035 - Process Access](../Data%20Components/DC0035%20-%20Process%20Access.md)
- **auditd:SYSCALL** — module load or memory map path · [DC0016 - Module Load](../Data%20Components/DC0016%20-%20Module%20Load.md)

## Mutable elements

- **SyscallType** — Filter for fork, mmap, ptrace based on context
- **ProcessName** — Whitelist known daemon and scheduled task patterns
- **MAPS Path** — Tune suspicious memory map regions (e.g., /tmp/.evilshmem)
