# AN0648 - Analytic 0648

[Enterprise](../../README.md) / [Analytics](README.md)

Processes accessing LSASS memory or SAM registry hives outside of trusted security tools, often followed by file creation or lateral movement. Detects unauthorized access to sensitive OS subsystems for credential extraction.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0234#AN0648)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=10 · [DC0035 - Process Access](../Data%20Components/DC0035%20-%20Process%20Access.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Security** — EventCode=4663, 4670, 4656 · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **WinEventLog:Security** — EventCode=4662 · [DC0071 - Active Directory Object Access](../Data%20Components/DC0071%20-%20Active%20Directory%20Object%20Access.md)

## Mutable elements

- **AccessMask** — Set to detect full access rights (0x1F0FFF) or modify based on tool behavior.
- **TimeWindow** — Define how soon access to LSASS is followed by suspicious file or registry activity.
- **ParentProcessFilter** — Allowlist known security tools or system processes accessing LSASS.
