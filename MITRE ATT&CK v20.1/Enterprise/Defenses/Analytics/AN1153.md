# AN1153 - Analytic 1153

[Enterprise](../../README.md) / [Analytics](README.md)

Unusual access to bash history, registry credentials paths, or private key files by unauthorized or scripting tools, with correlated file and process activity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0412#AN1153)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=11 · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **WinEventLog:Security** — EventCode=4688 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=13, 14 · [DC0063 - Windows Registry Key Modification](../Data%20Components/DC0063%20-%20Windows%20Registry%20Key%20Modification.md)

## Mutable elements

- **TimeWindow** — Defines the threshold time for accessing multiple sensitive files indicating automation.
- **SuspiciousProcessList** — Process names to monitor (e.g., reg.exe, cmd.exe, powershell.exe, etc.)
