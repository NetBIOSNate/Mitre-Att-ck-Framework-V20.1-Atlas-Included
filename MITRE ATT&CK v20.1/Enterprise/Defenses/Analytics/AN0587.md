# AN0587 - Analytic 0587

[Enterprise](../../README.md) / [Analytics](README.md)

Instance enters degraded/unhealthy state due to abnormal process load or memory exhaustion, often caused by automation or script-based attacks.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0208#AN0587)

**Platforms**  [IaaS](../../Platforms/IaaS.md)

## Log sources and channels

- **AWS:CloudWatch** — StatusCheckFailed or StatusCheckFailed_System for burstable instances (t2/t3) · [DC0018 - Host Status](../Data%20Components/DC0018%20-%20Host%20Status.md)
- **AWS:CloudTrail** — StartInstances · [DC0080 - Instance Start](../Data%20Components/DC0080%20-%20Instance%20Start.md)
- **VPCFlowLogs:All** — High volume internal traffic with low entropy indicating looped or malicious DoS script · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **InstanceType** — Burstable vs compute-optimized instances impact DoS effect
- **FailureThreshold** — How many consecutive StatusCheckFailed events to consider critical
