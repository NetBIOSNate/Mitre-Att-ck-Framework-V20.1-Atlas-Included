# AN0700 - Analytic 0700

[Enterprise](../../README.md) / [Analytics](README.md)

Execution of Homebrew, pip3, npm, or manually downloaded PKGs from Terminal or shell, followed by the creation of startup agents, interpreter spawns, or outbound connections to unfamiliar domains. Defender links Terminal commands to plist creation, unsigned binary launches, and `python3` or `node` processes connecting to remote endpoints.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0252#AN0700)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Command line invocation of pip3, brew install, npm install from interactive Terminal · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:unifiedlog** — Creation of new LaunchAgent or LoginItem plist files in ~/Library/LaunchAgents/ · [DC0059 - File Metadata](../Data%20Components/DC0059%20-%20File%20Metadata.md)
- **NSM:Flow** — Outbound HTTP/S initiated by newly installed interpreter process · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **StartupAgentPaths** — Filter user persistence plist directories like ~/Library/LaunchAgents
- **UnsignedBinaryAlerting** — Enable alerting for new binaries lacking Apple or organization signature
- **InstallToNetWindow** — Correlate install action to interpreter-based network behavior
