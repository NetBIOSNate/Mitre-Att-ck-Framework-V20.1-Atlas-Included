# AN1158 - Analytic 1158

[Enterprise](../../README.md) / [Analytics](README.md)

Access to container image layers or mounted secrets (e.g., Docker secrets) by processes not tied to entrypoint or orchestration context.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0412#AN1158)

**Platforms**  [Containers](../../Platforms/Containers.md)

## Log sources and channels

- **auditd:SYSCALL** — read of /run/secrets or docker volumes by non-entrypoint process · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **containerd:Events** — unusual process spawned from container image context · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **EntrypointAllowlist** — Container entrypoints that are permitted to read secrets
- **VolumeMountPath** — Paths to credentials/secrets inside container images
