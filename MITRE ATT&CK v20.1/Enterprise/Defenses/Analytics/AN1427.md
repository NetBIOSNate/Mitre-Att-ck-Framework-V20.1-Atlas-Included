# AN1427 - Analytic 1427

[Enterprise](../../README.md) / [Analytics](README.md)

Programmatic access to user content via stolen access tokens in platforms like Slack, GitHub, Google Workspace — especially from new IPs, apps, or excessive resource access.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0515#AN1427)

**Platforms**  [SaaS](../../Platforms/SaaS.md)

## Log sources and channels

- **saas:googleworkspace** — Access via OAuth credentials with unusual scopes or from anomalous IPs · [DC0002 - User Account Authentication](../Data%20Components/DC0002%20-%20User%20Account%20Authentication.md)
- **saas:slack** — OAuth token use by unknown app client_id accessing private channels or files · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **GeoVelocity** — Flag when token use appears across geographically distant logins
- **OAuthScopeSensitivity** — Weight certain scopes (admin, file.read) as higher risk
