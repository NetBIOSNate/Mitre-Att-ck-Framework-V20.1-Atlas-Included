# AN0253 - Analytic 0253

[Enterprise](../../README.md) / [Analytics](README.md)

Manual or script-based installation of extension-like modules into browser config directories or IDE plugin paths, followed by suspicious network activity

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0092#AN0253)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **fs:fileevents** — creat · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **NSM:Flow** — Abnormal browser traffic volume or destination · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **DirectoryPath** — Common plugin or extension directories may vary by distro or browser (e.g., ~/.config/google-chrome/Default/Extensions)
- **ExecPath** — Path to scripting tools used in installation (e.g., bash, curl, unzip)
- **TimeWindow** — Tunable interval between install and first network beacon
