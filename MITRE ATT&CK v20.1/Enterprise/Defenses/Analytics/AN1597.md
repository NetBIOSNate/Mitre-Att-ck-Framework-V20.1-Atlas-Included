# AN1597 - Analytic 1597

[Enterprise](../../README.md) / [Analytics](README.md)

Detect loading or inspection of kernel extensions (kextstat, kextfind) and file access to /System/Library/Extensions/. Monitor unexpected usage of these utilities by non-administrative users or scripts.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0579#AN1597)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — exec: Execution of kextstat, kextfind, or ioreg targeting driver information · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:unifiedlog** — read: File access to /System/Library/Extensions/ or related kernel extension paths · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)

## Mutable elements

- **AllowedMaintenanceTasks** — Tune detection by excluding expected system diagnostic or patch-related invocations of kext utilities.
