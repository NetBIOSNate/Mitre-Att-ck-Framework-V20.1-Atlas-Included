# AN1171 - Analytic 1171

[Enterprise](../../README.md) / [Analytics](README.md)

Detects Automator, AppleScript, or Terminal executing curl, lftp, or TFTP for binary transfer to untrusted IPs or unusual ports.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0416#AN1171)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:osquery** — socket_events · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **macos:unifiedlog** — log stream --predicate · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **FilePathAccessed** — e.g., ~/Documents, ~/Library/logs/
- **NetworkPortAnomaly** — Non-standard FTP/TFTP ports used (e.g., FTP over 443)
