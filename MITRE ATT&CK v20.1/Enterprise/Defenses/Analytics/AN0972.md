# AN0972 - Analytic 0972

[Enterprise](../../README.md) / [Analytics](README.md)

VM or cloud instance generating anomalously high network egress targeting same destination IP or service, especially using stateless protocols.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0343#AN0972)

**Platforms**  [IaaS](../../Platforms/IaaS.md)

## Log sources and channels

- **AWS:VPCFlowLogs** — source instance sends large volume of traffic in short window · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **AWS:CloudWatch** — NetworkOut spike beyond baseline · [DC0018 - Host Status](../Data%20Components/DC0018%20-%20Host%20Status.md)

## Mutable elements

- **InstanceTrafficThreshold** — Alert when egress exceeds normal usage by X%.
- **ProtocolType** — Prioritize alerts on stateless protocols such as UDP and ICMP.
