# AN1529 - Analytic 1529

[Enterprise](../../README.md) / [Analytics](README.md)

Detects abnormal creation of binary files with significant size that are subsequently executed or accessed by non-standard users.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0553#AN1529)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — open · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **auditd:SYSCALL** — execve · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **linux:osquery** — file_events · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)

## Mutable elements

- **FileSizeThresholdMB** — Defines how large a file must be to consider it padded
- **UserContext** — Target abnormal user behavior outside of expected automation
- **TimeWindow** — Time window for correlating file creation and execution
