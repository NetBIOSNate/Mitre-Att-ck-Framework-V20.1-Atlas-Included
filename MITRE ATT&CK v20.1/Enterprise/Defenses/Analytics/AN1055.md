# AN1055 - Analytic 1055

[Enterprise](../../README.md) / [Analytics](README.md)

Track creation or update of SaaS automation scripts (e.g., Google Workspace Apps Script). Detect when these scripts are bound to user events such as file opens or account modifications, and correlate with subsequent abnormal API calls that exfiltrate or modify user data.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0374#AN1055)

**Platforms**  [SaaS](../../Platforms/SaaS.md)

## Log sources and channels

- **saas:appsscript** — Create / Update: Deployment of scripts with event-driven triggers · [DC0069 - Cloud Service Modification](../Data%20Components/DC0069%20-%20Cloud%20Service%20Modification.md)
- **saas:googledrive** — FileOpen / FileAccess: Event-driven script triggering on user file actions · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **ScriptScope** — Which SaaS apps or APIs can be legitimately automated in the environment
- **TriggerTypes** — Event-driven triggers (e.g., on file open, on user creation) considered suspicious
