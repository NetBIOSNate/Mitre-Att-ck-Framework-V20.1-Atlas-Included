# AN0692 - Analytic 0692

[Enterprise](../../README.md) / [Analytics](README.md)

IAAS (Cloud images/VMs): A new VM/instance is launched from a non-approved or newly-seen image (AMI/GCP Image/Azure Image). On first boot, cloud-init/user-data or embedded agents download code, spawn system utilities, or open outbound C2/mining traffic. The analytic correlates Instance/Image Creation → Instance Start → in-guest Process/Command Execution and/or anomalous network traffic.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0248#AN0692)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **AWS:CloudTrail** — RunInstances · [DC0080 - Instance Start](../Data%20Components/DC0080%20-%20Instance%20Start.md)
- **azure:activity** — Microsoft.Compute/virtualMachines/write: imageReference publisher NOT IN allowlist OR plan is new/unknown · [DC0076 - Instance Creation](../Data%20Components/DC0076%20-%20Instance%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **NSM:Flow** — New VM egress to crypto-mining pools or non-approved Internet ranges within minutes of boot · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **ApprovedImageCatalog** — Set of golden images/owners and digest/IDs allowed to launch.
- **UserDataInspection** — Whether to alert when userData/cloud-init contains exec or download directives.
- **FirstBootWindow** — Time after start considered first-boot (e.g., ≤30m) for correlation.
- **VMTagScope** — Restrict detection to prod or internet-facing subnets to reduce noise.
