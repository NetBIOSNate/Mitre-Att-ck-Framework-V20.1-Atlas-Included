# AN0092 - Analytic 0092

[Enterprise](../../README.md) / [Analytics](README.md)

Creation of files or directories with a leading '.' in privileged directories (/etc, /var, /usr/bin). Defender view: monitoring auditd logs for file creations where name begins with '.' and correlated with unusual user/process context.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0032#AN0092)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:FILE** — File creation with name starting with '.' · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **auditd:EXECVE** — Use of mv or cp to rename files with '.' prefix · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **DirectoryScope** — Restrict detection to critical directories to avoid noise from benign hidden files like .ssh or .config.
