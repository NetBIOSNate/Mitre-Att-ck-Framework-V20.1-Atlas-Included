# AN1489 - Analytic 1489

[Enterprise](../../README.md) / [Analytics](README.md)

Sustained execution of resource-intensive processes (e.g., cryptocurrency miners), often launched via scheduled tasks, WMI, or PowerShell. These processes frequently establish persistent external connections and attempt to evade detection using masqueraded or renamed binaries.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0540#AN1489)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=3, 22 · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **WinEventLog:Security** — EventCode=4698 · [DC0001 - Scheduled Job Creation](../Data%20Components/DC0001%20-%20Scheduled%20Job%20Creation.md)

## Mutable elements

- **Image** — The executable name of the miner or wrapper—can vary across campaigns.
- **DestinationIP** — May differ depending on the mining pool or proxy server.
- **ParentProcessName** — Useful for filtering known-good automation vs malicious task runners.
