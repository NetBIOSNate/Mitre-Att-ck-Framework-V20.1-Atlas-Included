# AN1113 - Analytic 1113

[Enterprise](../../README.md) / [Analytics](README.md)

Detection of automated tools or scripts periodically transmitting data to external destinations using scheduled tasks or background processes.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0397#AN1113)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — EventCode=4688 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=3, 22 · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **TimeWindow** — Used to detect repeated exfil activity over intervals (e.g., every 5 minutes).
- **DestinationIP** — Can be tuned to filter known internal or trusted destinations.
