# AN0945 - Analytic 0945

[Enterprise](../../README.md) / [Analytics](README.md)

Detects user or root invocation of `at` command to schedule a job, followed by job execution using LaunchServices and activity in /usr/lib/cron/at.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0333#AN0945)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — process: at, job runner · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **fs:fsusage** — file access to /usr/lib/cron/at and job execution path · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)
- **macos:osquery** — process_events · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **AtPermissions** — Whether `at.allow` and `at.deny` are properly configured.
- **ExecutionCommand** — Target binary executed via the at job.
- **RunUser** — Detection of root user scheduling job with unusual command.
