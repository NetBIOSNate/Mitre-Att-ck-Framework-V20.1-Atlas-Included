# AN2039 - Analytic 2039

[Enterprise](../../README.md) / [Analytics](README.md)

Detects exploitation attempts against security daemons or kernel security modules followed by daemon termination, disabled logging, module unload, audit stoppage, or reduced endpoint telemetry. Correlates local execution or network input with control degradation.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0900#AN2039)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:EXECVE** — execve, kill, ptrace, insmod, rmmod targeting security processes · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **auditd:DAEMON** — auditd stopped, config changed, logging suspended · [DC0041 - Service Metadata](../Data%20Components/DC0041%20-%20Service%20Metadata.md)

## Mutable elements

- **ProtectedProcessNames** — Names of EDR, audit, AV, firewall daemons
- **ModuleUnloadAllowlist** — Approved maintenance unload operations
- **HealthGapThreshold** — Expected telemetry heartbeat tolerance
