# AN0726 - Analytic 0726

[Enterprise](../../README.md) / [Analytics](README.md)

Detects staged data aggregated in /Users/Shared, /private/tmp with compression tools like ditto or zip, initiated via Terminal or AppleScript.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0261#AN0726)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — file events · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **macos:unifiedlog** — exec logs · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **StagingTargets** — Shared dirs commonly abused for local collection
- **CompressionBinaries** — zip, tar, ditto
- **TimeWindow** — Seconds/minutes between source file read and output staging write
