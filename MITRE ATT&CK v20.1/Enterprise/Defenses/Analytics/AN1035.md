# AN1035 - Analytic 1035

[Enterprise](../../README.md) / [Analytics](README.md)

Detects tampered hardware or firmware via anomalous host status telemetry. Behavioral chain: (1) Pre-OS or firmware components exhibit unexpected version changes, signature failures, or modified boot paths; (2) System management/firmware tools log hardware inventory drift; (3) Sensor health telemetry or boot attestation events fail baseline checks; (4) Follow-on process execution from altered firmware or unknown drivers after boot.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0368#AN1035)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — EventCode=1166, 7045 · [DC0018 - Host Status](../Data%20Components/DC0018%20-%20Host%20Status.md)
- **WinEventLog:Microsoft-Windows-CodeIntegrity/Operational** — Code integrity violations in boot-start drivers or firmware · [DC0059 - File Metadata](../Data%20Components/DC0059%20-%20File%20Metadata.md)
- **WinEventLog:Sysmon** — EventCode=6 · [DC0079 - Driver Load](../Data%20Components/DC0079%20-%20Driver%20Load.md)
- **WinEventLog:Sysmon** — EventCode=7 · [DC0016 - Module Load](../Data%20Components/DC0016%20-%20Module%20Load.md)
- **WinEventLog:Sysmon** — EventCode=10 · [DC0035 - Process Access](../Data%20Components/DC0035%20-%20Process%20Access.md)

## Mutable elements

- **BaselineFirmwareVersion** — Expected firmware/BIOS version for each hardware model.
- **BaselineDriverList** — Approved boot-start drivers.
- **IntegrityCheckInterval** — Frequency of integrity checks (e.g., daily, weekly).
