# AN0210 - Analytic 0210

[Enterprise](../../README.md) / [Analytics](README.md)

Detects embedded or emulated VBScript/VBA execution via Wine-based apps, Office for Mac abusing cross-platform .NET features, or macros dropped and invoked via AppleScript or third-party automation tools.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0076#AN0210)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — log stream --predicate 'eventMessage contains "wscript" OR "vbs"' · [DC0029 - Script Execution](../Data%20Components/DC0029%20-%20Script%20Execution.md)
- **macos:osquery** — process_events · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:syslog** — system.log · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **ScriptLocation** — Script run from ~/Downloads, ~/Library, or /tmp/
- **EmulationContext** — Wine or CrossOver launching legacy Windows scripting engines.
- **UserContext** — VB execution from non-standard or shared users on endpoint.
