# AN0056 - Analytic 0056

[Enterprise](../../README.md) / [Analytics](README.md)

Executable or binary files created without symbol tables or with stripped sections, especially by non-user shell processes or compilers invoked outside standard dev paths.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0019#AN0056)

**Platforms**  [Linux](../../Platforms/Linux.md)

- **auditd:EXECVE** — EXECVE · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **auditd:SYSCALL** — open, write · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)
- **linux:osquery** — hash, elf_info, file_metadata · [DC0059 - File Metadata](../Data%20Components/DC0059%20-%20File%20Metadata.md)

## Mutable elements

- **StripFlags** — Flag combinations in compiled binaries indicating symbol table removal
- **DirectoryScope** — Whitelist compiler output directories to reduce false positives
- **FileSizeRange** — Heuristic boundaries for abnormal small or overly large stripped binaries
