# AN1003 - Analytic 1003

[Enterprise](../../README.md) / [Analytics](README.md)

User creation or modification via dscl with IsHidden=1, UID<500, or plist edits to com.apple.loginwindow Hide500Users flag. Defender view: correlation of hidden account attributes with login screen exclusion.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0353#AN1003)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Execution of dscl . create with IsHidden=1 · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **macos:unifiedlog** — Modification of /Library/Preferences/com.apple.loginwindow plist · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)
- **macos:unifiedlog** — Creation of user account with UID <500 · [DC0013 - User Account Metadata](../Data%20Components/DC0013%20-%20User%20Account%20Metadata.md)

## Mutable elements

- **UIDThreshold** — Tune detection based on acceptable UID ranges for hidden/system accounts.
- **PlistScope** — Restrict plist monitoring to com.apple.loginwindow to reduce false positives.
