# AN0976 - Analytic 0976

[Enterprise](../../README.md) / [Analytics](README.md)

Monitor audit logs for setuid/setgid bit changes, executions where UID ≠ EUID (indicative of sudo or privilege escalation), and high-integrity binaries launched by unprivileged users.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0345#AN0976)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — setuid or setgid bit changes · [DC0059 - File Metadata](../Data%20Components/DC0059%20-%20File%20Metadata.md)
- **auditd:SYSCALL** — execve with UID ≠ EUID · [DC0034 - Process Metadata](../Data%20Components/DC0034%20-%20Process%20Metadata.md)
- **auditd:SYSCALL** — sudo or pkexec invocation · [DC0021 - OS API Execution](../Data%20Components/DC0021%20-%20OS%20API%20Execution.md)

## Mutable elements

- **WatchedDirectories** — Paths where unauthorized setuid binaries may be dropped
- **UserContext** — Which users are allowed to run sudo/pkexec or modify binaries
- **TimeWindow** — Duration between file permission change and elevated command execution
