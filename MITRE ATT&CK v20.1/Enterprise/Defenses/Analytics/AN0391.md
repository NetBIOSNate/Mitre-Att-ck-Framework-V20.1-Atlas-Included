# AN0391 - Analytic 0391

[Enterprise](../../README.md) / [Analytics](README.md)

Detects DYLD_INSERT_LIBRARIES abuse to hook credential-sensitive applications by correlating process spawns with unauthorized library injection and monitoring changes to the __TEXT segment (code) of credential handling binaries.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0139#AN0391)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — DYLD event subsystem · [DC0016 - Module Load](../Data%20Components/DC0016%20-%20Module%20Load.md)
- **fs:fsusage** — File Access Monitor · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **macos:osquery** — Memory Mappings · [DC0020 - Process Modification](../Data%20Components/DC0020%20-%20Process%20Modification.md)

## Mutable elements

- **DYLDInjectedPath** — Tunable based on naming patterns or location of malicious dylibs
- **ParentProcessName** — Hooking attempts may stem from terminal.app, bash, or AppleScript-based launchers
