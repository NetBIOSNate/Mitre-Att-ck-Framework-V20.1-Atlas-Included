# AN0312 - Analytic 0312

[Enterprise](../../README.md) / [Analytics](README.md)

Detection of changes or execution of shell initialization scripts like .bashrc, .profile, or /etc/profile for persistence.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0112#AN0312)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — EXECVE · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **auditd:PATH** — PATH · [DC0059 - File Metadata](../Data%20Components/DC0059%20-%20File%20Metadata.md)
- **linux:osquery** — file_events · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)

## Mutable elements

- **FilePath** — Initialization script path that can differ across user and system profiles.
- **UserContext** — User-level vs root-level configuration.
- **TimeWindow** — Useful to correlate between file change and subsequent execution.
