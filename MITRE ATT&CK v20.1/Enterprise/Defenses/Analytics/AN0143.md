# AN0143 - Analytic 0143

[Enterprise](../../README.md) / [Analytics](README.md)

Detect sudo activity with NOPASSWD in /etc/sudoers or disabling tty_tickets, followed by immediate privileged commands (e.g., echo 'Defaults !tty_tickets' >> /etc/sudoers).

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0052#AN0143)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — exec or sudo usage with NOPASSWD context or echo modifying sudoers · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **macos:unifiedlog** — Terminal process killed (killall Terminal) immediately after sudoers modification · [DC0033 - Process Termination](../Data%20Components/DC0033%20-%20Process%20Termination.md)

## Mutable elements

- **admin_user_context** — Define allowed users who may modify sudoers without investigation
- **terminal_restart_window** — Time window after sudoers file change to monitor for Terminal restarts
