# AN0867 - Analytic 0867

[Enterprise](../../README.md) / [Analytics](README.md)

Detects use of `dseditgroup` or `dscl` to add users to privileged macOS groups (e.g., admin).

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0310#AN0867)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Process execution or directory service changes · [DC0010 - User Account Modification](../Data%20Components/DC0010%20-%20User%20Account%20Modification.md)

## Mutable elements

- **GroupName** — Focus on 'admin' or 'com.apple.access_ssh'
- **UserContext** — Detect unknown or transient users making group changes
- **TimeWindow** — Detect group modifications at suspicious times

## Detection strategies

- [DET0310 - Suspicious Addition to Local or Domain Groups](../Detection%20Strategies/DET0310%20-%20Suspicious%20Addition%20to%20Local%20or%20Domain%20Groups.md)
