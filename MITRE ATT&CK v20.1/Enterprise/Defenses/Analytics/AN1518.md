# AN1518 - Analytic 1518

[Enterprise](../../README.md) / [Analytics](README.md)

Access to user private key directories (e.g., /Users/*/.ssh) via Terminal, scripting engines, or non-default processes.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0549#AN1518)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — open/read access to private key files (id_rsa, *.pem, *.p12) · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **macos:unifiedlog** — launch of bash/zsh/python/osascript targeting key file locations · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **ProcessName** — Processes reading key files (osascript, python, bash, etc.)
- **FileAccessPath** — Private key and certificate paths like /Users/*/.ssh, /Library/Keychains/
