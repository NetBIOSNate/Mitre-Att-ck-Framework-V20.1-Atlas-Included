# AN1244 - Analytic 1244

[Enterprise](../../README.md) / [Analytics](README.md)

Detect user-initiated kextload commands or modifications to /Library/Extensions. Correlate with changes to KextPolicy database or unauthorized developer signing identities. Alert on attempts to disable SIP or load legacy extensions from unsigned sources.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0450#AN1244)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — kextload execution from Terminal or suspicious paths · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **macos:osquery** — Processes executing kextload, spctl, or modifying kernel extension directories · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:osquery** — New kext entries not signed by Apple or outside standard identifier prefix · [DC0031 - Kernel Module Load](../Data%20Components/DC0031%20-%20Kernel%20Module%20Load.md)
- **macos:osquery** — Modifications to /var/db/SystemPolicyConfiguration/KextPolicy or kext_policy table · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)

## Mutable elements

- **DeveloperIDAllowlist** — Approved developer IDs whose kexts should not trigger alerts
- **KextLoadTimeWindow** — Threshold for detecting kext loads outside standard install/update operations
- **SignatureCheckFlag** — Flag to enforce strict signing checks depending on SIP status
