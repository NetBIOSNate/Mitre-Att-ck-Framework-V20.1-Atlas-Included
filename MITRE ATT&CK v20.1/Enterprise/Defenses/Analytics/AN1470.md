# AN1470 - Analytic 1470

[Enterprise](../../README.md) / [Analytics](README.md)

Cloud API usage to create/import SSH keys or generate new access keys (CreateAccessKey, ImportKeyPair, CreateLoginProfile) from non-console access or unusual principals.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0531#AN1470)

**Platforms**  [IaaS](../../Platforms/IaaS.md)

## Log sources and channels

- **AWS:CloudTrail** — CreateAccessKey, ImportKeyPair, CreateLoginProfile, CreateKeyPair · [DC0087 - Active Directory Object Creation](../Data%20Components/DC0087%20-%20Active%20Directory%20Object%20Creation.md)
- **gcp:audit** — iam.serviceAccounts.keys.create, os-login.sshPublicKeys.add · [DC0010 - User Account Modification](../Data%20Components/DC0010%20-%20User%20Account%20Modification.md)

## Mutable elements

- **CallerIdentityContext** — Track root, federated identities, and STS tokens separately.
- **NewCredentialUsageWindow** — Time between key creation and first use (default: 5 min).
- **IAMRoleBaseline** — Expected services/accounts allowed to create keys.
