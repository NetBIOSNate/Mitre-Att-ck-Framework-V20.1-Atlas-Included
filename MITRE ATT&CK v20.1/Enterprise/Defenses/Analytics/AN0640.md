# AN0640 - Analytic 0640

[Enterprise](../../README.md) / [Analytics](README.md)

CLI-based or API-based network call from the hypervisor to external staging host, shortly followed by a connection to a second external IP by a spawned process or scheduled task.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0228#AN0640)

**Platforms**  [ESXi](../../Platforms/ESXi.md)

## Log sources and channels

- **esxi:hostd** — CLI network calls · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **esxi:cron** — process or cron activity · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **ScheduledTaskName** — Detect unknown or obfuscated task names launching follow-up stages
- **DestinationIP** — Scope multiple IP destinations outside corporate ranges in short sequence
