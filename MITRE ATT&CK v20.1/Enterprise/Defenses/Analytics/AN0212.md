# AN0212 - Analytic 0212

[Enterprise](../../README.md) / [Analytics](README.md)

Execution of file transfer or network access activity through non-primary interfaces (e.g., WiFi, Bluetooth, cellular) by processes not typically associated with such behavior (e.g., rundll32, powershell, regsvr32).

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0077#AN0212)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=3, 22 · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **WinEventLog:System** — EventCode=5005 (WLAN), EventCode=302 (Bluetooth) · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **WinEventLog:Sysmon** — EventCode=11 · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)

## Mutable elements

- **InterfaceType** — Filter for specific interface categories (e.g., WiFi, Bluetooth, 4G).
- **FileSizeThreshold** — Tunable for environment-specific large file access events pre-transfer.
- **TimeWindow** — Temporal correlation window for file read followed by network activity.
