# AN0419 - Analytic 0419

[Enterprise](../../README.md) / [Analytics](README.md)

Forged SAML tokens in IaaS environments often manifest as cross-cloud or cross-account authentication without matching STS events. Defenders may see AssumeRole or GetFederationToken API usage without a corresponding SAML assertion log from the trusted IdP.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0148#AN0419)

**Platforms**  [IaaS](../../Platforms/IaaS.md)

## Log sources and channels

- **AWS:CloudTrail** — AssumeRoleWithSAML · [DC0007 - Web Credential Usage](../Data%20Components/DC0007%20-%20Web%20Credential%20Usage.md)
- **CloudTrail:Signin** — SAML login without corresponding IdP authentication log · [DC0067 - Logon Session Creation](../Data%20Components/DC0067%20-%20Logon%20Session%20Creation.md)

## Mutable elements

- **CrossAccountUsage** — Flag SAML tokens used across unexpected accounts or cloud tenants.
