# AN1310 - Analytic 1310

[Enterprise](../../README.md) / [Analytics](README.md)

Detects file access to mbox/maildir files in conjunction with curl/wget/postfix execution, or anomalous shell scripts harvesting user mail directories.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0476#AN1310)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — open · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **linux:syslog** — postfix/smtpd · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **linux:osquery** — process_events · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **WatchedMailDirs** — Specify user mail directories (/var/mail, ~/Maildir)
- **ProcessNameList** — Tune based on local mail clients or curl usage in environment
- **TimeWindow** — Define how close together access and exfil events must occur
