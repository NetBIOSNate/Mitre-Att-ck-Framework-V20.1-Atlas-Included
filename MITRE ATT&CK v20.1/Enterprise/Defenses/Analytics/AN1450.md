# AN1450 - Analytic 1450

[Enterprise](../../README.md) / [Analytics](README.md)

Remote knock sequence followed by PF/socketfilterfw rule update or a background process listening on a new port; then a successful TCP session. Also flags WoL magic packets on local segment.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0524#AN1450)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — exec: Execution of /sbin/pfctl, /usr/libexec/ApplicationFirewall/socketfilterfw, ifconfig, tcpdump, npcap/libpcap consumers · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:unifiedlog** — Firewall rule enable/disable or listen socket changes · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **NSM:Flow** — Closed-port hits followed by success from same src_ip · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **PFAnchorPaths** — Anchors or conf files monitored for change (/etc/pf.conf, /etc/pf.anchors/*).
- **DeveloperMode** — Reduce noise on dev endpoints compiling or testing PF rules.
