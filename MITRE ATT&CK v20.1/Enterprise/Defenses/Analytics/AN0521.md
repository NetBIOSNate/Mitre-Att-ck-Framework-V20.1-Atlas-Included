# AN0521 - Analytic 0521

[Enterprise](../../README.md) / [Analytics](README.md)

Detects deletion or overwriting of bash history, syslog, audit logs, and .ssh metadata following privilege elevation or suspicious process spawning.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0184#AN0521)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — unlink, rename, open · [DC0040 - File Deletion](../Data%20Components/DC0040%20-%20File%20Deletion.md)
- **linux:cli** — cleared or truncated .bash_history · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **MonitoredPaths** — Adjust based on syslog/auditd file paths (/var/log/messages, /var/log/audit/audit.log)
- **UserContext** — Scope to root/sudo usage or anomalous user behavior
