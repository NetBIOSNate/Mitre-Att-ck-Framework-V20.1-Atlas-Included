# AN0889 - Analytic 0889

[Enterprise](../../README.md) / [Analytics](README.md)

Modification of container runtime security profiles (AppArmor, seccomp) or removal of monitoring agents within containers. Detect unauthorized mounting/unmounting of host /proc or /sys to disable logging or auditing.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0317#AN0889)

**Platforms**  [Containers](../../Platforms/Containers.md)

## Log sources and channels

- **kubernetes:audit** — seccomp or AppArmor profile changes · [DC0041 - Service Metadata](../Data%20Components/DC0041%20-%20Service%20Metadata.md)
- **docker:runtime** — Termination of monitoring sidecar or security container · [DC0033 - Process Termination](../Data%20Components/DC0033%20-%20Process%20Termination.md)

## Mutable elements

- **RuntimeProfiles** — Specify which security profiles should be monitored for modification.
