# AN0623 - Analytic 0623

[Enterprise](../../README.md) / [Analytics](README.md)

Detects SCCM, Intune, or remote push execution spawning scripts or binaries from SYSTEM context or unusual consoles (e.g., cmtrace.exe launching PowerShell or cmd.exe).

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0223#AN0623)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — EventCode=4688 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Application** — SCCM, Intune logs · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **ParentImageList** — Allowlist of known SCCM-related binary spawners (e.g., 'CCMExec.exe')
- **UserContext** — Expected deployment activity from scheduled system accounts
- **TimeWindow** — Unusual deployment timing outside standard maintenance hours
