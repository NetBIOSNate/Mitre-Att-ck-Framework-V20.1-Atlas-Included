# AN0734 - Analytic 0734

[Enterprise](../../README.md) / [Analytics](README.md)

Detects JavaScript for Automation (JXA) via osascript or compiled scripts using OSAKit APIs. Flags execution involving system modification, inter-process scripting, or browser abuse.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0264#AN0734)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — log stream with predicate 'eventMessage CONTAINS "osascript"' · [DC0029 - Script Execution](../Data%20Components/DC0029%20-%20Script%20Execution.md)
- **macos:osquery** — process_events · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:syslog** — /var/log/system.log · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **ScriptLocation** — Execution of JXA from user-controlled paths like ~/Downloads or /Volumes.
- **ParentProcess** — osascript invoked by third-party apps (VSCode, browsers, etc.).
- **APIInvocation** — Use of OSAKit API by apps not typically scripting-enabled.
