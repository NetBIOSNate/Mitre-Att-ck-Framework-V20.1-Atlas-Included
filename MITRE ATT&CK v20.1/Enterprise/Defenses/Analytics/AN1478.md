# AN1478 - Analytic 1478

[Enterprise](../../README.md) / [Analytics](README.md)

Detects unauthorized Wi-Fi associations and SSID scanning activity using unified logs and airport command telemetry. Anomalies include rapid SSID switching, connections to unapproved SSIDs, or repeated authentication failures.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0536#AN1478)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Association and authentication events including failures and new SSIDs · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **macos:osquery** — query: Historical list of associated SSIDs compared against baseline · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **BaselineSSIDHistory** — Historical record of corporate SSID associations per device; deviations may indicate rogue AP usage.
