# AN1247 - Analytic 1247

[Enterprise](../../README.md) / [Analytics](README.md)

Detection monitors extended attribute manipulation (xattr) to strip quarantine or trust metadata, anomalous installation of root certificates in /etc/ssl or /usr/local/share/ca-certificates, and unauthorized modification of system trust stores. Correlates with unexpected process execution involving package managers or custom certificate utilities.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0452#AN1247)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — chmod, chown, setxattr, or file writes to /etc/ssl/* or /usr/local/share/ca-certificates/* · [DC0059 - File Metadata](../Data%20Components/DC0059%20-%20File%20Metadata.md)
- **auditd:EXECVE** — Process execution of update-ca-certificates or openssl with suspicious arguments · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **CertificatePathList** — Paths to monitor for changes depending on distro-specific trust locations
- **RegexPatterns** — Regex patterns for suspicious use of xattr or openssl parameters
