# AN0116 - Analytic 0116

[Enterprise](../../README.md) / [Analytics](README.md)

Detects adversary removal of persistence implants (e.g., rc.local entries or crontab injections) via CLI (`rm`, `sed`, `crontab -r`) and deletion of startup or management scripts.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0040#AN0116)

**Platforms**  [ESXi](../../Platforms/ESXi.md)

## Log sources and channels

- **esxi:vmkernel** — /var/log/vmkernel.log · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **esxi:shell** — shell history · [DC0040 - File Deletion](../Data%20Components/DC0040%20-%20File%20Deletion.md)

## Mutable elements

- **ScriptRemovalPath** — e.g., /etc/rc.local, /etc/init.d/custom.sh
- **StartupEntryClearance** — Wipe or truncate of persistence locations
