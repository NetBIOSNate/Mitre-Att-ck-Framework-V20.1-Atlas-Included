# AN0246 - Analytic 0246

[Enterprise](../../README.md) / [Analytics](README.md)

Keylogging on legacy network devices via unauthorized system image modification or remote capture of console keystrokes (telnet, SSH) through altered firmware or man-in-the-middle key sniffing.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0089#AN0246)

**Platforms**  [Network Devices](../../Platforms/Network%20Devices.md)

## Log sources and channels

- **networkdevice:syslog** — Image Upgrade / Configuration Change · [DC0004 - Firmware Modification](../Data%20Components/DC0004%20-%20Firmware%20Modification.md)
- **NSM:Flow** — packet capture or DPI logs · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **FirmwareVersion** — Baseline hash or expected version for config/image integrity
- **Protocol** — Scope to plaintext channels or low-assurance SSH versions
