# AN0720 - Analytic 0720

[Enterprise](../../README.md) / [Analytics](README.md)

On Linux systems, forged credentials may be injected into browser session files, curl/wget headers, or token caches in memory. Detection can leverage auditd to track processes accessing sensitive files (~/.mozilla, ~/.config/chromium, ~/.aws/credentials) and correlate with suspicious outbound connections.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0260#AN0720)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — Processes reading credential or token cache files · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **WinEventLog:Sysmon** — Outbound requests with forged tokens/cookies in headers · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements
