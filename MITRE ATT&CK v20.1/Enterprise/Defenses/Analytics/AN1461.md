# AN1461 - Analytic 1461

[Enterprise](../../README.md) / [Analytics](README.md)

Execution of files containing right-to-left override characters (U+202E) to masquerade true file extensions. Often found in phishing payloads or file downloads.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0527#AN1461)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:PowerShell** — EventCode=4103, 4104, 4105, 4106 · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **WinEventLog:Windows Defender** — Operational · [DC0059 - File Metadata](../Data%20Components/DC0059%20-%20File%20Metadata.md)

## Mutable elements

- **FilenamePattern** — RTLO variants such as \u202E, %E2%80%AE, or byte-encoded forms
- **ExecutionContext** — Allows tuning for untrusted sources, e.g., browser downloads or email attachments
- **TimeWindow** — Defines correlation between file creation and process execution
