# AN0349 - Analytic 0349

[Enterprise](../../README.md) / [Analytics](README.md)

Unusual modification or creation of loginwindow-related plist files in '~/Library/Preferences/ByHost' correlated with unauthorized application paths and execution upon login.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0125#AN0349)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Execution of process launched via loginwindow session restore · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **fs:filesystem** — Modification or creation of files matching 'com.apple.loginwindow.*.plist' in ~/Library/Preferences/ByHost · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)
- **macos:unifiedlog** — LoginWindow context with associated PID linked to reopened plist paths · [DC0088 - Logon Session Metadata](../Data%20Components/DC0088%20-%20Logon%20Session%20Metadata.md)
- **macos:endpointsecurity** — es_event_file_rename_t or es_event_file_write_t · [DC0059 - File Metadata](../Data%20Components/DC0059%20-%20File%20Metadata.md)

## Mutable elements

- **UserContext** — Restrict to targeted users or unexpected users writing to plist
- **FilePathPattern** — Allow tuning for alternative persistence paths or directory redirection
- **TimeWindow** — Correlate plist write and process execution within logon window
- **BinaryAnomalyScore** — Optional scoring of launched binary based on code signing, entropy, and known safe apps
