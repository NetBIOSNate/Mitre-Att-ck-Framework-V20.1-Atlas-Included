# AN0229 - Analytic 0229

[Enterprise](../../README.md) / [Analytics](README.md)

Adversary modifies internal UI messages (e.g., login banners, desktop wallpapers) or hosted intranet web pages by creating or altering content files using scripts or unauthorized access. Often preceded by privilege escalation or web shell deployment.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0082#AN0229)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — EventCode=4663, 4670, 4656 · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **WinEventLog:Sysmon** — EventCode=11 · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=2 · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **FilePathPattern** — Location of web content or system UI config files that may vary across deployments (e.g., %SystemRoot%\Web, %APPDATA%\wallpaper.jpg)
- **TimeWindow** — Allowed hours for file/content modification events; defacement likely occurs during off-hours
- **UserContext** — System or domain accounts used to perform the modifications may be anomalous
