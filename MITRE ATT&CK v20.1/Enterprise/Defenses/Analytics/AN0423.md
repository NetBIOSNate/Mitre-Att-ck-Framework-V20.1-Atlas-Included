# AN0423 - Analytic 0423

[Enterprise](../../README.md) / [Analytics](README.md)

Detects data access or staging events followed by outbound data flows using unencrypted protocols (e.g., FTP, HTTP) initiated by unexpected processes or to rare destinations.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0149#AN0423)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=3, 22 · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Security** — EventCode=4663, 4670, 4656 · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **NSM:Flow** — http.log, ftp.log · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **UnencryptedProtocolList** — Set of protocols considered suspicious for outbound data exfiltration (e.g., FTP, HTTP).
- **DataTransferSizeThreshold** — Defines what amount of outbound data is considered abnormal for a host/user.
- **ParentProcessDenylist** — Processes that should not launch FTP/HTTP clients (e.g., winword.exe launching ftp.exe).
