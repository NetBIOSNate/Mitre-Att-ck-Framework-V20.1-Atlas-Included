# AN0950 - Analytic 0950

[Enterprise](../../README.md) / [Analytics](README.md)

Detects modification of system or application binaries by monitoring /usr/bin, /bin, and other privileged directories. Correlates file integrity monitoring (FIM) events with unexpected process executions or service restarts.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0336#AN0950)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — open, write · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)
- **auditd:EXECVE** — execve · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **WatchedDirectories** — Customize monitored directories (e.g., /usr/bin, /usr/sbin, /opt/apps) for binary tampering
- **BaselineHashes** — Maintain golden file hashes for integrity validation
