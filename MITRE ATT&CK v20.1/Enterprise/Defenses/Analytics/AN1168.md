# AN1168 - Analytic 1168

[Enterprise](../../README.md) / [Analytics](README.md)

Automated abuse of cloud-hosted applications (e.g., web apps, REST endpoints, internal APIs) causing compute exhaustion, high 5xx error rates, or frequent autoscaling triggers logged in app insights or cloudwatch.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0415#AN1168)

**Platforms**  [IaaS](../../Platforms/IaaS.md)

## Log sources and channels

- **AWS:CloudWatch** — Elevated 5xx response rates in application logs or gateway layer · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **AWS:CloudTrail** — InvokeFunction · [DC0070 - Cloud Service Metadata](../Data%20Components/DC0070%20-%20Cloud%20Service%20Metadata.md)
- **AWS:CloudMetrics** — Autoscaling, memory/cpu alarms, or instance unhealthiness · [DC0018 - Host Status](../Data%20Components/DC0018%20-%20Host%20Status.md)

## Mutable elements

- **HTTP5xxRateThreshold** — Ratio of 5xx error codes over requests indicating resource exhaustion.
- **FunctionInvocationRate** — Spike in lambda/API gateway executions indicating scripted behavior.
- **AutoscaleEventCount** — Triggers linked to app DoS where legitimate scaling is mimicked.
