# AN0718 - Analytic 0718

[Enterprise](../../README.md) / [Analytics](README.md)

Forged web credentials may manifest as anomalous SAML token issuance, OpenID Connect token minting, or Zimbra pre-auth key usage. Defenders may see tokens issued without normal authentication events, multiple valid tokens generated simultaneously, or signing anomalies in IdP logs.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0260#AN0718)

**Platforms**  [Identity Provider](../../Platforms/Identity%20Provider.md)

## Log sources and channels

- **azure:signinlogs** — SAML/OIDC tokens issued without corresponding MFA or password validation · [DC0006 - Web Credential Creation](../Data%20Components/DC0006%20-%20Web%20Credential%20Creation.md)
- **NSM:Connections** — Pre-authentication keys generated or token signing anomalies · [DC0007 - Web Credential Usage](../Data%20Components/DC0007%20-%20Web%20Credential%20Usage.md)

## Mutable elements

- **TokenLifetimeThreshold** — Limit the maximum time temporary tokens are valid.
- **ExpectedAuthFlows** — Define normal authentication flows (e.g., password+MFA) to baseline token issuance.
