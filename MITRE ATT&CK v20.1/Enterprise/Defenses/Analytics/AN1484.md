# AN1484 - Analytic 1484

[Enterprise](../../README.md) / [Analytics](README.md)

sshd, socat, or custom binaries initiating port forwarding or encapsulating traffic (e.g., RDP, SMB) through SSH or HTTP. Defender sees abnormal connect/bind syscalls, encrypted traffic on ports typically used for non-encrypted services, and outlier traffic volume patterns.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0538#AN1484)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — socket/connect calls showing SSH processes forwarding arbitrary ports · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **linux:syslog** — sshd sessions with unusual port forwarding parameters · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **linux:osquery** — socat, ssh, or nc processes opening unexpected ports · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **ForwardingFlags** — Specific sshd config flags indicating port forwarding.
- **ProtocolBaseline** — Define expected application protocols by port to catch tunneling mismatches.
