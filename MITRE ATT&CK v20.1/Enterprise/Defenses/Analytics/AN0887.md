# AN0887 - Analytic 0887

[Enterprise](../../README.md) / [Analytics](README.md)

Execution of commands that stop or kill processes associated with logging or security daemons (auditd, syslog, falco). Detect modifications to iptables or disabling SELinux/AppArmor enforcement. Correlate sudo/root context with abrupt service halts.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0317#AN0887)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:EXECVE** — systemctl stop auditd, kill -9 <pid>, or modifications to /etc/selinux/config · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **auditd:SYSCALL** — kill syscalls targeting logging/security processes · [DC0033 - Process Termination](../Data%20Components/DC0033%20-%20Process%20Termination.md)
- **linux:syslog** — iptables or nftables rule changes · [DC0051 - Firewall Rule Modification](../Data%20Components/DC0051%20-%20Firewall%20Rule%20Modification.md)

## Mutable elements

- **ServiceList** — Adjust monitored security service names depending on host configuration.
- **TimeWindow** — Correlate multiple kill/stop events in short succession.
