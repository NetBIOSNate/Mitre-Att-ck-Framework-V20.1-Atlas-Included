# AN2064 - Analytic 2064

[Enterprise](../../README.md) / [Analytics](README.md)

Detection identifies execution of scripts containing high concentrations of invisible Unicode characters followed by decoding or interpretation behaviors (e.g., base64 decode, eval) and subsequent process or network activity. Emphasis is placed on mismatch between file entropy/structure and execution output.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0920#AN2064)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — stat and lstat syscall results on files, including inode and permission info · [DC0059 - File Metadata](../Data%20Components/DC0059%20-%20File%20Metadata.md)
- **auditd:EXECVE** — execve of script/interpreter (bash, python, node) with suspicious encoded or non-printable content · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **DecodeUtility** — May include base64
- **EntropyThreshold** — Useful for tuning sections containing high entropy indicative of Unicode sequences
