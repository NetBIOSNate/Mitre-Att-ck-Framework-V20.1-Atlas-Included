# AN0251 - Analytic 0251

[Enterprise](../../README.md) / [Analytics](README.md)

Installation or execution of a malicious browser or IDE extension, followed by abnormal registry entries or outbound network connections from the host application

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0092#AN0251)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — EventCode=4688 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=11 · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=13, 14 · [DC0063 - Windows Registry Key Modification](../Data%20Components/DC0063%20-%20Windows%20Registry%20Key%20Modification.md)
- **WinEventLog:Sysmon** — EventCode=3, 22 · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **Image** — Path of browser or IDE launching subprocesses—may vary depending on installed applications
- **ParentImage** — Legitimate parent-child process relationships for known safe extensions
- **RegistryPath** — Expected registry keys under HKCU/HKLM for installed extensions
- **TimeWindow** — Tunable interval to correlate extension install with follow-on C2 traffic
