# AN0707 - Analytic 0707

[Enterprise](../../README.md) / [Analytics](README.md)

Detect abnormal access to unified logs via log show or fs_usage targeting system log files. Monitor for execution of shell utilities (cat, grep) against /var/log/system.log and for plist modifications enabling verbose logging.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0255#AN0707)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Execution of log show, fs_usage, or cat targeting system.log · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **macos:unifiedlog** — open: Access to /var/log/system.log or related security event logs · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)

## Mutable elements

- **DebugToolsContext** — Allowlist developers or administrators expected to review logs during debugging.
