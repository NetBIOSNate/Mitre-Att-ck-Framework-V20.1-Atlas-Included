# AN0304 - Analytic 0304

[Enterprise](../../README.md) / [Analytics](README.md)

Processes use built-in encoding utilities (e.g., `base64`, `xxd`, or `plutil`) to encode file contents followed by HTTP/HTTPS transfer via curl or custom applications.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0108#AN0304)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — base64 or curl processes chained within short execution window · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **macos:unifiedlog** — HTTP POST with encoded content in user-agent or cookie field · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **EncodedCommandLengthThreshold** — Minimum byte size of encoded strings to treat as suspicious
- **SuspiciousProcessChainDepth** — Number of chained processes within a short window to treat as a correlated behavior
