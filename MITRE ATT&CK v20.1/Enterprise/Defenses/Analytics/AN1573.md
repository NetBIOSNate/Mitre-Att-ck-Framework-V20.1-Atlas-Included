# AN1573 - Analytic 1573

[Enterprise](../../README.md) / [Analytics](README.md)

Applications or scripts invoking cloud storage APIs (Dropbox sync, iCloud, Google Drive client) in unexpected contexts. Defender perspective: detect sensitive file reads by non-standard applications followed by unusual encrypted uploads to external cloud storage domains.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0570#AN1573)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — execution of curl, rclone, or Office apps invoking network sessions · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:unifiedlog** — file read of sensitive directories · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **macos:unifiedlog** — outbound HTTPS connections to cloud storage APIs · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **WatchedApps** — Track processes that normally should not upload data (e.g., Preview, Calculator).
- **EntropyThreshold** — High-entropy file uploads may indicate encrypted payloads designed for exfiltration.
