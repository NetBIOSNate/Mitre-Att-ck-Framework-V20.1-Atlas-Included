# AN0706 - Analytic 0706

[Enterprise](../../README.md) / [Analytics](README.md)

Monitor for suspicious use of commands such as cat, less, grep, or journalctl accessing /var/log/ files. Abnormal enumeration of authentication logs (auth.log, secure) or bulk access to multiple logs in short time windows should be flagged.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0255#AN0706)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve: Execution of cat, less, grep, journalctl targeting log directories (/var/log/) · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **auditd:PATH** — open: Access to sensitive log files (/var/log/auth.log, /var/log/secure, /var/log/syslog) · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)

## Mutable elements

- **AdminMaintenanceScripts** — Filter routine scripts used for log rotation or troubleshooting.
