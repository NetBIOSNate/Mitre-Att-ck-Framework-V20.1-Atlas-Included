# AN0850 - Analytic 0850

[Enterprise](../../README.md) / [Analytics](README.md)

Exploitation of system or application vulnerability (e.g., CVE-based exploit) followed by service crash, restart, or repeated failure within a short time frame, impacting application/system availability.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0304#AN0850)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Application** — EventCode=1000 · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:System** — EventCode=7031, 7034 · [DC0060 - Service Creation](../Data%20Components/DC0060%20-%20Service%20Creation.md)

## Mutable elements

- **TimeWindow** — Time window between repeated service crashes or restarts (e.g., 5 crashes within 1 hour)
- **TargetApplication** — Critical applications to monitor based on environment (e.g., web server, database, VPN)
