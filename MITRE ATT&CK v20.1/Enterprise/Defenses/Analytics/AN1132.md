# AN1132 - Analytic 1132

[Enterprise](../../README.md) / [Analytics](README.md)

Unauthorized mirroring sessions initiated on routers/switches (e.g., via `monitor session`, `mirror port`) coupled with outbound traffic from mirrored interface to unexpected destinations.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0403#AN1132)

**Platforms**  [Network Devices](../../Platforms/Network%20Devices.md)

## Log sources and channels

- **networkdevice:syslog** — Config change: CLI/NETCONF/SNMP – 'monitor session', 'mirror port' · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **networkdevice:Flow** — Traffic from mirrored interface to mirror target IP · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **ConfigChangeType** — Tune based on accepted interface config changes (e.g., audit only mirror session creation)
- **MirrorDestinationPort** — Define high-risk ports used for exfil (e.g., 4443, 8443, 2055)
- **DeviceRole** — Define whether mirroring is expected on edge vs core vs distribution devices
