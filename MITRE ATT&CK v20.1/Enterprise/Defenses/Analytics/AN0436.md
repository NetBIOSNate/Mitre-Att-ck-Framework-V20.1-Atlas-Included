# AN0436 - Analytic 0436

[Enterprise](../../README.md) / [Analytics](README.md)

Unusual processes (e.g., powershell.exe, wscript.exe, mshta.exe) posting data to webhook endpoints (Discord, Slack, webhook.site) using HTTP POST/PUT requests. Defender perspective: suspicious process lineage followed by outbound HTTPS traffic to webhook domains.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0153#AN0436)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=3, 22 · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **WinEventLog:Security** — EventCode=4663, 4670, 4656 · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)

## Mutable elements

- **WebhookDomains** — Domains to monitor such as discord.com/api/webhooks, slack.com/api, webhook.site.
- **UploadSizeThreshold** — Threshold for abnormal data sent via webhook requests.
- **ApprovedApps** — List of approved business apps using webhooks to reduce noise.
