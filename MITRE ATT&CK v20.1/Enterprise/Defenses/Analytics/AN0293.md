# AN0293 - Analytic 0293

[Enterprise](../../README.md) / [Analytics](README.md)

Execution of hash cracking binaries or scripts (e.g., john, hashcat) following access to shadow file or dumped hashes

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0105#AN0293)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **linux:syslog** — auth.log or custom tool logs · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)

## Mutable elements

- **ShadowAccessPattern** — Access to /etc/shadow or known dumped hash files
- **CrackingBinaryPath** — Tool path or name associated with hash cracking
- **CPUUsageThreshold** — Sustained CPU load post-credential dump can be an indicator
