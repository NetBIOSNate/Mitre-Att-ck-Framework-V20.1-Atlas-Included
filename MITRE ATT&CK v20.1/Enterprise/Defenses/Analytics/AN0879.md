# AN0879 - Analytic 0879

[Enterprise](../../README.md) / [Analytics](README.md)

Detects execution of capture commands via CLI (`monitor capture`, `debug packet`, etc.) or unauthorized CLI access followed by logging configuration changes on Cisco/Juniper/Arista gear.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0314#AN0879)

**Platforms**  [Network Devices](../../Platforms/Network%20Devices.md)

## Log sources and channels

- **networkdevice:syslog** — admin login events · [DC0002 - User Account Authentication](../Data%20Components/DC0002%20-%20User%20Account%20Authentication.md)
- **networkdevice:syslog** — exec command='monitor capture' · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **networkdevice:syslog** — config change (e.g., logging buffered, pcap buffers) · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **AdminSessionDuration** — Tunable alerting threshold for interactive CLI sessions.
- **CaptureCommandList** — Define set of known capture/debug commands per vendor to flag unexpected usage.
