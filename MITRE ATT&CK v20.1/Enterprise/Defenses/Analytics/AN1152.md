# AN1152 - Analytic 1152

[Enterprise](../../README.md) / [Analytics](README.md)

Monitor VM-level DNS and network traffic logs for adversary-controlled domains or selective response behavior (e.g., dropped requests from security scanners).

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0411#AN1152)

**Platforms**  [ESXi](../../Platforms/ESXi.md)

## Log sources and channels

- **esxi:vmkernel** — DNS lookups resolving to domains with rapid changes in registration metadata · [DC0101 - Domain Registration](../Data%20Components/DC0101%20-%20Domain%20Registration.md)
- **esxi:vmkernel** — Suspicious traffic filtered or redirected by VM networking stack · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **MonitoredVMs** — Targeted virtual machines where adversaries may attempt to hide C2 traffic.
