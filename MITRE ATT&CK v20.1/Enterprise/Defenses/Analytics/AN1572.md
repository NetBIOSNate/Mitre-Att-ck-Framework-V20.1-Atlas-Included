# AN1572 - Analytic 1572

[Enterprise](../../README.md) / [Analytics](README.md)

Processes such as curl, wget, rclone, or custom scripts executing uploads to cloud storage endpoints. Defender perspective: detect chained events where tar/gzip is executed to compress files followed by HTTPS PUT/POST requests to known storage services.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0570#AN1572)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:EXECVE** — curl -T, rclone copy · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **auditd:SYSCALL** — read/open of sensitive file directories · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **NSM:Flow** — large HTTPS outbound uploads · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **AllowedTools** — Known tools used legitimately for backups (rclone, gsutil). Deviations raise suspicion.
- **WorkHours** — Baseline normal data transfer hours to reduce false positives.
