# AN1169 - Analytic 1169

[Enterprise](../../README.md) / [Analytics](README.md)

Detects FTP, SMB, or TFTP traffic initiated by suspicious processes like PowerShell, cmd.exe, or rundll32.exe—especially with large outbound file transfers or unbalanced traffic volume.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0416#AN1169)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=3, 22 · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **NSM:Flow** — ftp.log, smb_files.log · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **ProcessImageFilter** — Limit to non-standard FTP clients or suspicious binaries (e.g., cmd, mshta)
- **DataFlowDirectionThreshold** — Ratio of outbound:inbound bytes; e.g., >90% outbound
- **FilenamePattern** — Suspicious file extensions or naming (e.g., .zip, .rar, random hash names)
