# AN0097 - Analytic 0097

[Enterprise](../../README.md) / [Analytics](README.md)

Monitors execution of ps, top, or launchctl with unusual parent processes or from terminal scripts. Also detects AppleScript-based process listing or `system_profiler SPApplicationsDataType` misuse.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0034#AN0097)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — process launch · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:osquery** — Process Context · [DC0034 - Process Metadata](../Data%20Components/DC0034%20-%20Process%20Metadata.md)

## Mutable elements

- **ParentApp** — Tunable to detect discovery from non-UI tools or script-based execution (osascript, zsh, cron)
