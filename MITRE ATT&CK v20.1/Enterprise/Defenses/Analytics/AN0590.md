# AN0590 - Analytic 0590

[Enterprise](../../README.md) / [Analytics](README.md)

Detection of suspicious logon behavior using valid domain accounts across multiple hosts, off-hours, or simultaneous sessions from geographically distant locations.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0210#AN0590)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — EventCode=4624, 4625, 4768, 4769 · [DC0088 - Logon Session Metadata](../Data%20Components/DC0088%20-%20Logon%20Session%20Metadata.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=3, 22 · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **TimeWindow** — Tune for detection of off-hours or abnormal logon spikes.
- **UserContext** — Scope to sensitive domain accounts (e.g., Domain Admins).
- **LogonType** — Distinguish between interactive, service, and network logons.
