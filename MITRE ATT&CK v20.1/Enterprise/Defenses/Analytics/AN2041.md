# AN2041 - Analytic 2041

[Enterprise](../../README.md) / [Analytics](README.md)

Detects exploitation of cloud-native security boundaries or management components followed by disabled logging, detached agents, changed security groups, policy bypass, or telemetry suppression. Correlates suspicious API activity with reduced control coverage.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0900#AN2041)

**Platforms**  [IaaS](../../Platforms/IaaS.md)

## Log sources and channels

- **AWS:CloudTrail** — StopLogging, DeleteTrail, or DisableSecurityService · [DC0090 - Cloud Service Disable](../Data%20Components/DC0090%20-%20Cloud%20Service%20Disable.md)
- **AWS:CloudTrail** — ModifyInstanceAttribute · [DC0073 - Instance Modification](../Data%20Components/DC0073%20-%20Instance%20Modification.md)
- **AWS:CloudTrail** — AuthorizeSecurityGroupIngress · [DC0051 - Firewall Rule Modification](../Data%20Components/DC0051%20-%20Firewall%20Rule%20Modification.md)

## Mutable elements

- **CriticalTrailList** — Audit trails that must remain enabled
- **ControlChangeWindow** — Time after suspicious API sequence to inspect coverage loss
