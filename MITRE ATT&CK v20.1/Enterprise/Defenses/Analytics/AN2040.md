# AN2040 - Analytic 2040

[Enterprise](../../README.md) / [Analytics](README.md)

Detects crafted activity resulting in crashes or impairment of endpoint security extensions, network filters, launch daemons, or telemetry agents. Correlates process activity, system extension state changes, and telemetry interruption.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0900#AN2040)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Crash or abnormal termination of security agent or system extension host · [DC0034 - Process Metadata](../Data%20Components/DC0034%20-%20Process%20Metadata.md)
- **macos:unifiedlog** — Extension disabled, unloaded, failed to start · [DC0074 - Driver Metadata](../Data%20Components/DC0074%20-%20Driver%20Metadata.md)
- **NSM:Flow** — Traffic spike preceding control crash · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **ExtensionList** — Protected security system extensions
- **CrashBurstThreshold** — Multiple failures in short interval
