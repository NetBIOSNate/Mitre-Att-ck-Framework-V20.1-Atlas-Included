# AN1170 - Analytic 1170

[Enterprise](../../README.md) / [Analytics](README.md)

Detects usage of FTP, SCP, or TFTP by non-interactive shells or automation scripts transferring large data volumes to untrusted IPs.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0416#AN1170)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **NSM:Flow** — ftp.log, conn.log · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **TransferSizeThreshold** — Bytes sent in FTP upload or SCP push
- **CommandLinePatternMatch** — e.g., scp -r /var/log/* or ftp upload scripts
