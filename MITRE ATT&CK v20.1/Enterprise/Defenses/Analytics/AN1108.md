# AN1108 - Analytic 1108

[Enterprise](../../README.md) / [Analytics](README.md)

Unexpected file creation in web directories followed by web server processes (e.g., w3wp.exe) spawning command shells or script interpreters (e.g., cmd.exe, powershell.exe)

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0394#AN1108)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=11 · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Security** — EventCode=4624, 4648 · [DC0067 - Logon Session Creation](../Data%20Components/DC0067%20-%20Logon%20Session%20Creation.md)
- **NSM:Flow** — Inbound HTTP POST with suspicious payload size or user-agent · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **WebRootPath** — Custom web server directory depending on IIS or third-party hosting environment
- **ParentProcess** — Different server binaries (e.g., php-cgi.exe, apache.exe) that may launch scripts
