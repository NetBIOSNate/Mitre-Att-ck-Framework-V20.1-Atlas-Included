# AN0784 - Analytic 0784

[Enterprise](../../README.md) / [Analytics](README.md)

Identifies archive utilities (e.g., ditto, unzip, xar, pkgutil) used to extract payloads to non-standard paths, then correlates with execution or file permission changes (e.g., `chmod +x`) and process spawns from decompressed location.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0281#AN0784)

**Platforms**  [macOS](../../Platforms/macOS.md)

- **macos:unifiedlog** — Process launch · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:unifiedlog** — filesystem events · [DC0059 - File Metadata](../Data%20Components/DC0059%20-%20File%20Metadata.md)
- **fs:fsusage** — file open/write · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)

## Mutable elements

- **DecompressionPathMatch** — Target unusual extraction paths (~/Library/, /tmp/, /private/tmp/)
- **ToolBinaryNames** — List of decompression utilities used in the environment
- **FollowOnExecutionDelta** — Time between decompression and first binary execution
