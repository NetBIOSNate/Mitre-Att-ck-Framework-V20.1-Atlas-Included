# AN0292 - Analytic 0292

[Enterprise](../../README.md) / [Analytics](README.md)

Use of hash-cracking tools (e.g., John the Ripper, Hashcat) after credential dumping, combined with high CPU usage or GPU invocation via unsigned binaries accessing password hash files

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0105#AN0292)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Security** — EventCode=4663, 4670, 4656 · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **WinEventLog:Sysmon** — EventCode=11 · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=10 · [DC0035 - Process Access](../Data%20Components/DC0035%20-%20Process%20Access.md)

## Mutable elements

- **HashToolName** — Match execution against known cracking toolnames like hashcat.exe, john.exe, etc.
- **FilePathIndicators** — Watch for access to common hash dump locations (e.g., SAM, SYSTEM, NTDS.dit)
- **ExecutionContext** — Run context: local interactive user vs. scheduled task or remote session
