# AN0471 - Analytic 0471

[Enterprise](../../README.md) / [Analytics](README.md)

Detects use of `clear history` or `clear logging` commands on network device CLI to remove past activity logs.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0165#AN0471)

**Platforms**  [Network Devices](../../Platforms/Network%20Devices.md)

## Log sources and channels

- **networkdevice:syslog** — CLI command audit · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **CommandPattern** — Support detection of known variants: 'clear history', 'clear logging', etc.
- **DeviceType** — Router, switch, firewall—may have different CLI behaviors.
