# AN0556 - Analytic 0556

[Enterprise](../../README.md) / [Analytics](README.md)

Detect suspicious file creation, modification, or deletion in stored data directories (e.g., `/var/lib/mysql/`, `/var/log/`, mail spools). Identify shell commands interacting directly with structured data files instead of legitimate database utilities.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0193#AN0556)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — open, unlink, rename: File creation or deletion involving critical stored data · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **auditd:SYSCALL** — write: Modification of structured stored data by suspicious processes · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)

## Mutable elements

- **WatchedPaths** — Environment-specific paths where business-critical stored data resides.
- **CommandExclusions** — Legitimate scripts/utilities excluded to minimize false positives.
