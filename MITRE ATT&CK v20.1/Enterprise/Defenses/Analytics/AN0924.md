# AN0924 - Analytic 0924

[Enterprise](../../README.md) / [Analytics](README.md)

AppleScript or terminal sessions launch tools (`curl`, `nc`, `ssh`) to external IPs not commonly accessed. Outbound connections are made by LaunchAgents/LaunchDaemons, often masquerading as system services.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0325#AN0924)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — process logs · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **NSM:Flow** — pf firewall logs · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **macos:osquery** — launchd or network_events · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **LaunchAgentPath** — Detect persistence used to restart proxy after reboot.
- **ExternalPort** — Often high or non-standard ports, configurable for outbound proxy detection.
- **ProcessReputation** — Flag unsigned or anomalous binaries making external connections.
