# AN0128 - Analytic 0128

[Enterprise](../../README.md) / [Analytics](README.md)

Execution of commands to enumerate virtualization-related files or processes (e.g., '/sys/class/dmi/id/product_name', dmesg, lscpu, lspci), or querying hypervisor interfaces prior to malware execution.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0046#AN0128)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve or syscall invoking vm artifact check commands (e.g., dmidecode, lspci, dmesg) · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **auditd:SYSCALL** — sleep function usage or loops (nanosleep, usleep) in scripts · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **TimeWindow** — Duration between VM discovery commands and payload execution
- **CommandArtifactMatchList** — Command-line regex patterns indicative of sandbox evasion (e.g., grep QEMU, strings vmware)
