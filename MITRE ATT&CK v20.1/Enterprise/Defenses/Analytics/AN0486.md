# AN0486 - Analytic 0486

[Enterprise](../../README.md) / [Analytics](README.md)

Forged cookies on macOS may show up as abnormal access to Safari/Chrome cookie databases in ~/Library/Cookies, combined with unexpected logon sessions authenticated by those cookies. Unified Logs may show cookie injection events or abnormal access patterns to Keychain when linked to browser authentication flows.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0171#AN0486)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Abnormal process access to Safari or Chrome cookie storage · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **macos:unifiedlog** — New session initiated using cookies without normal MFA or password validation · [DC0007 - Web Credential Usage](../Data%20Components/DC0007%20-%20Web%20Credential%20Usage.md)

## Mutable elements

- **AuthorizedKeychainApps** — Applications permitted to use Keychain to generate cookies or tokens.
