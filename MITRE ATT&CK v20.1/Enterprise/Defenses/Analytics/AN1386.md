# AN1386 - Analytic 1386

[Enterprise](../../README.md) / [Analytics](README.md)

Hidden files via 'chflags hidden' or Apple-specific attributes, LaunchAgents/LaunchDaemons placed in non-standard hidden directories. Defender view: detect command execution modifying file flags and unusual plist creation in hidden paths.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0502#AN1386)

**Platforms**  [macOS](../../Platforms/macOS.md)

- **macos:unifiedlog** — Creation of LaunchAgents/LaunchDaemons in hidden or non-standard directories · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
