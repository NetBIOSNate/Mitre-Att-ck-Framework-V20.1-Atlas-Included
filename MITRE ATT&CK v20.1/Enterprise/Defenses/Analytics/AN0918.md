# AN0918 - Analytic 0918

[Enterprise](../../README.md) / [Analytics](README.md)

Detection of EFI/firmware manipulation attempts via abnormal driver loads, unsigned kexts, or tampered NVRAM variables associated with component firmware configuration.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0323#AN0918)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Firmware update events or kernel extension (kext) loads not signed by Apple · [DC0004 - Firmware Modification](../Data%20Components/DC0004%20-%20Firmware%20Modification.md)

## Mutable elements

- **ApprovedKextList** — List of trusted and signed kexts permitted in production systems
- **EFIHashBaseline** — Known-clean EFI image hashes used for verification
