# AN1413 - Analytic 1413

[Enterprise](../../README.md) / [Analytics](README.md)

Detects non-browser processes that establish encrypted outbound connections (e.g., TLS/SSL) to unfamiliar or atypical destinations for the host/user, following a data staging or compression event.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0512#AN1413)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=3, 22 · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Security** — EventCode=4663, 4670, 4656 · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **NSM:Flow** — ssl.log - Certificate Analysis · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **TimeWindow** — Correlates file access, encryption, and network transmission within a timeframe (e.g., 5 minutes).
- **CertificateIssuerDenylist** — Blocks or flags untrusted certificate authorities in SSL/TLS handshakes.
- **BinaryAllowlist** — Whitelist for known-good applications allowed to use encrypted outbound traffic.
