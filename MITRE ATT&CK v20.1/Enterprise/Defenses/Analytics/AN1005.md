# AN1005 - Analytic 1005

[Enterprise](../../README.md) / [Analytics](README.md)

Repeated SSH, VPN, or RDP gateway authentication attempts from external IPs → subsequent successful logon → remote shell or lateral movement activity (e.g., scp/sftp).

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0354#AN1005)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — ssh logins or execve of remote commands · [DC0088 - Logon Session Metadata](../Data%20Components/DC0088%20-%20Logon%20Session%20Metadata.md)
- **NSM:Connections** — Failed password or accepted password for SSH users · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **NSM:Flow** — connection: Inbound connections to SSH or VPN ports · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **KnownSSHClients** — Legitimate IPs or client fingerprints for SSH/VPN.
- **FailedLogonThreshold** — Number of failed SSH logins to trigger alert.
- **TimeWindow** — Correlation window for failed attempts and success.
