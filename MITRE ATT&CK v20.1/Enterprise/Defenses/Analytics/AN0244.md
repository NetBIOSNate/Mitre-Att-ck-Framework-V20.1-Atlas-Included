# AN0244 - Analytic 0244

[Enterprise](../../README.md) / [Analytics](README.md)

Detects non-system processes accessing /dev/input/* or issuing ptrace/evdev syscalls used for reading keystroke buffers directly.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0089#AN0244)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — open, read · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **auditd:SYSCALL** — ptrace, ioctl · [DC0021 - OS API Execution](../Data%20Components/DC0021%20-%20OS%20API%20Execution.md)

## Mutable elements

- **ProcessName** — Exclude known good applications (e.g. Xorg, GNOME Shell)
- **DevicePath** — Typically /dev/input/event*, but tunable to match custom input buses
