# AN0427 - Analytic 0427

[Enterprise](../../README.md) / [Analytics](README.md)

Detects use of unencrypted protocols (e.g., TFTP, FTP, HTTP) to transfer configuration files, routing tables, or logs to untrusted IP addresses, especially using administrative commands like `copy run ftp:`.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0149#AN0427)

**Platforms**  [Network Devices](../../Platforms/Network%20Devices.md)

## Log sources and channels

- **networkdevice:cli** — CLI command logs · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **networkdevice:syslog** — flow records · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **NSM:Flow** — PCAP inspection · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **ProtocolCommandWatchlist** — Flag commands like `copy`, `archive tar`, or `upload` directed at external hosts.
- **DestinationIPBlocklist** — Define external IP ranges unauthorized to receive router/switch configs.
