# AN1023 - Analytic 1023

[Enterprise](../../README.md) / [Analytics](README.md)

Outbound encrypted traffic initiated from hypervisor shell or via VM backdoor mechanisms to relays in VPS infrastructure, especially if traversing multiple nodes before reaching Internet destination. Packet captures or firewall logs show non-VM communication paths.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0359#AN1023)

**Platforms**  [ESXi](../../Platforms/ESXi.md)

## Log sources and channels

- **esxi:esxupdate** — /var/log/esxupdate.log or /var/log/vmksummary.log · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **esxi:vmkernel** — /var/log/vmkernel.log · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **NSM:Flow** — Relay patterns across IP hops · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **HopCount** — Threshold on number of IPs contacted in sequence without DNS resolution.
- **ShellAccess** — Flag if relay communication initiated by ESXi shell or unknown VM agent.
- **VPSIPRange** — Filter for known Tor/VPS egress networks.
