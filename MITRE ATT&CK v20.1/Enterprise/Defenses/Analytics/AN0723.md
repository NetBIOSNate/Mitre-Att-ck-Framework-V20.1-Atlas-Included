# AN0723 - Analytic 0723

[Enterprise](../../README.md) / [Analytics](README.md)

Forged web credentials in Office Suite contexts may appear as abnormal authentication headers in Outlook or Teams traffic, or unexplained OAuth grants in M365/Azure logs. Defenders should correlate token usage events with missing authentication flows and mismatched device/user context.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0260#AN0723)

**Platforms**  [Office Suite](../../Platforms/Office%20Suite.md)

## Log sources and channels

- **m365:oauth** — OAuth grants or tokens issued without expected user consent · [DC0006 - Web Credential Creation](../Data%20Components/DC0006%20-%20Web%20Credential%20Creation.md)
- **m365:signinlogs** — Token usage events with device/user mismatch · [DC0067 - Logon Session Creation](../Data%20Components/DC0067%20-%20Logon%20Session%20Creation.md)

## Mutable elements

- **OAuthAppAllowlist** — Approved OAuth apps and flows; flag unapproved or unexpected token grants.
