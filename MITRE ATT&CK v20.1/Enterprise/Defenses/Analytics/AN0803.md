# AN0803 - Analytic 0803

[Enterprise](../../README.md) / [Analytics](README.md)

Disabling mailbox or tenant-level audit logging, often using Set-MailboxAuditBypassAssociation or downgrading license tiers. Defender view: sudden absence of mailbox activity logging for monitored users.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0289#AN0803)

**Platforms**  [Office Suite](../../Platforms/Office%20Suite.md)

## Log sources and channels

- **m365:unified** — Set-MailboxAuditBypassAssociation or disabling Advanced Auditing · [DC0010 - User Account Modification](../Data%20Components/DC0010%20-%20User%20Account%20Modification.md)

## Mutable elements

- **UserScope** — Tune alerts for users where mailbox auditing should always remain enabled.
