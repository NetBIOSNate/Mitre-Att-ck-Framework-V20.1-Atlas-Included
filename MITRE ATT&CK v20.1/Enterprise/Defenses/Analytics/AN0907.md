# AN0907 - Analytic 0907

[Enterprise](../../README.md) / [Analytics](README.md)

Detects interactive or automated use of CLI commands like `show ip sockets`, `show tcp brief`, or SNMP queries for active sessions on routers/switches.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0320#AN0907)

**Platforms**  [Network Devices](../../Platforms/Network%20Devices.md)

## Log sources and channels

- **networkdevice:cli** — command logs · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **snmp:trap** — management queries · [DC0021 - OS API Execution](../Data%20Components/DC0021%20-%20OS%20API%20Execution.md)

## Mutable elements

- **CommandPatternList** — Monitors for known socket/session query strings.
- **PrivilegedUserCheck** — Restrict detections to non-admin roles executing advanced queries.
