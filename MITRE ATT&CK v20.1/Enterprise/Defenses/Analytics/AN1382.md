# AN1382 - Analytic 1382

[Enterprise](../../README.md) / [Analytics](README.md)

Detects GCC or Clang invoked on suspicious file paths (e.g., /tmp/, ~/Downloads) with output to executable binaries, followed by execution or outbound traffic from these binaries.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0501#AN1382)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **auditd:SYSCALL** — open,create · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **NSM:Flow** — conn.log · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **CompilerBinaryPath** — Specify path and binaries for detection (e.g., `/usr/bin/gcc`, `/opt/mingw/bin/gcc`)
- **FilePermissionProfile** — Match uncommon chmod behavior post-compilation (e.g., +x in `/tmp` or home directories)
