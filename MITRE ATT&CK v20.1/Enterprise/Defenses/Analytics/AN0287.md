# AN0287 - Analytic 0287

[Enterprise](../../README.md) / [Analytics](README.md)

Detects modification of LSASS and authentication DLLs, suspicious registry changes to password filter packages, and abnormal process access to lsass.exe. Correlates registry modifications, DLL loads, and process handle access events.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0104#AN0287)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — EventCode=4657 · [DC0063 - Windows Registry Key Modification](../Data%20Components/DC0063%20-%20Windows%20Registry%20Key%20Modification.md)
- **WinEventLog:Sysmon** — EventCode=10 · [DC0035 - Process Access](../Data%20Components/DC0035%20-%20Process%20Access.md)
- **WinEventLog:Sysmon** — EventCode=7 · [DC0016 - Module Load](../Data%20Components/DC0016%20-%20Module%20Load.md)

## Mutable elements

- **MonitoredRegistryKeys** — Specific LSASS and password filter registry paths monitored for modification.
- **TimeWindow** — Correlation window between registry change, DLL load, and lsass.exe access.
