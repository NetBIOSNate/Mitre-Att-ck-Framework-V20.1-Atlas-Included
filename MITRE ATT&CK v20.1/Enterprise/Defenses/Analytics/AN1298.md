# AN1298 - Analytic 1298

[Enterprise](../../README.md) / [Analytics](README.md)

Detects adversary tampering of shared directories via file drops (e.g., malicious LNK, EXE, VBS) followed by user execution or suspicious network activity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0471#AN1298)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=11 · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **WinEventLog:Security** — EventCode=5145 · [DC0102 - Network Share Access](../Data%20Components/DC0102%20-%20Network%20Share%20Access.md)

## Mutable elements

- **SharedPathPrefix** — Defines monitored shared directories (e.g., \\server\HR\).
- **ExecutableExtensions** — Monitored file types dropped in shared paths (e.g., .lnk, .exe, .vbs).
