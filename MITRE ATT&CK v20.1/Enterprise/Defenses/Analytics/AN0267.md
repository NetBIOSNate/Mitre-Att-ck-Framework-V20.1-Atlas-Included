# AN0267 - Analytic 0267

[Enterprise](../../README.md) / [Analytics](README.md)

Modifications to user accounts via `dscl`, `pwpolicy`, or System Preferences CLI (`sysadminctl`) that alter user groups, enable root, or bypass MDM restrictions.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0096#AN0267)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — com.apple.accountsd, com.apple.opendirectoryd · [DC0010 - User Account Modification](../Data%20Components/DC0010%20-%20User%20Account%20Modification.md)

## Mutable elements

- **ModifiedUserList** — Track known non-system user UIDs or service accounts.
- **GroupMembershipChanges** — List of sensitive groups (admin, _developer, _analyticsd).
