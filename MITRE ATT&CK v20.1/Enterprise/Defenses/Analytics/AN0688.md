# AN0688 - Analytic 0688

[Enterprise](../../README.md) / [Analytics](README.md)

Detection of unauthorized keylogger behavior through access to `/dev/input`, loading kernel modules (e.g., via insmod), or polling user input devices from non-user shells

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0246#AN0688)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **linux:syslog** — syscalls (open, read, ioctl) on /dev/input or /proc/*/fd/* · [DC0035 - Process Access](../Data%20Components/DC0035%20-%20Process%20Access.md)
- **linux:syslog** — dmesg or syslog for module loads · [DC0079 - Driver Load](../Data%20Components/DC0079%20-%20Driver%20Load.md)

## Mutable elements

- **PathTarget** — Can tune based on device paths accessed for keyboard input (e.g., /dev/input/event0)
- **UserContext** — Exclude root or admin-auth shell sessions if needed
- **ModuleWhitelist** — Set a known list of allowed kernel modules
