# AN0059 - Analytic 0059

[Enterprise](../../README.md) / [Analytics](README.md)

Detects modification of shell startup/logout scripts such as ~/.bashrc, ~/.bash_profile, or /etc/profile, followed by anomalous process execution or network connections upon interactive or remote shell login.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0020#AN0059)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — AUDIT_SYSCALL (open, write, rename, unlink) · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)
- **auditd:EXECVE** — execution of unexpected binaries during user shell startup · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **NSM:Flow** — unexpected network activity initiated shortly after shell session starts · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **TimeWindow** — Defines how soon after shell startup process execution or network activity is considered suspicious.
- **TargetUser** — Limits detection to specific user accounts or roles such as root or service accounts.
- **FilePathRegex** — Defines what shell configuration paths are considered relevant (e.g., .bashrc, .bash_logout, etc.)
