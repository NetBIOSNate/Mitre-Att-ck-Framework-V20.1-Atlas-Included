# AN0098 - Analytic 0098

[Enterprise](../../README.md) / [Analytics](README.md)

Detects process enumeration using `esxcli system process list` or `ps` on ESXi shell or via unauthorized SSH sessions. Correlates with interactive sessions and abnormal user roles.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0034#AN0098)

**Platforms**  [ESXi](../../Platforms/ESXi.md)

- **esxi:auth** — user session · [DC0034 - Process Metadata](../Data%20Components/DC0034%20-%20Process%20Metadata.md)

- **User** — Admins are expected to run these commands—flag if non-admin or unknown users do
