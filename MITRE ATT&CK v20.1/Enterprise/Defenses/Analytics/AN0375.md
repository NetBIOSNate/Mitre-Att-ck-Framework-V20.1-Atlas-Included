# AN0375 - Analytic 0375

[Enterprise](../../README.md) / [Analytics](README.md)

Detection of the creation of VSCode or JetBrains CLI tunneling profiles followed by persistent remote access via IDE-integrated tunnels, potentially authenticated via GitHub or JetBrains accounts.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0133#AN0375)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=11 · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **NSM:Flow** — Outbound connection to *.tunnels.api.visualstudio.com or *.devtunnels.ms · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **TimeWindow** — Used to define the temporal proximity between tunnel profile creation and outbound connection.
- **TunnelDomainPatterns** — Domain patterns for tunnel endpoints may change with IDE versions or organizations.
- **AuthorizedUserList** — Helps filter tunnel usage from trusted developer accounts.
