# AN0552 - Analytic 0552

[Enterprise](../../README.md) / [Analytics](README.md)

Alterations to plist configuration files (RulesActiveState.plist, SyncedRules.plist, UnsyncedRules.plist, MessageRules.plist) that define email hiding or filtering rules. Defender perspective: unexpected changes in these files associated with Mail.app processes.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0192#AN0552)

**Platforms**  [macOS](../../Platforms/macOS.md)

- **macos:unifiedlog** — Mail.app executing with parameters updating rules state · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
