# AN1589 - Analytic 1589

[Enterprise](../../README.md) / [Analytics](README.md)

Creation of inbox rules via PowerShell (New-InboxRule) or transport rules using Exchange cmdlets. Correlates user behavior, cmdlet usage, and rule properties.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0576#AN1589)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:PowerShell** — EventCode=4103, 4104, 4105, 4106 · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **WinEventLog:Security** — EventCode=4688 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **m365:exchange** — Cmdlet - New-InboxRule · [DC0070 - Cloud Service Metadata](../Data%20Components/DC0070%20-%20Cloud%20Service%20Metadata.md)

## Mutable elements

- **UserContext** — Certain service accounts or admin contexts may be expected to run these rules.
- **TimeWindow** — Correlate between rule creation and follow-on message forwarding within this timeframe.
- **TargetMailbox** — Whitelisted or trusted destination addresses may be tuned per org policy.
