# AN0284 - Analytic 0284

[Enterprise](../../README.md) / [Analytics](README.md)

Monitors for TCC-bypassing or unauthorized access to input services like IOHIDSystem or Quartz Event Services used in keylogging or screen monitoring.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0102#AN0284)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — subsystem=com.apple.TCC · [DC0034 - Process Metadata](../Data%20Components/DC0034%20-%20Process%20Metadata.md)
- **macos:osquery** — launchd or process_events · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **Service** — com.apple.accessibility, com.apple.quartz, etc. depending on the API path used
- **ParentProcess** — Unusual parent/child pairings can indicate malicious injection
