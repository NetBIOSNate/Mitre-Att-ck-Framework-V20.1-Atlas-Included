# AN0650 - Analytic 0650

[Enterprise](../../README.md) / [Analytics](README.md)

Unsigned processes accessing system memory or launching known credential scraping tools (e.g., osascript, dylib injections) to access the Keychain or sensitive memory regions.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0234#AN0650)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Code Execution & Entitlement Access · [DC0034 - Process Metadata](../Data%20Components/DC0034%20-%20Process%20Metadata.md)
- **macos:keychain** — Access to Keychain DB or system.keychain · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **macos:osquery** — Invocation of osascript or dylib injection · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **KeychainAccessPath** — Path to watch for abnormal access, e.g., /Library/Keychains/
- **SignedBinaryStatus** — Filter out signed/trusted binaries.
