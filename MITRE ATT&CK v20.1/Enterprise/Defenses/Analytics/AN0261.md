# AN0261 - Analytic 0261

[Enterprise](../../README.md) / [Analytics](README.md)

Detects unusual use of `cron` or `sleep` loops inside containers executing unfamiliar scripts or binaries repeatedly.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0094#AN0261)

**Platforms**  [Containers](../../Platforms/Containers.md)

## Log sources and channels

- **auditd:SYSCALL** — execve · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **containerd:runtime** — file change monitoring within /etc/cron.*, /tmp, or mounted volumes · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)

## Mutable elements

- **ContainerLabel** — Labels or tags indicating dev/test containers executing scheduled tasks.
- **ScriptFrequency** — Repetitive invocation pattern within short container lifespan.
- **ImageSource** — Unexpected container image sources creating cron entries.
