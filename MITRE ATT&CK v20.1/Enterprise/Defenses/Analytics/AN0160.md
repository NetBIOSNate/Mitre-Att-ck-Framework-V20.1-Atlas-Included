# AN0160 - Analytic 0160

[Enterprise](../../README.md) / [Analytics](README.md)

Detection of a process or script that accesses a common web service to retrieve content containing obfuscated indicators of a secondary C2 server (dead drop resolver behavior).

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0058#AN0160)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — subsystem: com.apple.network · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **macos:osquery** — process_events/socket_events · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **TargetService** — Known services abused for D2 (e.g., iCloud, Dropbox)
- **UserContext** — Useful to isolate rare users accessing web services for C2
- **TimeWindow** — Max time gap between dead drop resolver fetch and follow-on traffic
