# AN0543 - Analytic 0543

[Enterprise](../../README.md) / [Analytics](README.md)

Detects registry and Group Policy modifications that disable or weaken MFA, suspicious PowerShell usage modifying MFA-related attributes, and anomalous login sessions succeeding without expected MFA challenge.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0190#AN0543)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — EventCode=4739 · [DC0066 - Active Directory Object Modification](../Data%20Components/DC0066%20-%20Active%20Directory%20Object%20Modification.md)
- **WinEventLog:PowerShell** — Set-ADUser or Set-ADAuthenticationPolicy with MFA attributes disabled · [DC0029 - Script Execution](../Data%20Components/DC0029%20-%20Script%20Execution.md)

## Mutable elements

- **WatchedAttributes** — List of AD attributes or policy fields tied to MFA enforcement that may vary by organization.
- **TimeWindow** — Correlation window between MFA policy changes and anomalous login behavior.
