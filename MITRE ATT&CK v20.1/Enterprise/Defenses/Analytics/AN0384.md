# AN0384 - Analytic 0384

[Enterprise](../../README.md) / [Analytics](README.md)

Unusual direct disk access attempts (e.g., use of \\.\PhysicalDrive notation), abnormal writes to MBR/boot sectors, and installation of kernel drivers that grant raw disk access. Correlate anomalous process creation with disk modification attempts and driver loads.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0137#AN0384)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — EventCode=4673 · [DC0013 - User Account Metadata](../Data%20Components/DC0013%20-%20User%20Account%20Metadata.md)
- **WinEventLog:Sysmon** — Raw disk write access via \\.\PhysicalDrive* or \\.\C: · [DC0046 - Drive Modification](../Data%20Components/DC0046%20-%20Drive%20Modification.md)
- **WinEventLog:Sysmon** — EventCode=6 · [DC0079 - Driver Load](../Data%20Components/DC0079%20-%20Driver%20Load.md)

## Mutable elements

- **ProcessWhitelist** — Legitimate disk imaging or backup tools may trigger raw disk access — must be excluded per environment.
- **TimeWindow** — Correlate disk access, driver load, and process execution within a short timeframe to minimize false positives.
