# AN0931 - Analytic 0931

[Enterprise](../../README.md) / [Analytics](README.md)

Remote Desktop (RDP) logon by a user followed by unusual process execution, file access, or lateral movement activity within a short timeframe.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0327#AN0931)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — EventCode=4624, 4648 · [DC0067 - Logon Session Creation](../Data%20Components/DC0067%20-%20Logon%20Session%20Creation.md)
- **WinEventLog:Security** — EventCode=4778, EventCode=4779 · [DC0088 - Logon Session Metadata](../Data%20Components/DC0088%20-%20Logon%20Session%20Metadata.md)
- **WinEventLog:Sysmon** — EventCode=3, 22 · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **TimeWindow** — Temporal threshold to correlate login with post-login activity (e.g., 5 minutes)
- **UserContext** — Tune for non-admin users or service accounts expected to use RDP
- **ProcessList** — Define suspicious post-login processes such as cmd.exe, powershell.exe, certutil.exe
- **HostAccessPatterns** — Scope detection to uncommon or first-time access between source and destination hosts
