# AN0890 - Analytic 0890

[Enterprise](../../README.md) / [Analytics](README.md)

Unusual ESXi shell commands disabling syslog forwarding or stopping hostd/vpxa daemons. Detect modifications to firewall rules on ESXi host or disabling of lockdown mode.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0317#AN0890)

**Platforms**  [ESXi](../../Platforms/ESXi.md)

## Log sources and channels

- **esxi:shell** — esxcli system syslog config set --loghost='' or stopping hostd service · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **esxi:vmkernel** — Disabling or modifying firewall rules · [DC0043 - Firewall Disable](../Data%20Components/DC0043%20-%20Firewall%20Disable.md)

## Mutable elements

- **LogDestination** — Tune for environment-specific log forwarding hosts.
