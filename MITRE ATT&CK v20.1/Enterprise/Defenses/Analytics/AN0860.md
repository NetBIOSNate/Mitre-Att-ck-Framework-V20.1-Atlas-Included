# AN0860 - Analytic 0860

[Enterprise](../../README.md) / [Analytics](README.md)

Access to local credential/config files (e.g., ~/.aws/credentials) followed by metadata API calls or cloud role assumptions.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0307#AN0860)

**Platforms**  [IaaS](../../Platforms/IaaS.md)

## Log sources and channels

- **CloudTrail:GetObject** — sensitive credential files in buckets or local image storage · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **AWS:CloudTrail** — command-line execution invoking credential enumeration · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **AWS:CloudTrail** — sudden role assumption after credential file access · [DC0067 - Logon Session Creation](../Data%20Components/DC0067%20-%20Logon%20Session%20Creation.md)

## Mutable elements

- **CredentialFilePattern** — Regex to match common credential files (e.g., *.aws/credentials, token.txt)
- **RoleAssumptionScope** — Adjust scope of roles monitored (e.g., admin, service accounts)
- **TimeWindow** — Correlation timing between file access and AssumeRole
