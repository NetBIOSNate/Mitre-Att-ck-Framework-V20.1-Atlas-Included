# AN0472 - Analytic 0472

[Enterprise](../../README.md) / [Analytics](README.md)

Adversary registers a malicious Microsoft Exchange transport agent DLL (.NET assembly), configures it via PowerShell or Exchange Management Shell, and persists code execution by manipulating email processing logic based on rules or headers.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0166#AN0472)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:PowerShell** — EventCode=4103, 4104, 4105, 4106 · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **WinEventLog:Sysmon** — EventCode=7 · [DC0016 - Module Load](../Data%20Components/DC0016%20-%20Module%20Load.md)
- **WinEventLog:Application** — Exchange Transport Service loads unusual .NET assembly or errors upon transport agent execution · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **WinEventLog:Sysmon** — EventCode=11 · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)

## Mutable elements

- **TimeWindow** — May need tuning based on frequency of Exchange agent updates in environment.
- **AssemblyPath** — Specific DLL paths used by Exchange for registered agents may vary between deployments.
- **CmdletInvocationThreshold** — Tunable threshold for repeated use of transport agent management cmdlets.
