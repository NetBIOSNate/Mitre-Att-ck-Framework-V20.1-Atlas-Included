# AN1022 - Analytic 1022

[Enterprise](../../README.md) / [Analytics](README.md)

LaunchAgents or LaunchDaemons initiate persistent Tor or relay processes that make encrypted outbound connections. May be paired with sandbox bypasses or unsigned executables communicating over SOCKS proxies.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0359#AN1022)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — process, socket, and DNS logs · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:osquery** — process_events + launchd · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **macos:unifiedlog** — forwarded encrypted traffic · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **LaunchdLabel** — Regex for masking patterns in LaunchAgents with proxy behavior.
- **UnsignedBinary** — Allow for exceptions for known unsigned binaries.
- **SOCKSPortUsage** — Monitor local 9050/9150 activity and rerouted system traffic.
