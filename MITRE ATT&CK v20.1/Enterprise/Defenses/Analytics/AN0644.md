# AN0644 - Analytic 0644

[Enterprise](../../README.md) / [Analytics](README.md)

Monitors Gatekeeper, spctl, and unified log entries for binaries executed with unexpected or untrusted signatures. Correlates file metadata changes with process launches where signature validation is skipped, altered, or fails but the process still executes.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0230#AN0644)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Code signing verification failures or bypassed trust decisions · [DC0059 - File Metadata](../Data%20Components/DC0059%20-%20File%20Metadata.md)
- **macos:unifiedlog** — Execution of binaries with unsigned or anomalously signed certificates · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **DeveloperIDAllowList** — Maintain list of expected Developer IDs to minimize false positives from enterprise apps
- **TimeWindow** — Correlates file signature changes with subsequent executions
