# AN0557 - Analytic 0557

[Enterprise](../../README.md) / [Analytics](README.md)

Monitor sensitive data files such as plist-based storage, mail archives, or Office files for unexpected modifications. Detect anomalous processes modifying stored data outside expected update cycles using FSEvents and Unified Logs.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0193#AN0557)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Unexpected creation or modification of stored data files in protected directories · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)
- **macos:osquery** — CREATE, DELETE, WRITE: Stored data manipulation attempts by unauthorized processes · [DC0040 - File Deletion](../Data%20Components/DC0040%20-%20File%20Deletion.md)

## Mutable elements

- **FileIntegrityBaseline** — Baseline hash values or metadata for stored data files to detect manipulation.
- **AllowedEditors** — Whitelisted applications permitted to update stored data (e.g., Outlook, MySQL).
