# AN0843 - Analytic 0843

[Enterprise](../../README.md) / [Analytics](README.md)

A source performs a short closed-port sequence; the host then modifies iptables/nftables/ufw rules or starts a daemon binding a new socket, followed by a successful connection from the same source.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0302#AN0843)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve: Commands that alter firewall or start listeners: iptables|nft|ufw|firewall-cmd|pfctl|systemctl start sshd/telnet/dropbear; raw-socket/libpcap tools (tcpdump, tshark, nmap --raw). · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **auditd:SYSCALL** — socket/bind: New bind() to a previously closed port shortly after the sequence. · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **NSM:Flow** — Knock pattern: repeated REJ/S0 across ≥MinSequenceLen ports from same src_ip then SF success. · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **ServicePort** — Candidate port expected to open after knock (e.g., 22/2323).
- **KnockTolerance** — Max seconds between hits inside the sequence.
- **MgmtAllowList** — Automation allowed to change firewall/daemon state (config mgmt, orchestration).
