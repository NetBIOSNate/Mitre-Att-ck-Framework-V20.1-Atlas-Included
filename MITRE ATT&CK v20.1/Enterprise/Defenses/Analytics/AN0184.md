# AN0184 - Analytic 0184

[Enterprise](../../README.md) / [Analytics](README.md)

Adversary installs or modifies IIS components (ISAPI filters, extensions, or modules) using DLL files registered via configuration changes or administrative tools like AppCmd.exe. These components intercept or manipulate HTTP requests/responses for persistence or C2.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0068#AN0184)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — EventCode=4663, 4670, 4656 · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)
- **WinEventLog:Sysmon** — EventCode=11 · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=7 · [DC0016 - Module Load](../Data%20Components/DC0016%20-%20Module%20Load.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:System** — Changes to applicationhost.config or DLLs loaded by w3wp.exe · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **WinEventLog:Microsoft-IIS-Configuration** — Module or ISAPI filter registration events · [DC0065 - Service Modification](../Data%20Components/DC0065%20-%20Service%20Modification.md)

## Mutable elements

- **TimeWindow** — Adjustable time frame for detecting chained events (e.g., config change + module load)
- **UserContext** — Scope detection to specific users or roles allowed to modify IIS components
- **WatchedPaths** — Specific directories such as %windir%\System32\inetsrv\ for DLL monitoring
- **DLLNameEntropyThreshold** — Entropy or name patterns to flag suspicious DLLs registered as components
- **ParentProcessName** — Restrict to DLLs loaded by w3wp.exe or invoked via AppCmd.exe
