# AN0001 - Analytic 0001

[Enterprise](../../README.md) / [Analytics](README.md)

Detects access attempts to cloud instance metadata endpoints (e.g., 169.254.169.254) from virtual machines or containerized workloads. This includes both direct access and SSRF exploitation patterns.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0001#AN0001)

**Platforms**  [IaaS](../../Platforms/IaaS.md)

## Log sources and channels

- **AWS:VPCFlowLogs** — Outbound connection to 169.254.169.254 from EC2 workload · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **AWS:CloudTrail** — GetInstanceIdentityDocument · [DC0070 - Cloud Service Metadata](../Data%20Components/DC0070%20-%20Cloud%20Service%20Metadata.md)
- **ebpf:syscalls** — Process within container accesses link-local address 169.254.169.254 · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **TimeWindow** — Adjust temporal window for correlation of access attempts and SSRF triggers
- **UserContext** — Tune based on expected roles that access metadata APIs (e.g., root, service accounts)
- **RequestHeaderMatch** — Customize detection for HTTP Host headers indicating SSRF
