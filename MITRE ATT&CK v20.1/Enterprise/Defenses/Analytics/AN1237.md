# AN1237 - Analytic 1237

[Enterprise](../../README.md) / [Analytics](README.md)

Account creation using 'dscl -create' or via GUI tools. Detection involves command execution and file changes to the local directory services database.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0447#AN1237)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — dscl -create · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **macos:unifiedlog** — modification to /var/db/dslocal/nodes/Default/users/ · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)

## Mutable elements

- **UsernamePattern** — Accounts like 'svc*', 'backup*' may blend into legit naming patterns
- **SessionOrigin** — Identify if dscl was run locally, via ARD, or Terminal.app
