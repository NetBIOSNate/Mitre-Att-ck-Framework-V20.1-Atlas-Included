# AN0134 - Analytic 0134

[Enterprise](../../README.md) / [Analytics](README.md)

Detects deletion or overwriting of logs/configs that store SSH or proxy activity, such as /var/log/auth.log or custom .bash_history clearing tied to SSH sessions or firewall rule changes.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0049#AN0134)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **auditd:SYSCALL** — PATH · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)

## Mutable elements

- **CommandMatchPattern** — Commands like `> /var/log/auth.log`, `rm ~/.bash_history`, `iptables -F`
- **LogPathFilter** — Focus on /var/log/auth.log, /etc/ssh/, ~/.bash_history
