# AN0825 - Analytic 0825

[Enterprise](../../README.md) / [Analytics](README.md)

Detects unauthorized edits to system configuration profiles, unexpected certificate trust changes, or abnormal ARP/DNS patterns indicative of interception.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0296#AN0825)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Configuration profile modified or new profile installed · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **NSM:Flow** — TLS downgrade or inconsistent DNS answers · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **ProfileIdentifiers** — Known good vs suspicious configuration profiles per enterprise baseline.
- **TLSVersionThreshold** — Minimum TLS version accepted in network traffic inspection.
