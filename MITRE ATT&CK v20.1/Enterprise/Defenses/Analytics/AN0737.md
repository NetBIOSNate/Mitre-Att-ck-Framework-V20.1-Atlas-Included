# AN0737 - Analytic 0737

[Enterprise](../../README.md) / [Analytics](README.md)

Detects mailbox manipulation or deletion via PowerShell (e.g., Remove-MailboxExportRequest), file deletion from Outlook data stores (Unistore.db), or tampering with quarantined mail logs.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0266#AN0737)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:PowerShell** — EventCode=4103, 4104, 4105, 4106 · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **WinEventLog:Sysmon** — EventCode=23 · [DC0040 - File Deletion](../Data%20Components/DC0040%20-%20File%20Deletion.md)
- **WinEventLog:Security** — EventCode=4663, 4670, 4656 · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)
- **m365:exchange** — Transport Rule Modification · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)

## Mutable elements

- **MailstorePath** — Outlook files in AppData\Local\Comms\Unistore\data
- **TransportRuleNames** — Target suspicious rule changes (e.g., header removal)
- **PowerShellCommandMatch** — Regex match on `Remove-MailboxExportRequest` and similar Exchange cmdlets
