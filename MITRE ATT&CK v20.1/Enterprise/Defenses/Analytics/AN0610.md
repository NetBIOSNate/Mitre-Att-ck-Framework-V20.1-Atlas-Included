# AN0610 - Analytic 0610

[Enterprise](../../README.md) / [Analytics](README.md)

Adversary manipulation of shared library paths, environment variables, or replacement of service binaries. Defender observes suspicious modifications in /etc/ld.so.preload, service config changes, or file writes replacing existing executables.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0218#AN0610)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — open/write syscalls targeting /etc/ld.so.preload or binaries in /usr/bin · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)
- **linux:syslog** — Service restart with modified executable path · [DC0041 - Service Metadata](../Data%20Components/DC0041%20-%20Service%20Metadata.md)
- **linux:osquery** — Process execution with LD_PRELOAD or modified library path · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **MonitoredDirectories** — Directories where binary replacement should trigger alerts.
- **EnvVarMonitors** — Environment variables like LD_PRELOAD or PATH to monitor.
