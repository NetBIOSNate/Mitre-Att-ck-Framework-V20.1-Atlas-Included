# AN1522 - Analytic 1522

[Enterprise](../../README.md) / [Analytics](README.md)

Repeated failed SSH login attempts followed by a possible success from the same remote host

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0551#AN1522)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **linux:syslog** — sshd[pid]: Failed password · [DC0002 - User Account Authentication](../Data%20Components/DC0002%20-%20User%20Account%20Authentication.md)

## Mutable elements

- **PortScope** — Can be tuned to non-standard ports if SSH is moved from default
- **UserScope** — Filter high-value or restricted users (e.g., root, service)
- **AttemptThreshold** — Number of consecutive failures before flagging (e.g., >5 in 2 minutes)
