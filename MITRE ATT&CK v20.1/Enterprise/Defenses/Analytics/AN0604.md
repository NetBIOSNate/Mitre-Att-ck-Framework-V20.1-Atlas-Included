# AN0604 - Analytic 0604

[Enterprise](../../README.md) / [Analytics](README.md)

Userland or kernel-level ransomware encrypting user files (Documents, Desktop) using `srm`, `gpg`, or compiled payloads. Often correlated with ransom note creation in multiple directories.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0215#AN0604)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — file encrypted|new file with .encrypted extension|disk write burst · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)
- **macos:unifiedlog** — exec srm|exec openssl|exec gpg · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **ExtensionPattern** — Encrypted files may use .locked, .enc, or ransom-specific extensions.
- **VolumeTargeted** — Detect activity targeting mounted external or backup volumes.
