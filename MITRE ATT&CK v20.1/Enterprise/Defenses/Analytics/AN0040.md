# AN0040 - Analytic 0040

[Enterprise](../../README.md) / [Analytics](README.md)

Detects staging of sensitive files into temporary or public directories, compression with 7zip/WinRAR, or batch copy prior to exfiltration.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0014#AN0040)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — EventCode=4663, 4670, 4656 · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **WinEventLog:Sysmon** — EventCode=11 · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **StagingDirectoryList** — Temp folders or user profile staging directories
- **CompressionToolList** — 7z.exe, rar.exe, zip.exe paths
- **TimeWindow** — Temporal bounds for detecting batch staging activities
