# AN1580 - Analytic 1580

[Enterprise](../../README.md) / [Analytics](README.md)

Detects snapshot sharing, backup exports, or data object transfers from victim-owned cloud accounts to other cloud identities within the same provider (e.g., AWS, Azure) using snapshot sharing, S3 bucket policy updates, or SAS URI generation.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0573#AN1580)

**Platforms**  [IaaS](../../Platforms/IaaS.md)

## Log sources and channels

- **AWS:CloudTrail** — ModifySnapshotAttribute · [DC0058 - Snapshot Modification](../Data%20Components/DC0058%20-%20Snapshot%20Modification.md)
- **AWS:CloudTrail** — PutBucketPolicy · [DC0023 - Cloud Storage Modification](../Data%20Components/DC0023%20-%20Cloud%20Storage%20Modification.md)
- **AWS:CloudTrail** — CreateSnapshot · [DC0057 - Snapshot Creation](../Data%20Components/DC0057%20-%20Snapshot%20Creation.md)
- **AWS:CloudTrail** — CopySnapshot · [DC0062 - Snapshot Metadata](../Data%20Components/DC0062%20-%20Snapshot%20Metadata.md)
- **AWS:VPCFlowLogs** — High volume internal-to-internal IP transfer or cross-account cloud transfer · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **CrossAccountIDList** — List of external cloud accounts authorized for snapshot or bucket sharing
- **Region** — Geographic region in which the sharing occurs (may impact logging availability)
- **VolumeSizeThresholdGB** — Threshold to alert on snapshot size or object volume
- **TimeWindow** — Temporal window between snapshot creation and external sharing
