# AN0188 - Analytic 0188

[Enterprise](../../README.md) / [Analytics](README.md)

Unusual inbound email activity where attachments or embedded URLs are delivered to users followed by execution of new processes or suspicious document behavior. Detection involves correlating email metadata, file creation, and network activity after a phishing message is received.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0070#AN0188)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **m365:unified** — Send/Receive: Emails with suspicious sender domains, spoofed headers, or anomalous attachment types · [DC0038 - Application Log Content](../Data%20Components/DC0038%20-%20Application%20Log%20Content.md)
- **WinEventLog:Sysmon** — EventCode=11 · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **SuspiciousFileTypes** — Attachment types considered high risk (e.g., .exe, .js, .vbs, .scr, macro-enabled docs).
- **AllowedSenders** — Whitelist of known trusted senders to reduce false positives.
