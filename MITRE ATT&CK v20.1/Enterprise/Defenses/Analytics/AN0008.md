# AN0008 - Analytic 0008

[Enterprise](../../README.md) / [Analytics](README.md)

macOS clients joined to AD via LDAP may script account provisioning via `dsconfigad`, `dscl`, or LDAP scripts. Detection occurs when such tools run on a domain-joined system, followed by authentication attempts by a previously unseen account.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0003#AN0008)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — dsconfigad or dscl with create or append options for AD-bound users · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **macos:unifiedlog** — UserLoggedIn · [DC0067 - Logon Session Creation](../Data%20Components/DC0067%20-%20Logon%20Session%20Creation.md)

## Mutable elements

- **EnrollmentStatus** — Only flag on AD-bound systems with valid LDAP context
- **AccountType** — Distinguish between user accounts and computer accounts
