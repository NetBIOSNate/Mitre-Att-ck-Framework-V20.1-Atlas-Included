# AN0676 - Analytic 0676

[Enterprise](../../README.md) / [Analytics](README.md)

Unusual database command-line access (e.g., `psql`, `mysql`, `mongo`) from non-admin users, occurring outside typical automation windows or without known service context. Often followed by data dumps to .sql/.csv files or outbound data transfers. Defender sees CLI tools launched interactively or by unusual parent processes, file writes to dump-like filenames, and external connections shortly after.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0242#AN0676)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve: Execution of CLI tools like psql, mysql, mongo, sqlite3 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **auditd:PATH** — Creation of files with extensions .sql, .csv, .sqlite, especially in user directories · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **NSM:Flow** — http::post: Outbound HTTP POST from host shortly after DB export activity · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **AllowedDBClients** — List of user or automation accounts expected to use database clients
- **DumpFilePattern** — Filename patterns used to identify data dumps (e.g., *.sql, backup_*.csv)
- **TimeWindow** — Time threshold for correlating execution, file write, and outbound transfer
