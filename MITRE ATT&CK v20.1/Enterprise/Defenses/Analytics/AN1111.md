# AN1111 - Analytic 1111

[Enterprise](../../README.md) / [Analytics](README.md)

Detects abuse of AuthorizationExecuteWithPrivileges API to gain elevated privileges via user credential prompts, typically through invocation of /usr/libexec/security_authtrampoline. Detection involves correlation of API usage, binary reputation, and prompt context.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0395#AN1111)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Execution of /usr/libexec/security_authtrampoline or child processes originating from non-trusted binaries triggering credential prompts · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:unifiedlog** — Calls to AuthorizationExecuteWithPrivileges() observed via Apple System Logger or security_auditing tools · [DC0021 - OS API Execution](../Data%20Components/DC0021%20-%20OS%20API%20Execution.md)
- **macos:unifiedlog** — User credential prompt events without associated trusted installer package · [DC0002 - User Account Authentication](../Data%20Components/DC0002%20-%20User%20Account%20Authentication.md)

## Mutable elements

- **BinaryReputationList** — Allow list of trusted binaries invoking elevation prompts
- **TimeWindow** — Temporal correlation threshold between API call and credential prompt
- **PromptContextValidation** — Heuristic filters to determine whether a prompt context matches known legitimate installers
