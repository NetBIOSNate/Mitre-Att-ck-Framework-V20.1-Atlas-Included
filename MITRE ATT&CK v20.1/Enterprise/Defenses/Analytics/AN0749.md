# AN0749 - Analytic 0749

[Enterprise](../../README.md) / [Analytics](README.md)

Detects malicious archiving via system or third-party libraries (libz, libarchive) invoked by Python, Swift, or Objective-C binaries. Correlates unified logs of library loads with creation of compressed or encrypted archives (.zip, .gz, .bz2, .dmg).

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0268#AN0749)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Execution of Python, Swift, or other binaries invoking archiving libraries · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:unifiedlog** — Loading of libz.dylib, libarchive.dylib by non-standard applications · [DC0016 - Module Load](../Data%20Components/DC0016%20-%20Module%20Load.md)
- **macos:unifiedlog** — Creation of .zip, .gz, .dmg archives in /Users, /tmp, or application directories · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)

## Mutable elements

- **AllowedProcesses** — Applications allowed to load compression libraries (e.g., backup agents).
- **UserContext** — Flag archiving under privileged or system accounts as suspicious.
- **FileExtensionFilter** — Targeted monitoring of sensitive file formats or compressed containers.
