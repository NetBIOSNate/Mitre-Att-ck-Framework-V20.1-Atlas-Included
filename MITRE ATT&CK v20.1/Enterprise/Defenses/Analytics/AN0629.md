# AN0629 - Analytic 0629

[Enterprise](../../README.md) / [Analytics](README.md)

Unauthorized creation or modification of DLLs loaded by LSASS, abnormal registry values under LSA extensions, and anomalous DLL load activity into the lsass.exe process context—correlated during boot or logon events.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0225#AN0629)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — EventCode=3033 · [DC0016 - Module Load](../Data%20Components/DC0016%20-%20Module%20Load.md)
- **WinEventLog:Sysmon** — EventCode=6 · [DC0079 - Driver Load](../Data%20Components/DC0079%20-%20Driver%20Load.md)
- **WinEventLog:Sysmon** — EventCode=11 · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)

- **WinEventLog:Sysmon** — EventCode=12 · [DC0056 - Windows Registry Key Creation](../Data%20Components/DC0056%20-%20Windows%20Registry%20Key%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=13, 14 · [DC0063 - Windows Registry Key Modification](../Data%20Components/DC0063%20-%20Windows%20Registry%20Key%20Modification.md)

## Mutable elements

- **TimeWindow** — Correlate DLL file creation/modification with LSASS execution within a configurable timeframe (e.g., 5 min)
- **ImagePathPattern** — Tune based on known legitimate LSASS plugin DLL paths
- **SignatureValidation** — Flag unsigned DLLs loaded into lsass.exe or those signed by unexpected publishers
- **RegistryKeyScope** — Scope to specific registry keys: HKLM\SYSTEM\CurrentControlSet\Control\Lsa\Authentication Packages
- **FileHashAllowList** — Exclude known-good LSASS plugin DLLs based on cryptographic hash
