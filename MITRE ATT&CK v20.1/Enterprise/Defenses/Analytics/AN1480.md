# AN1480 - Analytic 1480

[Enterprise](../../README.md) / [Analytics](README.md)

1) New or updated software is delivered/installed from atypical sources or with signature/hash mismatches; 2) installer/updater writes binaries to unexpected paths or replaces existing signed files; 3) first run causes unsigned/abnormally signed modules to load or child processes to execute, optionally followed by network egress to new destinations.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0537#AN1480)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=7 · [DC0016 - Module Load](../Data%20Components/DC0016%20-%20Module%20Load.md)
- **WinEventLog:Sysmon** — EventCode=11 · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **WinEventLog:Microsoft-Windows-CodeIntegrity/Operational** — CodeIntegrity reports 'Invalid image hash' or 'Unsigned image' for new/updated binaries · [DC0059 - File Metadata](../Data%20Components/DC0059%20-%20File%20Metadata.md)
- **NSM:Flow** — First-time egress from host after new install to unknown update endpoints · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **TimeWindow** — Correlation window between install events and first-run activity (default 2h; adjust for staged rollouts).
- **TrustedPublishers** — Publisher/Signer allow-list to suppress expected updates.
- **TrustedUpdateHosts** — Known update CDNs/APIs (e.g., download.microsoft.com) to reduce egress false positives.
- **RiskScoreThreshold** — Score cut-off for alerting when combining path, signer, and reputation features.
