# AN0477 - Analytic 0477

[Enterprise](../../README.md) / [Analytics](README.md)

Firmware image uploaded via TFTP/SCP or web interface followed by reboot or unexpected loss of connectivity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0167#AN0477)

**Platforms**  [Network Devices](../../Platforms/Network%20Devices.md)

## Log sources and channels

- **NSM:Flow** — large upload to firmware interface port or path · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **networkdevice:firmware** — Firmware update initiated or bootloader tampering detected · [DC0004 - Firmware Modification](../Data%20Components/DC0004%20-%20Firmware%20Modification.md)

## Mutable elements

- **UploadSizeThreshold** — Size of firmware images varies by vendor
- **RebootWindow** — Reboots outside of patch maintenance may be suspicious
