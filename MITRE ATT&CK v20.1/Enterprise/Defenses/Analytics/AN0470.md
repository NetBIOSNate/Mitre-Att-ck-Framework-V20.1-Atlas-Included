# AN0470 - Analytic 0470

[Enterprise](../../README.md) / [Analytics](README.md)

Detects modification or truncation of `/var/log/shell.log` used to persist ESXi shell command history. Especially suspicious shortly after login or config changes.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0165#AN0470)

**Platforms**  [ESXi](../../Platforms/ESXi.md)

## Log sources and channels

- **esxi:shell** — /var/log/shell.log · [DC0040 - File Deletion](../Data%20Components/DC0040%20-%20File%20Deletion.md)

## Mutable elements

- **LogFilePath** — Path to shell command history on ESXi.
- **TimeWindow** — Time range post-login or privileged escalation.
