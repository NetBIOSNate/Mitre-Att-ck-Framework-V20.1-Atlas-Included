# AN1568 - Analytic 1568

[Enterprise](../../README.md) / [Analytics](README.md)

Detects USB HID device enumeration under `/sys/bus/usb/devices/` and rapid keystroke injection resulting in command execution such as bash or Python scripts launched without interactive user activity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0568#AN1568)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — execve: parent process is usb/hid device handler, child process bash/python invoked · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **linux:syslog** — New HID device enumeration with type 'keyboard' followed by immediate input injection · [DC0042 - Drive Creation](../Data%20Components/DC0042%20-%20Drive%20Creation.md)

## Mutable elements

- **USBVendorIDs** — Track suspicious or unapproved USB vendor/product IDs.
- **ScriptExecutionThreshold** — Time threshold for script execution after HID injection, e.g., less than 10 seconds.
