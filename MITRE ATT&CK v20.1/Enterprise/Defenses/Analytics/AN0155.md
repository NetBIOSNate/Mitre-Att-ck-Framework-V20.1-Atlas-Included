# AN0155 - Analytic 0155

[Enterprise](../../README.md) / [Analytics](README.md)

Detection of malicious certificate installation via monitoring execution of the `security add-trusted-cert` command and modifications to system keychains.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0056#AN0155)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Execution of /usr/bin/security add-trusted-cert or keychain modifications to System.keychain · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **macos:osquery** — query: Enumeration of root certificates showing unexpected additions · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)

## Mutable elements

- **MonitoredCommands** — Commands related to certificate management (e.g., security, profiles) that can be tuned per environment.
- **KeychainBaseline** — Baseline of expected certificates in System.keychain to reduce false positives from legitimate enterprise certificates.
