# AN0741 - Analytic 0741

[Enterprise](../../README.md) / [Analytics](README.md)

Persistent high CPU utilization combined with suspicious command-line execution (e.g., mining tools or obfuscated scripts) and outbound connections to mining/proxy networks.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0267#AN0741)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **Windows:perfmon** — High sustained CPU usage by a single process · [DC0018 - Host Status](../Data%20Components/DC0018%20-%20Host%20Status.md)
- **WinEventLog:Sysmon** — EventCode=3, 22 · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **TimeWindow** — Duration threshold for sustained CPU activity (e.g., >15 minutes)
- **DestinationIPList** — Known mining pool IPs or proxy service endpoints
- **ExecutableNamePatterns** — Regex list of suspicious or known mining tools
