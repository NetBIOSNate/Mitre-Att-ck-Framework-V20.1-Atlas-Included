# AN0464 - Analytic 0464

[Enterprise](../../README.md) / [Analytics](README.md)

Process opens /dev/bpf* (libpcap) or loads NetworkExtension filter, then after a crafted inbound packet the same process initiates an outbound connection to the trigger origin.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0162#AN0464)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **OpenBSM:AuditTrail** — open/openat of /dev/bpf*; ioctl BIOCSETF-like operations. · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:unifiedlog** — First outbound connection from the same PID/user shortly after an inbound trigger. · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **NSM:Flow** — Inbound one-off packet to uncommon port → outbound SF to same src_ip within TimeWindow. · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **BPFDevicePath** — Alternate BPF device paths if customized (default /dev/bpf*).
- **DeveloperMode** — Relax thresholds on known developer tooling hosts (Xcode, instrumenting tools).
