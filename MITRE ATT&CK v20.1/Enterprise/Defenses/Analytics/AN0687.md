# AN0687 - Analytic 0687

[Enterprise](../../README.md) / [Analytics](README.md)

Behavior chain involving unexpected API calls to capture keyboard input, driver loads for keyloggers, or remote use of smart card authentication via logon sessions not initiated by local user interaction

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0246#AN0687)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=10 · [DC0035 - Process Access](../Data%20Components/DC0035%20-%20Process%20Access.md)
- **WinEventLog:Security** — EventCode=4624, 4648 · [DC0067 - Logon Session Creation](../Data%20Components/DC0067%20-%20Logon%20Session%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=13, 14 · [DC0063 - Windows Registry Key Modification](../Data%20Components/DC0063%20-%20Windows%20Registry%20Key%20Modification.md)

## Mutable elements

- **AccessMask** — Tunable based on what memory-level access the keylogger uses (e.g., 0x10 for read)
- **ProcessNameExclusions** — Legitimate accessibility tools may use similar API calls (e.g., Magnifier.exe)
- **TimeWindow** — Define how quickly access + registry mod + smart card use must co-occur
