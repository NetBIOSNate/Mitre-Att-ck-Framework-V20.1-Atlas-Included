# AN1101 - Analytic 1101

[Enterprise](../../README.md) / [Analytics](README.md)

Adversary invokes 'dpkg -l', 'rpm -qa', or other package managers via shell or script to enumerate installed software.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0392#AN1101)

**Platforms**  [Linux](../../Platforms/Linux.md)

## Log sources and channels

- **auditd:SYSCALL** — Execution of dpkg, rpm, or other package manager with list flag · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **linux:shell** — Manual invocation of software enumeration commands via interactive shell · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)

## Mutable elements

- **ScriptName** — Path to the wrapper script that invokes enumeration commands.
- **TTYContext** — Scope detection to interactive vs. background shell contexts.
