# AN0885 - Analytic 0885

[Enterprise](../../README.md) / [Analytics](README.md)

Execution of CLI commands erasing file systems or storage (erase flash:, format disk, erase nvram:). Detect authentication events followed by destructive commands within the same privileged session.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0316#AN0885)

**Platforms**  [Network Devices](../../Platforms/Network%20Devices.md)

## Log sources and channels

- **networkdevice:cli** — erase flash:, erase nvram:, format disk · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **networkdevice:syslog** — Privileged login followed by destructive command sequence · [DC0002 - User Account Authentication](../Data%20Components/DC0002%20-%20User%20Account%20Authentication.md)

## Mutable elements

- **PrivilegedUsers** — Tune to exclude approved maintenance performed by authorized administrators.
- **CommandPatterns** — Expand or narrow destructive command coverage depending on vendor-specific syntax.
