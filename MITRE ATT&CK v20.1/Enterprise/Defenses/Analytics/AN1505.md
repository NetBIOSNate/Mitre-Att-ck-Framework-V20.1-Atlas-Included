# AN1505 - Analytic 1505

[Enterprise](../../README.md) / [Analytics](README.md)

Detects unexpected access or usage of cloud productivity tools (e.g., downloading large numbers of files, creating external shares) by internal users.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0546#AN1505)

**Platforms**  [SaaS](../../Platforms/SaaS.md)

## Log sources and channels

- **m365:unified** — FileAccessed, SharingSet · [DC0088 - Logon Session Metadata](../Data%20Components/DC0088%20-%20Logon%20Session%20Metadata.md)
- **gcp:audit** — drive.activity · [DC0002 - User Account Authentication](../Data%20Components/DC0002%20-%20User%20Account%20Authentication.md)

## Mutable elements

- **FileDownloadThreshold** — Defines excessive access based on number or size of downloads.
- **SharingPolicyViolationThreshold** — Defines external sharing behaviors that violate policy.
