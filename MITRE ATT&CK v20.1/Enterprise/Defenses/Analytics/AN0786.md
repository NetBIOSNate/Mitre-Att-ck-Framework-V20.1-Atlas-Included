# AN0786 - Analytic 0786

[Enterprise](../../README.md) / [Analytics](README.md)

Detection of suspicious token manipulation chains: use of token-related APIs (e.g., LogonUser, DuplicateTokenEx) or commands (runas) → spawning of a new process under a different security context (e.g., SYSTEM) → mismatched parent-child process lineage or anomalies in Event Tracing for Windows (ETW) token/PPID data → abnormal lateral or privilege escalation activity.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0283#AN0786)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Security** — EventCode=4672, 4634 · [DC0088 - Logon Session Metadata](../Data%20Components/DC0088%20-%20Logon%20Session%20Metadata.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=10 · [DC0035 - Process Access](../Data%20Components/DC0035%20-%20Process%20Access.md)
- **ETW:Token** — token_analysis: API calls such as DuplicateTokenEx or ImpersonateLoggedOnUser · [DC0021 - OS API Execution](../Data%20Components/DC0021%20-%20OS%20API%20Execution.md)
- **WinEventLog:Security** — EventCode=5136 · [DC0066 - Active Directory Object Modification](../Data%20Components/DC0066%20-%20Active%20Directory%20Object%20Modification.md)

## Mutable elements

- **TimeWindow** — Correlation time between suspicious API usage, runas, and process creation (e.g., 5–10m).
- **AllowedServiceAccounts** — Whitelist of service accounts permitted to spawn SYSTEM-level processes.
- **KnownAdminTools** — Legitimate administrative utilities that trigger token changes.
- **ParentProcessAnomalyThreshold** — Deviation threshold for PPID mismatches detected via ETW.
