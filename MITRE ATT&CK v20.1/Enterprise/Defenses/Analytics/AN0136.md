# AN0136 - Analytic 0136

[Enterprise](../../README.md) / [Analytics](README.md)

Detects firewall rule modifications or reset of logs/connection tables (e.g., `clear logging`, `erase startup-config`, `write erase`) following remote access activity on routers, switches, or VPN appliances.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0049#AN0136)

**Platforms**  [Network Devices](../../Platforms/Network%20Devices.md)

## Log sources and channels

- **networkdevice:syslog** — Command Audit / Configuration Change · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **NSM:Flow** — Session History Reset · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **CommandPattern** — e.g., `clear logging`, `no logging buffered`, `no ip domain-lookup`
- **DeviceTypeFilter** — Switches vs VPN vs routers
