# AN0664 - Analytic 0664

[Enterprise](../../README.md) / [Analytics](README.md)

Adversary modifies internal or external site content through manipulated application bundles, hosted content, or web server configs.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0238#AN0664)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — Execution of unexpected terminal or web scripts modifying /Library/WebServer/Documents · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:unifiedlog** — File creation or overwrite in common web-hosting folders · [DC0061 - File Modification](../Data%20Components/DC0061%20-%20File%20Modification.md)

## Mutable elements

- **TargetDirectoryPath** — Web root folders will vary depending on how services are configured on macOS (e.g., /Library/WebServer/Documents).
