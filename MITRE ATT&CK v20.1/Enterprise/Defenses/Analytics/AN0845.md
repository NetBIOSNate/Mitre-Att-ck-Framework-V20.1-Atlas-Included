# AN0845 - Analytic 0845

[Enterprise](../../README.md) / [Analytics](README.md)

Router/switch receives a knock pattern (same src touches device unicast, broadcast, and network-address on same or stepped ports) followed by ACL/line-vty/service enable and the first mgmt session success.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0302#AN0845)

**Platforms**  [Network Devices](../../Platforms/Network%20Devices.md)

## Log sources and channels

- **networkdevice:syslog** — Config/ACL changes, line vty transport input changes, telnet/ssh/http(s) enable, image/feature module changes. · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **NSM:Flow** — Series of denied/closed flows to distinct ports then success to mgmt port from same src_ip within TimeWindow. · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)

## Mutable elements

- **MgmtPortSet** — Mgmt ports to focus on: 22,23,2323,80,443,161,4786.
- **DeviceRole** — Tighten thresholds on edge/internet-facing devices.
