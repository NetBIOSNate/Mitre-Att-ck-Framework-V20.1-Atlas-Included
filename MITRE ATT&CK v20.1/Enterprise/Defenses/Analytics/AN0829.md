# AN0829 - Analytic 0829

[Enterprise](../../README.md) / [Analytics](README.md)

Abnormal invocation of diskutil or asr that modifies partition tables or initializes raw devices. Monitor for IOKit system calls targeting disk headers or EFI boot sectors, correlated with elevated privileges.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0297#AN0829)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — diskutil partitionDisk or eraseVolume with partition scheme modifications · [DC0064 - Command Execution](../Data%20Components/DC0064%20-%20Command%20Execution.md)
- **macos:unifiedlog** — IOKit raw disk write to EFI/boot partition sectors · [DC0046 - Drive Modification](../Data%20Components/DC0046%20-%20Drive%20Modification.md)

## Mutable elements

- **AdminToolWhitelist** — System provisioning workflows may legitimately re-partition disks; whitelist by context.
