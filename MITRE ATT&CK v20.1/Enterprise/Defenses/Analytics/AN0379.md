# AN0379 - Analytic 0379

[Enterprise](../../README.md) / [Analytics](README.md)

Detects unauthorized use of SMTP/IMAP/POP3 by suspicious binaries (e.g., PowerShell, rundll32) to exfiltrate data or beacon via email, often bypassing proxy or content filters.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0135#AN0379)

**Platforms**  [Windows](../../Platforms/Windows.md)

## Log sources and channels

- **WinEventLog:Sysmon** — EventCode=3, 22 · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **WinEventLog:Sysmon** — EventCode=1 · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **NSM:Flow** — smtp.log · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **ProcessImageName** — Limit to uncommon clients (e.g., scripts or CLI tools using .NET SMTP libraries)
- **DestPortFilter** — Typically 25, 587, 993, 995, or 465 – flag anomalies
- **AttachmentType** — Flag suspicious attachments (e.g., .zip, .7z, .bin)
