# AN0438 - Analytic 0438

[Enterprise](../../README.md) / [Analytics](README.md)

Unexpected apps or scripts (osascript, curl, Automator workflows) exfiltrating data via webhooks. Defender perspective: correlation of clipboard/file read operations followed by HTTPS POST traffic to webhook services.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0153#AN0438)

**Platforms**  [macOS](../../Platforms/macOS.md)

## Log sources and channels

- **macos:unifiedlog** — execution of osascript, curl, or unexpected automation · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **macos:unifiedlog** — file read of sensitive directories · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **macos:unifiedlog** — HTTPS POST to known webhook URLs · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **WebhookEndpoints** — Webhook URLs monitored for exfiltration.
- **EntropyThreshold** — High entropy payloads may indicate encoded/encrypted exfiltration.
