# T1030 - Data Transfer Size Limits

[Enterprise](../../../README.md) / [Exfiltration](../README.md)

An adversary may exfiltrate data in fixed size chunks instead of whole files or limit packet sizes below certain thresholds. This approach may be used to avoid triggering network data transfer threshold alerts.(Citation: Chunked Encoding)

[MITRE ATT&CK record](https://attack.mitre.org/techniques/T1030)

**Tactics**  [Exfiltration](../README.md)

**Platforms**  [Linux](../../../Platforms/Linux.md), [macOS](../../../Platforms/macOS.md), [Windows](../../../Platforms/Windows.md), [ESXi](../../../Platforms/ESXi.md)
