# T1036 - Masquerading

[Enterprise](../../../README.md) / [Stealth](../README.md)

Adversaries may attempt to manipulate features of their artifacts to make them appear legitimate or benign to users and/or security tools. Masquerading occurs when the name or location of an object, legitimate or malicious, is manipulated or abused for the sake of evading defenses and observation. This may include manipulating file metadata, tricking users into misidentifying the file type, and giving legitimate task or service names.

Renaming abusable system utilities to evade security monitoring is also a form of [Masquerading](https://attack.mitre.org/techniques/T1036).(Citation: LOLBAS Main Site)

## Mitigations

- [M1049 - Antivirus/Antimalware](../../../Defenses/Mitigations/M1049%20-%20Antivirus%20-%20Antimalware.md) — Anti-virus can be used to automatically quarantine suspicious files.
- [M1047 - Audit](../../../Defenses/Mitigations/M1047%20-%20Audit.md) — Audit user accounts to ensure that each one has a defined purpose.
- [M1040 - Behavior Prevention on Endpoint](../../../Defenses/Mitigations/M1040%20-%20Behavior%20Prevention%20on%20Endpoint.md) — Implement security controls on the endpoint, such as a Host Intrusion Prevention System (HIPS), to identify and prevent execution of potentially malicious files (such as those with mismatching file signatures).
- [M1045 - Code Signing](../../../Defenses/Mitigations/M1045%20-%20Code%20Signing.md) — Require signed binaries.
- [M1038 - Execution Prevention](../../../Defenses/Mitigations/M1038%20-%20Execution%20Prevention.md) — Use tools that restrict program execution via application control by attributes other than file name for common operating system utilities that are needed.
- [M1022 - Restrict File and Directory Permissions](../../../Defenses/Mitigations/M1022%20-%20Restrict%20File%20and%20Directory%20Permissions.md) — Use file system access controls to protect folders such as C:\\Windows\\System32.
- [M1018 - User Account Management](../../../Defenses/Mitigations/M1018%20-%20User%20Account%20Management.md) — Consider defining and enforcing a naming convention for user accounts to more easily spot generic account names that do not fit the typical schema.
- [M1017 - User Training](../../../Defenses/Mitigations/M1017%20-%20User%20Training.md) — Train users not to open email attachments or click unknown links (URLs). Such training fosters more secure habits within your organization and will limit many of the risks.
