# AN1689 - Analytic 1689

[Mobile](../../README.md) / [Analytics](README.md)

For Android, detect Remote Access Software by correlating analyst-visible device/network evidence and management state; use streaming or batched telemetry only where the documented collector is deployed. Correlate Application Permission via Android Enterprise DPC / Application Vetting [DevicePolicyManager.getPermissionGrantState(); PackageManager manifest/requested-permission review]; Network Connection Creation via Android Enterprise Network Logging / Enterprise VPN [DevicePolicyManager.retrieveNetworkLogs(): DnsEvent / ConnectEvent; VPN flow metadata]; Network Traffic Flow via Android Enterprise Network Logging / Enterprise VPN [DevicePolicyManager.retrieveNetworkLogs(): DnsEvent / ConnectEvent; VPN flow metadata]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0624#AN1689)

## Mutable elements

- **RASAppSignatures** — TeamViewer, AnyDesk, AirDroid, AirMirror package names.
- **ApprovedRASApps** — IT-authorized remote support packages. Keep minimal.
- **RASInfrastructureIPs** — Published IP ranges for approved RAS vendors. Derive from vendor documentation.
- **PersistentSessionThreshold** — Default 300s — confirms active session vs connection test.
- **InteractiveRatioRange** — Default inbound/outbound ratio 0.1–10.0 — interactive vs pure exfil. Derive from RAS session baseline.
