# AN1792 - Analytic 1792

[Mobile](../../README.md) / [Analytics](README.md)

For iOS, detect Phishing by correlating analyst-visible device/network evidence and management state; use streaming or batched telemetry only where the documented collector is deployed. Correlate Network Traffic Content via Enterprise Secure Web Gateway / Proxy [DNS/HTTP(S) inspection or proxy transaction metadata where enterprise decryption/inspection is deployed]; Network Traffic Flow via Apple Network Extension / Enterprise VPN [NEFilterFlow / per-app VPN / secure-web-gateway flow metadata]; Protected Configuration via Apple MDM [DeviceInformation / SecurityInfo / ProfileList / restrictions and compliance queries]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0684#AN1792)

**Platforms**  [iOS](../../Platforms/iOS.md)

- **webproxy:applog** — DNS/HTTP(S) inspection or proxy transaction metadata where enterprise decryption/inspection is deployed · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **iOS:NetworkExtension** — NEFilterFlow / per-app VPN / secure-web-gateway flow metadata · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **iOS:MDM** — DeviceInformation / SecurityInfo / ProfileList / restrictions and compliance queries · [DC0115 - Protected Configuration](../Data%20Components/DC0115%20-%20Protected%20Configuration.md)

## Mutable elements

- **URLReputationThreshold** — Default 50/100. Derive from threat intel feed vendor scoring.
- **SafariBrowsingBaseline** — Per-device Safari browsing destination baseline, 30-day. Derive by measurement.
- **PhishingWindow** — Default 300s from URL navigation to C2 contact.
