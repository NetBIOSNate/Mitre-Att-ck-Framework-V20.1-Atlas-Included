# AN1765 - Analytic 1765

[Mobile](../../README.md) / [Analytics](README.md)

For Android, detect Domain Generation Algorithms by correlating analyst-visible device/network evidence and management state; use streaming or batched telemetry only where the documented collector is deployed. Correlate Application Permission via Android Enterprise DPC / Application Vetting [DevicePolicyManager.getPermissionGrantState(); PackageManager manifest/requested-permission review]; Network Traffic Content via Enterprise Secure Web Gateway / Proxy [DNS/HTTP(S) inspection or proxy transaction metadata where enterprise decryption/inspection is deployed]; Network Traffic Flow via Android Enterprise Network Logging / Enterprise VPN [DevicePolicyManager.retrieveNetworkLogs(): DnsEvent / ConnectEvent; VPN flow metadata]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0669#AN1765)

## Mutable elements

- **MDMApprovedCatalog** — MDM-managed app list.
- **DGAEntropyThreshold** — Default 3.5 bits Shannon. Calibrate from fleet DNS baseline.
- **DGALabelLength** — Default 12 characters.
- **DGACandidateThreshold** — Default 10 high-entropy queries within window.
- **DGAWindow** — Default 60s.
- **DomainAgeThreshold** — Default 30 days — newly-registered C2 domain.
