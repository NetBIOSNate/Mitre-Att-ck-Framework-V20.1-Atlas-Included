# AN1844 - Analytic 1844

[Mobile](../../README.md) / [Analytics](README.md)

For iOS, detect Masquerading by correlating analyst-visible device/network evidence and management state; use streaming or batched telemetry only where the documented collector is deployed. Correlate Application Permission via Application Vetting [Code-signing entitlements and Info.plist privacy usage-description keys]; File Metadata via Application Vetting / Forensic Acquisition [Dynamic filesystem trace or acquired app-container/filesystem artifacts: bundle_id LIKE $KnownSystemNamespace$]; Network Traffic Flow via Apple Network Extension / Enterprise VPN [NEFilterFlow / per-app VPN / secure-web-gateway flow metadata]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0715#AN1844)

**Platforms**  [iOS](../../Platforms/iOS.md)

- **iOS:NetworkExtension** — NEFilterFlow / per-app VPN / secure-web-gateway flow metadata · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **KnownSystemNamespace** — com.apple.*, org.whispersystems.*, com.google.* — reserved/well-known namespaces.
- **MDMApprovedCatalog** — MDM-managed app list.
- **ImpersonatedAppPermissionProfile** — Permission set of each known-good app that could be impersonated. Derive from MDM app catalog audit.
- **ImpersonatedAppCDN** — Known network destinations for each enterprise app that could be impersonated.
