# AN1821 - Analytic 1821

[Mobile](../../README.md) / [Analytics](README.md)

For iOS, detect Remote Device Management Services by correlating analyst-visible device/network evidence and management state; use streaming or batched telemetry only where the documented collector is deployed. Correlate Application State via Apple MDM [InstalledApplicationList / ManagedApplicationList]; Cloud Service Enumeration via Application Vetting / Cloud Service Audit [Instrumented app API trace and corresponding cloud-service audit/API telemetry]; User Account Authentication via Application Vetting / Identity Provider Telemetry [App authentication flow instrumentation or IdP sign-in/audit events]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0702#AN1821)

**Platforms**  [iOS](../../Platforms/iOS.md)

## Log sources and channels

- **iOS:MDM** — InstalledApplicationList / ManagedApplicationList · [DC0123 - Application State](../Data%20Components/DC0123%20-%20Application%20State.md)
- **cloud:AuditLog** — Instrumented app API trace and corresponding cloud-service audit/API telemetry · [DC0083 - Cloud Service Enumeration](../Data%20Components/DC0083%20-%20Cloud%20Service%20Enumeration.md)
- **idp:AuditLog** — App authentication flow instrumentation or IdP sign-in/audit events · [DC0002 - User Account Authentication](../Data%20Components/DC0002%20-%20User%20Account%20Authentication.md)

## Mutable elements

- **FindMyQueryThreshold** — Default 5 queries per session — legitimate users check location once; adversary polls repeatedly.
- **LocationQueryWindow** — Default 300s.
- **UserKnownDevices** — User's registered device IPs and user agents from enterprise IdP device registry.
