# AN1649 - Analytic 1649

[Mobile](../../README.md) / [Analytics](README.md)

For iOS, detect System Information Discovery by correlating analyst-visible device/network evidence and management state; use streaming or batched telemetry only where the documented collector is deployed. Correlate API Calls via Application Vetting / Instrumented Dynamic Analysis [Dynamic API/runtime trace: UIDevice.current.model]; Application State via Apple MDM [InstalledApplicationList / ManagedApplicationList]; Network Connection Creation via Apple Network Extension / Enterprise VPN [NEFilterFlow / per-app VPN / secure-web-gateway flow metadata]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0601#AN1649)

## Mutable elements

- **SysInfoAllowList** — MDM agent, analytics SDK (pre-approved), crash reporter.
- **SysInfoWindow** — Default 30s at launch.
- **AppCDNList** — Per-app CDN. Derive by measurement.
- **FollowOnWindow** — Default 120s.
