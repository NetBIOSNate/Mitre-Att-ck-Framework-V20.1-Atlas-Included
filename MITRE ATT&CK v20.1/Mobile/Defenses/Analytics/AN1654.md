# AN1654 - Analytic 1654

[Mobile](../../README.md) / [Analytics](README.md)

For iOS, detect Compromise Hardware Supply Chain by correlating analyst-visible device/network evidence and management state; use streaming or batched telemetry only where the documented collector is deployed. Correlate Application Permission via Application Vetting [Code-signing entitlements and Info.plist privacy usage-description keys]; Application State via Apple MDM [InstalledApplicationList / ManagedApplicationList]; Network Traffic Content via Enterprise Secure Web Gateway / Proxy [DNS/HTTP(S) inspection or proxy transaction metadata where enterprise decryption/inspection is deployed]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0604#AN1654)

- **webproxy:applog** — DNS/HTTP(S) inspection or proxy transaction metadata where enterprise decryption/inspection is deployed · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **mobile:DynamicAnalysis** — Dynamic API/runtime trace: Supplemental baseband, IOKit, accessory, security, or activation-related subsystem anomalies on supervised device at activation — Unified Log supplemental confirmation · [DC0021 - OS API Execution](../Data%20Components/DC0021%20-%20OS%20API%20Execution.md)

## Mutable elements

- **TimeWindow** — Correlation window between enrollment/inventory concern and suspicious network activity.
- **SupervisedRequired** — Most strong posture and inventory analytics require supervised iOS devices.
- **AllowedDestinations** — Apple, MDM, update, enterprise, and managed SaaS destinations vary by organization.
- **BackgroundRefreshBaseline** — Expected background network behavior varies by managed app set and policy.
- **ActivationGracePeriod** — Benign activation, restore, and setup traffic can be noisy immediately after provisioning.
- **RecentUserInteractionWindow** — Defines how recently the user must have interacted for activity to be considered expected.
- **InventoryDriftTolerance** — Tuning for acceptable changes in inventory/configuration during upgrades or replacements.
