# AN1702 - Analytic 1702

[Mobile](../../README.md) / [Analytics](README.md)

For Android, detect Proxy Through Victim by correlating analyst-visible device/network evidence and management state; use streaming or batched telemetry only where the documented collector is deployed. Correlate Application Permission via Android Enterprise DPC / Application Vetting [DevicePolicyManager.getPermissionGrantState(); PackageManager manifest/requested-permission review]; Network Traffic Content via Enterprise Secure Web Gateway / Proxy [DNS/HTTP(S) inspection or proxy transaction metadata where enterprise decryption/inspection is deployed]; Network Traffic Flow via Android Enterprise Network Logging / Enterprise VPN [DevicePolicyManager.retrieveNetworkLogs(): DnsEvent / ConnectEvent; VPN flow metadata]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0631#AN1702)

**Platforms**  [Android](../../Platforms/Android.md)

- **android:DevicePolicyManager** — DevicePolicyManager.getPermissionGrantState(); PackageManager manifest/requested-permission review · [DC0114 - Application Permission](../Data%20Components/DC0114%20-%20Application%20Permission.md)
- **webproxy:applog** — DNS/HTTP(S) inspection or proxy transaction metadata where enterprise decryption/inspection is deployed · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **android:EnterpriseNetworkLog** — DevicePolicyManager.retrieveNetworkLogs(): DnsEvent / ConnectEvent; VPN flow metadata · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **mobile:DynamicAnalysis** — Dynamic API/runtime trace: App initializes proxy-capable or raw-socket networking constructs (ServerSocket, SOCKS proxy client, bidirectional relay) NOT IN $ApprovedProxyApps$ — proxy initialization is the technique enabler · [DC0021 - OS API Execution](../Data%20Components/DC0021%20-%20OS%20API%20Execution.md)

## Mutable elements

- **ApprovedProxyApps** — VPN client, enterprise proxy agent, MDM agent with tunnel capability. Derive from MDM catalog. Tightening: only MDM-provisioned VPN apps.
- **RelayWindow** — Default 5s between inbound session and outbound relay connection. Proxy relay is near-synchronous. Tightening: 2s.
- **FanOutThreshold** — Default 3 distinct outbound destinations per inbound session. Single-destination relay may be VPN; multi-destination fan-out is proxy.
