# AN1678 - Analytic 1678

[Mobile](../../README.md) / [Analytics](README.md)

For iOS, detect Download New Code at Runtime by correlating analyst-visible device/network evidence and management state; use streaming or batched telemetry only where the documented collector is deployed. Correlate Application Permission via Application Vetting [Code-signing entitlements and Info.plist privacy usage-description keys]; Network Traffic Content via Enterprise Secure Web Gateway / Proxy [DNS/HTTP(S) inspection or proxy transaction metadata where enterprise decryption/inspection is deployed]; Network Traffic Flow via Apple Network Extension / Enterprise VPN [NEFilterFlow / per-app VPN / secure-web-gateway flow metadata]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0618#AN1678)

**Platforms**  [iOS](../../Platforms/iOS.md)

## Log sources and channels

- **mobile:ApplicationVetting** — Code-signing entitlements and Info.plist privacy usage-description keys · [DC0114 - Application Permission](../Data%20Components/DC0114%20-%20Application%20Permission.md)
- **webproxy:applog** — DNS/HTTP(S) inspection or proxy transaction metadata where enterprise decryption/inspection is deployed · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **iOS:NetworkExtension** — NEFilterFlow / per-app VPN / secure-web-gateway flow metadata · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **AppCDNList** — Per-app declared CDN/update endpoints, 30-day baseline.
- **AppBaselineDomains** — Full per-app network destination baseline, 30-day.
- **MinPayloadSize** — Default 1024 bytes.
- **VersionCheckWindow** — Default 86400s — confirm version has not changed in 24hr before download event.
- **CodeDownloadWindow** — Default 120s between download and new destination.
