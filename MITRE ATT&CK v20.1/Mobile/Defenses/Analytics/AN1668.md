# AN1668 - Analytic 1668

[Mobile](../../README.md) / [Analytics](README.md)

For iOS, detect Dynamic Resolution by correlating analyst-visible device/network evidence and management state; use streaming or batched telemetry only where the documented collector is deployed. Correlate Application Permission via Application Vetting [Code-signing entitlements and Info.plist privacy usage-description keys]; Network Connection Creation via Apple Network Extension / Enterprise VPN [NEFilterFlow / per-app VPN / secure-web-gateway flow metadata]; Network Traffic Flow via Apple Network Extension / Enterprise VPN [NEFilterFlow / per-app VPN / secure-web-gateway flow metadata]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0613#AN1668)

## Mutable elements

- **MDMApprovedCatalog** — MDM-managed app list.
- **NXDOMAINThreshold** — Default 20 per device within window. Derive from per-device DNS baseline.
- **DGAWindow** — Default 60s.
- **AppBaselineDomains** — Per-app network destination baseline, 30-day.
- **DGASuccessWindow** — Default 30s between last NXDOMAIN and successful resolution.
