# AN1752 - Analytic 1752

[Mobile](../../README.md) / [Analytics](README.md)

For iOS, detect Keylogging by correlating analyst-visible device/network evidence and management state; use streaming or batched telemetry only where the documented collector is deployed. Correlate Application State via Apple MDM [InstalledApplicationList / ManagedApplicationList]; Network Traffic Flow via Apple Network Extension / Enterprise VPN [NEFilterFlow / per-app VPN / secure-web-gateway flow metadata]; Permissions Request via Application Vetting [Code-signing entitlements and Info.plist privacy usage-description keys]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0661#AN1752)

**Platforms**  [iOS](../../Platforms/iOS.md)

## Log sources and channels

- **iOS:MDM** — InstalledApplicationList / ManagedApplicationList · [DC0123 - Application State](../Data%20Components/DC0123%20-%20Application%20State.md)
- **iOS:NetworkExtension** — NEFilterFlow / per-app VPN / secure-web-gateway flow metadata · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **mobile:ApplicationVetting** — Code-signing entitlements and Info.plist privacy usage-description keys · [DC0116 - Permissions Request](../Data%20Components/DC0116%20-%20Permissions%20Request.md)

## Mutable elements

- **KeyboardAllowList** — IT-approved keyboard bundles.
- **KeyboardVendorEndpoints** — Known vendor cloud endpoints per approved keyboard.
- **KeystrokeFrequencyThreshold** — Default 2 packets/sec.
- **KeylogVolumeThreshold** — Default 10KB per session — keystroke logs are small but dense.
