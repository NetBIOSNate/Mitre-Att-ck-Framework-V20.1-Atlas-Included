# AN1739 - Analytic 1739

[Mobile](../../README.md) / [Analytics](README.md)

For Android, detect Boot or Logon Initialization Scripts by correlating analyst-visible device/network evidence and management state; use streaming or batched telemetry only where the documented collector is deployed. Correlate Application Permission via Android Enterprise DPC / Application Vetting [DevicePolicyManager.getPermissionGrantState(); PackageManager manifest/requested-permission review]; Host Status via Android Enterprise DPC [DevicePolicyManager policy/compliance/security-state queries and SecurityLog events where supported]; Network Traffic Flow via Android Enterprise Network Logging / Enterprise VPN [DevicePolicyManager.retrieveNetworkLogs(): DnsEvent / ConnectEvent; VPN flow metadata]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0654#AN1739)

## Mutable elements

- **KnownInitPaths** — Known legitimate init paths: /data/adb/modules/<OEM-approved>/. Derive from device baseline inventory. Tightening: any new /data/adb/modules entry is anomalous on production fleet devices.
- **AppBaselineDomains** — Per-device CDN baseline from 30-day measurement.
- **PostRebootWindow** — Default 300s after MDM-recorded reboot event.
