# AN1720 - Analytic 1720

[Mobile](../../README.md) / [Analytics](README.md)

For iOS, detect Clipboard Data by correlating analyst-visible device/network evidence and management state; use streaming or batched telemetry only where the documented collector is deployed. Correlate API Calls via Application Vetting / Instrumented Dynamic Analysis [Dynamic API/runtime trace: UIPasteboard.general.string property accessed by app]; Network Connection Creation via Apple Network Extension / Enterprise VPN [NEFilterFlow / per-app VPN / secure-web-gateway flow metadata]; System Notifications via Managed App Telemetry / Apple MDM [ManagedApplicationFeedback or application-generated telemetry]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0643#AN1720)

**Platforms**  [iOS](../../Platforms/iOS.md)

## Log sources and channels

- **mobile:DynamicAnalysis** — Dynamic API/runtime trace: UIPasteboard.general.string property accessed by app · [DC0112 - API Calls](../Data%20Components/DC0112%20-%20API%20Calls.md)
- **iOS:NetworkExtension** — NEFilterFlow / per-app VPN / secure-web-gateway flow metadata · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **iOS:ManagedAppLog** — ManagedApplicationFeedback or application-generated telemetry · [DC0117 - System Notifications](../Data%20Components/DC0117%20-%20System%20Notifications.md)

## Mutable elements

- **SensitiveClipPattern** — Wallet/IBAN/credential regex. Tunable to org context.
- **PasteNotifWindow** — Default 5s — iOS generates notification synchronously.
- **ClipExfilWindow** — Default 10s.
- **AppCDNList** — Per-app CDN. Derive by measurement.
