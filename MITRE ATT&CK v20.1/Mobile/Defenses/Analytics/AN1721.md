# AN1721 - Analytic 1721

[Mobile](../../README.md) / [Analytics](README.md)

For iOS, detect Software Packing by correlating analyst-visible device/network evidence and management state; use streaming or batched telemetry only where the documented collector is deployed. Correlate Application Permission via Application Vetting [Code-signing entitlements and Info.plist privacy usage-description keys]; Network Traffic Flow via Apple Network Extension / Enterprise VPN [NEFilterFlow / per-app VPN / secure-web-gateway flow metadata]; Protected Configuration via Apple MDM [DeviceInformation / SecurityInfo / ProfileList / restrictions and compliance queries]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0644#AN1721)

**Platforms**  [iOS](../../Platforms/iOS.md)

## Log sources and channels

- **mobile:ApplicationVetting** — Code-signing entitlements and Info.plist privacy usage-description keys · [DC0114 - Application Permission](../Data%20Components/DC0114%20-%20Application%20Permission.md)
- **iOS:NetworkExtension** — NEFilterFlow / per-app VPN / secure-web-gateway flow metadata · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **iOS:MDM** — DeviceInformation / SecurityInfo / ProfileList / restrictions and compliance queries · [DC0115 - Protected Configuration](../Data%20Components/DC0115%20-%20Protected%20Configuration.md)

## Mutable elements

- **MDMApprovedCatalog** — MDM-managed app list. All enterprise-cert-signed apps should be in this catalog.
- **AppCDNList** — Per-app declared CDN from app documentation or 30-day baseline.
- **CertInstallWindow** — Default 3600s between cert profile and app install.
- **PostLaunchWindow** — Default 300s after first app launch.
