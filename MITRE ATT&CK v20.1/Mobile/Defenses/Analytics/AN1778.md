# AN1778 - Analytic 1778

[Mobile](../../README.md) / [Analytics](README.md)

For Android, detect GUI Input Capture by correlating analyst-visible device/network evidence and management state; use streaming or batched telemetry only where the documented collector is deployed. Correlate Application State via Android Enterprise / EMM [Managed package inventory/status and package metadata]; Network Traffic Content via Enterprise Secure Web Gateway / Proxy [DNS/HTTP(S) inspection or proxy transaction metadata where enterprise decryption/inspection is deployed]; Permissions Request via Android Enterprise DPC / Application Vetting [DevicePolicyManager.getPermissionGrantState(); PackageManager manifest/requested-permission review]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0676#AN1778)

**Platforms**  [Android](../../Platforms/Android.md)

## Mutable elements

- **OverlayAllowList** — Approved chat bubble apps, enterprise accessibility tools. Minimal.
- **TargetAppList** — Banking, enterprise SSO, auth apps.
- **EnterpriseDestList** — Enterprise IdP, known app backend endpoints.
- **CredentialExfilWindow** — Default 30s — credential submission is immediate.
