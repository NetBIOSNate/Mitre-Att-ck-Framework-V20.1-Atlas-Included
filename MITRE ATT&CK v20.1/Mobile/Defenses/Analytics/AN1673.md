# AN1673 - Analytic 1673

[Mobile](../../README.md) / [Analytics](README.md)

For Android, detect Evade Analysis Environment primarily during application vetting or controlled analysis rather than assuming a live device SOC feed. Correlate API Calls via Application Vetting / Instrumented Dynamic Analysis [Dynamic API/runtime trace: APK or IPA contains SystemProperties.get() calls, Runtime.exec getprop invocations, or code patterns checking for emulator artifacts (ro.product.model=sdk, IMEI=000000, screen size, sensor absence) — static detection of environment-check co]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0616#AN1673)

**Platforms**  [Android](../../Platforms/Android.md)

## Mutable elements

- **EnvCheckThreshold** — Default 5 calls per category within window. Tightening: 3.
- **EnvCheckWindow** — Default 10s at cold launch.
- **SystemEnumAllowList** — MDM agent, diagnostic apps. Minimal.
- **AppCDNList** — Per-app CDN. Derive by measurement.
- **FollowOnWindow** — Default 120s.
