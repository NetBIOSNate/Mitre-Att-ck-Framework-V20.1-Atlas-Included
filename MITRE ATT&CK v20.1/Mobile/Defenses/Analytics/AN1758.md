# AN1758 - Analytic 1758

[Mobile](../../README.md) / [Analytics](README.md)

For Android, detect Exploitation for Privilege Escalation by correlating analyst-visible device/network evidence and management state; use streaming or batched telemetry only where the documented collector is deployed. Correlate Application Permission via Android Enterprise DPC / Application Vetting [DevicePolicyManager.getPermissionGrantState(); PackageManager manifest/requested-permission review]; Host Status via Android Enterprise DPC [DevicePolicyManager policy/compliance/security-state queries and SecurityLog events where supported]; Network Traffic Flow via Android Enterprise Network Logging / Enterprise VPN [DevicePolicyManager.retrieveNetworkLogs(): DnsEvent / ConnectEvent; VPN flow metadata]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0665#AN1758)

## Mutable elements

- **PatchLagThreshold** — Default 30 days. Align to org patch SLA.
- **PrivilegedAppList** — MDM agent, OTA update service, approved Device Admin apps.
- **EscalationWindow** — Default 600s after root detection. Adjust to MDM check-in interval.
- **AppBaselineDomains** — Per-device CDN baseline, 30-day measurement.
