# AN1827 - Analytic 1827

[Mobile](../../README.md) / [Analytics](README.md)

For Android, detect Non-Standard Port by correlating analyst-visible device/network evidence and management state; use streaming or batched telemetry only where the documented collector is deployed. Correlate Application Permission via Android Enterprise DPC / Application Vetting [DevicePolicyManager.getPermissionGrantState(); PackageManager manifest/requested-permission review]; Application State via Android Enterprise / EMM [Managed package inventory/status and package metadata]; Network Traffic Content via Enterprise Secure Web Gateway / Proxy [DNS/HTTP(S) inspection or proxy transaction metadata where enterprise decryption/inspection is deployed]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0706#AN1827)

**Platforms**  [Android](../../Platforms/Android.md)

## Log sources and channels

- **android:DevicePolicyManager** — DevicePolicyManager.getPermissionGrantState(); PackageManager manifest/requested-permission review · [DC0114 - Application Permission](../Data%20Components/DC0114%20-%20Application%20Permission.md)
- **android:EMM** — Managed package inventory/status and package metadata · [DC0123 - Application State](../Data%20Components/DC0123%20-%20Application%20State.md)
- **webproxy:applog** — DNS/HTTP(S) inspection or proxy transaction metadata where enterprise decryption/inspection is deployed · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **mobile:DynamicAnalysis** — Dynamic API/runtime trace: Background work scheduler, foreground service, or persistent service activates · [DC0021 - OS API Execution](../Data%20Components/DC0021%20-%20OS%20API%20Execution.md)

## Mutable elements

- **ApprovedPortMap** — Protocol-to-port allowlist: HTTPS:443, HTTP:80, DNS:53, SMTP:587, IMAP:993, etc. Derive from enterprise network policy. Any TLS outside 443, 8443 (if approved) is non-standard.
- **ApprovedNetworkApps** — Apps approved for non-standard port use (enterprise network tools, VoIP apps with custom ports). Derive from MDM catalog. Tightening: empty — all non-standard port use flagged.
- **InteractionThreshold** — Default 300s. Sessions starting >5min after last user interaction with no foreground trigger are background-initiated.
