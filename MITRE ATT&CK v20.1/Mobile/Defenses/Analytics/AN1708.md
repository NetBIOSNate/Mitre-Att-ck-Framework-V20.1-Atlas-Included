# AN1708 - Analytic 1708

[Mobile](../../README.md) / [Analytics](README.md)

For Android, detect Accounts by correlating analyst-visible device/network evidence and management state; use streaming or batched telemetry only where the documented collector is deployed. Correlate API Calls via Application Vetting / Instrumented Dynamic Analysis [Dynamic API/runtime trace: AccountManager.getAccounts() OR getAccountsByType() called > $AccountEnumThreshold$ times within $AccountEnumWindow$ by app NOT IN $ApprovedAuthenticatorApps$]; Network Traffic Flow via Android Enterprise Network Logging / Enterprise VPN [DevicePolicyManager.retrieveNetworkLogs(): DnsEvent / ConnectEvent; VPN flow metadata]; Permissions Request via Android Enterprise DPC / Application Vetting [DevicePolicyManager.getPermissionGrantState(); PackageManager manifest/requested-permission review]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0635#AN1708)

**Platforms**  [Android](../../Platforms/Android.md)

## Log sources and channels

- **mobile:DynamicAnalysis** — Dynamic API/runtime trace: AccountManager.getAccounts() OR getAccountsByType() called > $AccountEnumThreshold$ times within $AccountEnumWindow$ by app NOT IN $ApprovedAuthenticatorApps$ · [DC0112 - API Calls](../Data%20Components/DC0112%20-%20API%20Calls.md)
- **android:EnterpriseNetworkLog** — DevicePolicyManager.retrieveNetworkLogs(): DnsEvent / ConnectEvent; VPN flow metadata · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **android:DevicePolicyManager** — DevicePolicyManager.getPermissionGrantState(); PackageManager manifest/requested-permission review · [DC0116 - Permissions Request](../Data%20Components/DC0116%20-%20Permissions%20Request.md)

## Mutable elements

- **ApprovedAuthenticatorApps** — MDM agent, approved authenticator, sync adapter apps. Minimal.
- **AccountEnumThreshold** — Default 5 calls — sync adapters call getAccountsByType once per type; bulk = enumeration.
- **AccountEnumWindow** — Default 60s.
- **AccountUplinkThreshold** — Default 5KB — account metadata is small; even small upload is significant.
- **AppCDNList** — Per-app CDN. Derive by measurement.
- **ExfilWindow** — Default 120s.
