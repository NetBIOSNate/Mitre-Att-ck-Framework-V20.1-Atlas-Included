# AN2290 - Analytic 2290

[Mobile](../../README.md) / [Analytics](README.md)

On managed Android devices with the necessary network and security telemetry enabled, identify an application package retrieved through a browser, messaging application, third-party store, or another external delivery mechanism. Correlate the package retrieval with a subsequent installation event on the same device, using package identity, delivery source, timing, and installer provenance where available.

Prioritize cases where the delivery source is outside approved distribution channels, the installer is inconsistent with authorized workflows, and the application is not approved for the device or user. Exclude sanctioned enterprise deployments, approved testing, and documented alternative distribution channels.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0940#AN2290)

**Platforms**  [Android](../../Platforms/Android.md)

## Mutable elements

- **ApprovedDistributionSources** — Authorized application stores, enterprise distribution services, and approved third-party application repositories.
- **ApprovedInstallerPackages** — Package identifiers of trusted applications permitted to initiate package installation, including approved stores and enterprise deployment agents.
- **ApprovedApplicationPackages** — Application package identifiers authorized for installation on managed devices.
- **ApprovedDeliveryDomains** — Domains and endpoints permitted to distribute APK files or other supported Android application packages.
- **DeliveryCorrelationWindow** — Maximum time between an observed package download or delivery event and a corresponding installation event.
- **PackageIdentityMatchRequired** — Whether delivery-to-installation correlation requires matching package identifiers, hashes, or other available package attributes.
- **AllowedInstallSourceTypes** — Permitted installation-source classifications, where the Android version and collection mechanism expose them.
- **ApprovedSigningCertificates** — Trusted signing-certificate fingerprints used to distinguish authorized application packages from unexpected or modified packages.
- **AllowedInstallationExceptions** — Documented exceptions for enterprise sideloading, developer testing, device provisioning, and approved alternative distribution workflows.
- **MonitoredDeliveryChannels** — Browser downloads, messaging applications, email attachments, third-party stores, and other delivery mechanisms covered by available telemetry.
- **MinimumDeliveryEvidence** — Required evidence to establish package delivery, such as a validated APK retrieval, observed package-file creation, or equivalent artifact.
- **MinimumCorrelationConfidence** — Minimum combination of package identity, installer provenance, device identity, and timing required to associate delivery with installation.
