# AN1853 - Analytic 1853

[Mobile](../../README.md) / [Analytics](README.md)

For Android, detect Compromise Software Supply Chain from documented management, network, or vetting evidence; treat state queries as periodic observations rather than real-time events. Correlate Application Permission via Android Enterprise DPC / Application Vetting [DevicePolicyManager.getPermissionGrantState(); PackageManager manifest/requested-permission review]; Application State via Android Enterprise / EMM [Managed package inventory/status and package metadata]; File Creation via Application Vetting / Forensic Acquisition [Dynamic filesystem trace or acquired app-container/filesystem artifacts: Compromised app writes staging, cache, or export artifacts inconsistent with its declared function within $PostInstallWindow$]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0721#AN1853)

## Mutable elements

- **TimeWindow** — Correlation window between install/update and subsequent runtime/network effects.
- **AllowedAppList** — Approved managed or trusted applications vary by organization and device group.
- **AllowedInstallerSources** — Permitted installer source or app delivery mechanism differs by fleet and policy.
- **AllowedSigningBaseline** — Expected signing lineage, certificate relationship, or integrity metadata vary by package.
- **ForegroundStateRequired** — Some protected-resource use is legitimate only when an app is foregrounded.
- **RecentUserInteractionWindow** — Defines how close behavior must be to user interaction to be considered expected.
- **AllowedDestinations** — Expected app destinations, CDNs, APIs, and service providers vary by app and tenant.
