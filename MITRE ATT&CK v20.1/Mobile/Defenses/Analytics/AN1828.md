# AN1828 - Analytic 1828

[Mobile](../../README.md) / [Analytics](README.md)

For iOS, detect Non-Standard Port by correlating analyst-visible device/network evidence and management state; use streaming or batched telemetry only where the documented collector is deployed. Correlate Application Permission via Application Vetting [Code-signing entitlements and Info.plist privacy usage-description keys]; Application State via Apple MDM [InstalledApplicationList / ManagedApplicationList]; Network Traffic Content via Enterprise Secure Web Gateway / Proxy [DNS/HTTP(S) inspection or proxy transaction metadata where enterprise decryption/inspection is deployed]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0706#AN1828)

**Platforms**  [iOS](../../Platforms/iOS.md)

## Log sources and channels

- **mobile:ApplicationVetting** — Code-signing entitlements and Info.plist privacy usage-description keys · [DC0114 - Application Permission](../Data%20Components/DC0114%20-%20Application%20Permission.md)
- **iOS:MDM** — InstalledApplicationList / ManagedApplicationList · [DC0123 - Application State](../Data%20Components/DC0123%20-%20Application%20State.md)
- **webproxy:applog** — DNS/HTTP(S) inspection or proxy transaction metadata where enterprise decryption/inspection is deployed · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **mobile:DynamicAnalysis** — Dynamic API/runtime trace: Background task or persistent networking event activates · [DC0021 - OS API Execution](../Data%20Components/DC0021%20-%20OS%20API%20Execution.md)

## Mutable elements

- **ApprovedPortMap** — Protocol-to-port allowlist: HTTPS:443, HTTP:80, DNS:53, SMTP:587, IMAP:993, etc. Derive from enterprise network policy. Any TLS outside 443, 8443 (if approved) is non-standard.
- **ApprovedNetworkApps** — Apps approved for non-standard port use (enterprise network tools, VoIP apps with custom ports). Derive from MDM catalog. Tightening: empty — all non-standard port use flagged.
- **InteractionThreshold** — Default 300s. Sessions starting >5min after last user interaction with no foreground trigger are background-initiated.
