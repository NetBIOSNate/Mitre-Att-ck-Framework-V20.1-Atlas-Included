# AN1817 - Analytic 1817

[Mobile](../../README.md) / [Analytics](README.md)

For iOS, detect Bidirectional Communication by correlating analyst-visible device/network evidence and management state; use streaming or batched telemetry only where the documented collector is deployed. Correlate Application Permission via Application Vetting [Code-signing entitlements and Info.plist privacy usage-description keys]; Application State via Apple MDM [InstalledApplicationList / ManagedApplicationList]; Network Traffic Content via Enterprise Secure Web Gateway / Proxy [DNS/HTTP(S) inspection or proxy transaction metadata where enterprise decryption/inspection is deployed]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0700#AN1817)

**Platforms**  [iOS](../../Platforms/iOS.md)

## Log sources and channels

- **mobile:ApplicationVetting** — Code-signing entitlements and Info.plist privacy usage-description keys · [DC0114 - Application Permission](../Data%20Components/DC0114%20-%20Application%20Permission.md)
- **iOS:MDM** — InstalledApplicationList / ManagedApplicationList · [DC0123 - Application State](../Data%20Components/DC0123%20-%20Application%20State.md)
- **webproxy:applog** — DNS/HTTP(S) inspection or proxy transaction metadata where enterprise decryption/inspection is deployed · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **mobile:DynamicAnalysis** — Dynamic API/runtime trace: Background task activation immediately before retrieve-then-write cycle on supervised device · [DC0021 - OS API Execution](../Data%20Components/DC0021%20-%20OS%20API%20Execution.md)

## Mutable elements

- **ApprovedPlatformApps** — Apps approved for bidirectional use of each platform: note-taking app for its own cloud, email app for its service. Non-platform apps doing read-then-write cycles are anomalous.
- **BidirectionalCycleWindow** — Default 120s between inbound retrieval and outbound write constituting one C2 cycle. Tightening: 30s.
- **CycleCountThreshold** — Default 3 retrieve-write cycles within $ObservationWindow$. Single cycle may be legitimate; repeated cycles are C2 pattern.
- **ObservationWindow** — Default 3600s.
