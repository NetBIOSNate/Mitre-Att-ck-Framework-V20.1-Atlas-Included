# AN1789 - Analytic 1789

[Mobile](../../README.md) / [Analytics](README.md)

For iOS, detect File and Directory Discovery by correlating analyst-visible device/network evidence and management state; use streaming or batched telemetry only where the documented collector is deployed. Correlate Application State via Apple MDM [InstalledApplicationList / ManagedApplicationList]; Host Status via Apple MDM [DeviceInformation / SecurityInfo / ProfileList / restrictions and compliance queries]; Network Traffic Flow via Apple Network Extension / Enterprise VPN [NEFilterFlow / per-app VPN / secure-web-gateway flow metadata]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0682#AN1789)

**Platforms**  [iOS](../../Platforms/iOS.md)

## Log sources and channels

- **iOS:MDM** — InstalledApplicationList / ManagedApplicationList · [DC0123 - Application State](../Data%20Components/DC0123%20-%20Application%20State.md)
- **iOS:MDM** — DeviceInformation / SecurityInfo / ProfileList / restrictions and compliance queries · [DC0018 - Host Status](../Data%20Components/DC0018%20-%20Host%20Status.md)
- **iOS:NetworkExtension** — NEFilterFlow / per-app VPN / secure-web-gateway flow metadata · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **HighValueAppList** — Banking, auth, enterprise apps with sensitive local data.
- **HighValueAppCount** — Default 2 — single app could be accidental; multiple indicates targeted environment.
- **ConnectionBurstThreshold** — Default 5 connections to same dest within window.
- **SmallRequestThreshold** — Default 50KB per request — file listing and small file pickups.
- **ExfilWindow** — Default 300s after jailbreak detection.
