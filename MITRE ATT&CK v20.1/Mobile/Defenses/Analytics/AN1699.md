# AN1699 - Analytic 1699

[Mobile](../../README.md) / [Analytics](README.md)

For Android, detect Exploitation for Client Execution by correlating analyst-visible device/network evidence and management state; use streaming or batched telemetry only where the documented collector is deployed. Correlate Host Status via Android Enterprise DPC [DevicePolicyManager policy/compliance/security-state queries and SecurityLog events where supported]; Network Connection Creation via Android Enterprise Network Logging / Enterprise VPN [DevicePolicyManager.retrieveNetworkLogs(): DnsEvent / ConnectEvent; VPN flow metadata]; Process Creation via Application Vetting / Managed Device Telemetry [execve()]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0629#AN1699)

**Platforms**  [Android](../../Platforms/Android.md)

- **android:DevicePolicyManager** — DevicePolicyManager policy/compliance/security-state queries and SecurityLog events where supported · [DC0018 - Host Status](../Data%20Components/DC0018%20-%20Host%20Status.md)
- **android:EnterpriseNetworkLog** — DevicePolicyManager.retrieveNetworkLogs(): DnsEvent / ConnectEvent; VPN flow metadata · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **mobile:DynamicAnalysis** — execve() · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **MediaProcessList** — mediaserver, chromium, com.android.browser, com.android.mms, com.android.messaging. Expand per installed browser.
- **KnownMediaChildren** — Renderer, GPU process, sandboxed service workers. Derive from media process baseline.
- **ExploitWindow** — Default 10s between media process activity and child spawn.
- **AppBaselineDomains** — Per-app CDN baseline.
- **PostExploitWindow** — Default 30s between child spawn and C2 connection.
- **PatchLagThreshold** — Default 30 days. Context only — not primary signal.
