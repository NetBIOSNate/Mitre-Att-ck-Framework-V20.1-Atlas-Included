# AN1845 - Analytic 1845

[Mobile](../../README.md) / [Analytics](README.md)

For Android, detect Linked Devices by correlating analyst-visible device/network evidence and management state; use streaming or batched telemetry only where the documented collector is deployed. Correlate API Calls via Application Vetting / Instrumented Dynamic Analysis [Dynamic API/runtime trace: camera activated within app IN $MessagingAppList$ — QR scan requires camera access; activation in messaging app context is the trigger signal]; Network Connection Creation via Android Enterprise Network Logging / Enterprise VPN [DevicePolicyManager.retrieveNetworkLogs(): DnsEvent / ConnectEvent; VPN flow metadata]; Network Traffic Content via Enterprise Secure Web Gateway / Proxy [DNS/HTTP(S) inspection or proxy transaction metadata where enterprise decryption/inspection is deployed]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0716#AN1845)

**Platforms**  [Android](../../Platforms/Android.md)

## Log sources and channels

- **mobile:DynamicAnalysis** — Dynamic API/runtime trace: camera activated within app IN $MessagingAppList$ — QR scan requires camera access; activation in messaging app context is the trigger signal · [DC0112 - API Calls](../Data%20Components/DC0112%20-%20API%20Calls.md)
- **android:EnterpriseNetworkLog** — DevicePolicyManager.retrieveNetworkLogs(): DnsEvent / ConnectEvent; VPN flow metadata · [DC0082 - Network Connection Creation](../Data%20Components/DC0082%20-%20Network%20Connection%20Creation.md)
- **webproxy:applog** — DNS/HTTP(S) inspection or proxy transaction metadata where enterprise decryption/inspection is deployed · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **MessagingAppList** — org.thoughtcrime.securesms (Signal), com.whatsapp, com.whatsapp.w4b.
- **DeviceLinkAPIEndpoints** — /v1/devices, /v1/provisioning, /linked — Signal and WhatsApp device registration URI patterns.
- **QRLinkWindow** — Default 30s between camera activation and device link PUT — QR scan to registration is near-instantaneous.
- **SyncVolumeThreshold** — Default 5MB — message history sync is significantly larger than normal registration.
- **SyncWindow** — Default 120s after device link PUT.
