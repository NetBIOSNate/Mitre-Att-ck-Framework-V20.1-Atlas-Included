# AN1665 - Analytic 1665

[Mobile](../../README.md) / [Analytics](README.md)

For Android, detect Access Notifications from documented management, network, or vetting evidence; treat state queries as periodic observations rather than real-time events. Correlate Application Permission via Android Enterprise DPC / Application Vetting [DevicePolicyManager.getPermissionGrantState(); PackageManager manifest/requested-permission review]; Application State via Android Enterprise / EMM [Managed package inventory/status and package metadata]; OS API Execution via Application Vetting / Instrumented Dynamic Analysis [Dynamic API/runtime trace: App intercepts notification content from source_app IN $HighValueNotifApps$ (banking, auth, messaging) while AppState=background]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0611#AN1665)

**Platforms**  [Android](../../Platforms/Android.md)

- **android:EMM** — Managed package inventory/status and package metadata · [DC0123 - Application State](../Data%20Components/DC0123%20-%20Application%20State.md)
- **mobile:DynamicAnalysis** — Dynamic API/runtime trace: App intercepts notification content from source_app IN $HighValueNotifApps$ (banking, auth, messaging) while AppState=background · [DC0021 - OS API Execution](../Data%20Components/DC0021%20-%20OS%20API%20Execution.md)

## Mutable elements

- **NotificationAllowList** — Approved notification management apps (Tasker-equivalent enterprise tools, approved wearable companions). Minimal. Derive from MDM catalog.
- **HighValueNotifApps** — Banking, 2FA authenticator, enterprise email, SMS apps whose notification content contains OTPs or credentials. Derive from MDM app catalog by data-sensitivity tier.
- **InteractionThreshold** — Default 300s. Notification interception >5min after last user interaction with device locked = covert.
