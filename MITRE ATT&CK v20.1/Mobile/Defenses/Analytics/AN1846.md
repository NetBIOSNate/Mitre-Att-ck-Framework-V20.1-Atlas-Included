# AN1846 - Analytic 1846

[Mobile](../../README.md) / [Analytics](README.md)

For iOS, detect Linked Devices by correlating analyst-visible device/network evidence and management state; use streaming or batched telemetry only where the documented collector is deployed. Correlate Network Connection Creation via Apple Network Extension / Enterprise VPN [NEFilterFlow / per-app VPN / secure-web-gateway flow metadata]; Network Traffic Content via Enterprise Secure Web Gateway / Proxy [DNS/HTTP(S) inspection or proxy transaction metadata where enterprise decryption/inspection is deployed]; Permissions Request via Application Vetting [Code-signing entitlements and Info.plist privacy usage-description keys]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0716#AN1846)

**Platforms**  [iOS](../../Platforms/iOS.md)

## Mutable elements

- **MessagingBundleIDs** — org.whispersystems.signal, net.whatsapp.WhatsApp.
- **DeviceLinkAPIEndpoints** — /v1/devices, /v1/provisioning URI patterns for Signal and WhatsApp. Update from platform API documentation.
- **QRLinkWindow** — Default 30s between camera activation and device-link PUT — human QR scan-to-submit timing. Tightening: 15s.
- **SyncVolumeThreshold** — Default 5MB — message history sync is large relative to registration overhead.
- **SyncWindow** — Default 120s after device-link PUT.
