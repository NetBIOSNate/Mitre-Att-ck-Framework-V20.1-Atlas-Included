# AN1675 - Analytic 1675

[Mobile](../../README.md) / [Analytics](README.md)

For Android, detect Dead Drop Resolver by correlating analyst-visible device/network evidence and management state; use streaming or batched telemetry only where the documented collector is deployed. Correlate Application Permission via Android Enterprise DPC / Application Vetting [DevicePolicyManager.getPermissionGrantState(); PackageManager manifest/requested-permission review]; Application State via Android Enterprise / EMM [Managed package inventory/status and package metadata]; Network Traffic Content via Enterprise Secure Web Gateway / Proxy [DNS/HTTP(S) inspection or proxy transaction metadata where enterprise decryption/inspection is deployed]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0617#AN1675)

**Platforms**  [Android](../../Platforms/Android.md)

## Log sources and channels

- **android:DevicePolicyManager** — DevicePolicyManager.getPermissionGrantState(); PackageManager manifest/requested-permission review · [DC0114 - Application Permission](../Data%20Components/DC0114%20-%20Application%20Permission.md)
- **android:EMM** — Managed package inventory/status and package metadata · [DC0123 - Application State](../Data%20Components/DC0123%20-%20Application%20State.md)
- **webproxy:applog** — DNS/HTTP(S) inspection or proxy transaction metadata where enterprise decryption/inspection is deployed · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **mobile:DynamicAnalysis** — Dynamic API/runtime trace: Background work scheduler or persistent service triggered the platform retrieval without user interaction · [DC0021 - OS API Execution](../Data%20Components/DC0021%20-%20OS%20API%20Execution.md)

## Mutable elements

- **AppDeclaredCDN** — Per-app declared network destinations. Legitimate platform accesses (e.g., Slack app connecting to slack.com) should be in this list. Any platform access outside declared CDN is the dead-drop signal.
- **ApprovedPlatformApps** — Apps approved for each public platform: social media apps for their own platform, productivity apps for their cloud storage. Non-platform apps accessing these platforms in background are anomalous.
- **AppBaselineDomains** — 30-day per-app network destination baseline.
- **ResolverPivotWindow** — Default 120s between dead-drop fetch and C2 pivot connection. Tightening: 30s — synchronous resolve-then-connect.
