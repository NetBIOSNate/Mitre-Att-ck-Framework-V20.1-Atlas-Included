# AN1797 - Analytic 1797

[Mobile](../../README.md) / [Analytics](README.md)

For Android, detect Impair Defenses from documented management, network, or vetting evidence; treat state queries as periodic observations rather than real-time events. Correlate Application Permission via Android Enterprise DPC / Application Vetting [DevicePolicyManager.getPermissionGrantState(); PackageManager manifest/requested-permission review]; OS API Execution via Application Vetting / Instrumented Dynamic Analysis [Dynamic API/runtime trace: App invokes package management, DevicePolicyManager, or settings operations capable of disabling security tooling — API invocation to disable security control]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0687#AN1797)

## Mutable elements

- **ElevationAllowList** — MDM agent and approved Device Admin apps only. Any other app acquiring Device Admin then modifying security settings is Impair Defenses.
- **SecurityToolPackageList** — MDM agent, AV, MTD packages deployed on managed fleet. Derive from MDM enrollment configuration.
