# AN1682 - Analytic 1682

[Mobile](../../README.md) / [Analytics](README.md)

For iOS, detect Web Protocols by correlating analyst-visible device/network evidence and management state; use streaming or batched telemetry only where the documented collector is deployed. Correlate API Calls via Application Vetting / Instrumented Dynamic Analysis [Dynamic API/runtime trace: UNUserNotificationCenter or legacy UIApplication.registerForRemoteNotifications with Apple Team ID NOT IN $APNSAllowList$ — rogue APNS sender registration]; Network Connection Creation via Apple Network Extension / Enterprise VPN [NEFilterFlow / per-app VPN / secure-web-gateway flow metadata]; Network Traffic Content via Enterprise Secure Web Gateway / Proxy [DNS/HTTP(S) inspection or proxy transaction metadata where enterprise decryption/inspection is deployed]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0620#AN1682)

**Platforms**  [iOS](../../Platforms/iOS.md)

## Mutable elements

- **AppBaselineDomains** — Per-app CDN/update domains from 30-day baseline.
- **APNSAllowList** — Enterprise Apple Team IDs for deployed apps. Derive from Apple Developer account.
- **BeaconVarianceThreshold** — Default 15% interval variance.
