# AN1723 - Analytic 1723

[Mobile](../../README.md) / [Analytics](README.md)

For Android, detect Lockscreen Bypass by correlating analyst-visible device/network evidence and management state; use streaming or batched telemetry only where the documented collector is deployed. Correlate Application Permission via Android Enterprise DPC / Application Vetting [DevicePolicyManager.getPermissionGrantState(); PackageManager manifest/requested-permission review]; Application State via Android Enterprise / EMM [Managed package inventory/status and package metadata]; Protected Configuration via Android Enterprise DPC [DevicePolicyManager policy/compliance/security-state queries and SecurityLog events where supported]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0645#AN1723)

**Platforms**  [Android](../../Platforms/Android.md)

## Log sources and channels

- **android:DevicePolicyManager** — DevicePolicyManager.getPermissionGrantState(); PackageManager manifest/requested-permission review · [DC0114 - Application Permission](../Data%20Components/DC0114%20-%20Application%20Permission.md)
- **android:EMM** — Managed package inventory/status and package metadata · [DC0123 - Application State](../Data%20Components/DC0123%20-%20Application%20State.md)
- **android:DevicePolicyManager** — DevicePolicyManager policy/compliance/security-state queries and SecurityLog events where supported · [DC0115 - Protected Configuration](../Data%20Components/DC0115%20-%20Protected%20Configuration.md)

## Mutable elements

- **AuthPolicyAllowList** — MDM-managed authentication policy changes only. Any lock policy weakening outside MDM-authorized change is anomalous. Derive from MDM policy management logs.
- **ElevationAllowList** — Approved accessibility and Device Admin apps that may interact with lockscreen for legitimate purposes (enterprise kiosk). Derive from MDM catalog.
- **LockBypassWindow** — Default 10s between lock state and anomalous app activity. Lock-bypass is near-instantaneous.
