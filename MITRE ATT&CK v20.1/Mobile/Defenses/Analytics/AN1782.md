# AN1782 - Analytic 1782

[Mobile](../../README.md) / [Analytics](README.md)

For Android, detect Contact List by correlating analyst-visible device/network evidence and management state; use streaming or batched telemetry only where the documented collector is deployed. Correlate API Calls via Application Vetting / Instrumented Dynamic Analysis [Dynamic API/runtime trace: ContentResolver.query(ContactsContract) with projection=all_fields]; Network Traffic Flow via Android Enterprise Network Logging / Enterprise VPN [DevicePolicyManager.retrieveNetworkLogs(): DnsEvent / ConnectEvent; VPN flow metadata]; Permissions Request via Android Enterprise DPC / Application Vetting [DevicePolicyManager.getPermissionGrantState(); PackageManager manifest/requested-permission review]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0679#AN1782)

## Mutable elements

- **ApprovedContactsApps** — Approved CRM, exchange sync, address book apps. Derive from MDM catalog.
- **ContactQueryThreshold** — Default 50 queries/2min — CRM apps legitimately read contacts; tune by app category. Tightening: 20 for unknown apps.
- **ContactUplinkThreshold** — Default 100KB — contact records average ~4KB; 25 contacts = 100KB.
- **ContactSyncCDNList** — Exchange, Salesforce, Google People API endpoints.
- **ExfilWindow** — Default 120s.
