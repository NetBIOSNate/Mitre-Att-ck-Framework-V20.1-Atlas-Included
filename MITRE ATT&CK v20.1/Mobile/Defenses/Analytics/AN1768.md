# AN1768 - Analytic 1768

[Mobile](../../README.md) / [Analytics](README.md)

For iOS, detect Archive Collected Data from documented management, network, or vetting evidence; treat state queries as periodic observations rather than real-time events. Correlate Application Permission via Application Vetting [Code-signing entitlements and Info.plist privacy usage-description keys]; Application State via Apple MDM [InstalledApplicationList / ManagedApplicationList]; File Creation via Application Vetting / Forensic Acquisition [Dynamic filesystem trace or acquired app-container/filesystem artifacts: App writes large container, temp package, or high-entropy blob to container-local storage after clustered data access — staged archive artifact]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0670#AN1768)

**Platforms**  [iOS](../../Platforms/iOS.md)

## Log sources and channels

- **mobile:ApplicationVetting** — Code-signing entitlements and Info.plist privacy usage-description keys · [DC0114 - Application Permission](../Data%20Components/DC0114%20-%20Application%20Permission.md)
- **iOS:MDM** — InstalledApplicationList / ManagedApplicationList · [DC0123 - Application State](../Data%20Components/DC0123%20-%20Application%20State.md)
- **mobile:ForensicArtifacts** — Dynamic filesystem trace or acquired app-container/filesystem artifacts: App writes large container, temp package, or high-entropy blob to container-local storage after clustered data access — staged archive artifact · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **mobile:DynamicAnalysis** — Dynamic API/runtime trace: App performs bulk data transformation or packaging-like processing on collected records prior to outbound transfer on supervised device · [DC0021 - OS API Execution](../Data%20Components/DC0021%20-%20OS%20API%20Execution.md)

## Mutable elements

- **TimeWindow** — Correlation window between lifecycle event, local package creation, and upload
- **AllowedAppList** — Managed apps expected to archive, export, or synchronize data
- **AllowedDestinationList** — Approved cloud, enterprise, or sync endpoints for legitimate exports
- **ForegroundStateRequired** — Whether packaging or export should occur only during active user interaction
- **ArchiveSizeThreshold** — Minimum size for suspicious local package or blob
- **EntropyThreshold** — Threshold for identifying encrypted or compressed staged output
- **UplinkBytesThreshold** — Minimum outbound volume consistent with recently created archive
