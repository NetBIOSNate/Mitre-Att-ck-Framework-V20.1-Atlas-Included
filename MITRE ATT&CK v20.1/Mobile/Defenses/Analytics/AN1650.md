# AN1650 - Analytic 1650

[Mobile](../../README.md) / [Analytics](README.md)

For Android, detect Call Log by correlating analyst-visible device/network evidence and management state; use streaming or batched telemetry only where the documented collector is deployed. Correlate API Calls via Application Vetting / Instrumented Dynamic Analysis [Dynamic API/runtime trace: ContentResolver.query(CallLog.Calls) with query_count > $CallLogQueryThreshold$ by app NOT IN $ApprovedDialerApps$]; Network Traffic Flow via Android Enterprise Network Logging / Enterprise VPN [DevicePolicyManager.retrieveNetworkLogs(): DnsEvent / ConnectEvent; VPN flow metadata]; Permissions Request via Android Enterprise DPC / Application Vetting [DevicePolicyManager.getPermissionGrantState(); PackageManager manifest/requested-permission review]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0602#AN1650)

**Platforms**  [Android](../../Platforms/Android.md)

## Log sources and channels

- **mobile:DynamicAnalysis** — Dynamic API/runtime trace: ContentResolver.query(CallLog.Calls) with query_count > $CallLogQueryThreshold$ by app NOT IN $ApprovedDialerApps$ · [DC0112 - API Calls](../Data%20Components/DC0112%20-%20API%20Calls.md)
- **android:EnterpriseNetworkLog** — DevicePolicyManager.retrieveNetworkLogs(): DnsEvent / ConnectEvent; VPN flow metadata · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **android:DevicePolicyManager** — DevicePolicyManager.getPermissionGrantState(); PackageManager manifest/requested-permission review · [DC0116 - Permissions Request](../Data%20Components/DC0116%20-%20Permissions%20Request.md)

## Mutable elements

- **ApprovedDialerApps** — Default dialer, approved call backup apps. Minimal.
- **CallLogQueryThreshold** — Default 10 queries/2min — low threshold; call log has minimal legitimate background access.
- **CallLogUplinkThreshold** — Default 20KB — call records are small; even 200 records fit in ~20KB.
- **AppCDNList** — Per-app CDN. Derive by measurement.
- **ExfilWindow** — Default 120s.
