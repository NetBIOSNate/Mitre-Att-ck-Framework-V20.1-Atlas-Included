# AN1664 - Analytic 1664

[Mobile](../../README.md) / [Analytics](README.md)

For iOS, detect One-Way Communication by correlating analyst-visible device/network evidence and management state; use streaming or batched telemetry only where the documented collector is deployed. Correlate Application Permission via Application Vetting [Code-signing entitlements and Info.plist privacy usage-description keys]; Application State via Apple MDM [InstalledApplicationList / ManagedApplicationList]; Network Traffic Content via Enterprise Secure Web Gateway / Proxy [DNS/HTTP(S) inspection or proxy transaction metadata where enterprise decryption/inspection is deployed]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0610#AN1664)

**Platforms**  [iOS](../../Platforms/iOS.md)

## Log sources and channels

- **mobile:ApplicationVetting** — Code-signing entitlements and Info.plist privacy usage-description keys · [DC0114 - Application Permission](../Data%20Components/DC0114%20-%20Application%20Permission.md)
- **iOS:MDM** — InstalledApplicationList / ManagedApplicationList · [DC0123 - Application State](../Data%20Components/DC0123%20-%20Application%20State.md)
- **webproxy:applog** — DNS/HTTP(S) inspection or proxy transaction metadata where enterprise decryption/inspection is deployed · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)

## Mutable elements

- **ApprovedPlatformApps** — Apps approved for periodic read access to each platform. News readers (RSS/social), weather apps — legitimate pollers. Unknown apps periodically polling paste/code platforms are anomalous.
- **PollingIntervalThreshold** — Default 900s (15 min) maximum interval between fetches to same platform from background. More frequent background polling without user activity = C2 check-in.
- **CommandProcessWindow** — Default 30s between platform content retrieval and behavioral change (new connection, file write). Command processing is near-synchronous.
