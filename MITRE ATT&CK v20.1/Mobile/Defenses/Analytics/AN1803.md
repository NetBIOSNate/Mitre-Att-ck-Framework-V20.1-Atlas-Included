# AN1803 - Analytic 1803

[Mobile](../../README.md) / [Analytics](README.md)

For iOS, detect Replication Through Removable Media from documented management, network, or vetting evidence; treat state queries as periodic observations rather than real-time events. Correlate Host Status via Apple MDM [DeviceInformation / SecurityInfo / ProfileList / restrictions and compliance queries]; Protected Configuration via Apple MDM [DeviceInformation / SecurityInfo / ProfileList / restrictions and compliance queries]; System Settings via Apple MDM [DeviceInformation / SecurityInfo / ProfileList / restrictions and compliance queries]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0691#AN1803)

## Mutable elements

- **USBInstallWindow** — Default 300s between USB mode change and install or file delivery event. Tightening: 60s — synchronous USB delivery.
- **AuthorizedDeveloperDevices** — Device serial numbers authorized for developer mode (test/dev fleet only). Derive from IT device management. Production devices should have empty list.
