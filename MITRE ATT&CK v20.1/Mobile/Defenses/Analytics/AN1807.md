# AN1807 - Analytic 1807

[Mobile](../../README.md) / [Analytics](README.md)

For Android, detect Hijack Execution Flow from documented management, network, or vetting evidence; treat state queries as periodic observations rather than real-time events. Correlate File Access via Application Vetting / Forensic Acquisition [Dynamic filesystem trace or acquired app-container/filesystem artifacts: App loads executable or library from writable external directory (/sdcard/, app cache, /data/local/tmp/) — writable-path library load is exploitable hijack vector]; OS API Execution via Application Vetting / Instrumented Dynamic Analysis [Dynamic API/runtime trace: App loads library or executes component]; Process Creation via Application Vetting / Managed Device Telemetry [App execution triggered with unexpected parent context or via indirect invocation (intent redirect, implicit intent resolution to unexpected handler) — indirect invocation path is the flow hijack confirmation]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0694#AN1807)

**Platforms**  [Android](../../Platforms/Android.md)

## Log sources and channels

- **mobile:ForensicArtifacts** — Dynamic filesystem trace or acquired app-container/filesystem artifacts: App loads executable or library from writable external directory (/sdcard/, app cache, /data/local/tmp/) — writable-path library load is exploitable hijack vector · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **mobile:DynamicAnalysis** — Dynamic API/runtime trace: App loads library or executes component · [DC0021 - OS API Execution](../Data%20Components/DC0021%20-%20OS%20API%20Execution.md)
- **mobile:DynamicAnalysis** — App execution triggered with unexpected parent context or via indirect invocation (intent redirect, implicit intent resolution to unexpected handler) — indirect invocation path is the flow hijack confirmation · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)

## Mutable elements

- **AppInternalPaths** — Expected library load paths per app: /data/app/<package>/lib/, /data/dalvik-cache/. Derive from app package manifest and baseline measurement. Any library loaded from outside these paths is anomalous.
- **WritablePathList** — /sdcard/, /data/local/tmp/, /data/data/<app>/files/ — directories writable without elevated privilege that are exploitable for library substitution.
