# AN1806 - Analytic 1806

[Mobile](../../README.md) / [Analytics](README.md)

For Android, detect Disable or Modify Tools from documented management, network, or vetting evidence; treat state queries as periodic observations rather than real-time events. Correlate Application Permission via Android Enterprise DPC / Application Vetting [DevicePolicyManager.getPermissionGrantState(); PackageManager manifest/requested-permission review]; File Creation via Application Vetting / Forensic Acquisition [Dynamic filesystem trace or acquired app-container/filesystem artifacts: App writes to or modifies protected configuration files or local control structures of deployed security tools]; OS API Execution via Application Vetting / Instrumented Dynamic Analysis [Dynamic API/runtime trace: App invokes package manager operations (disable component, clear data, request uninstall) or settings modifications targeting security tool packages IN $SecurityToolPackageList$]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0693#AN1806)

## Mutable elements

- **SecurityToolPackageList** — MDM agent, MTD (Zimperium, Lookout, MS Defender), AV packages deployed on managed fleet. Derive from MDM enrollment configuration. Update when new tools deployed.
- **ElevationAllowList** — MDM agent only for legitimate Device Admin operations against security tools.
