# AN1854 - Analytic 1854

[Mobile](../../README.md) / [Analytics](README.md)

For iOS, detect Compromise Software Supply Chain from documented management, network, or vetting evidence; treat state queries as periodic observations rather than real-time events. Correlate Application Permission via Application Vetting [Code-signing entitlements and Info.plist privacy usage-description keys]; Application State via Apple MDM [InstalledApplicationList / ManagedApplicationList]; OS API Execution via Application Vetting / Instrumented Dynamic Analysis [Dynamic API/runtime trace: Launch services, extension-handling, or framework subsystem anomalies occur near install or first launch of recently updated trusted app on supervised device]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0721#AN1854)

- **mobile:DynamicAnalysis** — Dynamic API/runtime trace: Launch services, extension-handling, or framework subsystem anomalies occur near install or first launch of recently updated trusted app on supervised device · [DC0021 - OS API Execution](../Data%20Components/DC0021%20-%20OS%20API%20Execution.md)

## Mutable elements

- **TimeWindow** — Correlation window between app install/update and subsequent lifecycle or network anomalies.
- **SupervisedRequired** — Strongest app inventory and managed state analytics depend on supervised iOS devices.
- **AllowedManagedApps** — Approved managed app set varies by organization, business unit, and device profile.
- **ExpectedVersionTransitionPolicy** — Allowed upgrade paths, release rings, and phased rollout patterns vary by environment.
- **AllowedDestinations** — Expected app destinations, enterprise backends, Apple services, and CDNs differ by app.
- **BackgroundRefreshBaseline** — Legitimate background activity differs by app category and policy.
- **RecentUserInteractionWindow** — Defines how close runtime/network activity must be to user action to be considered expected.
- **UplinkBytesThreshold** — Threshold for suspicious post-update outbound transfer volume.
