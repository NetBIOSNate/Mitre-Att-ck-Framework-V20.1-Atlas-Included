# AN1700 - Analytic 1700

[Mobile](../../README.md) / [Analytics](README.md)

For iOS, detect Exploitation for Client Execution by correlating analyst-visible device/network evidence and management state; use streaming or batched telemetry only where the documented collector is deployed. Correlate Host Status via Apple MDM [DeviceInformation / SecurityInfo / ProfileList / restrictions and compliance queries]; Network Connection Creation via Apple Network Extension / Enterprise VPN [NEFilterFlow / per-app VPN / secure-web-gateway flow metadata]; Process Creation via Application Vetting / Managed Device Telemetry [com.apple.WebContent or com.apple.imagent process shows unexpected child spawn or memory fault at level=fault in Unified Log — kernel fault in message-processing subsystem is exploit execution signal]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0629#AN1700)

## Mutable elements

- **AppleSystemBaseline** — Known Apple CDN, update, and push notification server IP ranges. Derive from Apple published IP lists.
- **PostExploitWindow** — Default 60s between fault and C2 connection.
- **MinSecureVersion** — Latest Apple security release. Update from Apple security advisories.
