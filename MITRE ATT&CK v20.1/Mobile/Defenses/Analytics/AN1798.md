# AN1798 - Analytic 1798

[Mobile](../../README.md) / [Analytics](README.md)

For Android, detect Out of Band Data by correlating analyst-visible device/network evidence and management state; use streaming or batched telemetry only where the documented collector is deployed. Correlate API Calls via Application Vetting / Instrumented Dynamic Analysis [Dynamic API/runtime trace: NotificationListenerService.onNotificationPosted() receiving notifications from source_app IN $HighValueNotifApps$ by listener NOT IN $NotificationAllowList$]; Network Traffic Content via Enterprise Secure Web Gateway / Proxy [DNS/HTTP(S) inspection or proxy transaction metadata where enterprise decryption/inspection is deployed]; System Notifications via Android Enterprise / Managed App Telemetry [Documented DPC/admin callbacks or managed-app generated event telemetry]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0688#AN1798)

**Platforms**  [Android](../../Platforms/Android.md)

## Log sources and channels

- **mobile:DynamicAnalysis** — Dynamic API/runtime trace: NotificationListenerService.onNotificationPosted() receiving notifications from source_app IN $HighValueNotifApps$ by listener NOT IN $NotificationAllowList$ · [DC0112 - API Calls](../Data%20Components/DC0112%20-%20API%20Calls.md)
- **webproxy:applog** — DNS/HTTP(S) inspection or proxy transaction metadata where enterprise decryption/inspection is deployed · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **android:ManagedAppLog** — Documented DPC/admin callbacks or managed-app generated event telemetry · [DC0117 - System Notifications](../Data%20Components/DC0117%20-%20System%20Notifications.md)

## Mutable elements

- **NotificationAllowList** — Approved companion/wearable apps. Minimal. Derive from MDM catalog.
- **HighValueNotifApps** — Banking, auth, enterprise SSO, SMS/messaging app packages.
- **AppCDNList** — Per-app CDN. Derive by measurement.
- **NotifExfilWindow** — Default 30s — OTP codes expire quickly; transmission is immediate.
