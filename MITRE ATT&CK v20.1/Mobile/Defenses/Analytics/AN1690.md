# AN1690 - Analytic 1690

[Mobile](../../README.md) / [Analytics](README.md)

For iOS, detect Remote Access Software by correlating analyst-visible device/network evidence and management state; use streaming or batched telemetry only where the documented collector is deployed. Correlate Application Permission via Application Vetting [Code-signing entitlements and Info.plist privacy usage-description keys]; Network Connection Creation via Apple Network Extension / Enterprise VPN [NEFilterFlow / per-app VPN / secure-web-gateway flow metadata]; Network Traffic Flow via Apple Network Extension / Enterprise VPN [NEFilterFlow / per-app VPN / secure-web-gateway flow metadata]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0624#AN1690)

**Platforms**  [iOS](../../Platforms/iOS.md)

- **iOS:NetworkExtension** — NEFilterFlow / per-app VPN / secure-web-gateway flow metadata · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **RASAppBundleIDs** — TeamViewer, AnyDesk, AirServer iOS bundle IDs.
- **ApprovedRASApps** — IT-authorized iOS remote support bundles.
- **RASInfrastructureIPs** — RAS vendor published IP ranges.
- **PersistentSessionThreshold** — Default 300s.
- **InteractiveRatioRange** — Default 0.1–10.0.
