# AN1746 - Analytic 1746

[Mobile](../../README.md) / [Analytics](README.md)

For iOS, detect Subvert Trust Controls from documented management, network, or vetting evidence; treat state queries as periodic observations rather than real-time events. Correlate Application Permission via Application Vetting [Code-signing entitlements and Info.plist privacy usage-description keys]; File Creation via Application Vetting / Forensic Acquisition [Dynamic filesystem trace or acquired app-container/filesystem artifacts: app binary written to device with signing certificate matching manually-trusted enterprise cert NOT IN $EnterpriseCertAllowList$ within $ProfileInstallWindow$]; Protected Configuration via Apple MDM [DeviceInformation / SecurityInfo / ProfileList / restrictions and compliance queries]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0657#AN1746)

## Log sources and channels

- **mobile:ForensicArtifacts** — Dynamic filesystem trace or acquired app-container/filesystem artifacts: app binary written to device with signing certificate matching manually-trusted enterprise cert NOT IN $EnterpriseCertAllowList$ within $ProfileInstallWindow$ · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **iOS:MDM** — DeviceInformation / SecurityInfo / ProfileList / restrictions and compliance queries · [DC0115 - Protected Configuration](../Data%20Components/DC0115%20-%20Protected%20Configuration.md)

## Mutable elements

- **EnterpriseCertAllowList** — Approved enterprise signing certificate fingerprints. Derive from IT certificate management system.
- **ProfileInstallWindow** — Default 3600s between profile/cert trust and app install.
