# AN1730 - Analytic 1730

[Mobile](../../README.md) / [Analytics](README.md)

For Android, detect Compromise Application Executable from documented management, network, or vetting evidence; treat state queries as periodic observations rather than real-time events. Correlate Application Permission via Android Enterprise DPC / Application Vetting [DevicePolicyManager.getPermissionGrantState(); PackageManager manifest/requested-permission review]; Application State via Android Enterprise / EMM [Managed package inventory/status and package metadata]; File Creation via Application Vetting / Forensic Acquisition [Dynamic filesystem trace or acquired app-container/filesystem artifacts: APK, DEX, or native library written to app installation path outside MDM-authorized update mechanism — binary replacement is the persistence artifact]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0649#AN1730)

**Platforms**  [Android](../../Platforms/Android.md)

## Log sources and channels

- **android:DevicePolicyManager** — DevicePolicyManager.getPermissionGrantState(); PackageManager manifest/requested-permission review · [DC0114 - Application Permission](../Data%20Components/DC0114%20-%20Application%20Permission.md)
- **android:EMM** — Managed package inventory/status and package metadata · [DC0123 - Application State](../Data%20Components/DC0123%20-%20Application%20State.md)
- **mobile:ForensicArtifacts** — Dynamic filesystem trace or acquired app-container/filesystem artifacts: APK, DEX, or native library written to app installation path outside MDM-authorized update mechanism — binary replacement is the persistence artifact · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **mobile:DynamicAnalysis** — Dynamic API/runtime trace: App is replaced or reinstalled · [DC0021 - OS API Execution](../Data%20Components/DC0021%20-%20OS%20API%20Execution.md)

## Mutable elements

- **TrustedSignerBaseline** — Per-app expected signing certificate and signer lineage. Derive from MDM app deployment records and Play Store signing identity. Any signer change = compromise indicator.
- **ApkHashBaseline** — Per-version APK hash (SHA-256 of base APK) from trusted distribution. Derive from MDM app deployment artifacts or Google Play API. FORENSIC: compare extracted /data/app/<pkg>/base.apk hash against baseline.
- **PostModificationWindow** — Default 86400s behavioral observation window post-modification.
