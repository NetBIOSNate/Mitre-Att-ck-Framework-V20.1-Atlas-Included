# AN1786 - Analytic 1786

[Mobile](../../README.md) / [Analytics](README.md)

For Android, detect Protected User Data by correlating analyst-visible device/network evidence and management state; use streaming or batched telemetry only where the documented collector is deployed. Correlate API Calls via Application Vetting / Instrumented Dynamic Analysis [Dynamic API/runtime trace: ContentResolver.query() to sensitive provider URI (contacts, calendar, call_log, sms) with query_count > $ContentQueryThreshold$ by app NOT IN $ApprovedDataApps$]; Network Traffic Flow via Android Enterprise Network Logging / Enterprise VPN [DevicePolicyManager.retrieveNetworkLogs(): DnsEvent / ConnectEvent; VPN flow metadata]; Permissions Request via Android Enterprise DPC / Application Vetting [DevicePolicyManager.getPermissionGrantState(); PackageManager manifest/requested-permission review]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0681#AN1786)

**Platforms**  [Android](../../Platforms/Android.md)

## Log sources and channels

- **mobile:DynamicAnalysis** — Dynamic API/runtime trace: ContentResolver.query() to sensitive provider URI (contacts, calendar, call_log, sms) with query_count > $ContentQueryThreshold$ by app NOT IN $ApprovedDataApps$ · [DC0112 - API Calls](../Data%20Components/DC0112%20-%20API%20Calls.md)
- **android:EnterpriseNetworkLog** — DevicePolicyManager.retrieveNetworkLogs(): DnsEvent / ConnectEvent; VPN flow metadata · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)
- **android:DevicePolicyManager** — DevicePolicyManager.getPermissionGrantState(); PackageManager manifest/requested-permission review · [DC0116 - Permissions Request](../Data%20Components/DC0116%20-%20Permissions%20Request.md)

## Mutable elements

- **ApprovedDataApps** — Per-data-type approved apps: calendar sync, dialer, SMS default, CRM apps. Derive from MDM catalog.
- **ContentQueryThreshold** — Varies by data type: Contacts=50, Calendar=30, CallLog=10, SMS=20 queries/2min. Derive from per-app baseline.
- **UplinkThreshold** — Default 100KB. Adjust per data-type expected size.
- **AppCDNList** — Per-app CDN. Derive by measurement.
- **ExfilWindow** — Default 120s.
