# AN1843 - Analytic 1843

[Mobile](../../README.md) / [Analytics](README.md)

For Android, detect Masquerading from documented management, network, or vetting evidence; treat state queries as periodic observations rather than real-time events. Correlate Application Permission via Android Enterprise DPC / Application Vetting [DevicePolicyManager.getPermissionGrantState(); PackageManager manifest/requested-permission review]; File Creation via Application Vetting / Forensic Acquisition [Dynamic filesystem trace or acquired app-container/filesystem artifacts: app binary written to device storage as part of install — confirms impersonating app is being persisted]; File Metadata via Application Vetting / Forensic Acquisition [Dynamic filesystem trace or acquired app-container/filesystem artifacts: installed app package_name Levenshtein distance <= $NameDistanceThreshold$ to entry in $KnownAppCatalog$]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0715#AN1843)

## Mutable elements

- **NameDistanceThreshold** — Default Levenshtein distance 2. Tightening: 1 — only single-char variants. Loosening: 3 — more coverage, more FP.
- **KnownAppCatalog** — MDM-approved catalog plus Play Store reference catalog with cert fingerprints. Update with each new enterprise app deployment.
- **IconHashThreshold** — Default perceptual hash distance < 10. Derive from baseline icon hash comparison.
- **MDMApprovedCatalog** — MDM-managed app list.
