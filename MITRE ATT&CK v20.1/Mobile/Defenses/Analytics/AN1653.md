# AN1653 - Analytic 1653

[Mobile](../../README.md) / [Analytics](README.md)

For Android, detect Compromise Hardware Supply Chain by correlating analyst-visible device/network evidence and management state; use streaming or batched telemetry only where the documented collector is deployed. Correlate Application Permission via Android Enterprise DPC / Application Vetting [DevicePolicyManager.getPermissionGrantState(); PackageManager manifest/requested-permission review]; Application State via Android Enterprise / EMM [Managed package inventory/status and package metadata]; Network Traffic Content via Enterprise Secure Web Gateway / Proxy [DNS/HTTP(S) inspection or proxy transaction metadata where enterprise decryption/inspection is deployed]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0604#AN1653)

**Platforms**  [Android](../../Platforms/Android.md)

## Log sources and channels

- **android:DevicePolicyManager** — DevicePolicyManager.getPermissionGrantState(); PackageManager manifest/requested-permission review · [DC0114 - Application Permission](../Data%20Components/DC0114%20-%20Application%20Permission.md)
- **android:EMM** — Managed package inventory/status and package metadata · [DC0123 - Application State](../Data%20Components/DC0123%20-%20Application%20State.md)
- **webproxy:applog** — DNS/HTTP(S) inspection or proxy transaction metadata where enterprise decryption/inspection is deployed · [DC0085 - Network Traffic Content](../Data%20Components/DC0085%20-%20Network%20Traffic%20Content.md)
- **mobile:DynamicAnalysis** — Dynamic API/runtime trace: Protected resource use, privileged API invocation, or telephony/accessibility/overlay access occurs from system-app context while device is locked or before normal setup completion · [DC0021 - OS API Execution](../Data%20Components/DC0021%20-%20OS%20API%20Execution.md)

## Mutable elements

- **TimeWindow** — Correlation window between enrollment/posture anomaly, privileged capability use, and network egress.
- **AllowedOEMComponents** — Approved system identities, preload packages, and OEM services differ by model and fleet.
- **AllowedDestinations** — OEM update, activation, MDM, and enterprise service destinations vary by environment.
- **ForegroundStateRequired** — Some protected resource access may be legitimate only when the app is foregrounded.
- **RecentUserInteractionWindow** — Defines how close resource access must be to user interaction to be considered expected.
- **EnrollmentGracePeriod** — Initial setup/update behavior may generate benign network or configuration drift for a short period.
- **UplinkBytesThreshold** — Size threshold for suspicious outbound transfer from a device in abnormal posture.
- **ApprovedImageBaseline** — Known-good build fingerprint, patch, boot state, and baseband combinations vary by device fleet.
