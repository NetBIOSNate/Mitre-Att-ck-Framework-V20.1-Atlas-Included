# AN1802 - Analytic 1802

[Mobile](../../README.md) / [Analytics](README.md)

For Android, detect Replication Through Removable Media by correlating analyst-visible device/network evidence and management state; use streaming or batched telemetry only where the documented collector is deployed. Correlate Application Permission via Android Enterprise DPC / Application Vetting [DevicePolicyManager.getPermissionGrantState(); PackageManager manifest/requested-permission review]; File Creation via Application Vetting / Forensic Acquisition [Dynamic filesystem trace or acquired app-container/filesystem artifacts: File with binary signature (.apk, .dex, .so, .sh) written to app storage or /data/local/tmp/ from USB-mounted path or external storage within $USBInstallWindow$]; Process Creation via Application Vetting / Managed Device Telemetry [Application installed with install_source=adb or install_source=sideload from USB-connected host within $USBInstallWindow$ of USB mode change]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0691#AN1802)

**Platforms**  [Android](../../Platforms/Android.md)

## Log sources and channels

- **android:DevicePolicyManager** — DevicePolicyManager.getPermissionGrantState(); PackageManager manifest/requested-permission review · [DC0114 - Application Permission](../Data%20Components/DC0114%20-%20Application%20Permission.md)
- **mobile:ForensicArtifacts** — Dynamic filesystem trace or acquired app-container/filesystem artifacts: File with binary signature (.apk, .dex, .so, .sh) written to app storage or /data/local/tmp/ from USB-mounted path or external storage within $USBInstallWindow$ · [DC0039 - File Creation](../Data%20Components/DC0039%20-%20File%20Creation.md)
- **mobile:DynamicAnalysis** — Application installed with install_source=adb or install_source=sideload from USB-connected host within $USBInstallWindow$ of USB mode change · [DC0032 - Process Creation](../Data%20Components/DC0032%20-%20Process%20Creation.md)
- **android:DevicePolicyManager** — DevicePolicyManager policy/compliance/security-state queries and SecurityLog events where supported · [DC0118 - System Settings](../Data%20Components/DC0118%20-%20System%20Settings.md)

## Mutable elements

- **USBInstallWindow** — Default 300s between USB mode change and install or file delivery event. Tightening: 60s — synchronous USB delivery.
- **AuthorizedDeveloperDevices** — Device serial numbers authorized for developer mode (test/dev fleet only). Derive from IT device management. Production devices should have empty list.
