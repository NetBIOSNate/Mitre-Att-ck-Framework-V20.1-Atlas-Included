# AN1784 - Analytic 1784

[Mobile](../../README.md) / [Analytics](README.md)

For Android, detect Security Software Discovery by correlating analyst-visible device/network evidence and management state; use streaming or batched telemetry only where the documented collector is deployed. Correlate API Calls via Application Vetting / Instrumented Dynamic Analysis [Dynamic API/runtime trace: PackageManager.getPackageInfo() called for package names IN $SecurityToolPackageList$ by app NOT IN $AppEnumAllowList$]; Application State via Android Enterprise / EMM [Managed package inventory/status and package metadata]; Network Connection Creation via Android Enterprise Network Logging / Enterprise VPN [DevicePolicyManager.retrieveNetworkLogs(): DnsEvent / ConnectEvent; VPN flow metadata]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0680#AN1784)

## Mutable elements

- **SecurityToolPackageList** — Known MDM agent, MTD/EDR, AV package names. Maintain from vendor documentation. Update when new tools deployed.
- **AppEnumAllowList** — MDM agent, system diagnostic only.
- **GuardrailWindow** — Default 300s — time window within which C2 connection is expected post-check if guardrail not triggered.
