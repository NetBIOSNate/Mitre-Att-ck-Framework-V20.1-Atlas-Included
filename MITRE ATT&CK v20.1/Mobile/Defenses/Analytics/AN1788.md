# AN1788 - Analytic 1788

[Mobile](../../README.md) / [Analytics](README.md)

For Android, detect File and Directory Discovery by correlating analyst-visible device/network evidence and management state; use streaming or batched telemetry only where the documented collector is deployed. Correlate Application State via Android Enterprise / EMM [Managed package inventory/status and package metadata]; File Access via Application Vetting / Forensic Acquisition [Dynamic filesystem trace or acquired app-container/filesystem artifacts: opendir() or File.listFiles() on path IN $ExternalStoragePaths$ called > $FileEnumThreshold$ times within $EnumWindow$ by app NOT IN $FileEnumAllowList$]; Network Traffic Flow via Android Enterprise Network Logging / Enterprise VPN [DevicePolicyManager.retrieveNetworkLogs(): DnsEvent / ConnectEvent; VPN flow metadata]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0682#AN1788)

**Platforms**  [Android](../../Platforms/Android.md)

## Log sources and channels

- **android:EMM** — Managed package inventory/status and package metadata · [DC0123 - Application State](../Data%20Components/DC0123%20-%20Application%20State.md)
- **mobile:ForensicArtifacts** — Dynamic filesystem trace or acquired app-container/filesystem artifacts: opendir() or File.listFiles() on path IN $ExternalStoragePaths$ called > $FileEnumThreshold$ times within $EnumWindow$ by app NOT IN $FileEnumAllowList$ · [DC0055 - File Access](../Data%20Components/DC0055%20-%20File%20Access.md)
- **android:EnterpriseNetworkLog** — DevicePolicyManager.retrieveNetworkLogs(): DnsEvent / ConnectEvent; VPN flow metadata · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **ExternalStoragePaths** — /sdcard/, /storage/emulated/0/, /mnt/sdcard/. Vary by device.
- **FileEnumThreshold** — Default 100 directory operations within window. Derive from baseline file manager behavior.
- **EnumWindow** — Default 60s.
- **FileEnumAllowList** — Approved file managers, media apps, MDM agent.
- **UplinkThreshold** — Default 500KB.
- **AppCDNList** — Per-app CDN. Derive by measurement.
- **ExfilWindow** — Default 120s.
