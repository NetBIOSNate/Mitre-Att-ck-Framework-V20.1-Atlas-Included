# AN1820 - Analytic 1820

[Mobile](../../README.md) / [Analytics](README.md)

For Android, detect Remote Device Management Services by correlating analyst-visible device/network evidence and management state; use streaming or batched telemetry only where the documented collector is deployed. Correlate Cloud Service Enumeration via Application Vetting / Cloud Service Audit [Instrumented app API trace and corresponding cloud-service audit/API telemetry]; Protected Configuration via Android Enterprise DPC [DevicePolicyManager policy/compliance/security-state queries and SecurityLog events where supported]; User Account Authentication via Application Vetting / Identity Provider Telemetry [App authentication flow instrumentation or IdP sign-in/audit events]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0702#AN1820)

**Platforms**  [Android](../../Platforms/Android.md)

## Log sources and channels

- **cloud:AuditLog** — Instrumented app API trace and corresponding cloud-service audit/API telemetry · [DC0083 - Cloud Service Enumeration](../Data%20Components/DC0083%20-%20Cloud%20Service%20Enumeration.md)
- **android:DevicePolicyManager** — DevicePolicyManager policy/compliance/security-state queries and SecurityLog events where supported · [DC0115 - Protected Configuration](../Data%20Components/DC0115%20-%20Protected%20Configuration.md)
- **idp:AuditLog** — App authentication flow instrumentation or IdP sign-in/audit events · [DC0002 - User Account Authentication](../Data%20Components/DC0002%20-%20User%20Account%20Authentication.md)

## Mutable elements

- **AdminAllowedIPs** — IT office IPs, VPN egress IPs, known admin workstation IPs. Derive from IT network documentation.
- **LocationQueryThreshold** — Default 10 device queries per session. Single queries are normal; bulk is anomalous.
- **LocationQueryWindow** — Default 300s.
- **AuthCorrelationWindow** — Default 3600s between auth event and location query.
