# AN1705 - Analytic 1705

[Mobile](../../README.md) / [Analytics](README.md)

For iOS, detect Credentials from Password Store by correlating analyst-visible device/network evidence and management state; use streaming or batched telemetry only where the documented collector is deployed. Correlate Application State via Apple MDM [InstalledApplicationList / ManagedApplicationList]; Host Status via Apple MDM [DeviceInformation / SecurityInfo / ProfileList / restrictions and compliance queries]; Network Traffic Flow via Apple Network Extension / Enterprise VPN [NEFilterFlow / per-app VPN / secure-web-gateway flow metadata]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0633#AN1705)

**Platforms**  [iOS](../../Platforms/iOS.md)

## Log sources and channels

- **iOS:MDM** — InstalledApplicationList / ManagedApplicationList · [DC0123 - Application State](../Data%20Components/DC0123%20-%20Application%20State.md)
- **iOS:MDM** — DeviceInformation / SecurityInfo / ProfileList / restrictions and compliance queries · [DC0018 - Host Status](../Data%20Components/DC0018%20-%20Host%20Status.md)
- **iOS:NetworkExtension** — NEFilterFlow / per-app VPN / secure-web-gateway flow metadata · [DC0078 - Network Traffic Flow](../Data%20Components/DC0078%20-%20Network%20Traffic%20Flow.md)

## Mutable elements

- **CredentialStoreAppList** — Banking, enterprise SSO, password manager, email app bundle IDs.
- **CredentialStoreAppCount** — Default 2 — single app might not justify targeted Keychain dump.
- **CredentialDumpMin** — Default 10KB.
- **CredentialDumpMax** — Default 500KB — cap to exclude media exfil.
- **AppCDNList** — Per-device CDN baseline.
- **ExfilWindow** — Default 300s.
