# AN1736 - Analytic 1736

[Mobile](../../README.md) / [Analytics](README.md)

For iOS, detect Application Versioning by correlating analyst-visible device/network evidence and management state; use streaming or batched telemetry only where the documented collector is deployed. Correlate File Modification via Application Vetting / Forensic Acquisition [Dynamic filesystem trace or acquired app-container/filesystem artifacts: app version change in MDM inventory for bundle_id]; Network Connection Creation via Apple Network Extension / Enterprise VPN [NEFilterFlow / per-app VPN / secure-web-gateway flow metadata]; Permissions Request via Application Vetting [Code-signing entitlements and Info.plist privacy usage-description keys]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0652#AN1736)

## Mutable elements

- **PermissionDeltaAllowList** — Expected privacy permission additions per planned update. Derived from IT app review.
- **AppBaselineDomains** — Pre-update domain baseline anchored to prior version.
- **PostUpdateWindow** — Default 86400s. Tightening: 3600s.
