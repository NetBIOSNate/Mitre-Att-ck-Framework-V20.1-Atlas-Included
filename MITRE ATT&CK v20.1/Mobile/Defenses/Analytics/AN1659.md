# AN1659 - Analytic 1659

[Mobile](../../README.md) / [Analytics](README.md)

For Android, detect Generate Traffic from Victim by correlating analyst-visible device/network evidence and management state; use streaming or batched telemetry only where the documented collector is deployed. Correlate API Calls via Application Vetting / Instrumented Dynamic Analysis [Dynamic API/runtime trace: SmsManager.sendTextMessage() called by app NOT IN $ApprovedMessagingApps$]; Network Connection Creation via Android Enterprise Network Logging / Enterprise VPN [DevicePolicyManager.retrieveNetworkLogs(): DnsEvent / ConnectEvent; VPN flow metadata]; Permissions Request via Android Enterprise DPC / Application Vetting [DevicePolicyManager.getPermissionGrantState(); PackageManager manifest/requested-permission review]. Alert on a sequence or state change inconsistent with the device/app baseline, approved management policy, or expected user workflow; do not infer unobserved API calls, file/process activity, or payload content from management state alone.

[MITRE ATT&CK record](https://attack.mitre.org/detectionstrategies/DET0608#AN1659)

## Mutable elements

- **ApprovedMessagingApps** — Default SMS, approved messaging apps. Minimal.
- **PremiumNumberPattern** — Country-specific premium short code ranges. Derive from carrier/regulatory database. Update per regulatory changes.
- **SMSRateThreshold** — Default 5 premium SMS within window. Tightening: 2.
- **SMSWindow** — Default 60s.
