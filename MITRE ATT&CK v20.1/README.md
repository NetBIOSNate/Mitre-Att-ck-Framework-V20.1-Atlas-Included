## Finding a technique

Open a domain and its Tactics folder, then follow the numbered matrix columns. Each technique has a folder named for its ATT&CK ID and title. Sub-technique folders sit inside their parent technique. Open README.md in any of these folders for the official description and related records.

A technique appears under each tactic that MITRE assigns to it. The figures above count each ID once per domain. To find an entry directly, search this folder for its ATT&CK ID, including the decimal suffix for a sub-technique.

## Related records

Each domain has a Platforms index. Defenses contains mitigations, detection strategies, analytics and data components. The ICS defenses folder also includes industrial assets. Threat Intelligence covers groups, campaigns and software. Where MITRE supplies relationships, local links connect these records to techniques and procedure examples.
